# MuSiCNet: A Gradual Coarse-to-Fine Framework for Irregularly Sampled Multivariate Time Series Analysis

**핵심 평가:** MuSiCNet의 가장 중요한 기여는 불규칙 시계열을 여러 시간 해상도로 표현하고, 해상도 사이의 일관성을 학습에 활용한 설계입니다.  
P12 분류와 PAM 활동 분류에서 좋은 결과를 보고하지만, **외부 환경에 대한 일반화 성능이 검증된 모델로 보기는 어렵습니다.**  
특히 보간 결과의 단위, 주파수 거리의 가중치 변환, 일부 데이터셋 설명은 재현 전에 확인해야 합니다.

아래의 **p.는 첨부 PDF의 물리적 페이지 번호**이며, 전체 13쪽을 기준으로 합니다. 원문 결과, 분석자의 판단, 후속 실험 제안은 각각 **[저자 보고]**, **[해석]**, **[제안]**으로 구분합니다. 외부 연구 비교는 **2026년 10월 29일까지 확인한 원 논문·공식 학회 자료**를 사용하며, MuSiCNet 자체의 실험 결과와 섞지 않습니다.

## 1. Executive summary — 10문장

1. MuSiCNet은 관측 간격이 일정하지 않고 변수마다 관측 시점도 다른 다변량 시계열에서, 분류·보간·예측에 사용할 특징 표현을 학습하는 프레임워크입니다. **[저자 보고: pp.1–3]**
2. 저자는 불규칙성이 관측 해상도에 따라 상대적으로 달라진다는 관점에서, 원 시계열을 거친 해상도부터 세밀한 해상도까지 계층적으로 구성합니다. **[저자 보고: pp.1–2, Figure 1]**
3. 각 해상도에서는 CorrNet이 관측 시각에 따른 정보 집계와 주파수 패턴에 따른 변수 간 정보 결합을 수행합니다. **[저자 보고: pp.3–4, Figure 2, Eq.1–2]**
4. 인접한 해상도에서는 같은 표본의 특징 표현과 복원 결과가 일관되도록 두 종류의 학습 제약을 적용합니다. **[저자 보고: pp.4–5, Eq.5–6]**
5. 분류 실험에서 MuSiCNet은 P12와 PAM의 모든 보고 지표에서 비교 모델 중 가장 높은 평균값을 기록합니다. **[저자 보고: p.6, Table 1]**
6. P19 분류에서는 ViTST보다 성능이 낮으므로 모든 분류 데이터셋에서 최고 성능을 달성했다고 말할 수는 없습니다. **[표에 근거한 해석: p.6, Table 1]**
7. 보간, 즉 관측 기간 안에서 제공되지 않은 값을 추정하는 실험에서는 모든 조건에서 가장 낮은 표기 수치를 보고하지만, 비교 모델의 원 출처와 대조하면 단위 및 평가 대상 확인이 필요합니다. **[저자 보고·교차검증: p.6, Table 2; mTAN p.8, Table 1]** [arxiv.org](https://arxiv.org/pdf/2101.10318?utm_source=chatgpt.com)
8. 미래 예측에서는 USHCN에서 가장 낮은 평균 오차를 보이지만, MIMIC-III와 Physionet12에서는 GraFITi보다 오차가 큽니다. **[저자 보고: p.6, Table 3]**
9. 5회 반복 실험의 작은 표준편차는 실행 안정성에 관한 근거이며, 새로운 병원·사용자·관측 방식으로 옮겼을 때의 일반화를 입증하지는 않습니다. **[해석: p.5 실험 설명 및 일반화 주장]**
10. 후속 연구에서는 다중 해상도와 일관성 학습의 효과를 작은 구성으로 먼저 검증하고, 주파수 관계 계산의 미기재 사항과 데이터 분할 문제를 해결하는 것이 우선입니다. **[제안: Eq.1–6, Tables 4–6에 근거]**

## 2. 연구 배경, 해결하려는 문제, 목적과 필요성

### 2.1 무엇이 어려운가?

**[저자 보고]** 논문은 불규칙 다변량 시계열의 어려움을 두 가지로 구분합니다. **[pp.1–2]**

| 문제 | 의미 | 이해를 위한 예 |
|---|---|---|
| **변수 내부 불규칙성** | 하나의 변수에서 연속 관측 사이의 시간 간격이 일정하지 않음 | 어떤 생체신호가 일정한 간격 없이 측정됨 |
| **변수 간 불규칙성** | 서로 다른 변수의 관측 시점과 관측 수가 일치하지 않음 | 심박수와 혈액검사가 서로 다른 시점에 기록됨 |

> **용어 풀이 — 불규칙 다변량 시계열, ISMTS:** 여러 변수를 시간에 따라 관측하되, 시간 간격과 변수별 측정 시점이 일정하지 않은 데이터입니다.  
> **비동기성:** 여러 변수가 같은 시점에 함께 관측되지 않는 성질입니다.

일반적인 시계열 모델은 일정한 간격마다 모든 변수가 들어오는 형태를 처리하기 쉽습니다.  
이 때문에 불규칙 데이터를 일정한 시간 격자에 맞추고 빈 곳을 채우는 접근이 사용됩니다.  
저자는 이러한 **선행 보간·결측치 대체가 변수 관계를 왜곡할 수 있다**는 점을 문제로 제시합니다. **[pp.1–2, §1–2.1]**

> **용어 풀이 — 결측치 대체와 보간:** 결측치 대체는 없는 값을 추정해 채우는 일반적인 작업이며, 보간은 관측된 시간 범위 안에서 제공되지 않은 시점의 값을 추정하는 작업입니다.

### 2.2 연구가 제안하는 관점

**[저자 보고]** 관측 해상도를 낮추면 여러 관측을 하나의 시간 구간으로 묶을 수 있어, 변수 간 시점 차이가 완화되고 전체적인 변화가 더 잘 드러납니다. 그러나 이러한 거친 표현에서는 짧고 세밀한 변화가 사라질 수 있습니다. 반대로 원래 해상도에 가까워질수록 세부 정보는 보존되지만 불규칙성이 커져 학습하기 어려워집니다. **[p.2, Figure 1]**

따라서 연구의 목표는 다음 세 가지입니다.

1. **거친 해상도의 전체 추세와 세밀한 해상도의 국소 변화를 함께 학습한다.**
2. **관측 시점이 어긋난 변수 사이에서도 활용할 만한 관계 정보를 추출한다.**
3. **동일한 설계 원리를 분류·보간·예측에 적용한다.**

> **용어 풀이 — 스케일 또는 해상도:** 시간을 얼마나 잘게 나누어 데이터를 표현하는지를 뜻합니다. 거친 스케일은 큰 시간 구간의 변화, 세밀한 스케일은 짧은 시간 간격의 변화를 나타냅니다.  
> **표현학습:** 원자료에서 이후 분석에 유용한 특징 벡터를 학습하는 과정입니다.

### 2.3 목적과 필요성에 대한 평가

**[해석]** 이 연구의 의의는 불규칙성을 하나의 입력 형식 문제로만 처리하지 않고, **여러 해상도에서 서로 보완할 수 있는 학습 문제로 구성했다는 점**입니다.

다만 “기존 방법이 변수 간 관계를 전혀 처리하지 못했다”는 해석은 과도합니다.  
Raindrop 등은 이미 비동기 센서 간 관계를 학습했습니다.  
MuSiCNet의 차별성은 **다중 스케일 일관성 학습과 LSP-DTW 기반 관계 가중을 결합한 구체적인 구성**에서 평가해야 합니다. **[MuSiCNet pp.2–4; Raindrop pp.1–2]** [arxiv.org](https://arxiv.org/pdf/2110.05357?utm_source=chatgpt.com)

### 4.2 실험 절차

**[저자 보고]**

- **분류:** 학습·검증·시험을 80%·10%·10%로 무작위 분할하고, 방법 간 분할 인덱스를 동일하게 사용합니다. **[p.5, §4.1]**
- **보간:** 먼저 80%·20%로 학습·시험을 나눈 뒤 학습 부분의 20%를 검증에 사용합니다; 전체 기준으로 계산하면 64%·16%·20%입니다. **[p.5, §4.2]**
- **예측:** GraFITi의 평가 설정을 따르며, USHCN은 첫 3년, 의료 데이터는 첫 36시간을 관측한 후 각각 다음 3개 시점을 예측합니다. **[p.6, §4.3]**
- 결과는 **5회 독립 시행의 평균과 표준편차**로 보고합니다. **[p.5, §4]**
- MuSiCNet에는 나이·성별 등의 정적 속성을 넣지 않았다고 명시합니다. **[p.11, Appendix D]**

> **용어 풀이 — 정적 속성:** 관측 구간 안에서 시간에 따라 변하는 신호와 달리, 표본 전체에 붙는 특성입니다.  
> **표준편차:** 반복 실험의 결과가 평균 주변에서 얼마나 달라지는지를 나타내는 값이며, 평균의 신뢰구간과는 다릅니다.

주요 구현 설정은 최대 300 epoch, 초기 학습률 $10^{-3}$, 배치 크기 50, 인코더 출력 차원 256, GRU 은닉 차원 50, 스케일별 마스킹 비율 0.1입니다. AdamW를 사용하되 weight decay는 사용하지 않았다고 설명합니다. **[pp.12–13, Appendix E]**

## 5. 제안 방법과 모델 구조 — 수식 중심 설명

### 5.1 전체 구조

본문과 Figure 2에 따른 계산 흐름은 다음과 같습니다. **[pp.3–5, Figure 2]**

1. 원 시계열을 평균 풀링하여 여러 스케일로 구성합니다.
2. 각 스케일의 일부 관측을 가립니다.
3. 공유 CorrNet 인코더로 기준 시점별 표현을 계산합니다.
4. 디코더는 가려진 값을 복원하고, GRU는 스케일별 표현을 같은 차원의 벡터로 요약합니다.
5. 인접 스케일의 복원 결과와 특징 표현에 일관성 손실을 적용합니다.
6. 최종 스케일 표현 또는 복원값을 분류·보간·예측에 사용합니다.

**구조 해석의 경계:** 스케일 간 연결은 주로 **손실함수를 통한 제약**입니다. 거친 스케일의 예측값을 다음 스케일 입력에 직접 섞거나, 추론 중에 잔차를 순차 수정하는 별도 연산은 명확히 기술하지 않습니다. **[Figure 2(a), Eq.5–6, p.11 Algorithm 1]**

> **용어 풀이 — 인코더·디코더:** 인코더는 입력을 특징 표현으로 바꾸고, 디코더는 그 표현으로 관측값을 복원합니다.  
> **손실함수:** 모델의 예측이나 표현이 학습 목표에서 얼마나 벗어났는지 수치화하는 함수입니다.

### 5.2 입력과 공통 기호

논문은 표본 $n$의 변수 $d$를 다음과 같이 나타냅니다. **[p.3, §3.1]**

$$
X_{dn}=(\mathbf{x}_{dn},\mathbf{t}_{dn})
$$

```math
\mathbf{x}_{dn}
=
[x_{1dn},\ldots,x_{T_{dn}dn}],
\qquad
\mathbf{t}_{dn}
=
[t_{1dn},\ldots,t_{T_{dn}dn}].
```

- $n$: 표본 인덱스.
- $d$: 변수 인덱스.
- $T_{dn}$: 해당 표본·변수의 관측 수.
- $\mathbf{x}_{dn}$: 관측값 목록.
- $\mathbf{t}_{dn}$: 각 값의 관측 시각.
- $l=1,\ldots,L$: 스케일 인덱스; 작은 $l$은 거친 스케일, $L$은 가장 세밀한 스케일입니다.
- $\mathbf r^{(l)}$: 기준 시점별 잠재 표현.
- $\mathbf h^{(l)}$: GRU로 요약한 표본 표현.

> **용어 풀이 — 잠재 표현:** 직접 측정된 값 대신 모델 내부에서 학습된 특징입니다.

### 5.3 다중 스케일 구성 — 원문 Eq.(4)

```math
X_{\text{multi}}
=
M^{(l)}\odot
\left(\text{AvgPooling}_{L}(X)\right)
=
\left\{
X_{\text{mask}}^{(1)},\ldots,
X_{\text{mask}}^{(L)}
\right\}.
```

**기호 설명**

- $X$: 원래 시계열.
- $\text{AvgPooling}_{L}$: 여러 시간 해상도의 평균 풀링 결과를 만드는 연산.
- $M^{(l)}$: 스케일 $l$의 마스크.
- $\odot$: 원소별 곱.
- $X_{\text{mask}}^{(l)}$: 일부 관측이 가려진 스케일 $l$의 입력.

**[저자 보고]** 최초 창 크기는 전체 길이의 $1/4$이며, 이후 창을 절반씩 줄여 해상도를 높입니다. P12의 예시는 4, 8, 16, 32, 64, 원래 길이의 여섯 스케일입니다. **[p.4, Eq.4; p.5; p.13, Appendix E.1]**

**[해석]** 이 식은 여러 스케일을 만드는 절차를 압축한 표기입니다. 여러 스케일의 집합에 하나의 $M^{(l)}$를 곱하는 형태여서, 엄밀한 텐서 연산을 완전히 정의하지는 않습니다. 빈 풀링 구간의 처리도 자세히 설명하지 않습니다.

> **용어 풀이 — 평균 풀링:** 한 시간 구간의 여러 값을 평균으로 요약하는 연산입니다.  
> **마스킹:** 이미 관측된 값 중 일부를 학습 중에 가려, 모델이 이를 복원하도록 만드는 방법입니다.

### 5.4 연속시간 임베딩 — 원문 Eq.(7)

```math
\phi_h(t)[i]
=
\begin{cases}
\omega_{0h}t+\alpha_{0h}, & i=0,\\
\sin(\omega_{ih}t+\alpha_{ih}), & 0 < i < d_r.
\end{cases}
```

**기호 설명**

- $t$: 관측 시각 또는 표현을 계산할 기준 시각.
- $h$: $H$개 시간 임베딩 함수 중 하나의 인덱스.
- $i$: 임베딩 벡터 성분의 인덱스.
- $d_r$: 임베딩 차원.
- $\omega_{ih},\alpha_{ih}$: 학습 가능한 매개변수.

**[저자 보고]** 선형 성분은 비주기적인 시간 변화를, 사인 성분은 주기적인 패턴을 표현하는 데 사용됩니다. **[p.11, Appendix B]**

> **용어 풀이 — 임베딩:** 시간처럼 직접 신경망에서 다루기 어려운 정보를 숫자 벡터로 바꾸는 표현입니다. 여기서 함수 인덱스 $h$는 GRU 출력 $\mathbf h^{(l)}$와 다른 기호입니다.

### 5.5 CorrNet의 시간·변수 정보 결합 — 원문 Eq.(1)

```math
\text{CorrE}(Q_T,K_T,X)
=
A_T X C_T,
\qquad
A_T
=
\text{softmax}
\left(
\frac{Q_TK_T}{d_r}
\right).
```

**기호 설명**

- $Q_T$: 기준 시점에서 만든 query.
- $K_T$: 실제 관측 시각에서 만든 key.
- $A_T$: 시간 방향의 attention 가중치.
- $X$: 관측값.
- $C_T$: 변수 간 관계를 반영하는 행렬.
- $d_r$: 시간 임베딩 차원.

**[저자 보고]** 미리 정한 기준 시점 $\tau=[\tau_1,\ldots,\tau_K]$에서 정보를 집계하여, 관측 수가 서로 다른 입력을 신경망이 처리할 수 있는 표현으로 바꿉니다. **[p.4, §3.2]**

**[해석]** $A_TX$는 시간 방향의 관측 정보를 모으는 부분이고, $C_T$는 다른 변수의 정보를 얼마나 결합할지 조절하는 부분으로 읽을 수 있습니다.

**수식 재현 시 주의:** 위 식은 원문 표기 그대로입니다. 원문에는 $K_T^\top$나 $\sqrt{d_r}$가 없습니다. 행렬 차원이나 전치의 처리도 충분히 정의하지 않으므로, 통상적인 Transformer 식으로 임의 수정해서는 안 됩니다.

> **용어 풀이 — attention:** 여러 입력 중 어떤 정보에 더 큰 비중을 둘지 계산하는 방식입니다.  
> **Query·key:** 정보를 요청하는 기준과, 입력을 비교하기 위한 기준입니다.  
> **Softmax:** 여러 점수를 합이 1인 양의 가중치로 바꾸는 함수입니다.  
> **기준 시점:** 실제 관측 시각과 별개로, 모델이 표현을 계산하도록 미리 정한 시각입니다.

### 5.6 LSP-DTW를 이용한 변수 관계 — 원문 Eq.(2)

```math
c_{d_i d_j}
=
\text{DTW}
\left(
\text{LSP}(X_{d_i}),
\text{LSP}(X_{d_j})
\right)
```

```math
=
\min_{\pi}
\sum_{(m,n)\in\pi}
\left(
\text{LSP}(X_{d_i})[m]
-
\text{LSP}(X_{d_j})[n]
\right)^2.
```

**기호 설명**

- $X_{d_i},X_{d_j}$: 두 변수의 불규칙 시계열.
- $\text{LSP}$: Lomb–Scargle periodogram.
- $\text{DTW}$: 두 시퀀스의 대응 위치를 조정하며 거리를 구하는 연산.
- $m,n$: 두 주파수 표현의 원소 인덱스.
- $\pi$: DTW 정렬 경로.
- $c_{d_i d_j}$: 변수쌍에 대해 계산한 값.
- $C_T$: 변수쌍의 값을 모은 행렬.

**[저자 보고]** 먼저 불규칙 관측값을 LSP로 주파수 영역에 표현하고, 그 결과 사이에 DTW를 적용합니다.  
이 과정은 관계를 계산하기 전에 결측값을 보간할 필요가 없다는 점을 강조합니다. **[p.4, §3.2; Figure 2(c)]**

> **용어 풀이 — LSP:** 관측 간격이 일정하지 않은 데이터에서도 어떤 주기가 강하게 나타나는지 계산하는 방법입니다.  
> **주파수 스펙트럼:** 느린 변화부터 빠른 변화까지, 각 주기 성분의 강도를 나타낸 표현입니다.  
> **DTW:** 두 시퀀스의 대응 위치를 늘리거나 줄여 가장 잘 맞는 정렬을 찾는 방법입니다. 이 논문에서는 원래 시간축의 값이 아닌 **주파수 표현**에 적용합니다.

**가장 중요한 방법론상 미기재 사항:** Eq.(2)는 **작을수록 유사한 거리**입니다. 그런데 본문은 관련성이 큰 변수에 더 높은 가중치를 준다고 설명합니다. 거리에서 유사도 가중치로 변환하는 과정과 정규화가 제시되어 있지 않습니다.

따라서 $\exp(-c)$ 등의 변환을 MuSiCNet의 실제 방법인 것처럼 추가할 수 없습니다.  
LSP의 주파수 범위·격자·정규화 설정도 원문에 충분히 제시되지 않습니다. **[p.4, Eq.1–2; 부록]**

### 5.7 스케일 내부 복원 — 원문 Eq.(3)

```math
\ell_{\text{recon}}^{(l)}
=
\sum_i
\left\|
M^{(l)}
\odot
\left(
(\widehat X_{\text{reco}}^{(l)})_i
-
X_i^{(l)}
\right)
\right\|_2^2.
```

**기호 설명**

- $\widehat X_{\text{reco}}^{(l)}$: 디코더의 복원값.
- $X^{(l)}$: 해당 스케일의 원래 값.
- $M^{(l)}$: 손실을 계산할 위치를 선택하는 마스크.
- $i$: 합산 대상 인덱스.
- $\|\cdot\|_2^2$: 차이를 제곱하여 더하는 연산.

**[저자 보고]** CorrD 디코더는 상관행렬을 생략한 간소화 CorrE이며, 입력의 관측 시각을 기준으로 값을 복원합니다.  
모든 스케일이 하나의 인코더를 공유합니다. **[p.4, §3.2]**

**주의:** 원문은 이를 MSE라고 부르지만 식에는 평균을 내는 분모가 없습니다.  
또한 입력을 가리는 마스크와 복원 손실을 선택하는 마스크를 같은 기호로 사용하여, 0과 1의 정확한 의미가 불명확합니다.

> **용어 풀이 — MSE:** 예측값과 실제값의 차이를 제곱한 뒤 평균한 값입니다. 작은 값이 더 좋은 예측을 의미하지만, 데이터의 단위와 정규화 방식에 영향을 받습니다.

### 5.8 인접 스케일의 복원 일관성 — 원문 Eq.(5)

```math
\ell_{\text{adj}}^{(l)}
=
\sum_i
\left\|
\left(
\text{AvgPooling}_{l}
(\widehat X_{\text{reco}}^{(l)})
\right)_i
-
(\widehat X_{\text{reco}}^{(l-1)})_i
\right\|_2^2.
```

**기호 설명**

- $\text{AvgPooling}_{l}$: 세밀한 복원 결과를 바로 아래의 거친 해상도로 맞추는 풀링.
- $\widehat X_{\text{reco}}^{(l-1)}$: 거친 스케일의 복원값.
- $l\ge2$: 인접 스케일을 비교할 수 있는 범위.

**[저자 보고]** 세밀한 복원 결과를 평균했을 때 거친 스케일의 복원 결과와 일치하도록 학습합니다. **[p.4, §3.3]**

**[해석]** 해상도가 달라져도 전체 추세에 대한 예측이 모순되지 않도록 하는 제약입니다.  
거친 복원값을 정답으로 고정하거나, 한쪽의 학습 신호를 차단하는 구조는 명시되어 있지 않습니다.

> **용어 풀이 — 일관성 제약:** 같은 데이터를 서로 다른 방식으로 표현해도 모델의 판단이 서로 맞도록 요구하는 학습 조건입니다.

### 5.9 인접 스케일의 대조학습 — 원문 Eq.(6)

먼저 GRU로 스케일마다 길이가 다른 표현을 같은 차원으로 요약합니다.

```math
\mathbf h^{(l)}
=
\text{GRU}(\mathbf r^{(l)}).
```

그 후 다음 손실을 사용합니다.

```math
\ell_{\text{cons}}^{(l)}
=
-\sum_i
\log
\frac{
\exp\left(
\mathbf h_i^{(l)}
\cdot
\mathbf h_i^{(l-1)}
\right)
}{
\sum_{j=1}^{B}
\left[
\exp\left(
\mathbf h_i^{(l)}
\cdot
\mathbf h_j^{(l-1)}
\right)
+
\mathbb I_{[i\ne j]}
\exp\left(
\mathbf h_i^{(l)}
\cdot
\mathbf h_j^{(l)}
\right)
\right]
}.
```

**기호 설명**

- $B$: 배치 크기.
- $\mathbf h_i^{(l)}$: 표본 $i$의 스케일 $l$ 표현.
- $\cdot$: 두 벡터의 내적.
- $\mathbb I_{[i\ne j]}$: $i\ne j$이면 1, 그렇지 않으면 0인 지시함수.
- 분자: 같은 표본의 인접 스케일 표현 사이의 유사성.
- 분모: 같은 표본과 다른 표본을 함께 고려한 비교 기준.

**[저자 보고]** 같은 표본의 인접 스케일 표현은 가깝게, 배치 안의 다른 표본 표현은 멀어지게 학습합니다. **[p.5, Eq.6]**

> **용어 풀이 — GRU:** 이전 정보를 얼마나 유지하거나 갱신할지 조절하는 순환 신경망입니다.  
> **대조학습:** 같은 대상의 다른 표현은 가깝게, 다른 대상의 표현은 멀게 만드는 학습 방법입니다. 여기서 ‘같은 대상’은 같은 표본의 서로 다른 스케일입니다.

원문 식에는 유사도를 조절하는 temperature나 코사인 정규화가 없습니다. 그러한 설정을 사용했다고 가정하면 안 됩니다.

### 5.10 전체 학습 목적과 과제별 출력 — Eq.(8)–(11)

부록 Eq.(8)은 다음과 같이 인쇄되어 있습니다.

```math
\mathcal L
=
\sum_{l=1}^{L}
\ell_{\text{recon}}^{(l)}
+
\lambda_1\ell_{\text{adj}}^{(l)}
+
\lambda_2\ell_{\text{cons}}^{(l)}.
```

다만 **Algorithm 1은 스케일별 손실을 평균하고 과제 손실을 추가**합니다. 알고리즘 17행을 합 기호로 풀어 쓰면 분류의 경우 다음과 같습니다.

$$
\begin{aligned}
\mathcal L_{\text{overall}}
={}&
\frac1L\sum_{l=1}^{L}\ell_{\text{recon}}^{(l)}
+
\frac{\lambda_1}{L-1}
\sum_{l=2}^{L}\ell_{\text{adj}}^{(l)}\\
&+
\frac{\lambda_2}{L-1}
\sum_{l=2}^{L}\ell_{\text{cons}}^{(l)}
+
\lambda_3\mathcal L_{\text{cls}}.
\end{aligned}
$$

- $\lambda_1,\lambda_2,\lambda_3$: 각 손실의 중요도를 조절하는 가중치.
- 첫 세 항: 복원, 인접 스케일 복원 일관성, 인접 스케일 대조학습.
- 마지막 항: 과제에 맞춘 학습 목적.

**이 두 식은 표기가 완전히 같지 않으며, 위의 두 번째 식은 Algorithm 1을 풀어 쓴 것입니다.** **[p.11, Eq.8, Algorithm 1]**

#### 분류 — Eq.(9)

```math
\mathcal L_{\text{cls}}
=
\frac1C
\sum_{c=1}^{C}
\frac1{n_c}
\sum_{i=1}^{n_c}
\ell_{\text{CE}}
\left(
\text{CLS}(\mathbf h_i^{(L)}),y_i
\right).
```

- $C$: 클래스 수.
- $n_c$: 클래스 $c$의 표본 수.
- $\text{CLS}$: 최종 표현에 적용하는 분류 모듈.
- $y_i$: 실제 라벨.
- $\ell_{\text{CE}}$: 교차엔트로피 손실.

클래스별 평균을 구한 뒤 다시 평균하는 형태여서, 표본 수가 큰 클래스에만 학습이 치우치는 것을 조절하려는 구성으로 읽을 수 있습니다. **[p.11]**

> **용어 풀이 — 교차엔트로피:** 모델이 정답 클래스에 높은 확률을 주도록 학습하는 대표적인 분류 손실입니다.

#### 보간 — Eq.(10)

```math
\mathcal L_{\text{int}}
=
\sum_i
\left\|
M^{(L)}
\odot
\left(
(\widehat X_{\text{reco}}^{(L)})_i
-
X_i^{(L)}
\right)
\right\|_2^2.
```

최종 스케일의 복원 손실입니다. $\widehat X_{\text{reco}}^{(L)}$는 복원값, $X^{(L)}$는 실제값, $M^{(L)}$는 평가할 위치를 선택하는 마스크입니다.  
저자는 분류 모듈과 분류 손실을 제거하면 보간에 적용할 수 있다고 설명합니다. **[p.11, Appendix A·C]**

#### 미래 예측 — Eq.(11)

```math
\mathcal L_{\text{fore}}
=
\sum_i
\left\|
(M_{\text{fore}})_i
\odot
\left(
(\widehat X_{\text{fore}}^{(L)})_i
-
(X_{\text{fore}})_i
\right)
\right\|_2^2.
```

- $\widehat X_{\text{fore}}^{(L)}$: 미래 예측값.
- $X_{\text{fore}}$: 미래 구간의 실제 관측값.
- $M_{\text{fore}}$: 정답이 실제로 존재하는 위치를 선택하는 마스크.

분류 모듈을 예측 모듈로, 분류 손실을 예측 손실로 바꿉니다. **예측 모듈의 상세 구조는 충분히 설명하지 않습니다.** **[p.11, Appendix A·C]**

## 9. 일반화 성능 향상 가능성과 문서가 답하지 않는 질문

### 9.1 일반화에 관해 실제로 보여 준 범위

| 일반화의 의미 | 논문이 제공하는 증거 | 평가 |
|---|---|---|
| 같은 데이터셋의 미관측 표본에 대한 성능 | 시험 분할 결과 | 평가함 |
| 반복 실행의 안정성 | 5회 평균·표준편차 | 평가함 |
| 같은 구조의 여러 과제 적용 | 분류·보간·예측 실험 | 평가함 |
| 학습과 다른 관측 빈도·센서 구성에 대한 대응 | 별도 분포 이동 실험 없음 | 미검증 |

**근거:** pp.5–7, §4 및 Tables 1–5.

> **용어 풀이 — 분포 이동:** 학습할 때와 사용할 때 데이터의 특성이나 관측 방식이 달라지는 상황입니다.  
> **외부분포 일반화, OOD 일반화:** 학습 때와 다른 환경에서도 성능이 유지되는 능력입니다.

### 9.2 어떤 설계가 일반화에 기여할 가능성이 있는가?

다음은 **구조에 근거한 해석이며, 논문이 확인한 외부 일반화 결과는 아닙니다.**

| 설계 | 일반화와 연결되는 해석 | 함께 검증해야 할 위험 |
|---|---|---|
| 다중 스케일 | 특정 시간 해상도에만 의존하지 않는 표현을 유도할 수 있음 | 중요한 짧은 변화가 평균화될 수 있음 |
| 공유 인코더 | 해상도마다 별도 모델을 학습하는 것보다 공통 특징 추출을 요구함 | 모든 변수에 같은 해상도 구조가 적합한지 불명 |
| 복원 일관성 | 해상도 변화에도 전체 추세 예측이 맞도록 제약함 | 잘못된 거친 복원까지 세밀한 복원에 강요할 수 있는지 확인 필요 |
| 스케일 간 대조학습 | 동일 표본의 해상도 차이를 덜 민감하게 처리하도록 학습함 | 서로 다른 표본이지만 의미상 같은 사례를 과도하게 멀어지게 하는지 미검증 |
| LSP-DTW | 비동기 관측에서 보간 없이 관계 정보를 얻을 수 있음 | 주기성이 약하거나 관측이 매우 적은 경우의 신뢰성이 미검증 |

**근거가 되는 구조:** pp.2–5, Figure 2, Eq.1–6.

일반화 연구에서 특히 중요한 질문은 **불규칙성 중 무엇을 줄이고, 무엇을 정보로 보존해야 하는가**입니다. PrimeNet은 관측 밀도 자체가 유용한 정보를 포함할 수 있다고 보고합니다. 이에 비추어 보면 MuSiCNet의 풀링이 관측값의 추세를 보존하는 것과 별개로, 관측 과정의 정보를 얼마나 유지하는지 확인할 필요가 있습니다. **[외부 연구 및 해석: PrimeNet p.1]** [ojs.aaai.org](https://ojs.aaai.org/index.php/AAAI/article/view/25876/25648?utm_source=chatgpt.com)

### 9.3 문서가 답하지 않는 핵심 질문

1. **관측 간격 분포가 바뀌어도 성능이 유지되는가?**  
   보간의 관측 비율별 결과만으로 학습·시험 간 관측 방식 변화에 대응한다고 판단할 수 없습니다.

2. **새로운 병원·기상관측소·사용자에게 이전되는가?**  
   환경을 분리한 외부 검증이 필요합니다.

3. **평균 풀링이 짧지만 중요한 사건을 지우는가?**  
   전체 평균 지표 외에 짧은 사건을 별도로 평가한 결과가 없습니다.

4. **LSP-DTW는 어떤 신호에서 신뢰할 수 있는가?**  
   관측 수, 주기성, 주파수 격자, 위상 차이에 따른 분석이 없습니다.

5. **스케일 수와 손실 가중치에 얼마나 민감한가?**  
   설정값과 탐색 범위는 있지만 체계적인 민감도 결과는 없습니다.

6. **센서 하나가 완전히 사라져도 동작하는가?**  
   일부 값을 무작위 제거하는 상황과 센서 전체의 부재는 구분해야 합니다.

7. **긴 미래 구간이나 실시간 처리에도 적합한가?**  
   긴 예측 지평과 실행 지연을 평가하지 않았습니다.

8. **낮은 오차가 신뢰할 수 있는 확률로 이어지는가?**  
   예측 불확실성이나 확률 보정에 대한 결과가 없습니다.

> **용어 풀이 — 민감도 분석:** 설정값을 바꾸었을 때 결과가 얼마나 달라지는지 확인하는 분석입니다.  
> **확률 보정:** 모델이 80%라고 예측한 사건이 실제로도 비슷한 비율로 발생하는지 평가하는 것입니다.

## 11. 결론, 명시적 한계, 우선 검증할 접근법

### 11.1 저자가 제시한 시사점과 후속 계획

**[저자 보고]** 결론은 다음 두 가지를 강조합니다. **[p.7, §5]**

- 추가적인 거친 스케일의 시계열이 전체적인 시간 정보를 제공하여 세밀한 시계열 분석을 돕습니다.
- 시간 attention과 주파수 관계 행렬을 함께 사용하는 CorrNet이 변수 내부·변수 사이의 정보 추출을 지원합니다.

**첨부 v1에는 별도의 Limitations 절이나 구체적인 후속 연구 계획이 없습니다.** 저자가 직접 인정하는 주요 상충관계는 거친 스케일의 세부 정보 손실과 세밀한 스케일의 높은 학습 난도입니다. **[p.2]** 의료 예측 두 조건에서 GraFITi가 더 우수하다는 점도 결과 설명에 나타납니다. **[p.6]**

외부 검증 부재, 단위·마스크 설명 부족, 관계 복원의 정답 부재 등은 **본 보고서의 분석상 한계 지적**이며, 저자가 명시한 한계와 구분해야 합니다.

### 11.2 학술적·실용적 영향

**[해석]** 학술적으로 가장 유용한 기여는 **시간 해상도 간 일관성을 불규칙 시계열 표현학습의 명시적 목표로 만든 점**입니다. 이 아이디어는 전체 MuSiCNet을 그대로 구현하지 않더라도 기존 시간 attention 모델에 추가하여 검증할 수 있습니다. **[Eq.5–6, Table 4]**

실용적 적용을 판단하려면 데이터셋 내 평균 성능 외에 실제 사용 환경의 관측 방식, 센서 부재, 처리 비용, 예측 불확실성을 평가해야 합니다. 원문 결과는 이러한 검증을 시작할 근거를 제공하지만, 임상적 신뢰성이나 운영 환경 성능을 확정하지는 않습니다. **[pp.5–7의 실험 범위에 대한 해석]**

### 11.3 가장 유망한 접근법과 빠른 검증 순서

아래는 **새로운 실험 제안**입니다. 논문이 이미 수행한 연구나 입증한 개선 효과가 아닙니다.

| 우선순위 | 검증할 아이디어 | 작은 실험 구성 | 핵심 확인 사항 |
|---|---|---|---|
| **1** | **다중 스케일 + 공유 인코더** | 기존 시간 attention 모델의 단일 스케일과 2–3개 스케일을 비교 | 모델 크기를 크게 늘리지 않고도 이점이 있는가 |
| **2** | **복원 일관성 손실** | 같은 모델에 Eq.(5)만 추가 | 해상도나 관측 빈도가 바뀔 때 성능 저하가 줄어드는가 |
| **3** | **LSP-DTW 관계 행렬** | 단위행렬·무작위 행렬·보간-DTW·LSP-DTW만 교체 | 관계 추정의 순수 효과가 있는가; 주파수 설정과 거리 변환에 민감한가 |
| **4** | **스케일 간 대조학습** | 복원 일관성·대조학습을 각각 켜고 끄는 네 조건 비교 | 추가 복잡도에 비해 저라벨 학습이나 관측 변화 대응에 이점이 있는가 |

**가장 먼저 검증할 구성은 ‘소수 스케일의 평균 풀링 + 공유 인코더 + 복원 일관성 손실’입니다.** 구성요소 제거 실험이 이 방향을 지지하고, LSP-DTW의 미기재 설정을 결정하기 전에도 별도로 검증할 수 있기 때문입니다. **[해석·제안: p.6, Table 4]**

### 11.4 일반화 향상 여부를 판정할 평가 설계

**[제안]** 모델을 복잡하게 만들기 전에 다음 평가를 갖추는 것이 중요합니다.

1. **학습·시험의 관측 조건을 다르게 설정합니다.**  
   관측 빈도 변화, 긴 관측 공백, 센서 전체 누락을 각각 구분합니다.

2. **표본을 환경 단위로 분리합니다.**  
   PAM은 사용자 단위, 의료는 가능한 경우 기관·시간 단위로 분리하여 기존 무작위 분할과 비교합니다.

3. **모든 관계 행렬과 전처리는 허용된 입력으로만 계산합니다.**  
   가린 값이나 예측해야 할 미래가 관계 계산에 들어가지 않도록 범위를 명시합니다.

4. **동일 분할·반복 조건·튜닝 예산으로 차이를 평가합니다.**  
   평균값과 함께 표본 또는 반복 단위의 성능 차이에 대한 불확실성을 제시합니다.

5. **전체 평균과 취약 조건을 함께 보고합니다.**  
   짧은 사건, 관측이 극히 적은 변수, 새로운 관측 방식에서의 성능을 별도로 평가합니다.

MuSiCNet의 일반화 연구 가치는 **다중 해상도의 일관성이 실제 관측 환경 변화에 대한 안정성으로 이어지는지 검증할 수 있다는 점**에 있습니다. 현재 원문은 그 가능성을 탐색할 구조와 일부 데이터셋 내 근거를 제공하며, 외부 일반화의 효과 크기는 후속 실험으로 확인해야 합니다.
