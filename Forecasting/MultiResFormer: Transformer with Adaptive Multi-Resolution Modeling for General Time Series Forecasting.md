## 1. Executive summary — 9문장

1. MultiResFormer는 미리 정한 시간 척도에 의존하는 시계열 예측 모델이 다양한 반복 주기와 복잡한 시간적 관계를 충분히 포착하지 못할 수 있다는 문제를 해결하려는 연구입니다. **[저자 보고: pp.1–2]**
2. 모델은 각 블록에서 입력의 주요 반복 주기를 검출하고, 이를 관측 구간을 나누는 길이로 사용하여 여러 시간 척도를 구성합니다. **[저자 보고: p.5, 식 (1)]**
3. 길이가 다른 구간들을 동일한 개수의 표본으로 변환하여 같은 Transformer를 적용하고, 원래 시간 길이를 알려 주는 해상도 정보를 추가합니다. **[저자 보고: pp.4–5, Figure 2, 식 (2)]**
4. Transformer의 attention은 반복 주기 사이의 관계를, feed-forward network는 한 주기 내부의 변화를 처리하도록 설계되었습니다. **[저자 보고: p.5, §3.3]**
5. 각 블록이 입력과 같은 크기의 시계열 표현을 출력하므로, 마지막 예측층의 파라미터 부담을 줄일 수 있습니다. **[저자 보고: p.4, §3.1]**
6. 실험은 8개 다변량 장기 예측 데이터셋과 M4 단변량 단기 예측 데이터로 수행되었습니다. **[저자 보고: p.6, Table 1]**
7. 데이터셋별 평균 오차에서는 PatchTST보다 8개 중 6개 데이터셋에서 우수하지만, Electricity와 Traffic에서는 뒤집니다. **[검토·계산: p.6, Table 2]**
8. ETTh1의 효율 비교에서는 파라미터가 0.26M으로 PatchTST의 0.53M보다 적으면서 가장 낮은 MSE를 보였습니다. **[저자 보고: p.8, Figure 5]**
9. 다만 다른 데이터셋으로의 무재학습 전이 성능은 검증하지 않았으며, 반복 실험의 불확실성 미보고와 일부 표·본문의 불일치 때문에 광범위한 일반화 성능까지 입증했다고 해석하기는 어렵습니다. **[검토·해석: pp.6–8, 12–14]**

> **용어 풀이**
>
> - **Attention:** 입력의 어떤 부분을 얼마나 참고할지 가중치를 계산하는 연산입니다.
> - **Feed-forward network, FFN:** 각 입력 표현을 같은 신경망에 통과시켜 특징을 변환하는 구성 요소입니다.
> - **파라미터:** 학습으로 조정되는 모델의 숫자이며, 0.26M은 약 26만 개를 뜻합니다.
> - **MSE:** 예측 오차를 제곱하여 평균한 지표로, 큰 오차에 더 민감합니다.
> - **일반화:** 학습에 사용하지 않은 데이터에서도 예측 능력을 유지하는 성질입니다.

## 2. 연구 배경, 목적 및 필요성

### 2.1 해결하려는 문제

**[저자 보고]** 실제 시계열에는 여러 시간 척도의 변화가 공존합니다. 기존 방법은 고정된 패치 길이를 사용하거나, 일정한 비율로 시계열을 반복 축소하여 여러 해상도를 만듭니다. 저자는 이러한 사전 정의 방식이 불필요한 척도를 포함하거나 중요한 척도를 놓칠 수 있다고 지적합니다. **[pp.1–3, Figure 1]**

> **용어 풀이**
>
> - **패치, patch:** 연속된 여러 시점의 관측값을 하나의 입력 단위로 묶은 것입니다.
> - **해상도, resolution:** 이 논문에서는 주로 한 패치가 포함하는 시간 길이에 따른 관찰 척도를 뜻합니다.
> - **다운샘플링:** 더 적은 표본으로 시계열을 표현하는 과정입니다.

또한 저자는 시계열의 변화를 다음 두 종류로 구분합니다. **[pp.2–3, 5]**

| 변화 유형 | 의미 | 이해를 위한 예시 |
|---|---|---|
| **주기 내부 변화, intraperiod variation** | 한 반복 주기 안에서 나타나는 변화 | 하루 안에서 시간대별 전력 사용량이 달라지는 현상 |
| **주기 사이 변화, interperiod variation** | 서로 다른 반복 주기 사이의 관계 | 날짜에 따라 하루 전체 전력 사용 패턴이 달라지는 현상 |

위 예시는 개념 설명이며, 모든 데이터에서 하루 길이가 검출된다는 의미는 아닙니다.

### 2.2 연구 목적

연구의 목적은 세 가지로 정리할 수 있습니다.

1. **데이터에 맞는 시간 척도를 자동으로 선택한다.**  
   각 블록에서 검출한 주요 주기를 패치 길이로 사용합니다. **[p.5, §3.2]**

2. **여러 척도를 모델링하면서 파라미터 증가를 억제한다.**  
   서로 다른 길이의 패치를 동일한 차원으로 변환하여 Transformer를 공유합니다. **[pp.2, 5]**

3. **예측 성능과 모델 크기의 균형을 개선한다.**  
   블록의 출력 크기를 원래 시계열과 동일하게 유지하여 예측 헤드를 작게 만듭니다. **[p.4, §3.1; p.8, Figure 5]**

> **용어 풀이 — 예측 헤드:** 모델이 추출한 표현을 최종 미래 예측값으로 바꾸는 마지막 층입니다.

### 2.3 필요성에 대한 평가

**[검토·해석]** 이 논문의 중요한 질문은 “Transformer를 얼마나 복잡하게 만들 것인가?”보다 **“시계열을 어떤 시간 단위로 나누어 Transformer에 제공할 것인가?”**에 있습니다. 주기가 서로 다른 데이터를 공통 구조로 처리하려면, 패치 길이 선택과 길이가 다른 패치의 표현 방법을 함께 해결해야 하기 때문입니다. 이 해석은 논문의 주기 검출·보간·공유 구조를 연결한 것입니다. **[pp.2, 4–6]**

다만 **파라미터 공유가 과적합을 줄일 수 있다는 설명은 저자의 설계 가설**입니다. 이 논문은 공유 여부만을 독립적으로 바꾸어 일반화 효과를 검증하지 않았습니다. **[p.2; p.7, Table 4]**

> **용어 풀이 — 과적합:** 학습 데이터에 지나치게 맞추어져 새로운 데이터에서 성능이 떨어지는 현상입니다.

## 4. 연구 방법과 주요 데이터 소스

### 4.1 실험 설계

**[저자 보고]** 연구는 새 예측 모델을 설계하고, 기존 모델과 벤치마크 성능을 비교하는 실험 연구입니다. 주요 검증은 장·단기 예측, 구성 요소 제거 실험, 입력 길이 변화, 효율 비교, 내부 표현 분석으로 구성됩니다. **[pp.6–8, §4]**

> **용어 풀이 — 구성 요소 제거 실험, ablation study:** 모델의 일부를 제거하거나 대체하여 그 요소의 기여를 조사하는 실험입니다.

### 4.4 비교 공정성과 재현성

**[저자 보고]** 장기 예측에서는 테스트 시 마지막 배치를 버리던 데이터 로더 오류를 발견하여 모든 baseline을 다시 실행했습니다. 배치 크기에 따라 평가 대상이 달라지던 문제를 수정한 조치입니다. **[p.7, 각주 1]**

**[검토·해석]** 따라서 이 논문의 재실행 수치와 baseline 원 논문의 기존 수치를 섞어 비교하면 안 됩니다. M4는 baseline 수치를 TimesNet에서 가져왔으므로 장기 실험과 재실행 정책도 다릅니다. **[p.7, Table 3 및 각주 1]**

블록 수, attention head 수, dropout 등 전체 설정표와 반복 실행 횟수는 첨부 버전에 제시되지 않습니다. **[p.12, Appendix A]**

## 5. 제안 방법: 수식과 모델 구조

### 5.1 전체 구조와 기호

전체 흐름은 다음과 같습니다. **[p.4, Figure 2, §3.1]**

**입력 정규화 → MultiResFormer 블록 $N$개 → 공유 선형 예측 헤드 → 역정규화**

각 블록은 **주기 검출 → 여러 길이로 패칭 → 공통 길이로 보간 → 공유 Transformer → 원래 길이 복원 → 가중합**을 수행합니다.

| 기호 | 의미 |
|---|---|
| $I$ | 과거 입력 길이 |
| $O$ | 미래 예측 길이 |
| $V$ | 변수 수 |
| $\mathbf X\in\mathbb R^{I\times V}$ | 현재 블록의 입력 시계열 표현 |
| $N$ | 블록 수 |
| $\ell$ | 블록 인덱스 |
| $k$ | 선택하는 주요 주기의 수 |
| $f_i$ | 선택된 Fourier 주파수 인덱스 |
| $P_i=\text{Period}_i$ | $i$번째 분기의 패치 길이 |
| $n_i=\lceil I/P_i\rceil$ | $i$번째 분기의 패치 개수 |
| $d$ | 보간 후 공통 패치 길이·모델 차원 |
| $\mathbf{RE}\in\mathbb R^d$ | 학습 가능한 기본 해상도 벡터 |

Figure 2의 $D$와 본문의 $d$는 같은 역할을 합니다. 배치 축은 위 차원 표기에서 생략했습니다. **[pp.4–5]**

### 5.2 입력 정규화: RevIN

**[저자 보고]** 각 변수의 입력 구간을 시간축 기준 평균 0, 분산 1로 정규화하고, 예측 후 입력 구간의 통계량을 사용해 원래 수준과 척도로 복원합니다. 이를 위해 RevIN을 사용합니다. **[p.4, §3.1]**

> **용어 풀이 — RevIN:** 시계열마다 평균과 변동 크기를 제거한 상태에서 예측하고, 출력에서 다시 복원하는 정규화 방식입니다.

RevIN 자체는 기존 연구이며, 시간에 따라 평균·분산이 달라지는 분포 변화에 대응하기 위해 제안되었습니다. 따라서 MultiResFormer의 모든 성능 개선을 새로운 해상도 선택 구조의 효과로만 돌릴 수는 없습니다. [seharanul17.github.io](https://seharanul17.github.io/RevIN/?utm_source=chatgpt.com)

### 5.3 주요 주기 검출 — 원문 식 (1)

각 변수의 시간축에 FFT를 적용하고, 진폭이 큰 주파수를 선택합니다.

```math
\mathbf A
=
\text{Avg}
\left(
\text{Amp}
\left(
\text{FFT}(\mathbf X)
\right)
\right),
```

```math
\{f_1,\ldots,f_k\}
=
\underset{f\in\{1,\ldots,\lfloor I/2\rfloor\}}
{\text{argTopk}}(\mathbf A),
```

```math
P_i=\text{Period}_i
=
\left\lceil\frac{I}{f_i}\right\rceil.
```

**[저자 보고: p.5, §3.2]**

**기호 설명**

- $\text{FFT}$: 각 변수에 적용하는 고속 Fourier 변환.
- $\text{Amp}$: Fourier 성분의 진폭을 계산하는 연산.
- $\text{Avg}$: 변수 축의 진폭 평균.
- $\mathbf A$: 공통 진폭 정보.
- $\text{argTopk}$: 진폭이 가장 큰 $k$개 주파수의 **인덱스** 선택.
- $f_i$: 실제 Hz가 아니라 입력 구간에 대한 주파수 인덱스.
- $\lceil\cdot\rceil$: 올림하여 정수로 만드는 연산.
- 검색 범위는 1부터 시작하므로 0번 주파수는 제외됩니다.

> **용어 풀이**
>
> - **Fourier 변환:** 복잡한 파형을 반복 속도가 서로 다른 성분으로 나누어 보는 방법입니다.
> - **진폭:** 해당 반복 성분의 크기입니다.
> - **주기:** 한 번 반복되는 데 필요한 시간 길이입니다.

**중요한 구현 범위:** 실제 배치 구현에서는 변수뿐 아니라 **배치의 서로 다른 샘플 사이에서도 진폭을 평균**한다고 설명합니다. 따라서 각 샘플이 완전히 독립적으로 자기 주기를 선택하는 구조라고 설명하면 부정확합니다. **[p.5]**

저자는 주기 검출 결과를 패치 길이 선택에만 사용하므로 검출 방법이 미분 가능할 필요는 없으며, 자기상관 기반 방법 등으로 대체할 수도 있다고 설명합니다. 대체 검출기의 성능 실험은 없습니다. **[p.5]**

> **용어 풀이 — 자기상관:** 시계열을 일정 시간만큼 이동시킨 뒤 원래 시계열과 얼마나 비슷한지 측정하는 방법으로, 반복 주기 탐지에 사용할 수 있습니다.

### 5.4 비중첩 패칭과 선형 보간

**[저자 보고]** $i$번째 분기는 길이와 이동 간격을 모두 $P_i$로 설정하여 시계열을 겹치지 않게 나눕니다. 길이가 나누어떨어지지 않으면 마지막 관측값을 반복하여 끝을 채웁니다. 이후 각 패치를 길이 $d$로 선형 보간합니다. **[p.5, §3.3]**

> **용어 풀이**
>
> - **패딩:** 처리에 필요한 길이를 맞추기 위해 추가 값을 채우는 작업입니다.
> - **선형 보간:** 가까운 표본 사이를 직선으로 연결하여 새로운 위치의 값을 계산하는 방법입니다.

분기별 차원 변화는 다음과 같습니다.

| 단계 | 표현의 모양 |
|---|---|
| 블록 입력 | $I\times V$ |
| 패딩·패칭 | $V\times n_i\times P_i$ |
| 길이 $d$로 보간 | $V\times n_i\times d$ |
| 공유 Transformer 통과 | $V\times n_i\times d$ |
| 원래 길이 $P_i$로 보간 | $V\times n_i\times P_i$ |
| 펼치기·패딩 제거 | $I\times V$ |

여기서 다음 식은 원문에 제시된 차원을 정리한 **설명식**입니다.

$$
n_i=\left\lceil\frac{I}{P_i}\right\rceil.
$$

$n_i$는 패치 수이며, $I$와 $P_i$는 각각 입력 길이와 해당 분기의 패치 길이입니다. **[pp.5–6, Figure 2]**

**보간을 사용하는 이유:** 입력마다 패치 길이가 달라지므로 고정된 입력 차원을 요구하는 학습형 선형 패치 임베딩을 그대로 쓰기 어렵습니다. 보간으로 입력 차원을 통일하면 여러 분기가 같은 Transformer를 사용할 수 있습니다. **[pp.2, 5]**

**[검토·해석]** 길이를 줄인 뒤 다시 늘리는 보간이 원래 정보를 완벽하게 복원한다는 보장은 없습니다. 따라서 Figure 1의 정보 보존 설명을 전체 모델 경로의 무손실성으로 확대해서는 안 됩니다. **[p.2, Figure 1; p.5, §3.3]**

### 5.5 해상도 임베딩 — 원문 식 (2)

보간 후에도 원래 패치 길이를 알 수 있도록 다음 벡터를 더합니다.

```math
\mathbf{Res}_i
=
\mathbf{RE}\times\frac{1}{P_i}.
```

**[저자 보고: p.5, §3.3]**

- $\mathbf{RE}\in\mathbb R^d$: 무작위 초기화 후 학습하는 기본 벡터.
- $\mathbf{Res}_i\in\mathbb R^d$: $i$번째 분기에 추가하는 해상도 정보.
- $P_i$: 해당 분기의 원래 패치 길이.
- $\mathbf{RE}$는 **전체 모델에서 공유**됩니다.

**쉽게 말하면**, 모든 패치를 같은 길이로 바꾼 뒤에도 “이 조각이 원래 얼마나 긴 시간을 담았는지” 알려 주는 장치입니다. 해상도마다 별도의 벡터를 학습하는 대신, 하나의 벡터를 $1/P_i$로 조정합니다.

원문의 절차를 하나로 묶으면 다음 **설명식**으로 나타낼 수 있습니다.

```math
\mathbf Z_i
=
\text{Interp}_{P_i\rightarrow d}
\left(
\text{Patch}_{P_i}
\left(
\text{Pad}(\mathbf X)
\right)
\right)
+
\mathbf{Res}_i.
```

- $\mathbf Z_i\in\mathbb R^{V\times n_i\times d}$: Transformer에 들어가는 분기 입력.
- $\text{Pad}$: 끝부분 패딩.
- $\text{Patch}_{P_i}$: 길이 $P_i$로 분할.
- $\text{Interp}_{P_i\rightarrow d}$: 패치 길이를 $P_i$에서 $d$로 보간.
- $\mathbf{Res}_i$는 해당 분기의 각 패치에 동일하게 더해집니다.

### 5.6 공유 Transformer: 주기 사이와 주기 내부 모델링

**[저자 보고]** 분기마다 다음 두 연산을 적용합니다. **[p.5, §3.3]**

| 구성 요소 | 처리하는 축 | 저자가 부여한 역할 |
|---|---|---|
| Multi-head attention, MHA | 패치와 패치 사이 | 주기 사이 변화 모델링 |
| FFN | 각 패치의 $d$차원 표현 내부 | 주기 내부 변화 모델링 |

> **용어 풀이 — Multi-head attention:** 여러 attention 연산이 서로 다른 표현 관점에서 관계를 계산하도록 만든 구조입니다.

이를 이해하기 위한 **표준 Transformer 연산식**은 다음과 같습니다. 아래 식은 MultiResFormer 원문에 추가로 실린 수식이 아니라, 원문이 사용하는 MHA·FFN의 작동 원리를 설명하기 위한 것입니다. [arxiv.org](https://arxiv.org/html/1706.03762v7?utm_source=chatgpt.com)

한 변수의 패치 표현을 $\mathbf Z\in\mathbb R^{n_i\times d}$라고 하면,

$$
\mathbf Q_h=\mathbf ZW_h^Q,\qquad
\mathbf K_h=\mathbf ZW_h^K,\qquad
\mathbf V_h=\mathbf ZW_h^V,
$$

```math
\mathbf B_h
=
\text{Softmax}
\left(
\frac{\mathbf Q_h\mathbf K_h^\top}{\sqrt{d_a}}
\right)
\mathbf V_h,
```

```math
\text{MHA}(\mathbf Z)
=
\text{Concat}(\mathbf B_1,\ldots,\mathbf B_H)W^M.
```

- $h$와 $H$: attention head 인덱스와 개수.
- $\mathbf Q_h,\mathbf K_h,\mathbf V_h$: 각각 query, key, value 표현.
- $W_h^Q,W_h^K,W_h^V,W^M$: 학습하는 투영 행렬.
- $d_a$: query·key의 차원.
- $\mathbf B_h$: $h$번째 head의 출력.
- $\text{Concat}$: 여러 head 출력을 이어 붙이는 연산.
- $\top$: 행렬 전치.

> **용어 풀이 — Query·Key·Value:** query와 key의 유사도로 어느 패치를 참고할지 결정하고, 그 가중치로 value를 합치는 구조입니다.

FFN의 일반적인 형태는 다음과 같습니다.

```math
\text{FFN}(\mathbf z)
=
\phi(\mathbf zW_1+\mathbf b_1)W_2+\mathbf b_2.
```

- $\mathbf z$: 한 패치의 표현.
- $W_1,W_2$: 학습 행렬.
- $\mathbf b_1,\mathbf b_2$: 편향.
- $\phi$: 비선형 활성화 함수.

패치 표현의 여러 좌표를 함께 변환하므로, 한 주기 내부의 패턴을 처리할 수 있습니다. 다만 **MultiResFormer v2는 활성화 함수 선택, head 수, 정규화·잔차 연결의 상세 구성을 명시하지 않습니다.** **[p.5, §3.3; p.12, Appendix A]**

**공유 범위도 구분해야 합니다.**

- Transformer는 **한 블록 안의 여러 해상도 분기 사이에서 공유**됩니다.
- 깊이가 다른 $N$개 블록까지 Transformer 가중치를 공유한다고 명시하지는 않습니다.
- 변수는 채널 독립 방식으로 처리하지만, 주기 선택에는 변수·배치 평균 진폭을 사용합니다. **[pp.3–5]**

> **용어 풀이 — 채널 독립 방식:** 각 변수의 시계열을 별도로 처리하면서 같은 모델 가중치를 사용하는 방식입니다. 변수 간 attention을 직접 계산하는 구조와 구분됩니다.

### 5.7 원래 길이 복원과 적응적 집계 — 원문 식 (3)

분기 출력을 원래 패치 길이로 보간한 뒤 펼치고, 추가 패딩을 제거합니다. 이를 다음 **설명식**으로 쓸 수 있습니다.

```math
\mathbf R_i
=
\text{Truncate}_{I}
\left(
\text{Flatten}
\left(
\text{Interp}_{d\rightarrow P_i}
\left(
T_\ell(\mathbf Z_i)
\right)
\right)
\right).
```

- $T_\ell$: $\ell$번째 블록에서 분기들이 공유하는 Transformer.
- $\mathbf R_i\in\mathbb R^{I\times V}$: 복원된 $i$번째 분기 출력.
- $\text{Flatten}$: 패치를 시간 순서로 이어 붙이는 연산.
- $\text{Truncate}_I$: 패딩에 해당하는 끝부분을 제거하는 연산.
- 변수축·시간축을 원래 순서로 복원하는 재배열은 표기에서 생략했습니다. **[p.6, §3.4]**

집계 가중치는 선택된 주파수의 진폭으로 결정합니다.

```math
\{A_1,\ldots,A_k\}
=
\underset{f\in\{1,\ldots,\lfloor I/2\rfloor\}}
{\text{Topk}}(\mathbf A),
```

```math
\{w_1,\ldots,w_k\}
=
\text{Softmax}(\{A_1,\ldots,A_k\}).
```

**[저자 보고: p.6, §3.4]**

- $A_i$: 선택된 주파수의 진폭값.
- $\text{Topk}$: 인덱스가 아니라 상위 진폭값을 반환하는 연산.
- $w_i$: $i$번째 분기의 집계 가중치.

식 (3)의 Softmax를 풀어 쓰면,

$$
w_i=\frac{\exp(A_i)}{\sum_{j=1}^{k}\exp(A_j)}.
$$

여기서 $\exp$는 지수함수이고, $j$는 선택한 분기를 합산하는 인덱스입니다. 모든 $w_i$는 양수이며 합이 1입니다.

> **용어 풀이 — Softmax:** 여러 숫자를 합이 1인 가중치로 바꾸는 연산입니다. 이 모델에서는 선택된 진폭이 클수록 해당 분기에 높은 비중을 부여합니다.

최종 블록 출력은 원문의 가중합 설명을 정리한 다음 식입니다.

```math
\mathbf X^{(\ell)}
=
\sum_{i=1}^{k}w_i\mathbf R_i
\in\mathbb R^{I\times V}.
```

$\mathbf X^{(\ell)}$은 $\ell$번째 블록의 출력입니다. 분기 가중치를 별도 학습형 라우터가 결정하는 구조는 아니며, 원문은 진폭의 Softmax를 사용합니다. **[p.6]**

### 5.8 최종 예측 헤드와 효율

마지막 블록 출력에 변수 간 공유 선형 예측 헤드를 적용합니다. 차원을 드러내기 위해 편향을 생략한 **설명식**은 다음과 같습니다.

```math
\widetilde{\mathbf Y}_{:,v}
=
W_{\text{pred}}\mathbf X^{(N)}_{:,v},
\qquad
W_{\text{pred}}\in\mathbb R^{O\times I}.
```

- $v$: 변수 인덱스.
- $\mathbf X^{(N)}$: 마지막 블록 출력.
- $W_{\text{pred}}$: 모든 변수에 공유되는 시간축 변환 행렬.
- $\widetilde{\mathbf Y}$: 역정규화 전 미래 예측값.
- $:$ : 해당 축의 모든 원소.

이후 역정규화하여 최종 예측을 얻습니다. **[p.4, §3.1]**

**[검토·해석]** 여기서 중요한 효율 이점은 고차원 패치 표현 전체를 큰 예측층에 넣는 대신, 원래 길이 $I$의 표현에서 $O$를 예측한다는 점입니다. 반면 $k$에 따라 파라미터가 늘지 않는다고 해서 연산량도 일정한 것은 아닙니다. 또한 p.2의 attention 관련 $O(1)$ 표현을 전체 계산이 상수 시간이라는 뜻으로 읽어서는 안 됩니다. 표준 self-attention의 패치 간 연산은 패치 수의 제곱에 비례합니다. **[pp.2–5]** [arxiv.org](https://arxiv.org/html/1706.03762v7?utm_source=chatgpt.com)

감소율은 다음 계산을 사용했습니다.

```math
\text{감소율}(\%)
=
100
\frac{e_{\text{PatchTST}}-e_{\text{MultiResFormer}}}
{e_{\text{PatchTST}}}.
```

$e$는 해당 데이터셋의 Table 2 MSE입니다. 음수는 MultiResFormer의 오차가 더 크다는 뜻이며, 계산은 반올림된 인쇄값 기준입니다.

**[검토·해석]**

- 평균 기준으로는 두 지표 모두 **8개 중 6개 데이터셋에서 PatchTST보다 낮습니다.**
- ETTm1·ETTm2·Weather의 차이는 작으므로, 반복 실행의 변동성을 확인해야 우위의 신뢰도를 판단할 수 있습니다.
- ILI의 평균 개선도 모든 예측 길이에 걸쳐 유지되지는 않습니다. 예를 들어 $O=48$에서는 MSE가 MultiResFormer **2.052**, PatchTST **1.852**입니다. **[p.13, Table 5]**
- Table 5의 32개 조건을 직접 집계하면 PatchTST 대비 MSE는 **21승·1동률·10패**, MAE는 **21승·2동률·9패**입니다. 이는 반올림된 표의 집계이며 통계적 유의성 검정은 아닙니다. **[p.13, Table 5]**

### 6.2 TimesNet 대비 개선율의 재현성

**[저자 보고]** 본문은 TimesNet 대비 전체적으로 **MSE 16.5%, MAE 10.7% 감소**를 보고합니다. **[p.7, §4.1]**

**[검토·계산]** 그러나 집계식을 명시하지 않습니다. Table 5의 32개 조건마다 TimesNet을 분모로 상대 감소율을 계산한 뒤 동일 가중치로 평균하면 다음과 같습니다.

| 지표 | 저자 보고 | Table 5 인쇄값으로 계산한 32조건 상대 감소율 평균 |
|---|---:|---:|
| MSE | 16.5% | 약 16.44% |
| MAE | 10.7% | 약 9.30% |

따라서 **16.5%와 10.7%는 저자 보고치로 인용해야 하며, 특히 MAE 10.7%는 위 계산 방식으로 재현되지 않는다고 표시하는 것이 정확합니다.** 원문만으로 다른 집계 방식이나 올바른 교정값을 확정할 수 없습니다.

## 8. 통계적으로 취약한 부분, 제한사항, 문서가 답하지 않는 질문

### 8.1 통계적·비교상 취약점

| 항목 | 확인된 내용 | 해석에 미치는 영향 |

| 유의성 검정 | 통계적 검정 미보고 | 저자의 “significant margin”을 “통계적으로 유의함”으로 번역하면 안 됨 |

**근거: pp.7–8, Tables 3–4, Figures 4–5; p.12, Appendix A; pp.13–14, Tables 5–6.**

> **용어 풀이**
>
> - **Random seed:** 초기 가중치와 데이터 순서 등 무작위 과정을 재현하기 위한 시작값입니다.
> - **신뢰구간:** 추정값의 불확실성을 구간으로 표시하는 방법입니다.
> - **통계적 유의성:** 관측된 차이가 우연한 변동만으로 설명되기 어려운지 평가하는 개념입니다.

### 8.2 저자가 직접 언급한 제약과 향후 계획

첨부 버전에는 별도의 **Limitations 절이 없습니다**. 직접 확인되는 내용은 다음과 같습니다.

1. **Pathformer와의 비교 유보:** 당시 코드가 없고 입력 길이도 달라 후속 비교로 남겼습니다. **[p.6, §4]**
2. **코드 공개 계획:** 최종 원고와 함께 구현 코드를 제공하겠다고 적었습니다. **[p.12, Appendix A]**
3. **주기 통합을 위한 평균 사용:** 변수·샘플 간 평균이 성능에 심각한 영향을 주지 않았다고 서술하지만, 이를 별도로 수치화한 결과는 없습니다. **[p.5, §3.2]**
4. **대체 주기 검출기의 적용 가능성:** 자기상관·혼합 검출법을 사용할 수 있다고 언급합니다. 이는 검증된 비교 결과나 구체적인 후속 일정은 아닙니다. **[p.5]**

| 주기가 약하거나 급변하는 시계열에서는 어떤가? | 주기 검출에 의존하는 설계의 적용 범위 문제 | p.5; 실험 §4 |
| 다른 데이터셋·변수·관측 간격으로 전이하는가? | 제목의 “General”을 평가할 직접 실험이 필요 | pp.6–8 |
| 예측 구간과 불확실성도 정확한가? | 원문은 주로 미래 값의 오차를 평가 | Tables 2–6 |

## 9. 모델 일반화 성능 향상 가능성: 무엇이 입증되었는가?

### 9.1 검증된 범위를 먼저 구분해야 함

| 일반화의 의미 | MultiResFormer의 근거 |
|---|---|
| 학습에 사용하지 않은 시점의 예측 | 벤치마크 테스트 결과 제시 |
| 여러 분야에서 같은 모델 구조 사용 | 전력·기상·교통·질병·M4에 적용 |
| 하나의 학습된 모델을 다른 데이터셋에 그대로 적용 | 보고되지 않음 |
| 학습하지 않은 변수 집합 예측 | 별도 실험 없음 |
| 매우 적은 목표 데이터로 적응 | 별도 실험 없음 |
| 급격한 주기 변화·노이즈·결측에 대한 강건성 | 별도 실험 없음 |

**[검토·해석: pp.6–8, §4]**

따라서 이 논문의 “일반적 시계열 예측”은 **다양한 벤치마크에 적용 가능한 구조**라는 범위에서 이해하는 것이 적절합니다.

> **용어 풀이**
>
> - **제로샷, zero-shot:** 목표 데이터에 맞추어 모델 가중치를 추가 학습하지 않고 예측하는 설정입니다.
> - **미세조정, fine-tuning:** 이미 학습한 모델을 목표 데이터로 추가 학습하는 과정입니다.
> - **강건성, robustness:** 잡음이나 데이터 조건 변화에도 성능을 유지하는 성질입니다.

### 9.2 일반화와 연결될 수 있는 설계 요소

**[저자 가설과 검토]**

- **적응적 패치 길이:** 데이터마다 다른 주요 반복 척도에 대응하려는 설계입니다. 다만 변화하는 주기를 실제로 얼마나 잘 추적하는지는 별도 실험이 없습니다. **[p.5]**
- **해상도 간 파라미터 공유:** 여러 시간 척도에서 공통 패턴을 재사용할 수 있다는 가설을 제공합니다. 공유가 과적합을 줄인다는 직접 검증은 부족합니다. **[pp.2, 5]**
- **해상도 정보 추가:** 보간 후에도 원래 길이를 알려 주므로 척도 차이를 구별하도록 돕습니다. 확인된 효과는 제한된 제거 실험의 소폭 변화입니다. **[p.5, 식 (2); p.7, Table 4]**
- **RevIN:** 입력의 평균·분산 변화에 대응하도록 설계되었지만, 이 논문 자체의 별도 분포 변화 시험은 없습니다. **[p.4]**
- **변수별 공유 처리:** 변수 수에 비례해 독립된 모델을 만들 필요를 줄이지만, 중요한 변수 간 관계를 직접 활용하는 능력은 별도로 검증해야 합니다. **[pp.3–4]**

핵심적인 미검증 질문은 **“척도에 적응하는 구조가 새로운 데이터 분포에도 적응하는가?”**입니다. 두 능력이 동일하다고 가정할 근거는 원문에 없습니다.

>

> **용어 풀이**
>
> - **사전학습:** 여러 데이터에서 먼저 공통 패턴을 학습하는 단계입니다.
> - **기반 모델, foundation model:** 폭넓은 데이터로 학습한 뒤 여러 작업에 재사용하도록 설계한 모델입니다.
> - **Decoder-only:** 앞에서 관측한 내용에 조건을 두어 뒤의 내용을 예측하도록 구성한 Transformer 계열입니다.
> - **양자화:** 연속적인 수치를 제한된 수의 구간이나 기호로 바꾸는 과정입니다.
> - **공변량:** 예측 대상 외에 예측을 돕는 추가 변수입니다.
> - **확률 예측:** 미래의 한 값뿐 아니라 가능한 값의 범위나 분포를 예측하는 방식입니다.

### 10.3 이 비교가 후속 연구에 주는 의미

**[검토·해석]** 비교한 최근 연구들은 일반화를 더 구체적인 조건으로 나누어 평가합니다. 학습하지 않은 변수, 다른 데이터셋에 대한 미세조정, 무재학습 전이, 다변량·공변량 조건부 예측은 각각 다른 능력입니다.

MultiResFormer의 후속 검증에서도 다음 조건을 명시해야 합니다.

- 목표 데이터의 가중치 학습을 허용하는지.
- 목표 검증 데이터로 패치 길이·입력 길이 등을 선택하는지.
- 사전학습 데이터와 평가 데이터의 출처가 중첩되는지.
- 동일한 테스트 창과 예측 길이를 사용하는지.
- 점예측 오차와 확률 예측 지표 중 무엇을 비교하는지.

특히 **TimesFM의 마지막 테스트 창 결과**, **Moirai의 검증 기반 설정 선택**, **Chronos-2의 사전학습 중첩 구분**은 숫자만 나열한 모델 순위가 왜 부정확할 수 있는지 보여 줍니다. [arxiv.org](https://arxiv.org/html/2310.10688v4?utm_source=chatgpt.com)

MultiResFormer가 이들 후대 연구에 직접적인 영향을 주었다는 인용·계승 관계는 본 조사에서 확인하지 못했습니다. 확인되는 기여는 **적응적 시간 척도 선택을 작은 공유 구조로 구현하는 구체적인 설계 대안을 제시했다는 점**입니다. **[첨부 논문 pp.2, 4–6]**

| **5** | 배치 평균 주기 선택 | 같은 샘플을 서로 다른 배치에 넣어 주기·예측 변화 측정 | 예측이 함께 처리한 샘플의 구성에 민감한가? |

**제안의 근거:** 주기 검출은 p.5 식 (1), 보간과 공유는 pp.5–6, 해상도 임베딩은 p.5 식 (2), 집계는 p.6 식 (3)에 대응합니다. 특히 임베딩은 Table 4에 제한적 비교가 있어 재현 실험의 시작점으로 적합합니다.

### 11.2 일반화 검증을 확장하는 순서

**첫째, 시간에 따른 변화부터 평가합니다.**  
시간 순서를 유지한 평가 구간을 여러 개 두고, 주기가 안정적인 구간과 달라지는 구간의 결과를 나눕니다. 전체 평균뿐 아니라 변화 구간에서의 오차를 확인해야 합니다.

**둘째, 동일 계열 데이터셋 간 전이를 평가합니다.**  
입력·출력 차원을 맞춘 ETTh1→ETTh2 같은 조건에서 시작할 수 있습니다. 가중치를 고정한 평가, 헤드만 학습한 평가, 전체 미세조정을 구분하면 어느 수준의 적응이 필요한지 알 수 있습니다.

**셋째, 분야가 다른 데이터로 확대합니다.**  
여러 데이터셋 중 하나를 학습에서 완전히 제외하여 평가합니다. 이때 $d$와 주기 선택 설정을 결정하는 데 사용할 수 있는 데이터 범위를 먼저 정해야 합니다.

**넷째, 변수 관계의 기여를 별도로 시험합니다.**  
채널 독립 구조를 유지한 모델과 작은 변수 관계 모듈을 추가한 모델을 비교합니다. iTransformer·Moirai·Chronos-2가 제시한 변수 관계 처리 방법은 실험 설계의 참고가 됩니다. [arxiv.org](https://arxiv.org/html/2310.06625v4?utm_source=chatgpt.com)

**다섯째, 예측 불확실성을 별도 과제로 평가합니다.**  
확률 출력이나 예측 구간을 추가한다면 점예측 오차와 구간의 적절성을 따로 평가해야 합니다. 기존 MSE 개선만으로 불확실성 추정의 개선을 가정할 수는 없습니다.

### 11.3 공통 검증 원칙

- 같은 데이터 분할, 입력 길이, 예측 길이와 학습 예산을 사용합니다.
- 여러 seed에서 결과의 평균과 변동성을 보고합니다.
- 주기 선택·정규화·보간·모델 크기의 영향을 분리합니다.
- 테스트 오차를 보고 설정을 선택하지 않습니다.
- 관측 간격이 다른 데이터에서는 스텝 수와 실제 시간 길이를 함께 기록합니다.
- 시간적으로 의존하는 오차의 불확실성을 평가할 때는 연속 구간 단위 재표본화 등을 고려합니다.

> **용어 풀이 — 연속 구간 단위 재표본화:** 개별 시점을 무작위로 섞는 대신 시간상 붙어 있는 구간을 묶어 다시 뽑는 방법으로, 시간적 관계를 일부 유지하며 불확실성을 평가하려는 접근입니다.

## 12. 결론 및 시사점

### 12.1 저자들이 제시한 시사점

**[저자 보고]** MultiResFormer는 주요 주기에 맞춘 패칭, 보간 기반 파라미터 공유, 해상도 임베딩, 블록 내부 복원을 결합하여 예측 성능과 파라미터 효율을 개선하는 모델입니다. 결론은 이러한 구조와 벤치마크 결과를 요약합니다. **[p.8, §5]**

논문의 영향 진술은 전력·교통·기상 등 시계열 예측이 활용되는 분야를 언급하지만, 실제 운영 비용 절감이나 의사결정 개선을 별도 실험으로 측정하지는 않습니다. **[p.9, Impact Statement]**

명시된 후속 계획은 Pathformer와의 비교 및 코드 제공 정도이며, 광범위한 후속 연구 로드맵은 제시하지 않습니다. **[pp.6, 12]**

### 12.2 학술적·실용적 의미에 대한 평가

**[검토·해석]** 학술적으로 가장 중요한 기여는 **입력의 시간 단위를 데이터에서 선택하고, 그 차이를 보간과 공유 파라미터로 처리하는 설계**입니다. 이는 시계열의 표현 단위가 예측 성능에 미치는 영향을 연구할 구체적인 출발점을 제공합니다.

실용적으로는 적은 파라미터로 여러 시간 척도를 처리하려는 접근이 관심을 받을 만합니다. 다만 현재 근거는 제한된 벤치마크와 ETTh1 효율 비교에 기반하므로, 실제 환경에서는 데이터별 재학습 비용, 추론 시간, 배치 민감도, 결측·주기 변화의 영향을 확인해야 합니다. **[pp.5–8, 12]**

### 12.3 일반화 성능 관점의 최종 판단

**MultiResFormer는 일반화 성능을 연구할 만한 설계 요소를 제공하지만, 새로운 데이터셋으로의 일반화 향상을 입증한 모델로 평가하기에는 증거가 부족합니다.**

가장 설득력 있는 다음 단계는 **적응적 패치 길이와 해상도 임베딩의 효과를 작은 통제 실험으로 재현한 뒤, 시간 변화·변수 변화·데이터셋 전이를 구분하여 평가하는 것**입니다. 이 과정을 거쳐야 현재의 성능 향상이 주기 선택, 파라미터 공유, 정규화 또는 특정 벤치마크 특성 중 무엇에서 비롯되는지 더 정확하게 설명할 수 있습니다.
