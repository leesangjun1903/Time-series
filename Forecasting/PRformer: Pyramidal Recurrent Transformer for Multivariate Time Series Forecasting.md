# PRformer: Pyramidal Recurrent Transformer for Multivariate Time Series Forecasting

**핵심 판단:** PRformer는 **각 변수의 시간적 패턴을 먼저 학습하고, 이후 변수 사이의 관계를 학습하는 설계**가 여러 장기 예측 벤치마크에서 효과적임을 보여 줍니다.  
다만, **학습하지 않은 도메인·변수·분포 변화에 대한 일반화 성능까지 입증한 논문은 아닙니다.**  
특히 다중 스케일 피라미드의 추가 효과와 통계적 신뢰성은 후속 검증이 필요합니다. [원문 pp.6–8, Tables 4–5, Figures 3–4]

## 1. Executive summary — 9문장

1. PRformer는 기존 Transformer가 긴 시계열의 순서와 여러 시간 규모의 패턴을 충분히 활용하지 못한다는 문제의식에서 출발합니다. [원문 pp.1–2]
2. 핵심 모듈인 **Pyramidal RNN Embedding, PRE**는 피라미드 합성곱으로 시계열을 여러 규모로 압축하고, 규모별 GRU로 순서를 반영한 표현을 학습합니다. [원문 pp.3–4, Figure 1, Eqs.2–4]
3. PRformer의 Transformer는 PRE가 생성한 **변수별 표현을 토큰으로 사용하여 변수 사이의 관계**를 학습하고, 선형층으로 미래 값을 예측합니다. [원문 pp.3–5, Figure 2, Eqs.1·5]
4. 저자는 8개 데이터셋에서 과거 720개 시점으로 미래 96·192·336·720개 시점을 예측하는 실험을 수행했습니다. [원문 p.5, Table 2; p.7, Table 4]
5. PRformer는 32개 데이터셋·예측 길이 조합 중 **MSE 25개, MAE 28개에서 최저 오차**를 기록했습니다. [원문 p.7, Table 4]
6. 그러나 PatchTST보다 항상 우수하지는 않으며, 인쇄 수치를 평균하면 Solar-Energy의 MSE는 25.00% 낮지만 ETTh1·ETTh2의 평균 MSE는 오히려 높습니다. [재계산: 원문 p.7, Table 4]
7. PRE를 Transformer·Reformer·Informer·Flowformer에 적용한 실험은 여러 예측 구조에 이 모듈을 결합할 수 있음을 보여 줍니다. [원문 p.6, Table 3; p.12, Table 7]
8. 긴 관측창 활용과 훈련 자원 효율에 관한 실험도 긍정적이지만, 각각 일부 데이터셋과 특정 실행 조건에서 확인된 결과입니다. [원문 p.8, Figures 3–4]
9. 반복실험의 분산·신뢰구간과 미관측 도메인·변수에 대한 전이 실험이 보고되지 않았으므로, 일반화에 관한 결론은 평가된 벤치마크와 설정 범위에 한정해야 합니다. [해석: 원문 pp.5–12의 실험 및 부록]

> **용어 설명**
>
> - **다변량 시계열**: 온도·습도·풍속처럼 여러 변수를 시간에 따라 함께 기록한 데이터입니다.
> - **임베딩**: 긴 입력을 모델이 처리하기 좋은 고정 길이 숫자 벡터로 표현한 것입니다.
> - **GRU**: 이전 정보를 얼마나 기억하고 갱신할지 조절하면서 순서대로 데이터를 읽는 순환신경망입니다.
> - **MSE / MAE**: 각각 예측오차의 제곱 평균과 절댓값 평균입니다. 둘 다 낮을수록 좋으며, MSE는 큰 오차에 더 민감합니다.

## 2. 연구 배경·목표·필요성

### 2.1 해결하려는 문제

**[저자 보고]** 논문은 다음 세 문제를 연결합니다.

첫째, 기존 Transformer는 시계열의 순서를 처리하기 위해 위치 인코딩에 의존하며, 저자는 이러한 방식이 시간적 패턴을 표현하는 데 제약이 될 수 있다고 주장합니다.  
특히 과거 관측창을 늘려도 예측이 개선되지 않거나 악화되는 현상에 주목합니다. [원문 p.1; pp.9–10, Eqs.7–8]

둘째, 시간점마다 토큰을 만드는 일반적인 자기주의는 입력 길이가 늘면 계산량이 빠르게 증가합니다.  
따라서 긴 과거 정보를 활용하려면 **시간적 정보를 보존하면서 처리할 시퀀스 길이를 줄이는 방법**이 필요합니다. [원문 pp.1–2]

셋째, 실제 시계열에는 일별·수일별 변화처럼 여러 시간 규모의 패턴이 공존할 수 있습니다.  
저자는 큰 규모의 변화와 작은 규모의 변화를 함께 표현해야 한다고 봅니다. [원문 pp.2–3]

> **용어 설명**
>
> - **관측창·룩백 윈도**: 예측할 때 참고하는 과거 구간입니다.
> - **위치 인코딩**: 모델에 “이 값이 몇 번째 시점에 있는가”를 알려 주는 숫자 표현입니다.
> - **자기주의, self-attention**: 입력 요소끼리의 관계를 계산하여, 어떤 정보를 얼마나 참고할지 정하는 연산입니다.
> - **시간 규모·스케일**: 몇 시간 단위의 변화와 며칠 단위의 변화처럼 패턴을 바라보는 시간적 해상도입니다.

### 2.2 연구 목적

이 연구의 목적은 **시간축의 표현 학습과 변수축의 관계 학습을 역할별로 분리하여 결합하는 것**입니다. [원문 pp.2–4, Figure 2]

- **PRE**는 각 변수의 과거 시계열에서 순서와 여러 규모의 패턴을 학습합니다.
- **Transformer encoder**는 PRE로 표현된 변수 사이의 의존성을 학습합니다.
- **선형 예측층**은 각 변수의 표현을 미래 예측값으로 변환합니다.

**[해석]** 이 논문의 중심 기여는 새로운 attention 공식을 만드는 것보다, **Transformer에 어떤 단위의 표현을 입력할 것인가를 재설계한 데** 있습니다.  
변수 전체를 하나의 토큰으로 사용하는 접근 자체와 PRE의 구체적 구성은 구분해야 하며, 이 차이는 iTransformer와의 비교에서 특히 중요합니다. [원문 pp.3–4, Figure 2; 관련 연구 비교는 §9]

### 2.3 연구의 필요성을 평가하면

**[해석]** 연구의 필요성은 분명합니다. 긴 이력을 처리하는 비용, 시간 순서를 반영하는 능력, 변수 간 관계를 함께 고려하기 때문입니다.  
다만 **“위치 인코딩 때문에 Transformer가 실패한다”는 설명은 저자의 설계 가설**이며, 이 논문의 실험만으로 모든 시계열 Transformer의 성능 차이를 설명하는 일반 법칙이 되지는 않습니다. [원문 pp.1–3; pp.9–10, Eqs.7–8]

## 5. 제안 방법과 모델 구조 — 수식 중심 설명

### 5.1 기호와 전체 처리 과정

원문은 $L$을 입력 길이와 encoder 층 수에 중복 사용합니다. 혼동을 피하기 위해 아래에서는 다음처럼 표기를 통일합니다.

| 기호 | 의미 |
|---|---|
| $L$ | 과거 입력 길이 |
| $H$ | 미래 예측 길이 |
| $C$ | 변수 수 |
| $D$ | 변수 하나의 임베딩 차원 |
| $J$ | Transformer encoder 층 수 |
| $S$ | PRE의 스케일 수 |
| $W_s$ | 스케일 $s$의 설정 주기·시간창 길이 |
| $\tau$ | 스케일 가중치 softmax의 온도 |

입력과 예측 대상은 다음과 같습니다.

$$
\mathbf X\in\mathbb R^{L\times C},
\qquad
\mathbf Y\in\mathbb R^{H\times C}.
$$

여기서 $\mathbf X$의 각 열은 한 변수의 과거 이력이며, $\mathbf Y$의 각 열은 그 변수의 미래 값입니다. [원문 p.3]

원문 Eq.1의 핵심 과정은 다음과 같습니다.

```math
\mathbf h_i^{(0)}
=
\text{PREmbedding}(\mathbf X_{:,i}),
\qquad i=1,\ldots,C,
```

```math
\mathbf Z^{(j+1)}
=
\text{Encoder}_j\left(\mathbf Z^{(j)}\right),
\qquad j=0,\ldots,J-1,
```

```math
\hat{\mathbf Y}_{:,i}
=
\text{Projection}\left(\mathbf h_i^{(J)}\right).
```

- $\mathbf h_i^{(j)}\in\mathbb R^D$: 변수 $i$의 $j$번째 층 표현입니다.
- $\mathbf Z^{(j)}\in\mathbb R^{C\times D}$: 변수 표현을 행별로 모은 행렬입니다.
- $\text{Projection}$: $D$차원 표현을 $H$개 미래 값으로 바꾸는 선형층입니다.
- 실제 전체 처리에서는 이 과정 앞에 RevIN 정규화, 뒤에 역정규화가 적용됩니다.

**구조의 핵심:** Transformer에 들어가는 토큰 수는 시간 길이 $L$이 아니라 **변수 수 $C$**입니다. [원문 pp.3–5, Figure 2]

> **용어 설명**
>
> - **토큰**: attention이 하나의 처리 단위로 취급하는 입력입니다. PRformer에서는 변수 하나의 과거 이력을 요약한 벡터가 토큰입니다.
> - **선형 투영**: 벡터에 학습 가능한 행렬을 곱해 다른 차원의 벡터로 변환하는 연산입니다.

### 5.2 Bottom-up: 피라미드 합성곱으로 시간 규모를 확대

원문 Eq.2를 기호만 통일하면 다음과 같습니다.

```math
K_s
=
\left\lfloor
\frac{W_s}{W_{s-1}}
\right\rfloor,
```

```math
\mathbf x_s
=
\text{Conv1d}
\left(
\mathbf x_{s-1};
\text{kernel}=K_s,\,
\text{stride}=K_s
\right).
```

- $K_s$: 해당 합성곱의 커널 크기이자 이동 간격입니다.
- $\mathbf x_{s-1},\mathbf x_s$: 이전 규모와 현재 규모의 특징 시퀀스입니다.
- $\lfloor\cdot\rfloor$: 내림 연산입니다.
- $W_s$: 해당 층이 표현하도록 설정한 시간 규모입니다.

Figure 1의 예시에서는 시간 규모가 **24 → 48 → 96**으로 증가하며, 합성곱의 kernel/stride는 차례로 **24, 2, 2**입니다. 각 단계는 더 긴 기간의 정보를 요약하여 GRU가 처리할 시퀀스를 짧게 만듭니다. [원문 p.1, Figure 1; p.3, Eq.2]

> **용어 설명**
>
> - **1차원 합성곱**: 시간축의 인접한 값들을 일정한 가중치로 결합하여 특징을 만드는 연산입니다.
> - **커널**: 한 번에 살펴보는 시간 구간과 그 구간에 적용할 가중치입니다.
> - **stride**: 다음 계산 위치로 이동하는 간격입니다.
> - **다운샘플링**: 시간축의 표현 길이를 줄이는 과정입니다.

**해석상 주의:** 여기서 “주기”는 **설정한 집계 규모**입니다. 해당 주기가 데이터에서 자동으로 발견되었다는 뜻은 아닙니다.

또한 Table 6의 실제 설정에는 `24, 48, 72, 144`처럼 인접 값이 항상 정수배는 아닌 목록이 있습니다. 부록은 여러 convolution–RNN chain으로 구조를 생성한다고 설명합니다. 따라서 이 목록을 하나의 단순한 연속 합성곱 체인으로 읽으면 부정확합니다. [원문 p.11, Table 6 및 Implementation Details of PRE]

### 5.3 Top-down: 큰 규모의 정보를 작은 규모에 결합

원문 Eq.3의 top-down 특징을 $\mathbf u_s$로 바꾸어 표기하면 다음과 같습니다.

```math
\mathbf u_{s-1}
=
\text{Upsample}(\mathbf u_s),
```

```math
\mathbf f_{s-1}
=
\mathbf x_{s-1}
+
\mathbf u_{s-1}.
```

- $\mathbf u_s$: top-down 경로의 특징입니다.
- $\mathbf x_{s-1}$: 같은 규모의 bottom-up 특징입니다.
- $\mathbf f_{s-1}$: 두 경로를 더해 GRU에 전달하는 특징입니다.

최상위에서는 큰 규모의 특징을 복사하여 사용하고, 이를 아래로 업샘플링합니다. Figure 1·2에서 **더한 결과는 각 규모의 GRU로 전달**됩니다. [원문 p.3, Eq.3; pp.1·4, Figures 1–2]

**[저자 보고]** 큰 규모의 변화 정보를 작은 규모에 전달하면, 세부 변화를 큰 흐름에 맞추어 표현할 수 있다고 주장합니다.

**[해석]** 이는 여러 시간 해상도의 정보를 결합하는 설계입니다. 다만 잡음에 강해진다는 설명을 직접 확인하는 별도의 잡음 실험은 제시되지 않습니다.

> **용어 설명**
>
> - **업샘플링**: 특징 시퀀스의 길이를 늘려 다른 해상도의 특징과 결합할 수 있게 만드는 연산입니다.
> - **측면 연결**: 피라미드의 같은 해상도에 있는 두 경로의 특징을 연결하는 구조입니다.
> - 업샘플링은 압축 과정에서 사라진 원자료를 정확히 복구한다는 뜻이 아닙니다.

### 5.4 규모별 GRU와 가중 연결

각 규모의 특징 시퀀스를 별도의 GRU로 처리하고, 마지막 은닉 상태를 사용합니다. 원문 Eq.4를 명확히 쓰면 다음과 같습니다.

```math
\mathbf r_s
=
\text{GRU}_s(\mathbf f_s)_{\text{last}},
\qquad
\mathbf r_s\in\mathbb R^{D/S}.
```

- $\mathbf r_s$: 스케일 $s$를 요약한 마지막 은닉 상태입니다.
- $\mathbf f_s$: 해당 스케일의 시간 순서를 가진 특징 시퀀스입니다.
- 각 GRU의 은닉 차원은 전체 임베딩 차원 $D$를 스케일 수 $S$로 나눈 값입니다.

스케일별 가중치는 다음과 같습니다.

```math
\beta_s
=
\frac{\exp(\alpha_s/\tau)}
{\sum_{q=1}^{S}\exp(\alpha_q/\tau)}.
```

- $\alpha_s$: 학습 가능한 스케일별 계수이며 초기값은 $1/S$입니다.
- $\beta_s$: 정규화된 가중치로, 전체 합은 1입니다.
- $\tau$: 온도 파라미터입니다. 작은 값은 가중치 차이를 더 뚜렷하게 만들 수 있습니다.
- $q$: 분모에서 모든 스케일을 순회하는 인덱스입니다.

최종적으로 가중한 벡터를 연결합니다.

```math
\mathbf h
=
\text{Concat}
\left(
\beta_1\mathbf r_1,\ldots,\beta_S\mathbf r_S
\right)
\in\mathbb R^D.
```

**중요:** 이 연산은 스케일 벡터의 **가중합이 아니라 가중 연결**입니다. 각 스케일의 벡터 구간이 남습니다. [원문 p.4, Eq.4]

부록은 연결 뒤에 $D\rightarrow D$ 선형층을 적용한다고 추가 설명합니다.

```math
\mathbf h_{\text{PRE}}
=
\text{Linear}_{D\rightarrow D}(\mathbf h).
```

이 선형층은 본문 Eq.4에는 나타나지 않고, p.11의 구현 설명에 명시되어 있습니다.

> **용어 설명**
>
> - **은닉 상태**: 순환신경망이 지금까지 읽은 정보를 저장하는 내부 벡터입니다.
> - **게이트**: 정보를 얼마나 유지하거나 갱신할지 조절하는 장치입니다. GRU에는 reset·update gate가 있습니다.
> - **softmax**: 여러 점수를 양수의 비율로 바꾸고, 합이 1이 되도록 만드는 함수입니다.
> - **Concat**: 여러 벡터를 순서대로 이어 붙이는 연산입니다.

**명시되지 않은 사항:** 논문은 $\tau$의 구체적 값을 제시하지 않습니다. 또한 $\alpha_s$는 입력별 함수로 정의되지 않으므로, 이를 **입력마다 주기를 자동 탐지하는 장치**로 설명할 근거는 없습니다. [원문 p.4, Eq.4; p.11, Table 6]

### 5.5 변수 간 multi-head attention

변수 임베딩 행렬 $\mathbf Z\in\mathbb R^{C\times D}$에서 attention head $k$의 질의·키·값을 만듭니다.

$$
\mathbf Q_k=\mathbf Z\mathbf W_k^Q,\qquad
\mathbf K_k=\mathbf Z\mathbf W_k^K,\qquad
\mathbf V_k=\mathbf Z\mathbf W_k^V.
$$

```math
\mathbf A_k
=
\text{Softmax}
\left(
\frac{\mathbf Q_k\mathbf K_k^\top}{\sqrt{d_k}}
\right),
\qquad
\mathbf O_k=\mathbf A_k\mathbf V_k.
```

- $\mathbf W_k^Q,\mathbf W_k^K,\mathbf W_k^V\in\mathbb R^{D\times d_k}$: 학습 가능한 투영 행렬입니다.
- $d_k$: head $k$의 차원입니다.
- $\mathbf Q_k,\mathbf K_k,\mathbf V_k\in\mathbb R^{C\times d_k}$.
- $\mathbf A_k\in\mathbb R^{C\times C}$: 변수 사이의 attention 가중치 행렬입니다.
- $\mathbf O_k\in\mathbb R^{C\times d_k}$: 해당 head의 출력입니다.
- $\top$: 행렬 전치입니다.

**원문 표기 주의:** Eq.5는 좌변을 $(O_k)^\top$로 적지만, 같은 문단에서 정의한 출력 차원과 우변의 차원이 맞지 않습니다. 위 식은 **차원 일관성을 위해 좌변의 전치를 제거한 재표기**입니다. [원문 p.4, Eq.5]

Encoder에는 attention 외에도 잔차 연결, LayerNorm, feed-forward network가 포함됩니다. [원문 pp.4–5, Figure 2]

> **용어 설명**
>
> - **multi-head attention**: 여러 종류의 관계를 병렬로 계산하는 attention입니다.
> - **잔차 연결**: 변환 결과에 원래 입력을 더하여 정보와 학습 신호가 전달되기 쉽게 하는 구조입니다.
> - **LayerNorm**: 한 표현 벡터 내부의 값들을 정규화하는 연산입니다.
> - attention 가중치는 모델이 사용하는 관계를 나타내지만, 그 자체가 인과관계의 증거는 아닙니다.

### 5.6 손실함수와 정규화

학습 손실은 MAE입니다.

```math
\mathcal L_{\text{MAE}}
=
\frac{1}{HC}
\sum_{t=1}^{H}
\sum_{i=1}^{C}
\left|
\hat y_t^{(i)}-y_t^{(i)}
\right|.
```

- $y_t^{(i)}$: 변수 $i$의 미래 시점 $t$ 실제 값입니다.
- $\hat y_t^{(i)}$: 해당 값의 예측입니다.
- $H,C$: 예측 길이와 변수 수입니다.

이 식은 원문 Eq.6에 해당합니다. 평가 지표인 MSE를 같은 기호로 풀어 쓰면 다음과 같습니다.

```math
\text{MSE}
=
\frac{1}{HC}
\sum_{t=1}^{H}
\sum_{i=1}^{C}
\left(
\hat y_t^{(i)}-y_t^{(i)}
\right)^2.
```

원문은 RevIN을 사용하여 입력을 정규화하고, 예측을 역정규화한다고 설명합니다.  
**정규화가 데이터를 정규분포로 만든다고 보장하는 것은 아니며**, RevIN을 사용했다는 사실만으로 모든 분포 변화에 강하다고 결론 내릴 수도 없습니다. [원문 p.5]

### 5.7 계산 복잡도: 저자 주장과 구조 분석의 구분

**[저자 보고]** Table 1은 PRformer의 시간·메모리 복잡도를 다음과 같이 제시합니다.

$$
O\left(\frac{L}{W}+D^2\right).
$$

여기서 $W$는 피라미드 최하단의 시간창 길이이며, $L$은 입력 길이, $D$는 임베딩 차원입니다. [원문 p.5, Table 1]

**[해석]** 그러나 변수 토큰의 개수는 $C$이므로, 일반적인 dense attention의 점수 계산과 값 혼합에는 다음 비용이 발생합니다.

$$
O(C^2D).
$$

질의·키·값의 선형 투영에는 보통 다음 항도 포함됩니다.

$$
O(CD^2).
$$

두 식의 $C$는 변수 수, $D$는 임베딩 차원이며, 이는 **논문의 표를 그대로 옮긴 값이 아니라 구조에서 도출한 분석**입니다.

따라서 정확한 판단은 다음과 같습니다.

- 변수 수·모델 폭·스케일 수를 고정하면, 시간축의 $L^2$ attention을 피한다는 설명은 타당합니다.
- Table 1은 변수 수 $C$, 층 수, GRU 폭, 합성곱 채널 수에 대한 비용을 충분히 구분하지 않습니다.
- **“모든 차원에 대해 전체 비용이 선형”이라는 결론은 뒷받침되지 않습니다.**

| V2 | PRE를 선형 임베딩으로 교체 | 12/32 | 전체 모델이 25개 우수, 3개 동률, 4개 열세 |
| V3 | 피라미드의 최하단 스케일만 사용 | 23/32 | 전체 모델이 **16개 우수, 7개 동률, 9개 열세** |

**출처:** 원문 pp.6–7, Table 5. 마지막 열은 인쇄 수치로 재계산했습니다.

여기서 32는 **4개 데이터셋 × 4개 예측 길이 × 2개 지표**입니다. Table 4의 32와 구성이 다릅니다.

**[해석]** PRE와 변수 attention의 기여는 비교적 넓게 관찰됩니다. 그러나 **다중 스케일 피라미드가 단일 스케일보다 일관되게 우수하다는 증거는 더 제한적**입니다.

실제로 Traffic의 $H=720$에서는 다음과 같습니다.

- 전체 모델: MSE **0.421**, MAE **0.258**
- 단일 스케일 V3: MSE **0.412**, MAE **0.257**

이 결과는 후속 연구에서 복잡한 피라미드를 바로 구현하기보다 **단일 스케일 합성곱+GRU의 효과부터 검증할 이유**를 제공합니다. [원문 p.7, Table 5; 후속 실험 우선순위는 해석]

## 7. 가장 중요한 그림 선정과 해석

### 7.1 최우선: Figure 2 — 전체 구조, p.4

이 그림에서 가장 중요한 부분은 **시간축과 변수축의 역할 분담**입니다.

- PRE는 변수별 과거 시계열을 처리합니다.
- attention은 그 결과인 변수 토큰 사이에 적용됩니다.
- 최종 선형층은 미래 구간을 출력합니다.

**[해석]** 이 구조를 이해하면 PRformer가 “시간점 사이 attention을 더 효율적으로 계산하는 모델”과 어떻게 다른지 분명해집니다. 성능 향상의 핵심 후보는 **시간 표현을 PRE에 맡긴 선택**입니다. [원문 Figure 2, pp.3–5]

### 7.2 상세 구조: Figure 1 — PRE, p.1

Figure 1은 다음의 결합을 보여 줍니다.

- bottom-up 합성곱
- top-down 업샘플링과 측면 덧셈
- 스케일별 GRU
- 가중 연결

**[해석]** 단순히 여러 크기의 합성곱을 병렬로 사용하는 것보다, **큰 규모의 정보를 작은 규모에 전달한 뒤 각각의 순서 정보를 읽는다**는 점이 핵심입니다. 다만 실제 피라미드 구조는 설정값에 따라 생성되므로, 그림의 세 층을 모든 실험의 고정 구조로 읽어서는 안 됩니다. [원문 p.1, Figure 1; p.11]

### 8.3 위치 인코딩에 관한 이론적 주장도 제한해서 읽어야 한다

**[저자 보고]** 부록은 사인·코사인 위치 인코딩의 내적이 시간차에만 의존함을 보입니다.

```math
\mathbf p_t^\top\mathbf p_{t+\Delta}
=
\sum_{k=0}^{D_p/2-1}
\cos(\omega_k\Delta),
\qquad
\omega_k=10000^{-2k/D_p}.
```

- $\mathbf p_t$: 시점 $t$의 사인·코사인 위치 인코딩 벡터입니다.
- $\Delta$: 두 시점 사이의 차이입니다.
- $D_p$: 위치 인코딩 차원입니다.
- $\omega_k$: 차원 쌍 $k$에 해당하는 주파수입니다.

이 식은 원문 Eqs.7–8의 내용을 간략히 정리한 것입니다. [원문 pp.9–10]

**[해석]** 이 등식 자체는 맞지만, 실제 attention에는 데이터 내용과 학습된 질의·키 투영도 포함됩니다. 따라서 **위치 벡터끼리의 내적 성질만으로 전체 Transformer가 비정상 시계열의 의존성을 학습할 수 없다고 증명되지는 않습니다.**

또한 순서 정보가 없는 자기주의는 엄밀히는 입력 순서를 바꾸면 출력 순서도 함께 바뀌는 **순열 등변성**을 가집니다. 원문의 “순서에 불변”이라는 표현은, 순서를 별도로 알려 주지 않으면 시간적 위치를 구별하기 어렵다는 문제의식으로 읽는 것이 적절합니다.

> **용어 설명**
>
> - **비정상 시계열**: 평균·분산·상관관계 등 데이터의 통계적 특성이 시간에 따라 달라지는 시계열입니다.
> - **평행이동 불변성**: 전체 시간 위치를 같이 이동해도 어떤 계산 결과가 달라지지 않는 성질입니다.
> - **순열 등변성**: 입력의 나열 순서를 바꾸면 출력도 같은 순서로 바뀌는 성질입니다.

### 8.4 저자가 직접 언급한 한계는 무엇인가?

**PRformer 자체의 한계를 체계적으로 정리한 별도 limitations 절은 없습니다.**

pp.9–10의 **“Limitations of Positional Encoding”**은 기존 Transformer의 위치 인코딩에 대한 비판입니다. PRformer의 제한사항을 정리한 절로 소개하면 부정확합니다.

저자는 기존 RNN의 고정 크기 은닉 상태와 기울기 소실·폭발 문제를 설명하고, 합성곱으로 시퀀스를 줄이는 것을 설계 동기로 제시합니다. 하지만 이러한 문제를 PRformer가 수학적으로 제거했다고 증명하지는 않습니다. [원문 pp.1–2]

> **용어 설명**
>
> **기울기 소실·폭발**은 긴 계산 경로를 따라 학습 신호가 지나갈 때 지나치게 작아지거나 커지는 현상입니다.

### 8.5 문서가 답하지 않는 질문

1. **성능 향상의 주된 원인은 무엇인가?**  
   GRU, 합성곱 압축, 변수 토큰화, 다중 스케일, RevIN 중 무엇이 얼마나 기여하는지 완전히 분리되어 있지 않습니다.

2. **다중 스케일이 필요한 조건은 무엇인가?**  
   V3가 전체 모델보다 좋은 경우가 있는데, 어떤 데이터 특성이 피라미드의 효과를 결정하는지 분석하지 않습니다.

3. **주기 설정은 새 데이터에서도 그대로 사용할 수 있는가?**  
   주기 목록의 선택 민감도와 도메인 간 재사용성이 평가되지 않았습니다.

4. **새 변수·새 도메인으로 전이되는가?**  
   동일 데이터셋 시험 성능과 다른 수준의 질문이며, 별도 검증이 없습니다.

5. **하나의 변수 이력을 고정 길이 벡터로 압축할 때 어떤 정보가 손실되는가?**  
   급격한 변화나 짧은 사건의 정보가 얼마나 보존되는지 분석하지 않습니다.

6. **변수 관계가 바뀌거나 일부 변수가 손상되면 어떻게 되는가?**  
   결측·잡음·변수 추가·변수 간 시간 정렬 변화에 대한 통제 실험이 없습니다.

7. **실제 배포의 예측 불확실성과 지연시간은 어떠한가?**  
   예측구간의 신뢰도나 추론 지연시간을 체계적으로 평가하지 않습니다.

**근거 범위:** 원문 pp.3–12의 방법·실험·부록. 위 항목은 문서의 공백에 대한 분석이며, 성능이 반드시 나쁘다는 주장은 아닙니다.

## 9. 2020년 이후 관련 연구 비교 분석

다음 표는 PRformer와 직접적인 설계 관계가 있거나, **일반화 평가를 어떻게 확장할지 보여 주는 연구**를 선정한 것입니다. 마지막 열은 각 연구의 설계에 근거한 분석입니다.

### 9.1 대표 연구 비교

|---|---|---|

> - **주파수 표현**: 시계열을 얼마나 빠르게 반복되는 변화들로 구성되어 있는지 살펴보는 표현입니다.
> - **패치**: 연속된 여러 시간점을 한 묶음으로 만든 입력 단위입니다.
> - **채널 독립 처리**: 변수별로 시계열을 처리하는 방식입니다. 모델 가중치는 변수 사이에 공유할 수 있습니다.
> - **자기지도 사전학습**: 정답 라벨 대신 입력의 일부를 가리고 복원하는 등의 과제로 표현을 미리 학습하는 방법입니다.
> - **외생변수·공변량**: 예측 대상 외에 참고하는 입력입니다. 예를 들어 전력 수요 예측에서 기온이나 휴일 정보가 해당합니다.
> - **few-shot**: 적은 학습자료를 사용하는 조건입니다.
> - **zero-shot**: 목표 데이터나 과제에 대한 추가 학습 없이 예측하는 조건입니다. 사전학습 자료와 목표 자료의 중복 여부를 함께 확인해야 합니다.
> - **파운데이션 모델**: 여러 데이터에서 미리 학습하여 다양한 과제에 재사용하도록 만든 모델입니다.

### 9.2 일반화 연구에서 특히 참고할 차이

**첫째, “일반화”를 평가 대상별로 나눠야 합니다.**

PatchTST는 다른 데이터셋으로의 **전이 후 학습**, iTransformer는 같은 데이터셋의 **미관측 변수 예측**, TimeMixer++는 **소량 데이터와 추가 학습 없는 데이터셋 간 전이**를 각각 평가합니다. 이들은 서로 다른 실험입니다. PRformer가 비슷한 구조를 가진다고 해서 해당 능력이 자동으로 확인되는 것은 아닙니다. [arxiv.org](https://arxiv.org/html/2211.14730v2?utm_source=chatgpt.com)

**둘째, 최신 사전학습 모델에서도 데이터 중복을 확인해야 합니다.**

Chronos-2는 fev-bench의 데이터·과제를 학습 중 보지 않았다고 보고하지만, GIFT-Eval에서는 일부 데이터셋의 **훈련 구간과 사전학습 자료의 중복**을 명시합니다. 시험 구간 중복과 훈련 구간 중복은 구분해야 하며, 모든 평가를 같은 강도의 zero-shot 근거로 묶어서는 안 됩니다. [Chronos-2 §5.1] [arxiv.org](https://arxiv.org/html/2510.15821v1?utm_source=chatgpt.com)

**셋째, PRformer의 연구 가치는 모듈 단위로 검증하는 것이 적절합니다.**

**[해석]** 관련 연구를 고려하면, PRformer의 가장 구체적인 연구 질문은 다음과 같습니다.

> “변수 간 관계 학습 구조를 고정했을 때, 합성곱과 GRU를 결합한 시간 표현이 선형·패치·분해 기반 표현보다 어떤 조건에서 더 잘 일반화하는가?”

이는 현재 논문에서 제기할 수 있는 후속 질문입니다. **후속 연구가 PRformer를 직접 채택하거나 영향을 받았다는 인용 관계는 이 분석에서 확인하지 않았으므로, 실제 영향력을 단정하지 않습니다.**

## 10. 결론·시사점·우선 검증할 기술

### 10.1 저자가 제시한 시사점과 후속 방향

**[저자 보고]** 논문은 시계열 Transformer의 성능을 높이기 위해 attention뿐 아니라 **시간적 표현 자체의 품질**에 주목해야 한다고 제안합니다. PRE를 더 다양한 효율적 Transformer 예측기에 결합하고, RNN과 Transformer를 통합하는 연구가 이어지기를 기대합니다. [원문 p.6; p.8, Conclusion]

공식 저장소에는 다른 시계열 과제에 PRformer를 적용하고 더 많은 Transformer 변형과 결합하는 방향도 기재되어 있습니다. 이는 **첨부 v1 본문과 구분되는 공식 저장소의 후속 계획**입니다. [GitHub](https://github.com/usualheart/PRformer?utm_source=chatgpt.com)

### 10.2 학술적·실용적 의미

**[해석: 학술적 의미]** PRformer는 시간 의존성과 변수 의존성을 서로 다른 모듈에 맡기는 설계를 검토할 근거를 제공합니다. 특히 변수 간 attention을 고정하고 시간 임베딩만 바꾸는 비교는, 예측 성능의 원인을 더 명확하게 분석하는 데 유용합니다. [근거: 원문 Figure 2, Table 5]

**[해석: 실용적 의미]** Figure 4의 조건에서는 PatchTST보다 훈련 시간과 메모리 사용이 적습니다. 비슷한 입력 구성과 실행 환경에서 검증한다면 자원 제약이 있는 예측 시스템의 후보가 될 수 있습니다. 다만 실제 배포 적합성은 추론 지연시간, 변수 수 증가, 결측 처리, 예측 불확실성을 추가 측정해야 판단할 수 있습니다. [근거: 원문 p.8, Figure 4]

### 10.4 일반화 성능을 중점으로 한 후속 연구

**[제안 1: 미관측 변수]**  
iTransformer의 Figure 5처럼 일부 변수로 학습한 뒤 나머지 변수를 예측하는 실험을 수행합니다. 먼저 PRE와 출력층의 파라미터 공유 및 변수 수 변경 가능성을 확인해야 합니다. 이 실험은 PRE가 특정 변수에만 맞춰진 표현인지 검증합니다. [arxiv.org](https://arxiv.org/html/2310.06625v4?utm_source=chatgpt.com)

**[제안 2: 데이터셋 간 전이]**  
ETT 계열의 한두 전이 방향부터 시작하고, **추가 학습 없는 적용**, **마지막 선형층만 학습**, **전체 미세조정**을 분리합니다. 이 구분은 PRE의 표현 재사용성과 목표 데이터 적응 효과를 구별하는 데 필요합니다. 관련 실험 설계는 PatchTST Table 5와 TimeMixer++ Table 6에서 확인할 수 있습니다. [arxiv.org](https://arxiv.org/html/2211.14730v2?utm_source=chatgpt.com)

**[제안 3: 주기 설정과 강건성]**  
주기 목록을 약간 바꾸거나 일부 변수를 누락시키는 조건에서 성능 변화를 측정합니다. 우선 수동 주기 설정의 민감도를 확인한 뒤, 자동 주기 선택 같은 복잡한 확장 여부를 결정하는 것이 합리적입니다. [제안 근거: PRformer p.11, Table 6; TimeXer Table 5] [arxiv.org](https://arxiv.org/html/2402.19072v2?utm_source=chatgpt.com)

**[제안 4: 통계 보고 강화]**  
주요 비교에는 여러 random seed의 평균·표준편차를 보고하고, 같은 시험 구간에서의 오차 차이를 분석해야 합니다. 시계열의 인접 시점은 서로 연관되므로, 신뢰구간을 계산할 때도 시간 구간의 의존성을 고려하는 방식이 적절합니다.

> **용어 설명**
>
> - **random seed**: 초기 가중치나 데이터 처리의 무작위성을 재현하기 위한 설정값입니다.
> - **선형층만 학습하는 평가, linear probing**: 학습된 표현은 고정하고 마지막 간단한 예측층만 학습하여 표현의 재사용성을 확인하는 방법입니다.
> - **강건성**: 입력이 일부 손상되거나 조건이 바뀌어도 성능을 유지하는 정도입니다.

**최종 평가:** PRformer에서 가장 먼저 이어받아 검증할 아이디어는 **합성곱으로 줄인 시퀀스를 GRU로 표현하고, 변수 간 관계 학습과 결합하는 방식**입니다. 다중 스케일과 학습 가중치의 추가 가치는 별도로 검증해야 하며, 일반화 성능의 향상을 주장하려면 기존 벤치마크 점수에 더해 **미관측 변수·데이터셋 전이·분포 변화 실험**이 필요합니다. [해석 근거: 원문 Figure 2, Tables 4–5]
