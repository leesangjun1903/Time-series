## 1. Executive Summary (10문장 이내)

1. 본 논문은 LLM(대형 언어 모델)을 **추가 파인튜닝 없이 제로샷(zero-shot)** 시계열 예측기로 활용할 때의 특성과 한계를 체계적으로 분석한다.
2. GPT-3.5-turbo, GPT-4-turbo, Gemini-1.0-Pro, Llama-2-13B를 대상으로 Darts 벤치마크 및 합성 데이터셋에서 실험을 수행하였다.
3. LLM은 **명확한 추세(trend)와 계절성(seasonality)을 가진 시계열**에서 전통적 모델 대비 우수한 성능을 발휘하나, 비주기적 데이터에서는 한계를 보인다.
4. STL 분해를 통해 정량화된 추세 강도 $Q_T$와 계절 강도 $Q_S$는 모델 성능(MAPE)과 강한 음의 상관관계를 보인다 (계절 강도 기준 Pearson $r \approx -0.68$).
5. 반사실적(counterfactual) 실험을 통해 LLM은 **입력 시퀀스의 후반부(출력에 가까운 부분)**에 더 민감하게 반응함을 확인하였다.
6. LLM은 명확한 계절성을 가진 데이터셋의 **주기(period)를 상당히 높은 정확도로 인식**할 수 있으며, 이것이 계절성 강한 데이터에서의 우수한 성능을 설명한다.
7. 두 가지 성능 향상 기법을 제안한다: **(1) 외부 지식(External Knowledge Enhancing, EKE)** 프롬프트 삽입, **(2) 자연어 표현(Natural Language Paraphrasing, NLP)** 시퀀스 변환.
8. NLP 방법은 거의 모든 모델과 데이터셋에서 LLMTime 기준 대비 MSE/MAE/MAPE를 대폭 낮추었으며, 특히 AirPassengers에서 GPT-3.5 기준 MAPE 14.43 → 0.99로 감소하였다.
9. 다중 주기를 가진 시계열에서는 주기 수가 늘어날수록 성능이 저하되어 LLM의 다중 주기 인식 능력에 한계가 있음을 시사한다.
10. 본 연구는 LLM 기반 시계열 예측의 능력·편향·한계를 정량적으로 분석한 첫 체계적 연구로, 후속 연구의 기준점(benchmark)을 제시한다.

### 2-1. 해결 문제 / 제안 방법 / 모델 구조 / 성능 향상 및 한계

#### ① 해결하고자 하는 문제

- LLM 기반 제로샷 시계열 예측에서 **어떤 유형의 데이터가 잘 예측되는가?**
- 입력 시퀀스의 **어느 구간**이 예측에 더 중요한가?
- LLM의 계절 인식 능력이 예측 성능을 어떻게 설명하는가?
- 파인튜닝 없이 **어떻게 성능을 더 향상**시킬 수 있는가?

#### ② 제안하는 방법 (수식 포함)

**[기본 예측 공식]** (Equation 1, p.2)

$$\hat{X}_t, \ldots, \hat{X}_{t+H-1} = F(X_{t-1}, \ldots, X_{t-K}; V; \lambda)$$

- $H$: 예측 스텝 수, $K$: 입력 스텝 수, $V$: 프롬프트, $\lambda$: 모델 파라미터

**[추세·계절 강도 정량화]** (Equation 5, p.3) — STL 분해 기반

$$Q_T = 1 - \frac{\text{Var}(X_R)}{\text{Var}(X_T + X_R)}, \quad Q_S = 1 - \frac{\text{Var}(X_R)}{\text{Var}(X_S + X_R)}$$

- $X_T$: 추세 성분, $X_S$: 계절 성분, $X_R$: 잔차 성분
- $Q_T, Q_S \in [0, 1]$: 값이 클수록 강한 추세/계절성

**[평가 지표]** (Equations 2–4, p.2)

$$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2, \quad \text{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|, \quad \text{MAPE} = \frac{1}{n}\sum_{i=1}^{n}\left|\frac{y_i - \hat{y}_i}{y_i}\right|$$

**[외부 지식 삽입 (EKE)]** (Section 5.2, p.6)

$$V_e = z + V_s$$

- $V_s$: 원본 프롬프트, $z$: 데이터셋 배경 정보(외부 지식)

**[자연어 표현 (NLP)]** (Section 5.3, p.6)

시계열 $X = [X_1, X_2, \ldots, X_n]$에 대해:

$$\text{"The value rises from } X_t \text{ to } X_{t+1} \text{, and falls from } X_{t+1} \text{ to } X_{t+2} \ldots"$$

**[합성 데이터 생성 함수]** (Section 3.2.1, p.3)

$$y = \alpha \cdot x + \beta_1 \cdot \cos(2\pi f_1 x) + \beta_2 \cdot \cos(2\pi f_2 x) + \epsilon, \quad \epsilon \sim \mathcal{N}(0, 1)$$

#### ③ 모델 구조

```
입력 시계열
    ↓ 전처리 (스케일링, 숫자→문자열, 스페이스 토크나이제이션)
    ↓ [옵션 A] EKE: 외부 지식(z) 프롬프트 앞에 삽입 → Ve = z + Vs
    ↓ [옵션 B] NLP: 숫자 시퀀스 → 자연어 설명 변환
    ↓ LLM (GPT-3.5/4-turbo, Gemini-1.0-Pro, Llama-2-13B)
    ↓ 출력 파싱 → 예측값 추출
예측 결과
```

#### ④ 성능 향상 및 한계

| 구분 | 내용 |
|------|------|
| **성능 향상** | NLP: AirPassengers GPT-3.5 MAPE 14.43→0.99 (−93%); EKE: MonthlyMilk GPT-3.5 MAPE 112.77→6.25 (−94%) |
| **한계 ①** | 비주기적 데이터(SunspotsDataset 등)에서 LLM 성능 불안정 (MAPE 수백%) |
| **한계 ②** | 다중 주기 시계열에서 주기 수 증가 시 성능 저하 |
| **한계 ③** | NLP 방법은 토큰 비용이 약 4배 증가 (200→797 토큰, Table 7) |
| **한계 ④** | 단변량(univariate) 예측에만 집중, 다변량 검증 부재 |
| **한계 ⑤** | 일부 모델(GPT-4 EKE)에서 ETTm2 MAPE 1.607→291.67로 오히려 악화 |

## 7. 가장 중요한 그림 5개 해석

### Figure 1 (p.3) — 전체 워크플로우

```
[입력] 시계열 수치 데이터
  ├─→ [분석] STL 분해 → 추세·계절·잔차 강도 산출 → LLM 선호도 규명
  ├─→ [EKE] 외부 지식(z) + 원본 프롬프트 → 개선된 프롬프트
  └─→ [NLP] 수치 → 자연어 서술 변환 → 자연어 프롬프트
         ↓
       LLM (GPT/Gemini/Llama)
         ↓
       예측값 출력
```

**해석**: 이 그림은 논문의 3가지 연구 흐름(선호도 분석, 주기 인식, 성능 향상)을 하나의 파이프라인으로 통합하여 보여준다. 특히 EKE와 NLP가 프롬프트와 시퀀스 입력에 각각 독립적으로 작용한다는 점에서 두 방법의 직교적(orthogonal) 성격을 시각화한다.

### Figure 2 (p.6) — GPT-3.5-turbo 반사실 실험

## 8. 결론: 시사점, 후속 연구 계획, 추가 방향

### 8-1. 저자 제시 시사점 및 후속 연구 계획

**시사점** (Section 7, p.7–8):
- LLM은 제로샷 설정에서 계절·추세 패턴 인식 능력을 이미 보유하고 있으며, 이는 파인튜닝 없이도 실무 활용 가능함을 의미
- 입력 전략(프롬프트 구성, 시퀀스 표현 방식)이 LLM 예측 성능에 결정적 영향을 미침
- WoolyDataset의 주기 오인식 등 **LLM의 토큰 수준 편향**에 대한 심층 분석이 필요

**저자 명시 후속 연구**:
- WoolyDataset의 주기 3 오예측 메커니즘 분석 ("We leave a comprehensive analysis of this phenomenon in the future", p.4)
- 본 연구를 시계열 분석의 벤치마크로 확립하고 후속 연구 인사이트 제공

---

### 8-1. 모델의 일반화 성능 향상 가능성 (중점)

**현재 일반화의 한계**:

| 한계 요소 | 내용 |
|-----------|------|
| 데이터 다양성 | 10개의 단변량 시계열로만 검증 → 다변량, 고빈도, 금융, 의료 등 도메인 미검증 |
| 모델 버전 고정 | GPT-3.5-turbo-1106 기준 → 모델 업데이트 시 재현 불가 |
| 언어 편향 | 영어 프롬프트만 사용 → 다국어 환경 일반화 미검증 |
| 예측 horizon | 단일 horizon 설정 → 단기/장기 예측 간 일반화 미검증 |

**일반화 향상을 위한 제안**:

1. **도메인 적응형 EKE**: 외부 지식을 자동으로 검색(RAG, Retrieval-Augmented Generation)하여 도메인에 구애받지 않는 지식 삽입 파이프라인 구축

2. **앙상블 전략**: 여러 LLM의 예측을 가중 평균하여 단일 모델 편향 감소

$$\hat{X}_{ensemble} = \sum_{k=1}^{K} w_k \cdot \hat{X}^{(k)}, \quad \sum_{k=1}^{K} w_k = 1$$

여기서 $w_k$는 검증 집합 성능 기반 가중치

3. **Few-shot 도메인 적응**: 제로샷에서 소수 샷(few-shot)으로 확장하여 새로운 도메인에서의 일반화 성능 향상

4. **패턴 강도 기반 라우팅**: $Q_S, Q_T$ 값에 따라 LLM 사용 여부를 결정하는 하이브리드 라우터 설계 (높은 계절성→LLM, 낮은 계절성→전통 모델)

### 8-2. 2020년 이후 최신 연구 비교 분석

| 연구 | 연도 | 방법 | 본 논문과의 관계 |
|------|------|------|----------------|
| **LLMTime** (Gruver et al.) | 2023 | 제로샷 LLM 예측기, 숫자→문자 변환 | 본 논문의 직접 기반 및 비교 대상 [6] |
| **Time-LLM** (Jin et al.) | 2023 | 텍스트 프로토타입으로 시계열 재프로그래밍 후 LLM 입력 | NLP 방법의 영감 원천 [24]; 본 논문은 파인튜닝 없는 대안 제시 |
| **Lag-Llama** (Rasul et al.) | 2023 | 시계열 파운데이션 모델 사전훈련 | 파인튜닝 기반 접근법 [7]; 본 논문은 제로샷의 경쟁력 입증 |
| **TimeGPT-1** (Garza & Mergenthaler-Canseco) | 2023 | 대규모 시계열 데이터로 사전훈련된 전용 모델 | 상업적 불투명성 문제 지적 [19] |
| **TEMPO** (Cao et al.) | 2023 | 프롬프트 기반 GPT 시계열 예측 | 파인튜닝 필요 vs. 본 논문 제로샷 비교 [21] |
| **LLM4TS** (Chang et al.) | 2024 | 2단계 파인튜닝 전략 | 데이터 효율적 접근 [22] |
| **PromptCast** (Xue & Salim) | 2023 | 프롬프트 기반 학습 패러다임 | 프롬프트 설계의 선행 연구 [25] |
| **TEST** (Sun et al.) | 2023 | 텍스트 프로토타입 임베딩으로 LLM 능력 활성화 | 입력 재표현 방식 비교 [8] |

**본 논문이 앞으로의 연구에 미치는 영향**:

1. **LLM 입력 선호도 분석의 표준화**: $Q_T, Q_S$ 기반 데이터셋 특성 분류가 향후 LLM 시계열 연구의 평가 기준으로 활용될 수 있다.
2. **프롬프트 엔지니어링의 체계화**: EKE와 NLP라는 두 축(프롬프트 내용 vs. 시퀀스 표현)이 향후 연구의 설계 공간으로 자리잡을 것이다.
3. **하이브리드 모델 설계 근거**: 계절성 기반 LLM 라우팅 전략의 이론적 근거를 제공한다.

**앞으로 연구 시 고려할 점**:

| 고려 사항 | 세부 내용 |
|-----------|-----------|
| **재현성 확보** | LLM API 버전 고정 및 temperature=0 설정, seed 명시 필요 |
| **다변량 확장** | 변수 간 상관 구조가 있는 다변량 시계열에서의 NLP/EKE 효과 검증 |
| **비용 분석** | NLP 방법의 4배 토큰 비용을 고려한 비용-성능 파레토 최적화 연구 |
| **자동 EKE** | 수동 외부 지식 구성의 한계를 극복하는 자동화(RAG, 위키피디아 검색 등) 방법 연구 |
| **LLM 버전 의존성** | 모델 업데이트(GPT-4o, Claude 3.5 등)에 따른 성능 변화 추적 연구 필요 |
| **불확실성 정량화** | 예측의 신뢰구간 제공을 위한 LLM 앙상블 또는 베이지안 접근법 통합 |
| **개념 이동 대응** | 비정상(non-stationary) 시계열에서 EKE의 동적 갱신 전략 연구 |
