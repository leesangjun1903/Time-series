# MCformer: Multivariate Time Series Forecasting with Mixed-Channels Transformer

**핵심 판단:** MCformer는 **목표 채널에 제한된 수의 다른 채널을 함께 입력하는 방식**으로, 채널 독립 모델의 장점을 유지하면서 채널 간 정보를 활용하려는 연구입니다.  
첨부 논문의 표에서는 PatchTST 대비 일관된 MSE 개선을 확인할 수 있습니다.  
다만 **일부 순위 표기에 오류가 있고, 다른 데이터셋·새로운 채널·분포 변화에 대한 일반화 성능은 별도로 검증되지 않았습니다.**  
따라서 “유망한 입력 구성 방법”이라는 평가와 “일반화 성능이 입증된 모델”이라는 평가는 구분해야 합니다. [원문 pp. 2–6, Fig. 2–3, Table II]

## 분석 기준

보고서에서는 다음을 구분합니다.

- **[저자 보고]**: 원문에 직접 서술되거나 표·그림에 제시된 내용입니다.
- **[재계산]**: 원문에 공개된 숫자로 다시 계산한 결과입니다.

## 1. Executive summary — 8문장

1. MCformer는 전력·교통·기상처럼 여러 변수의 시간 변화를 함께 예측하는 **다변량 시계열 예측**을 대상으로, 시간적 패턴과 변수 간 관계를 동시에 활용하려는 모델입니다. [pp. 1–3]
2. 저자는 채널별로 독립적인 입력을 처리하는 **CI(Channel Independence)**가 다른 채널의 정보를 직접 활용하지 못하고, 여러 채널을 함께 처리하는 **CD(Channel Dependence)**는 불필요한 채널 정보로 장기 패턴 학습을 방해할 수 있다는 문제를 제기합니다. [pp. 1–2, Fig. 1]
3. 제안하는 Mixed Channels 전략은 목표 채널에 소수의 다른 채널을 함께 쌓아 입력하고, 목표 채널별 입력들이 Transformer 인코더의 가중치를 공유하도록 구성합니다. [pp. 2–4, Fig. 2–3]
4. 모델은 RevIN 정규화, 채널 혼합, 시간 구간을 묶는 패치화, 투영, 일반적인 Transformer 인코더, 선형 예측 헤드와 역정규화로 구성됩니다. [pp. 3–5, Fig. 3, Algorithm 1]
5. 저자는 5개 데이터셋과 데이터셋별 4개 예측 길이에서 8개 비교 모델을 평가했으며, 공개된 표에서는 MCformer의 MSE가 PatchTST보다 20개 조건 모두에서 낮습니다. [pp. 5–6, Tables I–II; 재계산]
6. Table II의 예측 길이별 MSE를 데이터셋 안에서 단순평균하면, PatchTST 대비 상대 감소율은 약 3.29%에서 20.11%입니다. [p. 6, Table II; 재계산]
7. 그러나 저자가 보고한 1위·2위 횟수는 실제 표의 숫자와 일치하지 않으며, 반복 실험의 변동성이나 통계적 유의성도 보고되지 않았습니다. [pp. 5–7, Table II, Fig. 6]
8. 이 논문은 제한적 채널 혼합의 실용적 가능성을 보여주지만, 새로운 데이터셋이나 센서로의 전이와 분포 변화에 대한 일반화까지 입증한 연구로 해석하기는 어렵습니다. [pp. 5–8; 해석]

## 2. 연구 배경, 목적과 필요성

### 2.1 해결하려는 문제

**[저자 보고]** 다변량 시계열에서는 두 종류의 정보를 함께 고려해야 합니다.

- **시간적 의존성**: 한 변수의 과거 변화가 그 변수의 미래와 연결되는 관계입니다.
- **채널 간 의존성**: 서로 다른 변수의 변화가 연결되는 관계입니다.

저자는 기존 모델들이 이 두 정보를 결합하는 과정에서 어려움을 겪는다고 설명합니다. 특히 채널 간 정보를 활용하는 것이 항상 예측 성능 향상으로 이어지지는 않는다는 점에 주목합니다. [pp. 1–3]

> **용어 설명 — 채널:** 이 논문에서 채널은 하나의 변수에 해당하는 시계열입니다. 예를 들어 고객별 전력 사용량을 예측한다면 고객 한 명의 사용량 시계열이 하나의 채널입니다.  
> **의존성:** 한 정보가 다른 정보를 이해하거나 예측하는 데 관련되는 관계입니다. 통계적 의존성이 있다고 해서 곧바로 인과관계가 성립하는 것은 아닙니다.

### 2.2 CI, CD와 Mixed Channels의 차이

| 전략 | 입력을 처리하는 방식 | 저자가 기대하는 장점 | 저자가 지적하는 문제 |
|---|---|---|---|
| **CI** | 각 채널을 별도의 입력으로 처리하면서 모델 가중치를 공유 | 여러 채널의 학습 사례를 활용하고, 다른 채널의 방해를 줄임 | 현재 예측에서 다른 채널의 관측 정보를 직접 사용하기 어려움 |
| **CD** | 여러 채널의 정보를 함께 사용 | 변수 간 관계를 활용할 수 있음 | 불필요한 채널 정보가 장기 시간 패턴 학습에 영향을 줄 수 있음 |
| **Mixed Channels** | 목표 채널과 제한된 수의 다른 채널을 함께 입력 | 공유 모델의 장점을 유지하면서 일부 채널 관계를 활용 | 어떤 채널을 얼마나 섞을지 선택해야 함 |

**근거:** 원문 pp. 1–3, Fig. 1–2.

**[해석]** MCformer의 연구 질문은 다음처럼 정리할 수 있습니다.

> **“공유 모델을 사용하는 채널별 예측 구조에 필요한 만큼의 다른 채널 정보를 추가하면 성능을 개선할 수 있는가?”**

이는 **입력에 포함할 정보의 범위를 조절하는 문제**입니다. MCformer의 핵심 기여는 이 입력 구성 방식에 있으며, attention 계산식 자체는 일반적인 Transformer의 식을 사용합니다. [pp. 3–5, 식 (2)–(4), Fig. 3]

### 2.3 연구 목적과 필요성

**[저자 보고]** 연구 목적은 다음 세 가지입니다.

1. CI가 갖는 채널별 학습 사례 활용의 장점을 유지합니다.
2. 일부 채널 정보를 결합해 채널 간 관계를 활용합니다.
3. 과도한 채널 결합이 장기 시간 특징을 방해하는 문제를 줄입니다. [p. 2, 기여점 설명]

**[해석]** 이 연구의 필요성은 “다른 채널을 사용할 것인가”뿐 아니라 **“어떤 범위의 채널 정보를 사용할 것인가”를 설계 대상으로 삼았다는 점**에 있습니다. 다만 원문이 사용하는 *inter-channel correlation forgetting*은 설명적 가설에 가깝습니다. 이미 학습한 관계가 학습 과정에서 사라지는 현상을 직접 측정한 실험은 제시하지 않습니다. [p. 2, pp. 6–8]

> **용어 설명 — 일반화:** 학습에 직접 사용하지 않은 사례에서도 예측이 잘 작동하는 성질입니다. 같은 데이터셋의 다른 시점, 새로운 센서, 다른 지역의 데이터는 서로 다른 일반화 문제입니다.  
> **채널 간 상관관계 망각:** 저자가 CI의 정보 활용 한계를 설명하기 위해 사용하는 표현입니다. 이 논문에서는 이를 독립된 측정 지표나 이론으로 검증하지 않습니다.

## 4. 방법론과 모델 구조 — 수식 중심 설명

### 4.1 예측 문제와 기호

원문은 과거 관측 길이에 $t$를 사용하고, 패치 수를 설명할 때는 $L$을 사용합니다. 혼동을 줄이기 위해 여기서는 **입력 길이를 $L$로 통일**합니다. [p. 3, §III-A; p. 4]

$$
X\in\mathbb{R}^{L\times M},
\qquad
\hat{Y}=f_{\theta}(X)\in\mathbb{R}^{h\times M}.
$$

- $X$: 과거 다변량 관측값.
- $L$: 입력으로 사용하는 과거 시점 수.
- $M$: 전체 채널 수.
- $h$: 미래 예측 시점 수.
- $\hat{Y}$: 모든 채널의 미래 예측값.
- $f_{\theta}$: 학습 파라미터 $\theta$를 갖는 예측 모델.
- $x^i=[x_1^i,\ldots,x_L^i]$: $i$번째 채널의 과거 시계열.

위 식은 원문의 문제 정의를 정리한 설명용 표현입니다.

### 4.2 전체 구조

Fig. 3과 Algorithm 1을 종합하면 다음 구조입니다. [pp. 3–5]

| 단계 | 수행하는 작업 | 목적 |
|---|---|---|
| 1. RevIN | 채널별 입력을 정규화 | 입력의 평균·분산 차이를 조정 |
| 2. 채널별 재구성 | 다변량 입력을 목표 채널별 사례로 구성 | 공유 모델이 여러 채널의 사례를 학습하도록 구성 |
| 3. Mixed Channels | 목표 채널에 다른 채널들을 쌓음 | 보조 채널 정보 제공 |
| 4. Patch·Projection | 인접 시점을 묶고 표현 벡터로 변환 | 국소 시간 패턴과 채널 정보를 토큰에 담음 |
| 5. 위치 정보 추가 | 학습 가능한 위치 임베딩을 더함 | 패치 순서를 구분 |
| 6. Transformer Encoder | 패치 간 정보를 결합 | 긴 범위의 패턴 학습 |
| 7. Flatten·Linear Head | 출력 표현을 펼쳐 미래 값으로 변환 | 목표 채널의 예측 생성 |
| 8. Unflatten·역정규화 | 채널별 예측을 모으고 스케일 복원 | 최종 다변량 예측 출력 |

> **용어 설명 — 인코더:** 입력을 예측에 유용한 내부 표현으로 변환하는 신경망입니다.  
> **토큰:** Transformer가 하나의 처리 단위로 받아들이는 벡터입니다. 이 논문에서는 혼합 채널의 시간 패치가 토큰으로 변환됩니다.  
> **예측 헤드:** 모델의 내부 표현을 최종 예측값으로 바꾸는 마지막 부분입니다.

### 4.3 RevIN: 입력의 평균·분산을 조정하고 출력에서 복원

**[저자 보고]** 학습 데이터와 시험 데이터의 분포 차이를 다루기 위해 RevIN을 사용합니다. 다음은 원문 식 (1)을 평균·분산 기호로 정리한 표현입니다. [p. 3, §III-B]

```math
\tilde{x}^{\,i}
=
\text{RevIN}(x^i)
=
\gamma_i
\frac{x^i-\mu_i}
{\sqrt{\sigma_i^2+\varepsilon}},
```

$$
\mu_i=\text{Mean}(x^i),
\qquad
\sigma_i^2=\text{Var}(x^i).
$$

- $\tilde{x}^{\,i}$: 정규화된 채널 $i$의 입력.
- $\mu_i$: 해당 입력 시계열의 평균.
- $\sigma_i^2$: 해당 입력 시계열의 분산.
- $\varepsilon$: 분모의 수치적 안정성을 위한 작은 상수.
- $\gamma_i$: 식에 등장하는 스케일 계수이며, **MCformer 본문은 그 의미와 학습 여부를 명확히 설명하지 않습니다.**

예측 후에는 제거한 통계 정보를 되돌립니다. 다만 역정규화의 구체적인 식은 제시하지 않습니다. 또한 원문 식 (1)에는 이동 계수 $\beta_i$가 없습니다. 이를 일반적인 RevIN 식으로 보완해 MCformer의 원문 식처럼 제시해서는 안 됩니다. [pp. 3–4, Algorithm 1]

> **용어 설명 — 정규화:** 값의 중심과 크기를 일정한 기준으로 조정하는 작업입니다.  
> **분포 이동:** 학습할 때와 실제 예측할 때 데이터의 통계적 성질이 달라지는 현상입니다.  
> **비정상성:** 평균·분산 등의 특성이 시간에 따라 달라지는 성질입니다. 여기서 “비정상”은 데이터가 잘못되었다는 뜻이 아닙니다.

**[해석]** RevIN은 평균·스케일 차이에 대응하려는 설계 요소입니다. MCformer가 채널 간 관계의 변화까지 견딘다는 근거는 별도로 필요합니다. 또한 RevIN 자체는 선행 연구의 기법입니다. [GitHub](https://github.com/ts-kim/RevIN?utm_source=chatgpt.com)

### 4.4 채널별 재구성: 학습 사례의 공유

원문은 다음과 같이 표기합니다. [p. 3, §III-C]

$$
X_F=\text{Flatten}(X)\in\mathbb{R}^{LM\times 1}.
$$

- $X_F$: 채널별 데이터를 펼친 표현.
- $\text{Flatten}$: 데이터를 펼치는 연산.
- $L$, $M$: 각각 입력 길이와 채널 수.

본문 설명상 이 결과는 **길이 $L$의 채널별 사례 $M$개처럼 취급**됩니다. Fig. 2는 이러한 목표 채널별 입력이 Transformer 인코더의 파라미터를 공유한다고 명시합니다. [p. 2, Fig. 2]

**[해석]** 저자의 “데이터 확장”은 기존 다변량 관측을 채널별 학습 단위로 재구성한다는 의미입니다. 새로운 관측을 수집하거나 통계적으로 독립인 표본을 $M$배 확보한다는 뜻으로 해석할 수는 없습니다.

> **용어 설명 — 파라미터 공유:** 서로 다른 입력에 같은 모델 가중치를 사용하는 방식입니다. 여러 채널에서 반복되는 패턴을 함께 학습할 수 있게 합니다.

### 4.5 Mixed Channels Block: 제한된 채널을 함께 쌓기

저자는 먼저 다음 간격을 계산합니다. [p. 3]

$$
\Delta=\left\lfloor\frac{M}{m}\right\rfloor.
$$

- $\Delta$: 설명을 위해 붙인 채널 선택 간격 기호.
- $M$: 전체 채널 수.
- $m$: 원문에서 “혼합할 채널 수”라고 설명하는 값.
- $\lfloor\cdot\rfloor$: 소수 부분을 버리는 내림 연산.

원문 식 (2)는 다음과 같습니다.

```math
U^i
=
\text{MixedChannels}(x^i,m)
=
\left[
\text{stack}(x^i,C^1,C^2,\ldots,C^m)
\right].
```

- $U^i$: 목표 채널 $i$를 중심으로 만든 혼합 입력.
- $C^j$: 채널 간격에 따라 선택된 채널의 시계열.
- $\text{stack}$: 여러 채널의 값을 나란히 쌓는 연산.

**핵심은 다른 채널의 시계열을 목표 채널과 함께 입력으로 제공한다는 점입니다.** 현재 방법에 상관관계를 학습해 채널을 선택하는 모듈이 명시되어 있지는 않습니다. 더 정교한 채널 조합은 후속 연구로 제시됩니다. [pp. 3, 8]

#### 원문 수식의 중요한 불일치

같은 문단은 다음 차원을 제시합니다.

$$
U^i\in\mathbb{R}^{L\times m}.
$$

하지만 식 (2)는 $x^i$와 $C^1,\ldots,C^m$을 쌓으므로 **표기상 총 $m+1$개 채널**입니다. 따라서 다음 사항은 원문만으로 확정할 수 없습니다.

- $m$에 목표 채널이 포함되는지.
- 식의 마지막 항이 $C^{m-1}$이어야 하는지.
- 채널 인덱스가 배열 끝을 넘으면 어떻게 처리하는지.
- 같은 채널의 중복 선택을 허용하는지.

이 보고서에서는 어느 쪽이 저자의 실제 구현인지 추정하지 않습니다. [p. 3, 식 (2)]

### 4.6 패치와 투영

원문 식 (3)은 다음과 같습니다. [p. 4]

```math
\mathcal{P}^i
=
\text{Projection}
\left(
\text{Patch}(U^i)
\right).
```

투영 후 차원과 패치 수는 다음과 같이 제시됩니다.

$$
\mathcal{P}^i\in\mathbb{R}^{D\times N},
\qquad
N=
\left\lfloor\frac{L-p}{S}\right\rfloor+2.
$$

- $\mathcal{P}^i$: 목표 채널 $i$의 패치 표현.
- $D$: 투영 후 표현 차원이며, 원문에서는 이 차원을 $P$로 표기합니다.
- $N$: 패치 개수.
- $p$: 패치 하나가 포함하는 시점 수.
- $S$: 다음 패치로 이동하는 간격.
- $L$: 전체 입력 길이.

저자는 혼합된 채널의 인접 시간 구간을 묶고, 단층 MLP로 시간·채널 정보를 표현 벡터에 반영한다고 설명합니다. [pp. 3–4]

> **용어 설명 — 패치:** 연속된 여러 시점을 묶은 작은 시간 구간입니다.  
> **스트라이드:** 패치를 만들 때 시작 위치를 이동하는 간격입니다.  
> **투영·임베딩:** 입력값을 모델이 처리하는 고정 길이 벡터로 변환하는 과정입니다.  
> **MLP:** 선형 변환과 활성화 함수 등을 이용하는 기본적인 신경망 구조입니다.

**[표기 주의]** 패치 수의 마지막 항은 원문에서 $+2$입니다. 추가 패딩이나 마지막 패치를 만드는 규칙은 설명하지 않습니다. 특정 패딩 방식을 가져와 원문 구현으로 확정해서는 안 됩니다.

**[해석]** Fig. 4는 같은 토큰 수로 더 긴 과거 구간을 담을 수 있다는 개념을 설명합니다. 패치화만의 일반화 향상을 따로 검증한 실험은 아닙니다. [p. 4, Fig. 4]

### 4.7 위치 정보와 Transformer attention

먼저 학습 가능한 위치 정보를 더합니다. [p. 4, §III-D]

```math
X_{\text{in}}^i
=
\mathcal{P}^i+W_{\text{pos}},
\qquad
W_{\text{pos}}\in\mathbb{R}^{D\times N}.
```

- $X_{\text{in}}^i$: 위치 정보가 추가된 입력 표현.
- $W_{\text{pos}}$: 패치 위치를 나타내는 학습 가능한 벡터들의 배열.

이후 query, key, value를 계산합니다.

$$
Q^i=(X_{\text{in}}^i)^\top W^Q,
\qquad
K^i=(X_{\text{in}}^i)^\top W^K,
\qquad
V^i=(X_{\text{in}}^i)^\top W^V.
$$

- $W^Q,W^K,W^V$: 세 종류의 표현을 만드는 학습 행렬.
- $Q^i$: query, 다른 패치에서 어떤 정보를 찾을지 나타내는 표현.
- $K^i$: key, 패치 간 관련성을 계산할 때 비교하는 표현.
- $V^i$: value, 관련성 가중치에 따라 모을 정보.
- $\top$: 행렬의 전치.

원문 식 (4)는 일반적인 scaled dot-product attention입니다. [p. 5]

```math
\text{Attention}(Q^i,K^i,V^i)
=
\text{Softmax}
\left(
\frac{Q^i(K^i)^\top}{\sqrt{d_k}}
\right)V^i.
```

- $d_k$: key 벡터의 차원.
- $\sqrt{d_k}$: 내적값의 크기를 조절하는 항.
- $\text{Softmax}$: 관련성 점수를 가중치로 바꾸는 함수.

**구조적으로 중요한 점:** 여기서 attention이 직접 연결하는 단위는 **혼합 채널 정보가 담긴 시간 패치들**입니다. 채널 자체를 토큰으로 삼아 모든 채널 쌍에 attention을 적용하는 구조와는 구분해야 합니다. [pp. 4–5, 식 (3)–(4); 구조 해석]

인코더는 multi-head attention, feedforward network, 잔차 연결, LayerNorm으로 구성됩니다. [pp. 4–5, Fig. 3]

> **용어 설명 — Self-attention:** 같은 입력 안의 여러 토큰이 서로의 정보를 가중합하는 연산입니다.  
> **Multi-head:** 서로 다른 관점의 attention을 여러 개 계산하는 방식입니다.  
> **Feedforward network:** 각 토큰의 표현을 추가로 변환하는 신경망입니다.  
> **잔차 연결:** 변환된 결과에 원래 입력을 더해 정보 전달과 학습을 돕는 연결입니다.  
> **LayerNorm:** 내부 표현의 값 크기를 조정해 학습을 안정화하는 정규화입니다.

### 4.8 출력과 학습 목표

Fig. 3의 출력부는 인코더 표현을 펼친 뒤 선형 헤드로 예측값을 만듭니다. Algorithm 1은 채널별 예측을 $h\times M$ 형태로 재구성하고 역정규화한다고 설명합니다. [p. 4]

평가식은 원문 식 (5)–(6)입니다. 아래에서는 앞의 채널 인덱스와 구분하기 위해 합산 인덱스를 $\tau$로 바꿨습니다. [p. 5]

```math
\text{MSE}
=
\frac{1}{h}
\sum_{\tau=1}^{h}
(y_{\tau}-\hat{y}_{\tau})^2,
```

```math
\text{MAE}
=
\frac{1}{h}
\sum_{\tau=1}^{h}
|y_{\tau}-\hat{y}_{\tau}|.
```

- $y_{\tau}$: 미래 시점 $\tau$의 실제값.
- $\hat{y}_{\tau}$: 해당 시점의 예측값.
- $h$: 예측 길이.

**Algorithm 1에서 최적화하는 손실은 식 (5), 즉 MSE입니다.** MSE와 MAE를 함께 합산해 최적화한다고 쓰여 있지는 않습니다. 또한 식 자체에는 배치와 전체 채널에 대한 평균 방식이 명시되어 있지 않습니다. [pp. 4–5]

> **용어 설명 — MSE:** 오차를 제곱한 뒤 평균한 값으로, 큰 오차에 더 큰 벌점을 줍니다.  
> **MAE:** 오차의 절댓값을 평균한 값입니다. 두 지표 모두 낮을수록 좋습니다.

또한 예측 길이별 평균으로 보더라도 모든 데이터셋·모든 지표에서 최상은 아닙니다. 예를 들어 Solar-Energy 평균 MSE는 MCformer가 0.24375, Informer가 0.23575이고, PEMS 평균 MAE는 MCformer가 0.250, TimesNet이 0.248입니다. **따라서 원문의 “모든 데이터셋에서 우수하다”는 강한 표현에는 범위 제한이 필요합니다.** [Table II; 재계산]

## 6. 가장 중요한 그림의 선정과 해석

### 6.1 Fig. 2–3: 논문의 핵심 아이디어와 실제 구조

**선정 이유:** MCformer의 기여를 가장 직접적으로 보여줍니다. Fig. 2는 목표 채널별 입력 구성과 인코더 가중치 공유를, Fig. 3은 혼합·패치·투영·예측 헤드의 연결을 보여줍니다. [pp. 2, 4]

**[해석]** 핵심은 **채널별 예측을 유지하면서 각 예측에 제한된 다변량 문맥을 제공하는 것**입니다. 또한 Fig. 3을 보면 채널 혼합이 Transformer 인코더에 들어가기 전에 수행된다는 점을 알 수 있습니다.

### 6.2 Fig. 5: 채널 수가 증가하면 개선폭도 커지는가?

**[저자 보고]** 채널이 많아질수록 CI 모델 대비 개선폭이 커진다고 해석합니다. [p. 6]

**[재계산]** 그림의 세로축은 백분율 정확도가 아니라 **평균 MSE의 절대 차이**와 일치합니다. 예를 들어 PatchTST 대비 차이는 Weather에서 0.00850, Traffic에서 0.10125입니다. [Table II, Fig. 5]

**[해석]** 다음 이유로 채널 수 자체의 효과를 입증했다고 보기는 어렵습니다.

- 하나의 데이터셋에서 채널 수만 바꾼 실험이 아닙니다.
- 채널 수와 데이터의 분야·길이·분포·예측 구간이 함께 달라집니다.
- 절대 MSE 차이는 비교 모델의 원래 오차 크기에도 영향을 받습니다.
- TiDE 곡선은 Solar-Energy에서 Electricity로 갈 때 감소하므로 엄밀하게 단조 증가하지 않습니다.

> **용어 설명 — 교란 요인:** 확인하려는 요인과 함께 변해 결과의 원인을 구분하기 어렵게 만드는 다른 조건입니다. 이 그림에서는 데이터셋의 특성이 교란 요인입니다.

### 6.3 Fig. 6: 채널을 많이 섞을수록 좋은가?

**[저자 보고]** 일정 범위까지는 혼합이 도움이 되지만, 지나치게 많은 채널을 혼합하면 MSE가 다시 증가할 수 있습니다. [p. 7]

**[그림 판독]** 표시된 최저점은 조건별로 다릅니다. Weather 일부 조건에서는 혼합 수 7 부근, PEMS에서는 6 부근이 낮습니다. Traffic의 세 그래프에서는 최저점이 각각 다른 위치에 있습니다.

특히 다음을 주의해야 합니다.

1. **Traffic의 입력 길이는 Fig. 6에서 336, Table II에서 96입니다.**
2. x축이 2부터 시작하므로 목표 채널만 사용하는 기준점은 없습니다.
3. 본문은 Traffic에서 9개부터 악화한다고 쓰지만, **Traffic $336/192$ 그래프는 9개에서 가장 낮은 MSE**를 보입니다.
4. 반복 결과나 오차막대가 없어 최적점의 안정성은 판단할 수 없습니다.
5. PEMS $96/24$의 그림상 최저 MSE는 약 0.124인데, Table II의 같은 입력·예측 길이는 0.100입니다. 다른 설정이 무엇인지 설명되지 않아 차이를 해소할 수 없습니다.

마지막 수치는 그림을 읽은 근삿값이므로 원자료 오류라고 단정할 수는 없습니다. 다만 **주 실험과 혼합 수 실험의 설정을 더 명확히 공개할 필요가 있습니다.**

> **용어 설명 — Ablation study:** 모델의 일부 요소를 제거하거나 변경해 그 요소의 영향을 확인하는 실험입니다. 효과를 정확히 구분하려면 나머지 조건을 최대한 동일하게 유지해야 합니다.

### 6.4 Fig. 7: 시간에 따라 변하는 상관관계를 재현하는가?

**[저자 보고]** Electricity에서 무작위로 선택한 6개 채널을 이용해 실제값과 예측값의 상관 변화 곡선을 비교합니다. 위쪽은 실제값, 아래쪽은 예측값입니다. [pp. 7–8]

**[해석]** 그림에서는 실제와 예측의 변화 형태가 유사합니다. 이는 채널 관계를 보존할 가능성을 보여주는 사례입니다. 다만 다음은 확인되지 않습니다.

- 상관계수 계산 방식과 상세 이동창 설정.
- 전체 321개 채널에 대한 대표성.
- 상관관계 재현 오차의 정량 지표.
- 같은 조건에서 CI 모델보다 더 잘 재현하는지.

따라서 **상관관계 변화의 시각적 재현**이라는 범위에서 해석하는 것이 적절합니다.

Fig. 1은 CI·CD·Mixed Channels를 설명하는 개념도로, Fig. 4는 패치화의 역할을 설명하는 보조 그림으로 유용합니다. 두 그림 자체가 성능 향상의 실험 근거는 아닙니다. [pp. 1, 4]

### 7.3 저자가 직접 언급한 한계와 분석자의 지적

**저자가 직접 언급한 문제·연구 범위**

- 혼합 채널 수가 너무 많으면 성능이 나빠질 수 있습니다. [p. 7, Fig. 6]
- 적은 채널 수를 가진 ETT·ILI는 평가에서 제외했습니다. [p. 5]
- 채널 조합을 더 정교하게 만드는 연구와 설명 가능성 개선을 후속 과제로 제시합니다. [p. 8, §V]

**분석자가 지적하는 한계**

- 혼합 수 정의와 패치 처리 규칙에 불명확한 부분이 있습니다.
- 표의 순위와 강조 표시가 일부 틀립니다.
- 채널 수 효과와 데이터셋 차이가 충분히 분리되지 않았습니다.
- 일반화·계산 효율·통계적 안정성에 관한 직접 근거가 부족합니다.

원문에는 별도의 **Limitations 절은 없습니다.** 따라서 위 분석자의 지적을 저자가 인정한 한계로 바꿔 쓰면 안 됩니다.

## 8. 2020년 이후 관련 연구 비교 분석

### 8.1 비교의 기준

MCformer와 직접 연결되는 설계 및 평가 문제를 중심으로 2022–2026년의 연구를 선정했습니다. 아래의 “일반화”는 모두 같은 의미가 아닙니다.

> **용어 설명 — 전이학습:** 한 데이터에서 학습한 표현이나 모델을 다른 데이터의 과제에 사용하는 것입니다.  
> **미세조정:** 새 데이터로 모델을 추가 학습하는 것입니다.  
> **Zero-shot 평가:** 대상 데이터에서 추가 학습하지 않고 예측하는 평가입니다.  
> **강건성:** 잡음·결측·분포 변화 같은 교란 상황에서도 성능을 유지하는 성질입니다.

### 8.2 방법과 실제 평가 범위 비교

| 연구 | MCformer와 연결되는 설계 차이 | 저자가 실제로 확인한 평가와 시사점 |
|---|---|---|
| **RevIN, 2022** | 시계열별 평균·스케일을 제거하고 복원하는 정규화 기법 | MCformer가 채택한 선행 기법입니다. 정규화의 효과와 채널 혼합의 효과를 별도로 확인해야 합니다. [공식 프로젝트·구현] [GitHub](https://github.com/ts-kim/RevIN?utm_source=chatgpt.com) |
| **PatchTST, 2023** | 채널 독립 처리, 패치 토큰, 공유 임베딩·Transformer | MCformer의 가장 직접적인 비교 기준입니다. 원 논문은 Electricity 사전학습 후 다른 데이터셋으로의 미세조정도 평가합니다. [§4.2, Table 5; Appendix A.5.2] [arxiv.org](https://arxiv.org/html/2211.14730v2?utm_source=chatgpt.com) |
| **Crossformer, 2023** | 시간축과 변수축을 나누는 2단계 attention, 계층적 구조 | MCformer의 입력 단계 혼합과 달리 변수 간 관계를 명시적으로 처리합니다. 공식 구조 설명만으로 전이 성능을 단정할 수는 없습니다. [공식 README, Fig. 1–3] [GitHub](https://github.com/Thinklab-SJTU/Crossformer?utm_source=chatgpt.com) |
| **TSMixer, 2023** | 시간축 MLP와 변수축 MLP를 번갈아 적용 | 표준 장기예측 벤치마크에서 시간축만 사용하는 TMix-Only와 성능이 비슷하다고 보고합니다. 채널 혼합의 이익이 데이터에 따라 달라질 수 있음을 보여줍니다. [§4.1, §5.1] [arxiv.org](https://arxiv.org/html/2303.06053v5?utm_source=chatgpt.com) |
| **iTransformer, 2024** | 변수별 전체 이력을 하나의 토큰으로 만들고 변수축에 attention 적용 | 채널의 20%로 학습하고 추가 학습 없이 전체 채널을 예측하는 실험이 있습니다. MCformer의 미관측 채널 평가에 참고할 수 있습니다. [§4.2, Fig. 5; Appendix F.3] [arxiv.org](https://arxiv.org/html/2310.06625v4?utm_source=chatgpt.com) |
| **SOFTS, 2024** | 모든 시계열을 하나의 공통 표현으로 요약한 뒤 각 채널에 재분배 | PEMS03의 한 채널에 잡음을 추가하는 실험을 수행합니다. 이는 채널 잡음에 대한 강건성 근거이며 도메인 전이와는 다른 평가입니다. [§4.2, Fig. 6(c)] [arxiv.org](https://arxiv.org/html/2404.14197v3?utm_source=chatgpt.com) |
| **CSformer, 2025 학회 발표** | 채널 독립 이후 혼합, 채널·시퀀스 attention과 공유 파라미터 | ETTh2→ETTh1, ETTh1→ETTm1 전이를 평가합니다. 이 두 설정의 결과를 모든 도메인으로 확대할 수는 없습니다. [§4, Table 6] [arxiv.org](https://arxiv.org/html/2312.06220v2?utm_source=chatgpt.com) |
| **TimeFilter, 2025** | 채널과 시간 패치 사이의 관계를 그래프로 만들고 패치별로 필요한 관계를 선택 | 13개 데이터셋의 예측과 구성 요소 분석을 보고합니다. 고정 간격 혼합을 입력에 맞춰 조절하는 방향과 연결됩니다. [§4–5] [arxiv.org](https://arxiv.org/html/2501.13041v2?utm_source=chatgpt.com) |
| **xCPD, 2026 사전공개본** | 그래프의 주파수 구조를 이용해 채널·패치 관계를 나누고 처리 경로를 선택 | ETT 간 zero-shot 전이를 평가하지만, 저자도 광범위한 도메인 전이는 후속 과제로 남깁니다. [§5.3, Tables 5·13] [arxiv.org](https://arxiv.org/html/2603.13702v1?utm_source=chatgpt.com) |
| **MixBench-TS, 2026 사전공개본** | 채널 혼합이 유용한 데이터를 판별하고 평가하는 벤치마크 | 데이터에 실제로 예측에 도움이 되는 채널 관계가 있는지 평가합니다. MCformer는 비교 모델에 포함되지 않습니다. [§4, §7] [arxiv.org](https://arxiv.org/html/2609.32656v1?utm_source=chatgpt.com) |

> **용어 설명 — 그래프:** 채널이나 패치를 점으로, 그 관계를 연결선으로 나타낸 구조입니다.  
> **라우팅:** 입력에 따라 사용할 처리 경로나 모듈을 선택하는 방식입니다.  
> **그래프 주파수:** 그래프의 연결 구조를 기준으로 신호가 얼마나 부드럽거나 급격하게 변하는지 구분하는 표현입니다.

### 8.3 최근 연구가 MCformer 평가에 주는 시사점

#### ① 일반화를 주장하려면 평가 대상을 구체적으로 나눠야 합니다

PatchTST의 사전학습 후 미세조정, iTransformer의 미관측 채널 예측, SOFTS의 잡음 시험은 서로 다른 능력을 평가합니다. **MCformer의 기존 벤치마크 개선을 이 세 종류의 능력으로 자동 확장할 수는 없습니다.** [관련 논문들의 위 평가 절; 해석]

#### ② “몇 개를 섞는가”에 더해 “언제 어떤 관계를 사용하는가”가 중요합니다

TimeFilter와 xCPD는 채널 관계를 입력이나 패치에 따라 선택하는 방법을 제안합니다. 이들과 연결해 볼 때, MCformer의 고정 간격 선택은 후속 실험의 단순한 기준점으로 유용합니다. 다만 더 복잡한 선택 방식이 MCformer보다 항상 낫다는 결론은 동일 조건의 비교가 있어야 가능합니다. [arxiv.org](https://arxiv.org/html/2501.13041v2?utm_source=chatgpt.com)

#### ③ 채널 혼합의 이익은 벤치마크 구성에도 좌우될 수 있습니다

**[관련 연구의 저자 보고]** MixBench-TS는 자체 통일 프로토콜에서 CI 모델의 MSE 최상위 횟수가 표준 데이터셋에서는 10/10, 새 벤치마크에서는 3/10이라고 보고합니다. 그러나 새 데이터셋들은 TSMixer의 혼합 이익이 양수인 경우를 선택해 구성되었고, 그 지표가 특정 모델 계열에 의존한다는 한계도 인정합니다. [§7.1–7.3, §8] [arxiv.org](https://arxiv.org/html/2609.32656v1?utm_source=chatgpt.com)

**[해석]** 이는 MCformer의 우수성을 대신 입증하는 결과가 아닙니다. 후속 평가에서 **기존 벤치마크와 채널 간 예측 정보가 확인된 데이터를 함께 사용해야 한다는 근거**로 읽는 것이 적절합니다.

### 8.4 MCformer의 이후 연구에 대한 영향은 어디까지 말할 수 있는가?

**[해석]** MCformer의 학문적 의미는 채널 독립과 전체 채널 결합 사이에서 **제한적 혼합이라는 단순한 설계 선택**을 실험했다는 데 있습니다. 이 문제의식은 후속 시기의 선택적 채널 관계 활용 연구들과 연결됩니다.

다만 발표 시점이나 아이디어의 유사성만으로 직접적인 계승 관계를 확정할 수는 없습니다. 예를 들어 CSformer의 최초 사전공개본은 2023년으로, 2025년 학회 발표만 보고 MCformer 이후에 시작된 연구라고 해석해서는 안 됩니다. [arxiv.org](https://arxiv.org/html/2312.06220v1?utm_source=chatgpt.com)

## 9. 결론, 일반화 가능성과 후속 연구 제안

### 9.1 저자가 제시한 결론과 시사점

**[저자 보고]** 저자는 제한된 채널 정보를 혼합하면서 CI의 사례 활용 장점을 유지하면, 장기 특징을 방해하는 문제를 줄이고 다변량 예측을 개선할 수 있다고 결론 내립니다. [p. 8, §VI]

**[해석]** 표에서 확인되는 가장 강한 성과는 **해당 실험 설정에서 PatchTST·TiDE 대비 오차가 낮다는 점**입니다. 실용적으로는 여러 센서나 고객의 시계열을 다루는 예측 시스템에서, 기존 채널 독립 모델에 소수의 보조 채널을 추가하는 접근을 시험할 근거가 됩니다. 다만 실제 적용의 계산 비용과 운영 환경의 강건성은 별도 검증이 필요합니다. [pp. 5–8]

### 9.2 일반화 성능 향상 가능성: 설계 동기와 실증을 구분해야 합니다

| 설계 요소 | 일반화에 도움이 될 수 있다고 해석하는 이유 | MCformer가 실제 입증한 범위 |
|---|---|---|
| **공유 인코더** | 여러 채널에서 공통된 시간 패턴을 함께 학습할 수 있음 | 공유 구조와 벤치마크 결과를 제시 |
| **제한적 채널 혼합** | 유용한 보조 정보를 제공하면서 포함하는 채널 범위를 조절 | 일부 혼합 수에서 더 낮은 MSE 관찰 |
| **패치화** | 인접 시간 구간을 하나의 표현으로 다룸 | 구조와 개념 설명 제시 |
| **RevIN** | 입력의 평균·스케일 차이를 조정 | 모델에 포함하지만 독립 효과 실험은 미보고 |

**근거:** pp. 2–7, Fig. 2–4·6.

이 요소들은 일반화 향상의 **가능성을 설명하는 설계 근거**입니다. 다음 능력에 대한 직접적인 증거는 이 문서에 없습니다.

- 학습하지 않은 센서나 변수의 예측.
- 다른 데이터셋으로의 무조정 전이.
- 채널 수 변경에 대한 적응.
- 채널 관계 변화, 결측, 잡음에 대한 강건성. [pp. 5–8]

특히 채널별 정규화 계수나 예측 헤드를 어떻게 공유하는지 명확하지 않으므로, **새로운 채널을 처리할 수 있는 구조인지부터 확인해야 합니다.**

### 9.3 저자가 직접 제시한 후속 연구 계획

원문 §V의 계획은 크게 두 가지입니다. [p. 8]

1. **더 정교한 채널 조합 전략**  
   채널 상관관계를 더 깊이 분석하고 채널 조합과 모델 구조를 조정해 예측을 개선합니다.

2. **해석 가능성과 설명 가능성 개선**  
   모델이 어떤 채널에 주목하고 어떤 정보로 예측하는지 이해할 수 있도록 합니다.

> **용어 설명 — 해석 가능성:** 모델 내부의 작동이나 사용하는 정보를 이해할 수 있는 정도입니다.  
> **설명 가능성:** 특정 예측이 왜 나왔는지 사람이 이해할 수 있는 설명을 제공하는 성질입니다.

### 9.4 빠르게 검증할 가치가 큰 기술과 실험

아래는 **분석자의 제안**입니다. 성능 향상이 확인되었다는 뜻은 아닙니다.

| 우선 검증할 접근 | 선정 이유 | 작은 규모의 검증 방법 | 확인할 질문 |
|---|---|---|---|
| **소수 채널 혼합 + 공유 인코더** | MCformer의 핵심 아이디어에 가장 가까움 | 동일 인코더에 목표 채널만 입력하는 경우와 소수 채널을 추가하는 경우 비교 | 혼합 자체의 이익이 재현되는가? |
| **단순한 채널 선택 규칙 비교** | 복잡한 새 모델 없이 조합의 중요성을 확인 가능 | 고정 간격·무작위·과거 입력의 상관 기반 선택 비교 | 선택 방식이 결과를 얼마나 좌우하는가? |
| **혼합 입력 + 작은 MLP 또는 선형 모델** | 입력 구성의 이익과 Transformer의 이익을 분리 가능 | 같은 혼합 입력을 단순한 예측기에 제공 | 복잡한 인코더가 반드시 필요한가? |
| **RevIN의 독립 효과 확인** | 전처리와 혼합 효과가 섞이는 것을 줄임 | 같은 모델에서 RevIN 사용 여부만 변경 | 개선의 어느 부분이 정규화에서 오는가? |
| **보조 채널 가리기·순서 변경 시험** | 실제 사용 시 취약점을 빠르게 드러낼 수 있음 | 일부 보조 채널 제거, 채널 열 순서 변경 | 특정 채널이나 열 순서에 과하게 의존하는가? |

첫 실험에서는 원문의 $m$과 혼동하지 않도록 **목표 채널을 포함한 실제 입력 채널 수를 $k$로 새로 정의**하는 편이 명확합니다. 예를 들어 $k\in\{1,2,4,8\}$을 비교할 수 있습니다. 이 값들은 원문의 최적 설정이 아니라 검증용 예시입니다.

인코더 크기와 학습 예산은 고정하고, 혼합 수 증가에 따라 투영층의 파라미터 수가 늘어나는 부분은 별도로 기록해야 합니다. 채널 선택에 상관관계를 사용한다면 **학습 구간 또는 현재 입력 구간에서만 계산**해야 합니다.

### 9.5 일반화 검증을 위한 후속 연구 순서

**[제안]** 복잡한 모델 확장 전에 다음 순서로 증거를 확보하는 것이 적절합니다.

1. **동일 구조의 비교부터 수행합니다.**  
   목표 채널만 사용하는 모델과 혼합 모델을 같은 조건에서 비교하고, 여러 초기화에서 평균·변동성을 보고합니다.

2. **한 데이터셋 안에서 채널 수 효과를 분리합니다.**  
   여러 채널 부분집합을 반복 추출해 Fig. 5에서 섞여 있는 데이터셋 차이를 줄입니다.

3. **일반화 문제를 별도로 평가합니다.**  
   미래 기간, 학습에서 제외한 채널, 다른 데이터셋, 잡음·결측 조건을 각각 시험합니다.

4. **시간에 따라 바뀌는 관계를 다룹니다.**  
   고정 혼합의 효과가 확인된 다음, 입력 구간에 따라 보조 채널을 바꾸거나 관련성이 낮은 채널의 기여를 줄이는 방법을 시험합니다.

5. **정확도와 비용을 함께 평가합니다.**  
   추가 채널 수에 따른 메모리, 학습 시간, 추론 시간을 측정해 실제로 사용할 수 있는 범위를 정합니다.

**최종 평가:** MCformer에서 우선 가져올 가치가 있는 것은 **공유 예측기에 제한된 다른 채널의 정보를 추가한다는 단순한 아이디어**입니다. 이 아이디어의 유효성은 원문의 비교표에서 일정 부분 지지되지만, 일반화 성능을 주장하려면 입력 구성의 정확한 정의, 공정한 동일 구조 비교, 반복 실험, 새로운 채널·분포에 대한 평가가 추가되어야 합니다.
