# Partial-Multivariate Model for Forecasting

**핵심 평가는 다음과 같습니다.** 이 논문은 **“변수 사이의 관계를 얼마나 넓게 학습할 것인가”를 조절하는 간단한 전략이 예측 성능과 변수 누락 대응에 유용할 수 있다**는 실험적 근거를 제시합니다.  
다만, 이를 설명하는 일반화 이론은 강한 가정에 의존하며, 새로운 데이터셋이나 처음 보는 변수에 대한 일반화까지 입증한 것은 아닙니다. [원문 pp.5–9, Appendix A]

**분석 기준:** Jaehoon Lee, Hankook Lee, Sungik Choi, Sungjun Cho, Moontae Lee의 **2024년 8월 19일 arXiv v1**입니다. 페이지 번호는 첨부 PDF에 인쇄된 번호를 사용합니다.

원문: 2408.09703v1.pdf

아래에서는 **[저자 보고]**, **[분석·해석]**, **[후속 연구 제안]**을 구분합니다. 외부 문헌 비교는 별도 절에 배치했으며, 그 결과를 PMformer 원 논문의 성과로 취급하지 않습니다.

## 1. Executive summary — 9문장

1. 이 논문은 다변량 시계열 예측에서 변수들을 독립적으로 처리하는 방식과 전체 변수의 관계를 함께 학습하는 방식 사이의 중간 접근법을 탐구합니다. [pp.1–3, Figure 1]
2. 제안 모델인 **PMformer**는 전체 변수에서 작은 부분집합을 구성하고, 모든 부분집합이 공유하는 하나의 신경망으로 부분집합 내부의 시간적 관계와 변수 간 관계를 학습합니다. [pp.3–4, Figure 2, Eqs.1–6]
3. 주 학습 방식은 매 반복마다 변수들을 무작위로 분할하는 것이며, 기본 추론에서는 서로 다른 분할로 얻은 예측을 세 번 평균합니다. [pp.4–6, Algorithm 1]
4. 저자들은 7개 데이터셋과 4개 예측 길이로 구성한 28개 과제에서 평균제곱오차 기준 27개 1위를 보고하지만, 표시된 수치로 보면 그중 하나는 공동 최저입니다. [pp.6–7, Table 1]
5. 추가적인 동시기 모델 비교에서는 12개 과제 중 10개에서 1위, 모든 과제에서 2위 이내를 기록합니다. [p.7, Table 2]
6. 같은 PMformer 계열을 비교한 Electricity의 720단계 예측에서는 부분 다변량 설정의 오차가 0.176으로, 단변량·전체 다변량 설정의 0.204보다 낮습니다. [p.8, Table 3]
7. 변수 조합의 다양성과 반복 추론이 성능에 도움이 되는 경향, 일부 기존 변수가 누락되어도 남은 변수의 예측 성능이 유지되는 경향도 보고합니다. [pp.8–9, Figures 4–6]
8. 일반화 성능에 대한 이론적 설명은 사후분포의 엔트로피와 학습 표본 수를 이용하지만, 실제 엔트로피를 계산하지 않았고 부분집합 개수를 독립 표본 수로 해석하는 데에는 검토가 필요합니다. [pp.5–6, 13–15]
9. 따라서 가장 확실한 결론은 **부분적인 변수 관계 학습의 실용적 유용성**이며, 새로운 변수·데이터셋·도메인으로의 일반화는 별도의 검증 과제로 남습니다. [pp.4, 6, 9]

> **용어 풀이**
>
> - **다변량 시계열:** 전력 사용량·기온·교통량처럼 여러 변수가 시간에 따라 함께 기록된 데이터.
> - **평균제곱오차, MSE:** 예측값과 정답의 차이를 제곱한 뒤 평균한 값; 작을수록 좋은 예측.
> - **일반화:** 학습에 사용하지 않은 데이터에서도 예측 능력을 유지하는 성질.
> - **사후분포의 엔트로피:** 학습 후 가능한 예측 함수들에 부여된 확률이 얼마나 넓게 퍼져 있는지를 나타내는 양; 입력 데이터 자체의 불확실성과는 구별.

## 2. 연구 배경·목표·필요성

### 2.1 해결하려는 문제

**[저자 보고]** 기존 접근법은 변수 간 정보를 활용하는 방식에 따라 두 극단으로 나뉩니다. [pp.1–3]

| 접근법 | 변수 간 정보를 사용하는 방식 | 논문이 지적하는 문제 |
|---|---|---|
| 단변량 방식 | 각 변수를 독립 입력으로 처리 | 다른 변수에서 얻을 수 있는 유용한 정보를 활용하지 못함 |
| 전체 다변량 방식 | 전체 변수 집합의 관계를 함께 처리 | 추가 정보를 사용해도 단변량 모델보다 성능이 낮아지는 경우가 있음 |
| 제안하는 부분 다변량 방식 | 작은 변수 부분집합 내부의 관계를 처리 | 관계 활용 범위를 조절하여 두 방식 사이의 중간 영역을 탐색 |

**중요한 용어 구분:** 이 논문에서 *univariate model*은 여러 변수마다 별도의 모델을 학습한다는 뜻이 아닙니다. 일반적으로 **하나의 공유 신경망이 각 변수를 독립적으로 처리하는 방식**을 가리킵니다. [p.2, Figure 1]

> **용어 풀이 — 변수·특징·채널:** 이 보고서에서는 논문의 *feature*, 관련 문헌의 *channel*, 일반적인 *variable*을 문맥상 같은 의미인 ‘변수’로 사용합니다.

### 2.2 연구 목적

**[저자 보고]** 연구 목적은 다음 세 가지로 정리할 수 있습니다. [pp.2–3]

- **모델링:** 전체 변수 중 일부의 관계만 처리하는 모델을 정의하고 구현한다.
- **성능 검증:** 부분 다변량 방식이 단변량·전체 다변량 방식보다 유리한 조건을 실험한다.
- **설명과 실용성:** 일반화 성능의 이론적 설명을 시도하고, 계산량과 변수 누락 대응을 평가한다.

### 2.3 왜 필요한가

**[분석·해석]** 이 연구가 제기하는 중요한 질문은 **“변수 간 관계가 존재하는가”뿐 아니라 “한 번에 얼마나 많은 관계를 학습하는 것이 유리한가”**입니다.

실제로 같은 모델 계열에서 부분집합 크기를 바꾸었을 때 성능이 달라지는 결과는, 관계를 많이 허용하는 것이 항상 좋은 선택은 아니라는 점을 뒷받침합니다.  
다만, 불필요한 관계가 정확히 어떤 경로로 성능을 악화시키는지는 논문에서 완전히 분리하여 확인하지 않았습니다. [Table 3, Figure 3, Table 9]

## 5. 제안 방법과 모델 구조 — 수식 중심 설명

### 5.1 부분 다변량 예측 문제의 정의

**[저자 보고: 원문 Eq.1, p.3]**

```math
\widehat{x}_{[T:T+\tau],\mathcal F}
=
f\!\left(x_{[0:T],\mathcal F},\mathcal F\right),
\qquad
\mathcal F\in\mathcal F^{\text{all}},
```

```math
\mathcal F^{\text{all}}
=
\left\{
\mathcal F\subseteq[0:D]:
\lvert\mathcal F\rvert=S
\right\}.
```

기호는 다음과 같습니다.

| 기호 | 의미 |
|---|---|
| $x_{t,d}$ | 시점 $t$에서 변수 $d$의 관측값 |
| $T$ | 과거 입력 길이 |
| $\tau$ | 미래 예측 길이 |
| $D$ | 전체 변수 수 |
| $S$ | 한 부분집합에 포함하는 변수 수 |
| $\mathcal F$ | 선택한 변수의 인덱스 집합 |
| $\mathcal F^{\text{all}}$ | 가능한 크기 $S$의 모든 변수 부분집합 |
| $f$ | 모든 부분집합이 공유하는 하나의 예측 모델 |
| $\widehat{x}$ | 예측값 |

원문의 $[a:b]$는 $a,a+1,\ldots,b-1$을 뜻합니다. 따라서 입력은 $T\times S$, 출력은 $\tau\times S$ 크기입니다. [p.3]

이 정의에서 다음 세 경우가 연결됩니다.

$$
S=1:\ \text{단변량},
\qquad
1<S<D:\ \text{부분 다변량},
\qquad
S=D:\ \text{전체 다변량}.
$$

핵심은 **부분집합마다 별도의 신경망을 만들지 않는다는 점**입니다. 변수 조합이 바뀌어도 같은 모델을 사용합니다. [pp.2–3, Figure 1]

### 5.2 시간 구간 분할과 토큰 생성

**[저자 보고: 원문 Eq.2, p.4]**

선택된 각 변수의 입력 이력을 여러 연속 구간으로 나누고, 구간마다 하나의 표현 벡터를 만듭니다.

```math
h^{(0)}_{b,i}
=
\text{Linear}
\left(
x_{[bT/N_S:(b+1)T/N_S],\mathcal F_i}
\right)
+
e_b^{\text{Time}}
+
e_{\mathcal F_i}^{\text{Feat}}.
```

- $N_S$: **시간 구간의 개수**이며, 변수 부분집합 크기 $S$와 다릅니다.
- $b$: 시간 구간 인덱스.
- $i$: 부분집합 내부의 변수 인덱스.
- $\mathcal F_i$: 해당 변수의 전체 데이터셋 내 식별자.
- $h^{(0)}_{b,i}$: 초기 토큰 표현.
- $d_h$: 각 표현 벡터의 차원.
- $e_b^{\text{Time}}$: 학습 가능한 시간 위치 임베딩.
- $e_{\mathcal F_i}^{\text{Feat}}$: 학습 가능한 변수 식별 임베딩.

전체 표현의 크기는 다음과 같습니다.

$$
h^{(0)}\in\mathbb R^{N_S\times S\times d_h}.
$$

> **용어 풀이**
>
> - **토큰:** 모델이 하나의 처리 단위로 받는 표현; 여기서는 ‘특정 변수의 특정 시간 구간’.
> - **임베딩:** 관측값이나 식별자를 신경망이 처리할 수 있는 벡터로 변환한 표현.
> - **선형층:** 입력에 학습 가능한 행렬과 편향을 적용하는 변환.

**[분석·해석]** 변수 임베딩이 $D$개의 기존 변수 ID에 연결되어 있다는 점은 중요합니다. 부분집합을 유연하게 처리한다는 사실만으로 처음 보는 변수 ID나 다른 데이터셋의 변수에 바로 일반화할 수 있다고 결론 내릴 수는 없습니다. [p.4, Eq.2]

### 5.3 시간 어텐션과 변수 어텐션

**[저자 보고: 원문 Eqs.5–6, p.4]**

먼저 각 변수 내부에서 시간 구간 간 관계를 계산합니다.

```math
\text{Temporal-Attention}(h)_{[0:N_S],i}
=
\text{MHSA}
\left(
h_{[0:N_S],i},
h_{[0:N_S],i},
h_{[0:N_S],i}
\right).
```

이후 같은 시간 구간에 속한 변수들 사이에서 정보를 혼합합니다.

```math
\text{Feature-Attention}(h,v)_{b,[0:S]}
=
\text{MHSA}
\left(
h_{b,[0:S]},
h_{b,[0:S]},
v_{b,[0:S]}
\right).
```

여기서 다음을 구분해야 합니다.

- $\text{MHSA}(Q,K,V)$: 다중 헤드 어텐션.
- $Q$: 어떤 정보를 찾을지 나타내는 query.
- $K$: 참고할 정보와의 적합도를 계산하는 key.
- $V$: 실제로 가중합하여 전달하는 value.
- $v=\text{Temporal-Attention}(h)$: 시간 어텐션의 결과.

**구조적으로 중요한 점:** 변수 어텐션의 $Q,K$는 **블록 입력 $h$**에서 오고, $V$는 **시간 어텐션의 결과 $v$**에서 옵니다. 따라서 시간 어텐션 결과 전체를 일반적인 자기어텐션에 그대로 넣는 구조로 설명하면 원문과 다릅니다. [Eq.6]

> **용어 풀이 — 다중 헤드 어텐션:** 여러 종류의 관계를 서로 다른 투영 공간에서 병렬로 계산하는 방식. 어텐션 가중치가 높다는 사실만으로 실제 인과관계가 확인되는 것은 아님.

### 5.4 PMformer 블록과 예측 헤드

**[저자 보고: 원문 Eqs.3–4, p.4]**

```math
\bar h^{(\ell-1)}
=
h^{(\ell-1)}
+
\text{Feature-Attention}
\left(
h^{(\ell-1)},
\text{Temporal-Attention}(h^{(\ell-1)})
\right),
```

```math
h^{(\ell)}
=
\bar h^{(\ell-1)}
+
\text{MLP}\left(\bar h^{(\ell-1)}\right),
\qquad
\ell=1,\ldots,L.
```

- $\ell$: 블록 번호.
- $L$: 전체 블록 수.
- $\bar h$: 어텐션 결과와 입력을 더한 중간 표현.
- $\text{MLP}$: 다층 퍼셉트론.

> **용어 풀이**
>
> - **잔차 연결:** 입력을 변환 결과에 다시 더하는 연결.
> - **MLP:** 선형변환과 비선형 함수를 여러 층으로 조합한 신경망.

마지막에는 각 변수의 시간 구간 표현들을 이어 붙여 선형층으로 미래 값을 예측합니다. 다음 식은 **원문 p.4의 설명을 수식으로 재표현한 것**입니다.

```math
\widehat{x}_{[T:T+\tau],\mathcal F_i}
=
\text{Linear}_{\text{out}}
\left(
\text{Concat}
\left[
h^{(L)}_{0,i},\ldots,h^{(L)}_{N_S-1,i}
\right]
\right).
```

$\text{Concat}$은 벡터 연결, $\text{Linear}_{\text{out}}$은 연결된 표현을 $\tau$개의 미래 값으로 바꾸는 출력층입니다.

전체 구조를 요약하면 다음과 같습니다.

| 단계 | 처리 대상 | 역할 |
|---|---|---|
| 변수 부분집합 선택 | 전체 $D$개 중 $S$개 | 함께 관계를 계산할 변수 구성 |
| 시간 구간 분할·임베딩 | 변수별 과거 이력 | 구간 단위 토큰 생성 |
| 시간 어텐션 | 각 변수의 $N_S$개 구간 | 시간적 관계 학습 |
| 변수 어텐션 | 같은 구간의 $S$개 변수 | 부분집합 내부 정보 결합 |
| 잔차 연결·MLP | 토큰 표현 | 표현 변환 |
| 선형 출력층 | 변수별 최종 표현 | 미래 $\tau$개 시점 예측 |

### 5.5 학습: 무작위 샘플링보다 무작위 분할을 주로 사용

**[저자 보고]** 독립적으로 부분집합을 여러 번 샘플링하면, 어떤 변수는 한 반복에서 여러 번 선택되고 다른 변수는 누락될 수 있습니다. 주 실험에서는 이를 줄이기 위해 전체 변수를 무작위로 분할합니다. [pp.4–5, Algorithm 1]

$D$가 $S$로 나누어떨어지면 부분집합 수는 다음과 같습니다.

$$
N_U=\frac{D}{S}.
$$

- $N_U$: 학습 반복 한 번에서 처리하는 부분집합 수.
- 각 부분집합은 서로 겹치지 않으며 전체 변수를 한 번씩 포함합니다.

알고리즘의 손실은 다음처럼 쓸 수 있습니다.

```math
\mathcal L
=
\frac{1}{N_U}
\sum_{g=0}^{N_U-1}
\text{MSE}
\left(
f(x_{\mathcal F^{(g)}},\mathcal F^{(g)}),
y_{\mathcal F^{(g)}}
\right).
```

- $g$: 부분집합 번호.
- $\mathcal F^{(g)}$: $g$번째 부분집합.
- $y_{\mathcal F^{(g)}}$: 해당 변수들의 미래 정답.
- $\mathcal L$: 전체 부분집합의 평균 학습 손실.

나누어떨어지지 않으면 일부 변수를 다른 부분집합에 추가로 포함하여 크기를 맞추고, 예측 후 중복된 출력은 제거합니다. [p.16, Algorithm 2]

**[분석·해석]** 이 방식은 매번 일부 변수를 버리는 것과 구별됩니다. 전체 변수의 예측을 수행하면서 **각 변수가 함께 상호작용하는 상대를 바꾸는 학습 방식**입니다.

### 5.6 추론: 서로 다른 분할의 예측을 평균

**[저자 보고]** 무작위 분할과 예측을 $N_I$번 반복한 뒤 평균합니다. [p.5, §3.4]

본문 설명을 수식화하면 다음과 같습니다.

```math
\widehat y_d
=
\frac{1}{N_I}
\sum_{r=1}^{N_I}
\left[
f\left(
x_{[0:T],\mathcal F_r(d)},
\mathcal F_r(d)
\right)
\right]_d.
```

- $N_I$: 추론 반복 횟수.
- $r$: 반복 번호.
- $\mathcal F_r(d)$: $r$번째 분할에서 변수 $d$가 속한 부분집합.
- $\widehat y_d$: 변수 $d$의 최종 미래 예측 벡터.
- $[\cdot]_d$: 부분집합 출력에서 변수 $d$에 해당하는 예측 선택.

저자는 유용한 특정 조합이 한 시행에서 선택될 확률을 $p$라 하면, 독립 시행 $N_I$회 중 적어도 한 번 선택될 확률이 다음과 같다고 설명합니다.

$$
1-(1-p)^{N_I}.
$$

**[분석·해석]** 이 식은 유용한 조합을 접할 확률에 관한 설명입니다. **여러 예측을 평균한 결과의 MSE가 반드시 감소한다는 증명은 아닙니다.** 성능 개선에 관한 직접 근거는 Figure 5의 실험입니다.

> **용어 풀이 — 앙상블:** 여러 예측을 결합하는 방식. 여기서는 여러 개의 별도 모델 대신, 같은 모델에 서로 다른 변수 분할을 적용한 예측을 평균.

### 5.7 계산량

**[저자 보고: Appendix D, p.19]**

부분집합 하나의 변수 간 어텐션 비용은 $O(S^2)$이고, 부분집합 수는 약 $D/S$이므로 다음과 같습니다.

```math
N_U O(S^2)
\simeq
\frac{D}{S}O(S^2)
=
O(DS).
```

**[분석·해석]** 반복 추론까지 고려하면 해당 어텐션 항은 대략 다음과 같습니다.

$$
O(N_I DS).
$$

이는 **변수 간 어텐션 부분의 계산량**입니다. 시간 어텐션, 선형 투영, MLP, 출력층 및 실제 하드웨어 실행시간까지 모두 포함한 식이 아닙니다. 또한 $S$를 $D$에 비례해 늘리면 $D$에 대한 이차 증가가 다시 나타납니다. [p.9, Appendix D]

## 6. 일반화 성능 향상: 저자의 이론과 그 한계

### 6.1 저자가 제시한 일반화 상한

**[저자 보고]** 출발점은 McAllester의 PAC-Bayes 상한입니다. [p.13, Eq.8]

$$
l(Q)
\le
\widehat l(Q,\mathcal T)
+
\sqrt{
\frac{
D_{\text{KL}}(Q\Vert P)
+\log(1/\delta)
+\frac52\log m
+8
}{
2m-1
}
}.
$$

저자는 훈련오차를 거의 0으로 가정하고, 사전분포에 관한 조건을 이용해 다음 형태를 제시합니다. [p.5, Eq.7]

$$
l(Q)
\le
\sqrt{
\frac{
-H(Q)
+\log(1/\delta)
+\frac52\log m
+8+C
}{
2m-1
}
}.
$$

기호 설명은 다음과 같습니다.

| 기호 | 의미 |
|---|---|
| $\mathcal T$ | 학습 데이터셋 |
| $m$ | 학습 표본 수 |
| $P$ | 가설에 대한 사전분포 |
| $Q$ | 학습 후 가설에 대한 사후분포 |
| $l(Q)$ | 사후분포에 대해 평균한 모집단 손실 |
| $\widehat l(Q,\mathcal T)$ | 학습 데이터에서 측정한 경험적 손실 |
| $D_{\text{KL}}(Q\Vert P)$ | 사후분포가 사전분포에서 얼마나 달라졌는지 나타내는 양 |
| $H(Q)$ | 사후분포 엔트로피 |
| $\delta$ | 확률적 보장의 실패확률 |
| $C$ | 사전분포 관련 상수 |

이 절의 $Q$는 어텐션의 query와 다른 기호입니다. 또한 엔트로피는 다음과 같이 정의됩니다.

```math
H(Q)
=
\mathbb E_{h\sim Q}[-\log Q(h)].
```

여기서 $h$는 가능한 예측 함수인 **가설**이며, 앞 절의 은닉 표현 $h^{(\ell)}$과 문맥이 다릅니다.

> **용어 풀이**
>
> - **PAC-Bayes:** 학습 데이터와 가설의 확률분포를 이용해, 일정 확률로 성립하는 일반화 오차 상한을 구하는 이론.
> - **가설:** 가능한 예측 함수 또는 모델.
> - **KL 발산:** 두 확률분포의 차이를 측정하는 양.
> - **상한:** 실제 값이 그보다 크지 않다고 보장하는 경계; 실제 오차 자체와는 다름.

### 6.2 왜 중간 크기의 부분집합이 좋다고 설명하는가

**[저자 보고]** 가능한 부분집합의 수는 다음과 같습니다.

```math
\lvert\mathcal F^{\text{all}}\rvert
=
\binom{D}{S}.
```

저자는 학습 표본 수 $m$이 이 조합 수에 비례한다고 보고, 조합 수 측면에서는 $S\approx D/2$가 유리하다고 설명합니다. [p.5]

또한 다음 관계를 제시합니다.

$$
S_+>S_-
\quad\Longrightarrow\quad
H(Q_{S_+})\le H(Q_{S_-}).
$$

- $S_+,S_-$: 서로 다른 두 부분집합 크기.
- $Q_{S_+},Q_{S_-}$: 각 크기에서의 사후분포.

저자의 직관은 큰 변수 집합의 관계를 모두 만족시키는 가설 영역이 더 작아진다는 것입니다. 따라서 엔트로피 관점은 작은 $S$를, 조합 수 관점은 $D/2$ 부근을 선호하므로, 두 효과를 함께 고려하면 최적값이 $1<S^\star<D/2$에 있을 것이라고 추론합니다. [pp.5–6]

### 6.3 이 설명을 읽을 때 필요한 제한

**[분석·해석]**

**첫째, 조합 수 증가와 독립 표본 수 증가는 다릅니다.**  
같은 시계열의 변수들을 다른 조합으로 묶은 입력들은 정보를 공유합니다. 따라서 $\binom{D}{S}$가 커졌다는 이유만으로 독립 관측의 수가 그 비율로 증가한다고 보기 어렵습니다. Figure 4는 **조합 다양성의 효과**를 보여주지만, PAC-Bayes에서 사용하는 표본 수의 해석까지 검증한 실험은 아닙니다. [pp.5, 7–8, 13–15]

**둘째, 실제 PMformer가 이론의 가정을 만족하는지 확인하지 않았습니다.**  
Appendix A에는 정답·출력의 범위가 0–1이라는 가정, 거의 0인 훈련손실, 사전분포의 하한과 상수에 관한 가정, 서로 다른 크기의 모델에 대한 가설분포 유사성 등 총 9개 가정이 등장합니다. 실제 $H(Q)$나 일반화 상한의 값은 계산하지 않습니다. [pp.13–15]

**셋째, 두 효과의 방향만으로 내부 최적점이 보장되지는 않습니다.**  
조합 수와 엔트로피가 서로 다른 크기를 선호한다는 사실만으로 $1<S^\star<D/2$를 엄밀히 보장할 수는 없습니다. 더 낮은 상한을 얻더라도 실제 손실의 순서가 반드시 같다는 결론도 바로 나오지 않습니다. 저자 역시 두 효과의 크기를 비교하지 못한다고 인정합니다. [p.6]

**넷째, 원문 수식에 확인이 필요한 부분이 있습니다.**  
Appendix A의 Eq.18은 최소 성공확률을 설명하면서 부등호를 $\le$로 표시합니다. 이는 해당 설명과 Chebyshev 부등식을 이용한 성공확률 하한의 방향에 맞지 않아 **오기 또는 유도 과정의 확인이 필요합니다**. [p.15, Eq.18]

### 6.4 일반화의 어느 부분이 실제로 검증되었는가

| 일반화의 종류 | PMformer 원 논문의 증거 |
|---|---|
| 같은 데이터셋의 이후 시간 구간 예측 | 있음: 주 실험 |
| 같은 데이터셋의 다양한 변수 조합 처리 | 있음: 부분집합 크기·풀 실험 |
| 학습 때 존재했던 변수 일부가 추론에서 누락 | 있음: 무작위 변수 제거 실험 |
| 처음 보는 변수의 식별자·의미로 전이 | 직접 실험 없음 |
| 다른 데이터셋으로 추가 학습 없이 전이 | 직접 실험 없음 |
| 서로 다른 도메인을 통합한 사전학습 | 직접 실험 없음 |
| 관계가 급변하는 시계열에서의 성능 유지 | 별도의 변화 조건 실험 없음 |

[근거: pp.4, 6–9, Appendix G]

**일반화에 관한 가장 타당한 해석은**, 다양한 변수 조합을 공유 모델로 처리하는 것이 데이터셋 내부의 예측과 일부 변수 누락 상황에서 유용하다는 것입니다. 광범위한 전이 성능은 아직 연구 가설입니다.

\text{비교 모델 MSE}
}
\times100\%.

이 계산값은 효과 크기의 요약이며, 통계적 유의성 검정 결과는 아닙니다.

## 9. 통계적으로 취약한 부분과 직접 비교하면 안 되는 수치

**표준편차가 없다고 지적하는 것은 부정확합니다.** PMformer의 표준편차는 Table 11에 있습니다. 예를 들어 Electricity $\tau=720$의 MSE는 ** $0.176\pm0.003$ **입니다.

## 10. 저자가 인정한 한계와 문서가 답하지 않는 질문

### 10.1 저자가 직접 밝힌 한계

**[저자 보고]**

1. 사후 엔트로피 $H(Q)$를 정확히 계산하지 않았다.
2. 표본 수와 엔트로피가 상한에 미치는 상대적 영향을 비교하지 못했다.
3. 더 정밀한 이론 분석과 일부 가정의 완화가 필요하다. [p.6; p.9, Limitation]

서로 다른 데이터셋의 변수 수가 달라도 고정된 크기 $S$를 사용할 수 있다는 점이 시계열 파운데이션 모델에 유익할 가능성도 언급합니다.  
그러나 이는 **Broader Impacts에서 제시한 가능성**이며, 실제 사전학습·전이 실험의 결과는 아닙니다. [p.9]

> **용어 풀이 — 파운데이션 모델:** 여러 데이터와 과제로 미리 학습하여 다양한 후속 문제에 재사용하는 범용 모델.

### 10.2 논문이 답하지 않는 질문

**[분석·해석]**

- **최적 $S$ 선택:** 시험 데이터를 보지 않고 적절한 부분집합 크기를 안정적으로 선택할 수 있는가?
- **성능 향상의 원인:** 관계 제한, 조합 다양성, 공유 학습, 반복 평균이 각각 얼마나 기여하는가?
- **새 변수 일반화:** 학습하지 않은 변수 ID와 새로운 의미의 변수를 어떻게 표현할 것인가?
- **시간에 따른 변화:** 변수 간 관계가 급변할 때에도 기존의 무작위 조합 전략이 효과적인가?
- **현실적인 누락:** 중요한 센서군 전체가 고장 나는 상황에서도 강건한가?
- **동일 비용 비교:** 총학습 시간과 추론 시간을 같게 맞춰도 성능 우위가 유지되는가?
- **불확실성과 응용 성과:** 예측구간의 정확도나 실제 의사결정 성과도 개선되는가?

이 질문들은 원문에 대한 비판인 동시에, 일반화 성능을 한 단계 더 검증하기 위한 후속 실험의 기준입니다.

### 11.2 ‘최초 제안’과 최신 버전에 관한 주의

**[분석·해석]** PMformer의 “처음 제안한다”는 표현은 저자들이 정의한 부분집합·공유 모델 방식의 범위에서 읽어야 합니다. 모든 중간적 채널 전략의 최초 제안으로 확대하기는 어렵습니다. 예를 들어 CCM의 최초 공개일은 **2024년 3월 31일**로 PMformer v1보다 앞섭니다. [arxiv.org](https://arxiv.org/abs/2404.01340?utm_source=chatgpt.com)

또한 PCD 논문의 초기 제목은 *Partial Channel Dependence with Channel Masks for Time Series Foundation Models*였지만, 확인한 **2026년 v4의 제목은 「Dataset-Driven Channel Masks in Transformers for Multivariate Time Series」**이고, 메타데이터에는 ICASSP 2026으로 기재되어 있습니다. 버전을 섞어 비교하면 안 됩니다. [arxiv.org](https://arxiv.org/abs/2410.23222?utm_source=chatgpt.com)

### 11.3 확인 가능한 후속 영향

**[외부 연구의 저자 보고]** 2025년의 가상자산 예측 연구는 PMformer를 직접 적용하여 BTCUSDT·ETHUSDT의 일별 수익률을 예측합니다. 이 연구는 예측오차 개선이 모의 거래 수익 개선으로 일관되게 이어지지 않는다고 보고합니다. [§III, §VII–VIII] [arxiv.org](https://arxiv.org/html/2512.04099v1?utm_source=chatgpt.com)

**[분석·해석]** 이는 PMformer의 실제 후속 응용 사례로 볼 수 있으며, 동시에 **예측 지표 개선과 응용 목적 달성은 따로 평가해야 한다**는 점을 보여줍니다. 다른 부분 의존성 연구들을 모두 PMformer의 직접적인 후속이라고 단정할 근거는 확인되지 않았습니다.

## 12. 유망한 접근법과 빠른 핵심 검증

다음은 **논문에서 이미 입증된 결과가 아니라, 그 결과를 바탕으로 제안하는 검증 계획**입니다.

### 12.1 우선 검증할 기술

### 12.2 일반화 성능 연구를 위한 다음 단계

**[후속 연구 제안]**

1. **기존 변수 누락과 새로운 변수 전이를 분리한다.**  
   학습 때 보았던 변수의 일부가 사라지는 조건과, 학습하지 않은 변수를 예측하는 조건을 별도로 설계해야 합니다.

2. **변수 ID 임베딩의 역할을 확인한다.**  
   변수 식별 임베딩을 사용하는 현재 방식과 변수 수·식별자에 덜 의존하는 표현을 비교하면, 공유 모델이 어느 정도 재사용 가능한 표현을 학습하는지 확인할 수 있습니다. [원문 Eq.2; Moirai §3.1.2]

3. **동일 계산 예산에서 비교한다.**  
   부분집합 크기와 반복 횟수를 함께 조절하고, MSE·MAE와 전체 추론시간·최대 메모리를 기록해야 합니다.

4. **누락 조건을 현실적으로 확장한다.**  
   무작위 변수 삭제 이후에는 서로 관련된 센서군의 동시 고장, 중요한 변수의 선택적 누락을 평가하고, 비교 모델에도 적절한 결측 처리 방법을 제공해야 합니다.

5. **시간에 따른 관계 변화를 평가한다.**  
   고정된 한 시험 구간 외에 여러 시점의 평가 구간을 사용하고, 변수 관계가 바뀌는 조건에서 고정 $S$와 적응적 관계 선택을 비교할 수 있습니다.

6. **이론에서는 조합 수와 유효 표본 수를 구별한다.**  
   같은 원시 시계열을 재조합한 입력의 의존성을 고려하고, 실제로 계산 가능한 일반화 지표와 연결하는 연구가 필요합니다.

> **용어 풀이 — 유효 표본 수:** 관측들 사이의 의존성을 고려했을 때, 독립적인 정보가 어느 정도 있는지를 나타내는 개념.

## 13. 결론 및 시사점

### 13.1 저자가 제시한 시사점과 후속 과제

**[저자 보고]** PMformer는 전체 변수 관계를 모두 사용하는 방식과 변수 관계를 무시하는 방식 사이에 실용적인 설계 공간이 있음을 보여줍니다. 공유 모델과 무작위 부분집합 처리는 예측 성능, 변수 간 어텐션 효율, 일부 변수 누락 대응에서 장점을 보였습니다. 후속 과제로는 사후 엔트로피의 정밀한 계산과 이론 가정의 완화를 제시합니다. [p.9]

### 13.2 학계·실무에 대한 해석

**[분석·해석 — 학계]** 가장 의미 있는 기여는 **부분집합 크기와 조합 다양성을 모델 설계의 명시적 변수로 만든 것**입니다. 향후 연구는 모델을 더 복잡하게 만드는 것뿐 아니라, 허용하는 변수 관계의 범위를 통제하고 그 효과를 분리하여 검증할 수 있습니다. [Eqs.1–6, Tables 3·9, Figures 3–4]

**[분석·해석 — 실무]** 변수 수가 많고 일부 입력을 사용할 수 없는 환경에서는 검토할 가치가 있습니다. 다만 실제 도입 판단에는 전체 실행시간, 누락 양상, 비교 모델의 결측 처리, 목표 업무의 성과 지표를 함께 평가해야 합니다. [Figures 6–7; 후속 응용 연구 §VII–VIII]

### 13.3 일반화 성능에 대한 최종 판단

**PMformer는 일반화 성능을 개선할 수 있는 유망한 학습 전략을 제시했지만, 모든 일반화 문제를 해결한 모델로 볼 근거는 없습니다.**

현재 증거가 가장 강한 부분은 **동일 데이터셋의 미래 예측과 기존 변수의 무작위 누락 상황**입니다. 다음 연구에서 중요한 것은 부분집합 전략의 효과가 **새로운 변수, 다른 데이터셋, 변화하는 관계, 동일 계산 예산**에서도 유지되는지 확인하는 일입니다. 이때 새로운 복잡한 구조보다 먼저 **같은 기본 모델에서 부분집합 크기·조합 다양성·추론 반복만 바꾸는 검증**이 가장 직접적인 출발점입니다.
