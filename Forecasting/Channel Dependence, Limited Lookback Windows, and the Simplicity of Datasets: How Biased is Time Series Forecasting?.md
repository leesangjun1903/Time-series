# Channel Dependence, Limited Lookback Windows, and the Simplicity of Datasets: How Biased is Time Series Forecasting?

**핵심 판단은 “CI와 CD 중 어느 쪽이 보편적으로 우월한가”보다, 데이터의 채널 관계·입력 길이·평가 조건이 모델에 얼마나 적합한지를 먼저 확인해야 한다는 것입니다.**  
다만 첨부본에는 본문 요약표와 부록 상세표 사이의 수치 불일치가 있어, 세부 순위와 효과 크기는 주의해서 해석해야 합니다.

보고서에서는 **[저자 보고]**, **[분석자의 해석]**, **[추가 검증 제안]**을 구분합니다. 외부 연구는 관련 연구 비교에 사용하며, 그 결과를 첨부 논문의 실험 결과와 섞지 않습니다.

## 1. Executive summary — 9문장

1. 이 논문은 장기 시계열 예측 연구의 모델 순위가 **과거 입력 길이인 lookback window를 고정하는 관행과 제한적인 벤치마크 구성에 의해 편향될 수 있다**고 주장합니다. **[pp.1–3, Figure 1]**
2. 저자들은 입력 길이를 모델별 하이퍼파라미터로 조정하면 모델 간 상대 순위가 바뀌며, 특히 채널 독립형 모델과 채널 의존형 모델의 비교가 달라진다고 보고합니다. **[p.2, Figure 1; p.10, Figure 3]**
3. 표준 데이터셋에서는 채널 독립형인 CI 모델이 대체로 유리하며, 본문 요약표에서 PatchTST-CI의 평균 순위는 비교한 10개 변형 중 가장 좋은 2.14입니다. **[p.8, Table 2]**
4. 반면 채널 간 상호작용을 갖는 여섯 ODE 데이터셋에서는 CD 변형이 24개 대응 비교 중 18개에서 우세하고, Crossformer-CD가 여섯 데이터셋 중 네 개에서 최저 평균 MSE를 기록했다고 보고합니다. **[p.3, Table 1; p.9, Table 4]**
5. Granger 분석은 ODE 데이터에서 다른 채널의 과거가 제공하는 선형 예측 정보가 더 큰 경향을 보여 주지만, 저자도 이를 물리적 인과관계의 증명으로 해석하지 않습니다. **[pp.8–9, Tables 3–4]**
6. 첨부 v3의 중심 기여는 새로운 예측망의 설계보다 **입력 길이 튜닝, CI/CD 대응 비교, 통계적 데이터 진단, ODE 평가를 결합한 실험 방법론**입니다. **[pp.3, 5–7, 15]**
7. 일반화에 관한 직접적인 증거는 데이터셋별로 학습한 모델의 테스트 성능이며, 새로운 도메인으로의 무학습 전이나 적은 학습 표본에서의 우위를 직접 입증하지는 않습니다. **[pp.7, 13–15]**
8. 본문 평균과 부록 상세값의 일부 불일치, 승수 집계 문제, 모델 간 유의성 검정의 부재 때문에 작은 성능 차이와 정확한 순위는 확정적으로 받아들이기 어렵습니다. **[Tables 1–2, 4, 8–10]**
9. 따라서 이 논문의 가장 유용한 시사점은 **일반화 성능을 높이려면 모델 복잡도를 늘리기 전에 데이터의 의존 구조와 관측 시간 범위에 맞는 모델·평가 설정을 검증해야 한다**는 것입니다. **[pp.10–11]**

> **용어 풀이**
>
> - **채널:** 온도·습도·전력 사용량처럼 동시에 관측하는 개별 변수.
> - **CI, Channel Independence:** 각 채널의 예측에 그 채널의 과거 입력만 사용하는 방식.
> - **CD, Channel Dependence:** 다른 채널의 과거 입력도 함께 활용하는 방식.
> - **MSE, 평균제곱오차:** 예측값과 실제값 차이를 제곱한 뒤 평균한 값으로, 작을수록 좋음.
> - **ODE, 상미분방정식:** 시간이 흐를 때 상태가 어떻게 변하는지를 변화율로 표현한 방정식.

## 2. 연구 배경, 해결하려는 문제, 목적과 필요성

### 2.1 해결하려는 문제

**[저자 보고]** 논문은 두 가지 평가 관행을 문제 삼습니다.

첫째, 모델과 데이터셋이 달라도 입력 길이를 흔히 $L=96$으로 고정합니다.  
그런데 모델마다 긴 이력을 활용하는 능력이 다르므로, 동일한 입력 길이에서 얻은 순위가 각 모델을 충분히 조정했을 때의 순위와 같지 않을 수 있습니다.  
실제로 Weather의 Figure 1에서는 입력 길이에 따라 Crossformer-CD와 TimeMixer-CD의 상대 성능이 역전됩니다. **[p.2, Figure 1]**

둘째, 자주 사용하는 ETT·Weather·Electricity·Traffic에서 얻은 결과를 다변량 시계열 전체의 특성처럼 해석합니다.  
저자들은 이 데이터들이 채널 상호작용을 활용하는 능력을 충분히 평가하지 못할 수 있다고 보고, 수학적으로 결합 구조가 존재하는 ODE 데이터를 추가합니다. **[pp.3, 6–7]**

> **용어 풀이 — 벤치마크 편향:** 평가용 데이터와 조건이 특정 모델에 유리해서, 그 결과를 더 넓은 문제에 적용할 때 판단이 달라질 수 있는 현상입니다. 여기서 “편향”은 연구자의 의도적 조작을 뜻하지 않습니다.

### 2.2 연구 목적

연구 목적은 다음 세 질문으로 정리할 수 있습니다.

| 연구 질문 | 논문이 사용한 확인 방법 |
|---|---|
| 입력 길이를 조정하면 모델 순위가 달라지는가? | 여러 $L$에서 하이퍼파라미터를 조정하고 성능·선택 빈도 비교 |
| 채널 간 정보 교환은 언제 도움이 되는가? | 같은 모델 계열의 CI/CD 변형 비교 |
| 표준 데이터에서 얻은 결론이 다른 구조의 데이터에서도 유지되는가? | 표준 데이터와 ODE 데이터의 성능 및 Granger 통계 비교 |

**근거:** pp.2–7, Figures 1–2, Table 1.

### 2.3 연구가 필요한 이유와 해석상의 경계

**[분석자의 해석]** 이 연구는 “새로운 구조가 기존 구조보다 좋다”는 주장에 앞서, **기존 모델의 입력 길이와 평가 데이터가 적절했는지** 확인하도록 요구한다는 점에서 의미가 있습니다.

다만 **고정된 입력 길이의 비교 자체가 항상 부당한 것은 아닙니다.**  
예를 들어 실제 서비스에서 최근 96개 관측값만 사용할 수 있다면, $L=96$ 비교는 그 제약에 맞는 평가입니다.  
반면 모델별 최대 성능을 비교하려면 각 모델의 $L$을 함께 조정해야 합니다.  
두 평가는 서로 다른 질문에 답하므로 별도로 보고하는 편이 명확합니다. **[해석 근거: p.2, Figure 1; pp.10–11]**

## 5. 제안하는 방법, 수식, 모델 구조

### 5.1 먼저 확인할 사항: v3의 제안은 평가 프레임워크

첨부 v3는 새로운 예측 모델의 전체 구조를 제안하는 형태가 아닙니다. 실질적인 제안은 다음 네 요소를 결합한 평가 방식입니다.

1. 모델별 입력 길이 조정.
2. 대응하는 CI/CD 변형 비교.
3. Granger 분석을 통한 채널 관계 진단.
4. 표준 데이터와 ODE 데이터의 병행 평가.

**FaCT는 p.14 Table 7의 “Crossformer/FaCT” 행명에 한 번 등장하지만, v3에는 FaCT의 구조·성능·런타임을 설명하는 본문이 없습니다.** 따라서 이 첨부본의 “제안 모델”을 FaCT라고 설명하는 것은 적절하지 않습니다. **[pp.3, 14–15]**

### 5.2 예측 문제와 목적함수

원문은 입력과 정답을 다음과 같이 정의합니다. **[p.4, §3]**

$$
X\in\mathbb{R}^{C\times L},
\qquad
Y\in\mathbb{R}^{C\times H},
\qquad
\widehat{Y}=f_\theta(X).
$$

- $C$: 채널 수.
- $L$: 과거 입력 길이.
- $H$: 미래 예측 길이.
- $X$: 모든 채널의 과거 관측값.
- $Y$: 예측해야 할 미래 실제값.
- $\widehat{Y}$: 모델의 예측값.
- $f_\theta$: 매개변수 $\theta$를 가진 예측 함수.

목표는 기대 예측 손실을 최소화하는 것입니다.

$$
\min_\theta
\mathbb{E}_{(X,Y)\sim p}
\left[
\ell\bigl(Y,f_\theta(X)\bigr)
\right].
$$

- $p$: 입력·정답 쌍의 데이터 분포.
- $\mathbb{E}$: 그 분포에 대한 평균.
- $\ell$: 손실함수이며, 이 연구에서는 주로 MSE를 사용합니다.

MSE를 성분별로 풀어 쓰면 다음과 같습니다. 이는 원문의 목적함수를 설명하기 위한 전개입니다.

```math
\text{MSE}(Y,\widehat{Y})
=
\frac{1}{CH}
\sum_{c=1}^{C}
\sum_{h=1}^{H}
\left(Y_{c,h}-\widehat{Y}_{c,h}\right)^2.
```

여기서 $c$는 채널 인덱스이고, $h$는 예측 구간 안의 미래 시점 인덱스입니다.

**[분석자의 해석]** 원문은 창으로 나눈 표본을 독립·동일분포처럼 다루는 최적화 표현을 사용하지만, 겹치는 시계열 창은 실제로 서로 의존할 수 있습니다. 따라서 이러한 수식 표현이 표본 간 독립성을 실증한 것은 아닙니다. **[p.4, §3]**

### 5.3 CI와 CD의 차이

**원문 식 (1): CI의 정의**는 다음과 같습니다. **[p.5]**

$$
\widehat{Y}(X)_c=f(x_{c,:}),
\qquad
c\in\{1,\ldots,C\}.
$$

- $x_{c,:}\in\mathbb{R}^{L}$: 채널 $c$의 과거 관측값.
- $f:\mathbb{R}^{L}\rightarrow\mathbb{R}^{H}$: 한 채널의 과거를 미래로 변환하는 함수.
- $\widehat{Y}(X)_c$: 채널 $c$에 대한 예측.

핵심은 채널 $c$를 예측할 때 **다른 채널의 현재 입력을 직접 섞지 않는다는 것**입니다. 동일한 $f$를 여러 채널에 적용할 수 있으므로, CI가 “채널마다 별도 모델을 따로 학습한다”는 뜻은 아닙니다.

CD는 설명용으로 다음처럼 표현할 수 있습니다.

$$
\widehat{Y}_c=f_{\theta,c}(X).
$$

$f_{\theta,c}$는 전체 입력 $X$를 이용해 채널 $c$를 예측하는 함수입니다. 이 식은 CI와의 차이를 보여 주는 **해설용 표현이며, 논문이 새로 제안한 번호 있는 식은 아닙니다.**

> **용어 풀이 — 채널 독립성과 통계적 독립성:** CI는 모델의 입력 처리 방식에 관한 말입니다. 실제 데이터의 채널들이 통계적으로 독립이라는 가정을 증명하거나 의미하지는 않습니다.

### 5.4 모델 구조와 CI/CD 변형

아래는 **이 연구의 실험 변형**을 중심으로 정리한 것입니다. **[pp.5–6; Appendix D, p.15]**

| 모델 | 주요 정보 처리 구조 | 이 논문에서 비교한 CI/CD 변형 |
|---|---|---|
| **DLinear** | 시계열을 추세와 잔여 성분으로 분해하고 선형 투영 결과를 결합 | CI만 사용 |
| **TSMixer** | 시간축과 채널축의 정보를 MLP로 혼합 | CD에서 채널 혼합 부분을 제거해 CI 구성; 원 연구의 TMix-Only에 대응 |
| **PatchTST** | 시간 구간을 패치로 나누고 Transformer로 처리 | 원형 CI와, 패치·채널 차원을 펼쳐 공동 attention을 적용한 CD 비교 |
| **Crossformer** | 시간 세그먼트 attention과 채널 attention을 순서대로 수행하는 Two-Stage Attention | 두 단계를 유지한 CD와, 두 번째 채널 attention 단계를 제거한 CI 비교 |
| **iTransformer** | 변수별 시간 이력을 토큰으로 만들고 변수 사이에 attention 적용 | CD만 사용 |
| **TimeMixer** | 여러 시간 해상도의 표현을 분해·혼합하여 예측 | 채널 혼합을 사용하는 설정과, 이를 제거하면서 다중 해상도 시간 혼합을 유지한 CI 비교 |

> **용어 풀이**
>
> - **패치·세그먼트:** 인접한 여러 시점을 하나의 처리 단위로 묶은 것.
> - **토큰:** 모델이 하나의 단위로 다루는 벡터 표현.
> - **attention:** 다른 위치나 변수의 정보를 얼마나 참고할지 학습하는 계산.
> - **MLP:** 선형 변환과 비선형 함수를 여러 층으로 쌓은 신경망.
> - **다중 해상도:** 짧은 시간 변동과 긴 시간 추세를 서로 다른 시간 간격에서 함께 보는 방식.

Crossformer 원 구조에는 채널 정보를 모았다가 나누는 router와 여러 시간 규모를 처리하는 계층형 encoder–decoder가 포함됩니다. 첨부 논문의 CI 변형은 그중 채널 attention 단계를 제거하는 비교입니다. [GitHub](https://github.com/Thinklab-SJTU/Crossformer/blob/master/readme.md?plain=1\&utm_source=chatgpt.com)

**[분석자의 해석]** 이 비교는 채널 혼합의 유용성을 살피는 데 도움이 되지만, 파라미터 수와 계산량까지 동일하게 맞춘 단일 요인 실험은 아닙니다. 단계를 제거하거나 공동 attention을 추가하면 모델 용량도 달라지므로, 성능 차이를 전부 “다른 채널 정보의 순수 효과”라고 해석하기 어렵습니다. **[근거: p.15]**

### 5.5 입력 길이와 다른 설정의 공동 선택

논문의 절차를 설명용 수식으로 정리하면 다음과 같습니다.

```math
(L^\star,\lambda^\star)
=
\underset{(L,\lambda)\in\mathcal{S}}{\text{arg min}}
\;
\text{MSE}_{\text{val}}
\left(f_{\widehat{\theta}(L,\lambda)}\right).
```

- $\mathcal{S}$: 실제 탐색에서 시험한 설정 조합.
- $L$: 입력 길이.
- $\lambda$: 학습률·층 수 등 나머지 하이퍼파라미터.
- $\widehat{\theta}(L,\lambda)$: 해당 설정으로 학습한 모델 매개변수.
- $\text{MSE}_{\text{val}}$: 검증 데이터의 평균제곱오차.
- $L^\star,\lambda^\star$: 시험한 후보 중 검증 성능이 가장 좋은 설정.

이는 무한한 설정 공간의 전역 최적해를 구했다는 뜻이 아니라, **제한된 탐색 후보 안에서 검증 성능으로 선택했다는 뜻**입니다. **[p.7, §5.3]**

입력 길이는 관측 간격과 함께 해석해야 합니다. 예를 들어 96개 입력은 시간별 데이터에서 4일이지만, 15분 간격 데이터에서는 1일입니다. 따라서 동일한 $L$이 동일한 실제 시간 범위를 뜻하지 않습니다. **[p.10, §6.4; p.13, Table 5]**

### 5.6 Granger 분석: 다른 채널이 추가 예측 정보를 주는가?

Granger 분석은 대상 채널 자신의 과거만 사용하는 회귀와, 다른 채널의 과거도 추가한 회귀를 비교합니다. **[p.5, 식 (2)–(4)]**

**제한 모형의 잔차 제곱합 — 원문 식 (2)**

```math
\text{SSR}_{u}
=
\sum_{t=L+1}^{L+H}
\left(
x_{c_1,t}
-a_0
-\sum_{i=1}^{L}a_i x_{c_1,t-i}
\right)^2.
```

**다른 채널을 추가한 모형의 잔차 제곱합 — 원문 식 (3)**

```math
\text{SSR}_{mv}
=
\sum_{t=L+1}^{L+H}
\left(
x_{c_1,t}
-a_0
-\sum_{i=1}^{L}a_i x_{c_1,t-i}
-\sum_{i=1}^{L}b_i x_{c_2,t-i}
\right)^2.
```

- $c_1$: 예측 대상 채널.
- $c_2$: 추가 정보를 제공하는 후보 채널.
- $x_{c,t}$: 시점 $t$의 채널 $c$ 관측값.
- $L$: 회귀에 포함하는 시차 수.
- $a_0$: 절편.
- $a_i,b_i$: 각각 자기 채널과 다른 채널의 과거값에 붙는 회귀계수.
- $\text{SSR}\_{u},\text{SSR}_{mv}$: 두 모형의 잔차 제곱합.
- $H$: 원문 식의 합산 구간 길이에 사용된 기호.

두 회귀는 각각 적합하는 것으로 이해해야 하며, 동일한 $a_i$ 기호를 썼다고 계숫값도 같다는 뜻은 아닙니다.

**검정 통계량 — 원문 식 (4)**

```math
F
=
\frac{
(\text{SSR}_{u}-\text{SSR}_{mv})/L
}{
\text{SSR}_{mv}/(N-k_{mv})
}.
```

- $N$: 회귀에 사용한 관측 수.
- $k_{mv}$: 다른 채널을 포함한 모형의 매개변수 수.
- 분자의 $L$: 추가한 시차 계수의 수.

검정의 귀무가설은 다음과 같이 표현할 수 있습니다.

$$
H_0:b_1=b_2=\cdots=b_L=0.
$$

즉, “채널 $c_2$의 과거를 추가해도 선형 예측에 도움이 되지 않는다”는 가설입니다.

> **용어 풀이**
>
> - **잔차:** 실제값에서 모형이 설명한 값을 뺀 오차.
> - **귀무가설:** 검정에서 우선 유지하고 증거가 충분할 때 기각하는 가설.
> - **$F$ 통계량:** 추가 변수로 줄어든 오차가 모형의 복잡도 증가에 비해 얼마나 큰지 평가하는 값.
> - **유의수준 0.05:** 귀무가설이 맞을 때 이를 잘못 기각할 확률을 통제하기 위한 기준.

실제 분석에서는 처음 1,000시점을 사용하고, 높은 Pearson 상관을 가진 중복 채널을 제거하며, ADF 검사와 필요한 차분을 수행합니다. 고차원 데이터에서는 20개 채널을 무작위 선택합니다. **[pp.14–15]**

> **용어 풀이**
>
> - **정상성:** 시계열의 통계적 특성이 시간에 따라 일정하다는 성질.
> - **ADF 검사:** 정상성과 관련된 단위근 여부를 확인하는 통계 검사.
> - **차분:** 연속 관측값의 차이를 취해 추세 등의 영향을 줄이는 변환.
> - **Pearson 상관:** 두 변수의 선형적인 동반 변화 정도.

**중요한 제한:** 이 분석은 다른 채널의 **선형 예측 정보**를 조사하며 물리적 인과를 증명하지 않습니다. 저자도 이를 명시합니다. 또한 식 (2)–(3)의 $H$개 합산 표기와 실제 첫 1,000시점 검정에서의 $N$ 사이 대응이 문서에 충분히 설명되어 있지는 않습니다. **[p.9, §6.3; p.14, Appendix C.3]**

### 5.7 ODE 수식의 역할

저자들은 단순화한 이중 진자 식으로 채널 결합을 설명합니다. **[p.7, 식 (5)–(6)]**

```math
\frac{d^2\theta_1(t)}{dt^2}
=
-\frac{2g}{l}\theta_1(t)
+\frac{g}{l}\theta_2(t),
```

```math
\frac{d^2\theta_2(t)}{dt^2}
=
\frac{2g}{l}\theta_1(t)
-\frac{2g}{l}\theta_2(t).
```

- $\theta_1(t),\theta_2(t)$: 두 진자의 각도.
- $t$: 연속 시간.
- $g$: 중력 가속도.
- $l$: 봉의 길이.
- $d^2\theta_j/dt^2$: 진자 $j$의 각가속도.

한 진자의 변화율에 다른 진자의 상태가 들어간다는 것이 핵심입니다.

**[분석자의 해석]** 이 두 식은 선형 결합으로 이루어진 단순화식이므로, 이것만으로 혼돈을 입증하거나 실제 혼돈 데이터 생성의 전체 방정식을 제시했다고 해석해서는 안 됩니다.  
또한 이 식은 예측 신경망의 구조가 아니라 **데이터에 채널 결합이 존재한다는 설명**입니다.

### 6.2 DLinear의 “58.3% 성능 저하”를 정확히 읽는 방법

저자들은 Crossformer 대비 DLinear의 성능 저하 중앙값을 58.3%로 보고합니다. **[p.9, §6.3]**

이를 오류 지표 기준으로 정확히 표현하면 다음과 같습니다.

> **Crossformer-CD 대비 DLinear의 MSE가 데이터셋별 중앙값 기준 약 58.3% 높았습니다.**

```math
r_d
=
100\left(
\frac{
\text{MSE}_{\text{DLinear},d}
}{
\text{MSE}_{\text{Crossformer-CD},d}
}
-1
\right).
```

- $d$: ODE 데이터셋.
- $r_d$: Crossformer-CD 대비 DLinear의 MSE 증가율(%).

lag 96에서 Lorenz의 $F$는 **353.25**, LorenzCoupled는 **160.95**인 반면, CellCycle은 **2.61**, Hopfield는 **1.92**입니다.

또한 시차가 커질 때 $F$가 작아지는 현상을 실제 물리적 결합의 약화로 곧바로 해석할 수 없습니다. 식 (4)에서 시차 수와 자유도 자체가 달라지기 때문입니다.

### 6.4 일반화 관점에서 중요한 RevIN 결과

| 데이터·모델 | RevIN 사용 | RevIN 미사용 | 관찰 |
|---|---:|---:|---|
| LorenzCoupled, Crossformer-CD | 0.453 | **0.276** | 이 ODE에서는 미사용이 유리 |
| Hopfield, Crossformer-CD | 0.058 | **0.049** | 미사용이 유리 |
| ETTh2, Crossformer-CD | **0.322** | 0.537 | 표준 데이터에서는 사용이 유리 |
| ETTm1, Crossformer-CD | **0.339** | 0.364 | 사용이 유리 |

**출처:** p.24, Table 13.

그러나 PatchTST는 같은 방향이 아닙니다. 예를 들어 Hopfield에서는 RevIN 사용 **0.151**, 미사용 **0.156**으로 사용 쪽이 조금 더 좋습니다.

따라서 지지되는 해석은 **“RevIN도 데이터와 모델의 조합별로 검증해야 한다”**입니다. “ODE에서는 RevIN이 해롭다”는 보편적 결론은 표에 의해 지지되지 않습니다. **[p.24, Appendix J]**

## 8. 통계적으로 취약한 부분과 비교 불가능한 수치

### 8.1 가장 중요한 문제: 본문 평균과 부록 값의 불일치

다음 불일치는 PDF 표 자체에서 확인됩니다.

| 항목 | 본문 요약표 | 부록의 네 예측 길이 값 | 부록 값의 단순평균 |

**[분석자의 판단]** 반올림으로 설명하기 어려운 차이입니다. 어느 표가 맞는지는 문서만으로 결정할 수 없으므로, 부록 평균을 임의로 정정값으로 채택하지 않았습니다. **정확한 세부 순위와 효과 크기에는 원시 실험 결과 확인이 필요합니다.**

### 8.2 CI/CD 승수도 일관되지 않음

Table 1은 표준 데이터의 결과를 **CI 21승, CD 7승**으로 보고합니다. 그러나 Table 2에서:

- 양쪽 모두 수치가 있는 쌍만 비교하면 **CI 21승, CD 4승**입니다.
- OOM을 패배로 처리해 28쌍을 모두 세면 **CI 22승, CD 6승**입니다.

따라서 21:7은 **저자의 보고값으로 인용할 수 있지만, Table 2로 일관되게 재구성되는 수치는 아닙니다.** **[pp.3, 8]**

> **용어 풀이 — OOM:** 메모리 부족으로 해당 실행의 결과를 얻지 못한 상태입니다. 그 자체가 예측오차 측정값은 아닙니다.

### 8.3 통계적 강도에 관한 평가

| 항목 | 원문이 제공하는 것 | 확인할 수 없는 것 또는 취약점 |
|---|---|---|
| **반복 실험** | 다섯 시드와 Table 10의 표준편차 | 모델 간 차이에 대한 쌍별 검정·신뢰구간은 확인되지 않음 |
| **표준편차 집계** | 네 예측 길이의 표준편차를 평균 | 이것은 네 예측 길이 평균 성능의 표준편차와 같지 않음 |
| **작은 성능 차이** | CellCycle의 Crossformer 0.429 대 0.428 | 0.001 차이를 통계적 우위로 확정하기 어려움 |
| **승수 합계** | 모델·데이터별 승패 집계 | 같은 데이터와 모델 계열을 공유하므로 24개·28개의 독립 표본으로 볼 수 없음 |
| **Granger 다중 검정** | 채널 쌍별 유의수준 0.05 | 다중검정 보정은 보고되지 않음 |
| **Granger 표본 선택** | 첫 1,000시점, 일부 데이터의 20개 채널 | 시간 구간·채널 표본을 바꿨을 때의 민감도는 미보고 |
| **탐색 예산** | 20회 trial | 모든 모델에서 충분히 좋은 설정을 찾았는지, 동일 계산예산인지 보장되지 않음 |
| **CI/CD 구조 비교** | 채널 혼합 부분의 추가·제거 | 모델 용량·연산량까지 통제한 비교는 아님 |
| **데이터 선택** | 결합이 명확하고 복잡한 ODE 여섯 개 | 전체 실세계 시계열의 대표 표본은 아님 |

**근거:** pp.4, 7, 14–15, 18–19; Tables 10–11.

> **용어 풀이**
>
> - **신뢰구간:** 추정값이 표본 변화에 따라 얼마나 불확실한지 표현하는 구간.
> - **다중검정 보정:** 많은 검정을 동시에 수행할 때 우연한 유의 결과가 늘어나는 문제를 조절하는 절차.
> - **민감도 분석:** 데이터 선택이나 설정을 바꾸어도 결론이 유지되는지 확인하는 분석.

### 8.4 직접 비교하면 안 되는 수치

1. **서로 다른 데이터셋의 MSE 절대값**  
   값의 척도와 난이도가 다르므로, Lorenz의 MSE가 Weather보다 크다는 사실만으로 모델 일반화가 더 나쁘다고 판단할 수 없습니다.

2. **단일 예측 길이 결과와 네 길이 평균**  
   Table 9의 Lorenz· $H=96$ Crossformer-CD **0.266**은 Table 4의 평균 **0.643**과 다른 조건의 수치입니다.

3. **자체 재실험값과 외부 논문 인용값**  
   Table 8의 별표 값과 OOM이 섞인 비교는 실행 조건이 완전히 통일되었다고 볼 수 없습니다.

4. **동일한 이름을 가진 다른 데이터**  
   Crossformer 원 저자 저장소는 원 논문의 WTH가 **12채널**이며, 21채널 Weather와 다르다고 명시합니다. 첨부 v3의 Weather는 21채널입니다. [GitHub](https://github.com/Thinklab-SJTU/Crossformer/blob/master/readme.md?plain=1\&utm_source=chatgpt.com)

5. **예측오차와 통계 검정량**  
   MSE, Granger $F$, 귀무가설 기각률은 서로 다른 질문에 답하므로 하나의 “성능 점수”로 합치면 안 됩니다.

## 9. 모델의 일반화 성능 향상 가능성

### 9.1 이 논문이 보여 준 일반화와 보여 주지 않은 일반화

| 일반화의 의미 | 이 논문의 근거 |
|---|---|
| **같은 데이터셋의 미관측 미래 구간 예측** | 테스트 분할 성능을 통해 직접 평가 |
| **여러 데이터 특성에서 통하는 설계 원칙** | 표준 데이터와 ODE의 비교로 제한적인 근거 제공 |
| **새 데이터셋으로 모델을 그대로 이전** | 직접 평가하지 않음 |
| **적은 학습 표본으로도 좋은 성능 유지** | 학습 표본 수를 줄이는 실험이 제시되지 않음 |
| **새로운 ODE 계수·초기조건·결합 구조에 적응** | 이를 별도 보류한 일반화 실험은 확인되지 않음 |
| **잡음·결측·관측 간격·환경 변화에 강건함** | 해당 요인을 통제한 체계적인 평가가 제시되지 않음 |

**근거:** pp.7, 11, 13–15의 실험 설정과 한계.

> **용어 풀이**
>
> - **zero-shot, 무학습 전이:** 새로운 데이터에 추가 학습 없이 예측하는 것.
> - **분포 이동:** 학습 때와 운영 때 데이터의 통계적 성질이 달라지는 현상.
> - **강건성:** 잡음이나 환경 변화에도 성능이 크게 무너지지 않는 성질.

특히 초록의 **“limited data에서 CD를 선호하라”**는 권고를 “학습 표본이 적을 때 CD가 더 잘 일반화한다고 실증했다”로 확대하면 안 됩니다. 짧은 입력 이력과 적은 학습 표본 수는 다른 조건입니다. **[p.1; pp.7, 13–15]**

### 9.2 일반화 개선 가능성에 대한 해석

**[분석자의 해석]** 논문이 지지하는 개선 가능성은 새로운 범용 모델의 입증보다 **문제에 맞는 설정을 선택해 불필요한 오차를 줄일 가능성**입니다.

- 채널 간 추가 예측 정보가 약하면 CI가 불필요한 관계를 학습하는 부담을 줄일 수 있습니다.
- 유용한 채널 관계가 있으면 적절한 CD 구조가 자기 채널만으로 부족한 정보를 보완할 수 있습니다.
- 입력 길이를 실제 시간 범위와 예측 길이에 맞추면 시간 정보를 더 적절히 사용할 수 있습니다.
- 정규화도 고정 처방으로 사용하지 않고 데이터·모델별로 검증해야 합니다.

이 설명은 관측 결과를 연결한 해석입니다. **일반화 개선량이나 적용 범위를 보장하는 이론은 논문에서 제시하지 않습니다.** **[pp.9–11, 24]**

### 9.3 유망한 접근과 빠른 핵심 검증

다음은 **[추가 검증 제안]**이며, 논문에서 이미 얻은 새 실험 결과가 아닙니다.

| 우선순위 | 접근 | 최소 검증 실험 | 확인할 질문 |
|---|---|---|---|
| **1** | **입력 길이 공동 튜닝** | 기존 CI·CD 모델 한 쌍에 같은 후보 길이와 탐색 예산 적용 | 기존 순위가 입력 길이 때문에 생겼는가? |
| **2** | **채널 혼합 유무 비교** | TSMixer의 시간 혼합만 사용하는 버전과 채널 혼합 버전 비교 | 해당 데이터에서 다른 채널 정보가 실제 이득을 주는가? |
| **3** | **Crossformer의 두 번째 attention 단계 검증** | CI/CD를 동일 분할·동일 예측 시점에서 비교 | ODE에서 관찰한 이득이 대상 데이터에도 나타나는가? |
| **4** | **RevIN 사용 여부 검증** | 기존 모델에 정규화 사용/미사용 설정만 바꾸어 비교 | 정규화가 유용한 신호까지 제거하는가? |
| **5** | **진단 기반 모델 선택 검증** | 학습 구간의 Granger 진단으로 선택 규칙을 만들고 별도 데이터에서 평가 | 통계적 진단이 CI/CD 선택을 실제로 개선하는가? |

초기에는 1–4번처럼 기존 구성요소를 바꾸는 실험이 적절합니다. 모델을 새로 크게 만드는 것보다 실패 원인을 확인하기 쉽기 때문입니다.

후속 평가에서는 동일 예측 시점의 오차를 비교하고, 시간 의존성을 보존하는 구간 단위 재표집으로 불확실성을 확인하는 방법을 고려할 수 있습니다.

> **용어 풀이 — 구간 단위 재표집:** 시점을 하나씩 무작위로 뽑는 대신 연속 구간을 묶어서 다시 뽑아, 시간적 의존성을 일부 유지하는 평가 방법입니다.

## 10. 2020년 이후 관련 연구 비교 분석

아래는 직접 관련성이 높은 연구를 **2026년 발표 사례까지 선별한 비교**입니다. 구조와 평가 목표를 비교하며, 서로 다른 실험의 MSE를 모아 순위를 만들지는 않았습니다.

**[분석자의 해석]** 세 가지 구분이 중요합니다.

**첫째, 첨부 논문의 차별성은 여러 기존 논점을 함께 검사했다는 데 있습니다.** TSMixer와 PatchTST도 채널 처리 및 입력 길이 문제를 다룹니다. 첨부 논문은 이를 ODE와 Granger 분석에 연결합니다. [arxiv.org](https://arxiv.org/html/2303.06053v5?utm_source=chatgpt.com)

**둘째, 최신 접근은 채널 관계를 선택적으로 활용하는 방향을 보여 줍니다.** DUET·TimeFilter·FusionTimePatch는 관계를 모두 무시하거나 모두 섞는 고정 선택을 넘어서는 설계를 제안합니다. 다만 이들이 첨부 논문의 영향을 받아 개발되었다는 계보까지 확인된 것은 아닙니다. [arxiv.org](https://arxiv.org/html/2412.10859v3?utm_source=chatgpt.com)

**셋째, 일반화의 평가 목표를 명시해야 합니다.** PatchTST의 데이터 간 미세조정, iTransformer의 새 채널 예측, Chronos-2의 zero-shot 평가를 모두 같은 의미의 “일반화 성능”으로 묶어 비교할 수는 없습니다. [arxiv.org](https://arxiv.org/html/2211.14730v2?utm_source=chatgpt.com)

다음은 첨부 v3만으로 답을 확정할 수 없는 질문입니다.

1. **Granger 값이 어느 수준이면 CD를 선택해야 하는가?**  
   검증된 임계값이나 자동 선택 규칙의 오류율은 제시되지 않습니다.

2. **Granger 통계가 실제 CD의 성능 이득을 얼마나 잘 예측하는가?**  
   데이터별 진단 점수와 이득 사이의 정량적인 예측·보정 분석이 없습니다.

3. **짧은 입력 길이에서의 이점이 적은 학습 표본에서도 유지되는가?**  
   학습 표본 수를 독립적으로 줄이는 실험이 필요합니다.

4. **ODE의 새로운 초기조건·매개변수·결합 구조에도 일반화하는가?**  
   새로운 시스템 조건을 따로 보류한 검증이 필요합니다.

5. **관측 잡음·결측·비동기 관측이 채널 혼합의 이점을 바꾸는가?**  
   실세계 적용을 위해 별도로 확인해야 합니다.

6. **동일 메모리·학습시간 예산에서도 같은 결론인가?**  
   모든 변형의 계산량과 예측 성능을 통합한 비교가 없습니다.

7. **최신 선택적 채널 혼합 모델을 포함하면 순위가 유지되는가?**  
   TimeFilter·DUET 등은 주요 성능표에서 직접 비교되지 않습니다.

8. **본문과 부록 중 어느 수치가 최종 실험 결과인가?**  
   원시 실행 기록과 집계 코드 확인이 필요합니다.

## 12. 결론, 시사점, 한계와 후속 연구

### 12.1 저자들이 제시한 결론과 시사점

**[저자 보고]** 논문의 권고는 입력 길이를 핵심 하이퍼파라미터로 조정하고, 표준 데이터에서 CI를 강한 기준선으로 사용하며, 채널 관계를 진단해 모델을 선택하고, 입력 길이를 모델 종류·관측 해상도와 함께 맞추라는 것입니다. **[pp.10–11]**

학계에는 **평가 조건과 데이터 구성이 모델에 대한 결론을 바꿀 수 있다는 점**이 중요합니다. 실무에는 모델 이름이나 복잡도보다 대상 데이터의 시간 범위와 채널 관계를 먼저 검증하는 절차가 유용합니다.

### 12.2 저자가 직접 언급한 한계

논문이 명시한 한계는 다음 네 가지입니다. **[p.11, “Limitations and Future Work”]**

- 입력 길이를 다섯 개 이산 후보로 제한했습니다.
- MSE 중심 평가여서 분포 예측이나 척도에 덜 의존하는 성능을 충분히 다루지 못합니다.
- ODE의 이점이 확률성이 강한 실제 데이터로 이전되는지는 추가 검증이 필요합니다.
- 결론은 평가한 모델 계열에 조건부이며, 향후 혼합 구조가 결과를 바꿀 수 있습니다.

> **용어 풀이**
>
> - **분포 예측:** 미래의 한 값뿐 아니라 가능한 값의 범위와 확률까지 예측하는 것.
> - **척도에 덜 의존하는 지표:** 데이터의 단위나 값의 크기가 달라도 비교하기 쉽도록 구성한 오차 지표.

저자들이 제시한 구체적인 후속 대상은 **고빈도 금융시장과 복잡한 인간 행동 분석**입니다. 이 분야에 대한 효과는 이미 검증된 결과가 아니라 후속 계획입니다. **[p.11]**

### 12.3 추가 후속 연구 방향

**[추가 검증 제안]**

우선 본문·부록 집계를 정합하게 만들고, 기존 CI/CD 대응 실험을 재현하는 것이 필요합니다. 그다음에는 다음 순서가 적절합니다.

1. **입력 길이와 채널 혼합 효과 분리:** 예측 시점과 학습 표본 수를 맞추어 비교합니다.
2. **실제 일반화 평가 추가:** 데이터셋·ODE 조건·채널 집합을 통째로 보류하여 평가합니다.
3. **선택적 채널 활용 검증:** 단순한 채널 선택이나 군집화부터 시작해, 모든 채널을 함께 쓰는 것보다 이득이 있는지 확인합니다.
4. **진단 규칙의 외부 검증:** 학습 데이터에서 얻은 관계 진단이 새로운 데이터의 CI/CD 선택에도 유효한지 평가합니다.
5. **평가 지표 확장:** MSE와 함께 평균절대오차, 데이터 척도를 고려한 지표, 필요하다면 확률 예측 지표를 보고합니다.

**최종 평가:** 이 논문은 모델 일반화의 새로운 해법을 확정하기보다, **일반화에 관한 주장을 더 정확하게 검증하기 위한 조건을 제시하는 연구**로 읽는 것이 적절합니다. 가장 먼저 활용할 아이디어는 입력 길이의 공동 튜닝과 같은 모델 계열의 CI/CD 비교이며, 정확한 세부 순위는 표의 불일치를 해소한 뒤 판단해야 합니다.
