# PSformer: Parameter-efficient Transformer with Segment Attention for Time Series Forecasting

**PSformer는 인코더 내부의 파라미터 공유와 변수·국소 시간 정보를 함께 처리하는 attention을 결합해, 작은 모델로 경쟁력 있는 장기 예측 성능을 보여 준 연구입니다.** 다만 실험이 뒷받침하는 일반화의 범위는 주로 **평가한 데이터셋의 테스트 성능**이며, 새로운 도메인·변수·분포로의 일반화까지 입증한 것은 아닙니다. [pp.6–8, Tables 2·5·6]

아래의 페이지 번호는 첨부 PDF의 인쇄 페이지를 따릅니다. **[저자 보고]**는 논문에 직접 제시된 내용, **[검증·해석]**은 표·수식의 대조나 그에 근거한 분석, **[추가 연구 제안]**은 아직 검증되지 않은 후속 실험을 뜻합니다. 관련 연구 비교는 별도의 1차 문헌에 근거하며, PSformer 자체의 실험 결과와 구분했습니다.

## 1. Executive summary — 10문장

1. PSformer는 다변량 장기 시계열 예측에서 시간적 의존성과 변수 간 관계를 활용하면서 모델 복잡도와 과적합 위험을 줄이려는 Transformer 모델입니다. [pp.1–2]
2. 각 변수의 시계열을 겹치지 않는 패치로 나누고, 같은 위치의 여러 변수 패치를 결합하여 하나의 세그먼트를 구성합니다. [p.3, Figure 1]
3. 제안한 Segment Attention은 변수와 패치 내부 시간 위치를 결합한 축에서 관계를 계산하고, 세그먼트 간 정보는 공유 변환 블록을 통해 혼합합니다. [pp.4–5, Figure 2]
4. 세 개의 완전연결층으로 구성된 PS Block을 한 인코더의 두 attention 단계와 최종 융합 단계에서 재사용하되, 기본 설정에서는 서로 다른 인코더끼리 파라미터를 공유하지 않습니다. [pp.5·7–8]
5. 학습에는 기존 방법인 RevIN과 SAM을 사용하며, Exchange 데이터셋에는 정규화 통계 계산 창을 별도로 조정합니다. [pp.6·14·26]
6. 주 실험 표에서 네 예측 길이의 평균 MSE는 8개 데이터셋 중 7개에서 가장 낮고, 평균 MAE는 8개 모두 최저 또는 공동 최저입니다. [p.6, Table 2]
7. ETTh1의 96시점 예측 설정에서 전체 학습 파라미터는 52,416개이고, 인코더 부분은 3,168개입니다. [p.13, Table 8]
8. 구성요소 제거 실험은 인코더 내부 공유와 Segment Attention의 유용성을 지지하지만, 단일 seed와 제한된 데이터셋 때문에 효과의 통계적 안정성은 확인하기 어렵습니다. [pp.8·12, Tables 5–7]
9. 기준선의 실험 조건이 섞여 있고 일부 표의 집계와 설명이 일치하지 않으므로, 논문의 성과는 비교 조건을 명시하여 해석해야 합니다. [pp.12·17·26–29]
10. 저자들은 두 핵심 기술을 시계열 사전학습 대형 모델에 적용하는 것을 후속 방향으로 제시하지만, 이 논문에서 실제 사전학습·제로샷 전이 성능을 검증하지는 않았습니다. [pp.8·28–29]

> **용어**
> - **다변량 시계열**: 같은 시간축에서 함께 관측되는 여러 변수의 데이터
> - **패치 / 세그먼트**: 패치는 한 변수의 짧은 연속 구간, 세그먼트는 같은 구간에 있는 여러 변수 패치의 결합
> - **과적합**: 학습 데이터의 세부 특성에 지나치게 맞추어 새로운 데이터의 예측 오차가 커지는 현상
> - **제로샷 전이**: 대상 데이터셋에서 추가 학습하지 않고 예측하는 평가 방식

## 2. 연구 배경·목표·필요성

### 2.1 해결하려는 문제

**[저자 보고]** 논문은 다음 세 문제를 연결합니다.

첫째, 다변량 시계열 예측은 **긴 시간 범위의 관계**와 **여러 변수 사이의 관계**를 함께 처리해야 합니다. 그러나 시간축 중심의 모델과 변수축 중심의 모델은 각각 다른 정보를 충분히 활용하지 못할 수 있습니다. [pp.1–3]

둘째, 복잡한 Transformer가 항상 단순한 선형 모델보다 좋은 것은 아닙니다. 저자들은 모델이 크면 잡음이나 불필요한 신호에 과적합할 가능성이 있다는 점을 동기로 제시합니다. 다만 이는 연구의 출발 가설이며, PSformer가 잡음의 종류와 강도를 통제한 실험으로 이 가설 전체를 검증한 것은 아닙니다. [pp.1–2]

셋째, 패치 기반 처리와 변수 간 관계 학습을 결합하면서도 **독립적으로 학습해야 할 파라미터를 적게 유지하는 구조**가 필요합니다. PatchTST의 패치 처리와 SAMformer의 변수 간 attention이 주요 비교 배경입니다. [pp.2–3·7]

> **용어**
> - **의존성**: 한 시점이나 변수의 정보가 다른 시점·변수의 값을 예측하는 데 연결되는 관계
> - **채널**: 이 논문에서 하나의 시계열 변수와 같은 의미
> - **공간적 관계**: 여기서는 주로 변수 간 관계를 의미하며, 반드시 지리적 거리나 물리적 공간을 뜻하지 않음

### 2.2 연구 목적과 필요성

**[저자 보고]** 목적은 다음과 같습니다.

- **표현력 확보:** 변수 간 관계와 패치 내부 시간 관계를 함께 학습합니다.
- **파라미터 효율 개선:** 동일한 PS Block을 여러 위치에서 재사용합니다.
- **예측 성능 개선:** 이러한 구조를 장기 예측 벤치마크와 구성요소 실험으로 평가합니다. [p.2, Contributions]

**[검증·해석]** 학술적으로 중요한 질문은 “큰 모델이 더 좋은가”보다 **어떤 축에서 정보를 혼합하고, 어느 범위까지 가중치를 공유해야 예측에 도움이 되는가**입니다. 특히 인코더 내부 공유와 인코더 사이 공유를 구분해 비교했다는 점이 연구의 구체적인 기여입니다. [p.8, Table 5]

### 4.3 기준선 결과를 확보한 방식

모든 기준선을 동일 환경에서 재학습한 것은 아닙니다.

- PSformer와 ModernTCN은 저자들이 실험했습니다.
- SAMformer·TSMixer·FEDformer·Autoformer 결과는 SAMformer 논문에서 가져왔습니다.
- iTransformer·PatchTST·RLinear 결과는 iTransformer 논문에서 가져왔습니다.

따라서 주표는 **여러 연구에서 수집한 결과와 저자 실험을 결합한 비교**로 읽어야 합니다.

## 5. 제안 방법과 모델 구조 — 수식 중심 해설

### 5.1 전체 흐름과 기호

모델은 다음 순서로 처리합니다.

**입력 → RevIN → 패치 분할·변수 결합 → PSformer 인코더 → 원래 차원으로 복원 → 선형 예측층 → RevIN 역변환**

이 흐름은 Figures 1–2에 제시됩니다. [pp.3–4]

| 기호 | 의미 |
|---|---|
| $M$ | 변수 수 |
| $L$ | 입력 과거 길이 |
| $F$ | 미래 예측 길이 |
| $P$ | 한 변수의 패치 길이 |
| $N$ | 패치 또는 세그먼트 개수, $L=NP$ |
| $C$ | 여러 변수 패치를 결합한 길이, $C=MP$ |
| $n$ | 인코더 개수 |

**RevIN**은 입력 구간의 통계적 수준과 크기를 정규화하고, 예측 후 원래 척도로 복원하는 기존 기법입니다. PSformer는 이를 채택하지만 상세 수식을 새로 제안하지는 않습니다. [p.4] [seharanul17.github.io](https://seharanul17.github.io/RevIN/?utm_source=chatgpt.com)

> **용어 — RevIN:** 입력마다 평균·분산 등의 통계적 차이를 조정한 뒤, 출력에서 그 정보를 복원하는 정규화 방식.

### 5.2 패치에서 세그먼트로 변환

입력은 다음과 같습니다.

$$
X\in\mathbb{R}^{M\times L},
\qquad
L=NP,
\qquad
C=MP.
$$

여기서 $X$는 다변량 입력, $\mathbb{R}^{M\times L}$은 변수 $M$개와 시간 위치 $L$개를 가진 실수 행렬입니다.

§3.1의 변환을 명확히 설명하기 위해, 정규화된 입력을 $\widetilde X$, 세그먼트 행렬을 $Z$라고 쓰면 다음과 같이 나타낼 수 있습니다.

```math
s_i
=
\text{vec}
\left(
\widetilde X_{:,\,(i-1)P+1:iP}
\right),
\qquad
Z=[s_1,\ldots,s_N]\in\mathbb{R}^{C\times N}.
```

- $i$: 세그먼트 위치, $1\le i\le N$.
- $s_i$: 같은 시간 구간에 있는 모든 변수의 패치를 결합한 벡터.
- $\text{vec}$: 해당 구간의 변수·시간 값을 정해진 순서로 펼치는 연산.
- $Z$: 원문의 재배열된 입력을 구분하기 위해 이 보고서에서 도입한 기호.

**핵심은 축의 의미입니다.**

- $Z$의 **한 열**은 하나의 세그먼트입니다.
- $Z$의 **한 행**은 특정 변수와 패치 내부 상대 시점의 조합에 대해, $N$개 세그먼트에서 모은 값입니다. [pp.3–5]

예를 들어 ETTh1에서는 $M=7$, $L=512$, $N=32$, $P=16$이므로 $C=112$이고, 인코더 입력은 $112\times32$입니다. [p.21, Appendix B.5]

### 5.3 Parameter Shared Block: 실제로 무엇을 공유하는가?

원문 식 (1)–(2)를 중간 변수 $U$로 구분하면 다음과 같습니다.

$$
U=\text{GeLU}(ZW^{(1)})W^{(2)}+Z,
\qquad
f_\theta(Z)=UW^{(3)}.
$$

- $Z,U\in\mathbb{R}^{C\times N}$: 블록 입력과 중간 출력.
- $W^{(j)}\in\mathbb{R}^{N\times N}$: $j$번째 학습 가중치, $j=1,2,3$.
- $\theta$: 이 블록의 학습 파라미터를 묶은 표기.
- $f_\theta$: PS Block 전체를 나타내는 함수.

따라서 원문 식 (3)은 다음과 같습니다.

```math
f_\theta(Z)
=
\left[
\text{GeLU}(ZW^{(1)})W^{(2)}+Z
\right]W^{(3)}.
```

위 식의 기호는 앞 식과 같으며, 출력 차원도 $C\times N$입니다. [p.5, 식 (1)–(3)]

> **용어**
> - **완전연결층**: 입력 성분을 학습된 가중합으로 변환하는 층
> - **GeLU**: 입력을 부드럽게 조절하는 비선형 활성화 함수
> - **잔차 연결**: 변환한 결과에 입력을 더하는 경로; 위 식의 $+Z$에 해당

공유되는 것은 **세 가중치가 서로 같은 값이라는 뜻이 아니라, 세 층으로 구성된 전체 블록**입니다. $W^{(1)},W^{(2)},W^{(3)}$는 서로 다른 가중치입니다.

**원문 표기의 주의점:** 저자는 이 비선형 블록을 $ZW^S$라고 줄여 씁니다. 하지만 GeLU를 포함하므로 $W^S$를 하나의 고정 선형행렬로 이해하면 부정확합니다. 여기서는 이를 함수 $f_\theta$로 표현했습니다. [p.5]

또한 행렬을 오른쪽에서 곱하므로, 이 블록은 **$N$개의 세그먼트 위치 사이 정보를 혼합**합니다.

### 5.4 첫 번째 Segment Attention

동일한 PS Block 출력을 Query, Key, Value로 사용합니다.

$$
Q_1=K_1=V_1=f_\theta(Z).
$$

- $Q_1,K_1,V_1\in\mathbb{R}^{C\times N}$.
- 아래첨자 1은 첫 번째 attention 단계.
- $f_\theta$는 앞에서 정의한 공유 비선형 블록.

attention과 출력은 다음과 같습니다.

$$
A_1=
\text{Softmax}
\left(
\frac{Q_1K_1^\top}{\sqrt{d_k}}
\right),
\qquad
O_1=A_1V_1.
$$

- $A_1\in\mathbb{R}^{C\times C}$: 관계 가중치 행렬.
- $O_1\in\mathbb{R}^{C\times N}$: 첫 단계 출력.
- $d_k$: Key 벡터 차원으로, 논문에 제시된 행렬 차원에서는 $N$에 해당.
- $\top$: 전치.
- $\text{Softmax}$: 점수를 정규화된 가중치로 바꾸는 함수. [p.5, 식 (4)–(5)]

> **용어 — Query·Key·Value:** 각각 관계를 조회하는 표현, 비교 대상 표현, 가중합할 정보를 나타내는 attention의 역할 구분이며, PSformer에서는 한 단계 내 세 값이 동일한 블록 출력으로 설정됨.

**수식 정정:** PDF의 식 (5)와 (7)에는 $K$의 전치가 빠져 있습니다. 그대로는 일반적으로 행렬 곱의 차원이 맞지 않습니다. 같은 페이지 본문이 $QK^\top\in\mathbb{R}^{C\times C}$라고 설명하므로, 위 식은 그 설명에 따라 전치를 보완했습니다.

### 5.5 두 번째 Segment Attention과 인코더 출력

첫 번째 출력에 ReLU를 적용한 뒤, 같은 블록을 다시 사용합니다.

```math
Q_2=K_2=V_2
=
f_\theta\left(\text{ReLU}(O_1)\right).
```

여기서 아래첨자 2는 두 번째 단계이고, $Q_2,K_2,V_2$의 차원은 모두 $C\times N$입니다.

$$
A_2=
\text{Softmax}
\left(
\frac{Q_2K_2^\top}{\sqrt{d_k}}
\right),
\qquad
O_2=A_2V_2.
$$

$A_2$는 두 번째 관계 행렬, $O_2$는 두 번째 단계 출력이며, 각각 $C\times C$, $C\times N$입니다. [p.5, 식 (6)–(7)]

> **용어 — ReLU:** 음수 입력은 0으로, 양수 입력은 그대로 통과시키는 활성화 함수.

마지막으로 입력과 잔차 연결을 구성하고 동일한 PS Block으로 융합합니다.

$$
E_\theta(Z)=f_\theta(O_2+Z).
$$

- $E_\theta$: 인코더 하나의 전체 변환.
- $O_2+Z$: 두 attention 단계를 거친 출력과 원래 입력의 합.
- 출력 차원: $C\times N$. [p.5, 식 (8)]

**공유 범위는 다음과 같습니다.**

- 첫 번째 SegAtt의 PS Block.
- 두 번째 SegAtt의 PS Block.
- 인코더 마지막 융합 PS Block.

이 세 위치가 파라미터를 공유합니다. 기본 모델에서 **인코더가 달라지면 별도의 파라미터를 사용**합니다. [pp.7–8, Table 5]

### 5.6 attention이 작동하는 축에 대한 정확한 해석

이 구조를 “ $N$개의 세그먼트 사이에 $N\times N$ attention을 계산한다”고 설명하면 잘못입니다.

**[저자 보고 및 수식 확인]**

- PS Block의 $N\times N$ 변환이 세그먼트 사이 정보를 혼합합니다.
- attention은 $C=MP$ 축에서 계산되어, 변수와 패치 내부 시간 위치의 조합을 연결합니다.
- 이때 관계 점수는 $N$개 세그먼트에 걸친 변환 표현을 이용합니다. [pp.4–5]

따라서 **각 세그먼트마다 서로 독립적인 attention 행렬을 만드는 구조로도 설명하면 안 됩니다.**

### 5.7 출력층과 위치 인코딩

$n$개 인코더의 최종 출력을 $Z^{(n)}$이라고 하면, 전체 예측 과정을 다음과 같이 정리할 수 있습니다.

```math
\widehat X
=
\text{RevIN}^{-1}
\left(
\mathcal R^{-1}(Z^{(n)})W^F
\right).
```

- $\mathcal R^{-1}$: $C\times N$ 표현을 원래의 $M\times L$ 형태로 복원하는 재배열.
- $W^F\in\mathbb{R}^{L\times F}$: 미래 구간으로 사상하는 선형 예측 가중치.
- $\widehat X\in\mathbb{R}^{M\times F}$: 최종 예측.
- $\text{RevIN}^{-1}$: 입력에서 사용한 통계를 이용하는 역정규화. [pp.3–5, Figures 1–2]

PSformer는 별도 위치 인코딩을 사용하지 않습니다. Table 10에서는 두 위치 인코딩 방식보다 기본형이 좋은 결과를 보입니다. [pp.13–14]

**[검증·해석]** 추가 위치 인코딩이 없더라도 시간순서가 사라지는 것은 아닙니다. 세그먼트 위치별 가중치를 가진 PS Block과 $L\rightarrow F$ 출력층은 위치에 의존합니다.

> **용어 — 위치 인코딩:** 입력이 어느 위치에 있는지를 알려주기 위해 별도로 더하는 표현.

### 5.8 SAM 학습

논문 Appendix A.7의 설명은 다음과 같습니다.

```math
\widehat\epsilon
=
\text{arg max}_{\|\epsilon\|\le\rho}
\mathcal L(\theta+\epsilon).
```

- $\theta$: 모델 파라미터.
- $\epsilon$: 파라미터에 가하는 작은 변화.
- $\rho$: 허용하는 변화의 범위.
- $\mathcal L$: 학습 손실.
- $\widehat\epsilon$: 주변에서 손실을 크게 만드는 변화.

그다음 다음과 같이 갱신합니다.

$$
\theta
\leftarrow
\theta-\eta\nabla_\theta
\mathcal L(\theta+\widehat\epsilon).
$$

- $\eta$: 학습률.
- $\nabla_\theta$: 파라미터에 대한 손실의 기울기.
- 나머지 기호는 앞 식과 같습니다. [p.14, Appendix A.7]

> **용어 — SAM과 평탄한 해:** 현재 가중치에서만 오차가 작기보다, 가중치가 조금 달라져도 오차가 크게 증가하지 않는 해를 찾는 최적화 방식.

이는 기존 SAM을 채택한 것이며, PSformer가 새로 제안한 최적화 알고리즘은 아닙니다. 또한 위 식은 내부 최대화의 개념적 정의이고, PSformer 원문은 실제 근사 계산을 상세히 설명하지 않습니다. SAM의 일반적인 목적은 원논문에서도 확인됩니다. [arxiv.org](https://arxiv.org/abs/2010.01412?utm_source=chatgpt.com)

### 5.9 파라미터 효율과 계산량은 구분해야 한다

**[검증·계산]** Table 8의 계수는 다음 관계와 일치합니다.

```math
\#\theta_{\text{enc}}
=
3n(N^2+N),
\qquad
\#\theta_{\text{full}}
=
3n(N^2+N)+(L+1)F.
```

- $\theta_{\text{enc}}$: 전체 인코더의 파라미터 개수.
- $\theta_{\text{full}}$: 출력층을 포함한 파라미터 개수.
- $n,N,L,F$: 앞서 정의한 인코더 수·세그먼트 수·입력 길이·예측 길이.
- $N^2+N$과 $(L+1)F$는 편향항을 포함한 계산입니다.

이는 **논문의 표에서 재구성한 계산식**이며, 원문 식 (1)–(3)은 편향항을 생략합니다.

$N=32$, $n=1$이면 인코더는 $3,168$개이고, $L=512$, $F=96$인 출력층은 $49,248$개이므로 합계 $52,416$개입니다. [p.13, Table 8]

반면 기본적인 조밀 행렬 연산으로 attention을 계산하면 다음 크기가 등장합니다.

$$
\text{attention 행렬 크기}=C^2=M^2P^2,
\qquad
\text{attention 연산량}=O(C^2N).
$$

- $C=MP$: 변수·패치 내부 시간의 결합 길이.
- $O(\cdot)$: 입력 크기에 따른 연산 증가 정도를 나타내는 표기.

이것은 **수식 차원에서 도출한 분석**입니다. 변수 수가 늘어도 가중치 수는 거의 유지되지만, attention 계산은 커집니다. 따라서 파라미터 효율을 곧바로 고차원 데이터의 실행시간·메모리 효율로 해석할 수 없습니다.

| 반복 실험 | PSformer 설정은 seed 1로 고정. [p.12, Table 7] | 초기화에 따른 성능 변동을 알 수 없음 |

| 튜닝 | $\rho$, 인코더 수, 세그먼트 수, 학습률 등을 검토. [pp.16·30] | 모델별 탐색 예산과 선택 절차가 같았는지 불명확 |
| 구성요소 비교 | 변형 간 파라미터·연산량 일치가 충분히 설명되지 않음. [p.8] | 구조 변화와 용량 변화의 효과가 섞일 수 있음 |
| 데이터 다양성 | 8개 중 4개가 ETT 계열. [p.6] | 8개의 독립적인 응용 분야를 검증한 것으로 해석하면 과장 |
| 일반화 원인 | 공유·SAM·RevIN을 완전히 분리한 요인 실험 없음 | 어느 요소가 얼마나 기여했는지 정량적으로 분리하기 어려움 |

**[검증·해석]** 같은 데이터셋의 네 예측 길이를 독립적인 네 데이터셋처럼 취급해서도 안 됩니다. 테스트 구간과 데이터 생성 특성이 겹치기 때문입니다.

하이퍼파라미터 선택 절차가 충분히 명시되지 않았다는 사실만으로 테스트 데이터 누출을 단정할 수는 없습니다. 정확한 결론은 **선택 과정의 독립성을 문서만으로 완전히 검증하기 어렵다**는 것입니다.

> **용어**
> - **신뢰구간**: 반복 표집이나 실험의 불확실성을 반영하는 추정 범위
> - **요인 실험**: 여러 구성요소의 사용 여부를 조합해 각 효과와 상호작용을 분리하는 실험
> - **데이터 누출**: 학습·선택 과정에서 평가에만 사용해야 할 정보가 들어가는 문제

**출처:** pp.6·29, Tables 2·16.

ETTh1의 표시값으로 계산하면, PSformer의 상대 MSE 감소율은 주표에서는 약 15.17%지만 Table 16의 비교에서는 약 5.25%입니다. 두 수치를 같은 비교 조건의 개선폭으로 사용할 수 없습니다.

> **용어 — noDL / DL:** 테스트 데이터의 마지막 불완전 배치를 유지하는지 또는 버리는지를 구분한 논문의 표기.

**② Exchange의 0.358과 0.417은 동일 설정 값이 아닙니다.**

Table 2는 0.358을, Table 15는 0.417을 보고합니다. 후자는 Table 14의 정규화 창 512 결과와 일치합니다. 설정을 구분하지 않고 서로 바꾸어 인용하면 안 됩니다. [pp.6·26–27]

**③ 추가 기준선 비교에는 입력·평가 조건 차이가 있습니다.**

- Table 16의 Crossformer 입력은 96, PSformer 입력은 512입니다.
- Time-LLM은 `DL` 조건의 원 논문 수치를 사용하며 PSformer 저자가 직접 재실행하지 않았습니다.
- Table 15의 FITS는 입력 길이 탐색을 수행한 설정입니다. [pp.26–29]

저자 자신도 추가 기준선의 설정 차이 때문에 완전히 공정한 비교가 어렵다고 인정합니다. [p.26, Appendix B.8.1]

**④ 인코더만의 파라미터 수와 다른 모델 전체 크기는 직접 비교할 수 없습니다.**

PSformer의 3,168개는 인코더 부분의 계수입니다. 동일 설정의 전체 모델은 52,416개입니다. [p.13, Table 8]

### attention 시각화에서 특히 주의할 점

**[검증·해석]** Figure 7의 색상 척도에는 음수가 있고, p.24에서는 공유 모델의 값 범위를 약 $[-3,3]$, 비공유 모델을 약 $[-30,40]$이라고 설명합니다.

하지만 Softmax 이후 attention 확률은 음수가 될 수 없습니다. 따라서 이 시각화는 **Softmax 이후 확률행렬 그 자체로 해석할 수 없습니다.**  
정규화 이전 점수인지, 별도 변환 결과인지가 충분히 명시되지 않았습니다. [pp.21·24–25, Figures 7·13–15]

> **용어 — attention 점수와 확률:** 정규화 전 점수는 음수일 수 있지만, Softmax를 통과한 가중치는 음수가 아닌 값.

이 그림들이 보여 주는 패턴은 탐색적 설명으로는 유용합니다. 그러나 “모델이 실제 원인을 발견했다”는 결론까지 뒷받침하지는 않습니다.

### 9.1 논문이 확인한 일반화의 범위

| 학습하지 않은 변수로의 적용 | 직접 평가 없음 |
| 다른 데이터셋으로의 무학습 전이 | 직접 평가 없음 |
| 분포 변화·결측·이상치에 대한 강건성 | 체계적 실험 없음 |

**근거:** pp.6–8·12·24–30의 실험과 부록.

### 9.2 일반화에 유리할 수 있는 구조적 이유

다음은 **수식과 실험에 근거한 해석**입니다.

**첫째, 공유가 독립적인 학습 자유도를 제한합니다.** 같은 블록을 반복 사용하면 각 위치가 별도의 변환을 마음대로 학습하는 정도가 줄어듭니다.  
Table 5의 결과는 이런 제약이 일부 조건에서 도움이 된다는 해석과 일관됩니다. 다만 파라미터가 적으면 반드시 더 잘 일반화한다는 보장은 없습니다. [p.8]

**둘째, 인코더 내부 공유는 공유와 표현 다양성 사이의 절충입니다.** 기본 모델은 인코더 내부에서는 재사용하고, 다른 인코더에는 다른 파라미터를 허용합니다.  
전체 공유보다 내부 공유가 유리했던 결과는 이 선택의 유망성을 보여 줍니다. [p.8, Table 5]

**셋째, SegAtt는 시간과 변수 관계를 결합하는 특정 구조적 가정을 제공합니다.** 이 가정이 데이터에 맞으면 유용할 수 있지만, 변수 관계가 약하거나 바뀌는 환경에서 얼마나 유지되는지는 아직 충분히 평가되지 않았습니다. [p.8, Table 6; pp.24·26]

> **용어 — 구조적 가정, 귀납적 편향:** 모델이 어떤 종류의 패턴을 더 쉽게 학습하도록 만드는 설계상의 제약이나 선호.

### 9.3 일반화 주장에 필요한 추가 구분

Figure 4의 안정적인 검증 손실과 여러 벤치마크에서의 좋은 결과는 의미가 있습니다. 그러나 다음 질문에는 별도 증거가 필요합니다.

- 데이터가 적어졌을 때도 우위가 유지되는가?
- 변수 간 상관관계가 바뀌어도 좋은가?
- 새로운 변수나 데이터셋에 추가 학습 없이 적용할 수 있는가?
- 정규화 설정과 SAM의 효과를 통제해도 공유 구조의 이득이 남는가?

또한 단변량 실험의 0열은 다양한 무관한 실제 신호나 잡음을 대표하지 않습니다. Table 13의 예측 길이 720에서는 PatchTST의 검증 손실이 NaN이어서 비교값 자체가 없습니다. [p.26]

| **Chronos-2, 2025** | 시간 attention과 group attention을 교대로 적용하고, 합성 다변량 구조로 학습 | 변수 간 정보 교환을 제로샷 예측과 연결한 사례; PSformer의 변수 관계 학습을 통제된 합성 데이터로 검사하는 데 참고 가능. [pp.2·5–6] [arxiv.org](https://arxiv.org/pdf/2510.15821?utm_source=chatgpt.com) |
| **Moirai 2.0, 2025 공개·2026년 v3** | 단순화한 decoder 구조와 분위수 예측; 해당 버전은 다변량·공변량 지원을 제거 | 변수 결합이 모든 모델·데이터 조건에서 이득을 보장하지 않음을 보여 주는 대비 사례; 저자는 고품질 데이터 부족 가능성을 논의. [pp.10–11, §6] [arxiv.org](https://arxiv.org/pdf/2511.11698v3?utm_source=chatgpt.com) |

> **용어**
> - **토큰**: attention이 하나의 단위로 처리하는 입력 표현
> - **router**: 여러 변수의 정보를 소수의 중간 표현으로 모아 전달하는 구조
> - **사전학습**: 여러 데이터에서 먼저 표현이나 예측 능력을 학습하는 단계
> - **공변량**: 예측 대상과 함께 사용하는 보조 변수
> - **분위수 예측**: 중앙값뿐 아니라 하위·상위 확률 수준에 해당하는 미래 값을 예측하는 방식
> - **합성 데이터**: 관계를 통제하여 인위적으로 생성한 데이터

### 11.2 최신 연구가 PSformer 해석에 주는 의미

**[검증·해석]** 최신 연구와 연결할 때 가장 중요한 것은 **무엇을 학습하지 않은 상태에서 잘 예측했는가**입니다.

PatchTST는 데이터셋 간 전이를, iTransformer는 미관측 변수를, Moirai와 Chronos-2는 대상별 추가 학습 없는 예측을 평가합니다. PSformer의 여러 데이터셋별 테스트 성능과 이 결과들은 서로 다른 일반화 질문에 답합니다.

또한 Chronos-2는 다변량 구조를 적극적으로 학습하는 반면, 확인한 Moirai 2.0 버전은 다변량·공변량 지원의 이득이 작아 이를 제거했다고 설명합니다. 이 대비에서 얻을 연구 질문은 **변수를 얼마나 많이 섞을 것인가보다, 어떤 데이터 관계와 학습 조건에서 결합이 유리한가**입니다. [arxiv.org](https://arxiv.org/pdf/2510.15821?utm_source=chatgpt.com)

PSformer가 이 후속 모델들에 직접 영향을 주었다는 근거는 확인하지 못했습니다. 따라서 직접적인 계보나 영향 관계보다 **관련된 연구 방향과 평가 기준**으로 연결하는 것이 정확합니다.

## 12. 결론·시사점·한계·후속 연구

### 12.1 저자가 제시한 결론과 후속 계획

**[저자 보고]** 저자들은 세그먼트 attention을 통한 변수 간 정보 전달과 파라미터 공유를 결합하여, 장기 다변량 예측에서 파라미터 효율과 정확도를 개선했다고 결론냅니다. 후속 계획은 이 기술들을 시계열 사전학습 대형 모델에 적용하여 모델 크기를 줄이고 다변량 정보 추출을 개선하는 것입니다. [p.8, §5]

### 12.2 학계와 실용 분야에 대한 시사점

**[검증·해석] 학술적 시사점**

이 연구는 **입력 재배열, attention 축, 공유 범위**가 중요한 설계 변수임을 보여 줍니다. 특히 인코더 내부 공유가 전체 공유보다 좋은 결과를 보인 점은, 공유 강도를 단순히 늘리기보다 위치별 역할을 고려해야 한다는 연구 질문을 제공합니다. [p.8, Table 5]

**[검증·해석] 실용적 시사점**

작은 학습 파라미터 수와 경쟁력 있는 오차는 제한된 모델 저장 공간이나 반복적인 데이터셋별 학습을 고려할 때 검토할 가치가 있습니다. 다만 실행 효율은 변수 수, attention 구현, 수렴 epoch, 정규화 설정을 함께 측정해야 합니다. 논문의 파라미터 수만으로 특정 운영 환경의 비용을 확정할 수는 없습니다. [pp.13·28–29]

### 12.4 가장 유망한 아이디어와 빠른 검증 방법

아래는 **추가 연구 제안**입니다. 복잡한 대형 모델 구현에 앞서 핵심 가정을 작은 실험으로 확인하는 데 목적이 있습니다.

| 우선순위 | 검증할 아이디어 | 최소 실험 | 확인할 질문 |
|---|---|---|---|
| **1** | **인코더 내부 파라미터 공유** | 같은 작은 구조에서 공유·비공유만 바꾸고 여러 seed로 반복 | 파라미터 감소와 오차 개선이 함께 재현되는가? |
| **2** | **RevIN 통계 창 선택** | 구조를 고정하고 Exchange에서 창 16·64·512 비교 | 주표 개선 중 정규화의 기여가 얼마나 큰가? |
| **3** | **SegAtt의 변수·시간 결합** | 작은 입력에서 변수축 attention·SegAtt·채널 독립형 비교 | 어떤 시간 지연·변수 관계에서 결합이 도움이 되는가? |
| **4** | **공유와 SAM의 상호작용** | 공유 여부 × SAM 여부의 $2\times2$ 실험 | 두 기술의 효과가 독립적인가, 특정 조합에 의존하는가? |

첫 실험에서는 입력 길이, 정규화, 학습률, 데이터 분할, 테스트 배치 처리와 튜닝 예산을 고정해야 합니다. 공유의 독립적인 효과를 더 분명히 보려면, 이후에는 **파라미터 수를 비슷하게 맞춘 비공유 모델**도 비교하는 것이 좋습니다.

### 12.5 일반화 성능을 직접 검증하는 후속 방향

**① 데이터가 줄어드는 상황을 직접 평가합니다.**

학습 데이터 비율을 단계적으로 줄이면서 공유·비공유 모델의 오차와 변동성을 비교하면, 논문의 “제한된 데이터에서 과적합 완화” 주장을 더 직접적으로 검사할 수 있습니다. 서로 다른 데이터셋의 크기를 비교하는 것보다 원인을 분리하기 쉽습니다.

**② 변수 관계를 통제합니다.**

관련 변수, 시간 지연이 있는 변수, 독립 잡음 변수, 관계가 바뀌는 변수를 구분하여 추가하는 실험이 필요합니다. 이는 SegAtt가 유익한 관계와 불필요한 관계를 어떻게 처리하는지 검증합니다.

**③ 일반화 대상을 명시한 평가를 추가합니다.**

미관측 변수, 다른 기간, 다른 데이터셋을 각각 분리해 평가해야 합니다. 사전학습으로 확장한다면 사전학습 데이터와 평가 데이터의 중복도 확인해야 합니다. 다양한 도메인·빈도·예측 길이와 평가 데이터의 분리를 다루는 GIFT-Eval은 이런 설계의 참고 자료입니다. [arxiv.org](https://arxiv.org/abs/2410.10393?utm_source=chatgpt.com)

**④ 출력층과 attention 비용을 함께 개선 대상으로 삼습니다.**

출력층은 파라미터의 큰 비중을 차지하고, attention은 변수 수 증가에 따른 연산 부담을 갖습니다. 출력층의 저차원 분해, 관계를 제한하는 attention 등은 별도의 검증 과제로 삼을 수 있지만, 이 논문이 해당 개선 효과를 입증한 것은 아닙니다.

> **용어 — 저차원 분해:** 큰 행렬을 더 작은 두 행렬의 곱으로 표현하여 파라미터 수를 줄이는 방법.

**최종 평가:** PSformer의 근거가 가장 강한 성과는 **작은 공유 블록과 변수·국소 시간 결합 구조를 통해 벤치마크 예측 성능을 개선했다는 점**입니다. 일반화 연구로서 다음 단계의 핵심은 모델을 크게 확장하는 것보다, 그 이득이 **어떤 데이터량·변수 관계·분포 변화에서도 유지되는지 통제된 실험으로 확인하는 것**입니다.
