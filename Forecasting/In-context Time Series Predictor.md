# In-context Time Series Predictor

**이 논문의 핵심 기여는 과거의 ‘입력 구간–실제 후속값’ 쌍을 하나의 예측 과제 토큰으로 만들어, 새로운 예측의 문맥으로 제공하는 것입니다.**  
논문은 이 설계가 여러 벤치마크, 특히 ETT 데이터셋 간 전이에 도움이 된다는 실험적 근거를 제시합니다.  
다만 범용 시계열 모델로서의 일반화, 자동적인 과적합 방지, 대규모 학습의 효과까지 입증한 것은 아닙니다.

분석 대상은 Jiecheng Lu, Yan Sun, Shihao Yang의 **ICLR 2025 논문과 부록 전체 27쪽**입니다.

이하 **[P]는 첨부 논문**, 페이지는 PDF에 인쇄된 페이지 번호를 뜻합니다. **[저자 보고]**, **[분석자의 해석]**, **[추가 연구 제안]**을 구분했으며, 계산한 비율에는 **[계산]**을 표시했습니다. 관련 연구 비교는 **2026년 10월 22일까지 확인한 1차 자료 중 직접 관련성이 높은 문헌**으로 한정했습니다.

## 1. Executive summary와 연구 배경

### 1.1 Executive summary — 9문장

1. ICTSP는 시계열의 관측값이나 개별 변수 전체 대신, **과거 입력과 그 뒤의 관측값을 묶은 예측 과제**를 Transformer의 토큰으로 사용하는 모델입니다. **[P, pp.4–5, 식 (5), Figure 2]**
2. 이러한 예제를 문맥으로 제공하여, 추론 시 모델 파라미터를 갱신하지 않고 현재 예측에 필요한 규칙을 활용하는 **문맥 내 학습, ICL**을 시계열 예측에 적용합니다. **[P, pp.2–5]**
3. 사전학습된 대규모 언어모델의 가중치를 사용하지 않으며, 주실험에서는 3개 Transformer 층과 128차원 잠재 표현을 사용합니다. **[P, p.7; p.18, §A.3.2]**
4. 전체 학습 데이터 실험에서는 데이터셋별 평균 MSE 기준 7개 중 6개에서 가장 좋은 결과를 보였고, 28개 데이터셋·예측길이 조합 중 18개에서 1위를 기록했습니다. **[P, p.7, Table 1; p.14, Table 6]**
5. 소량 학습 데이터 실험에서도 전반적으로 좋은 결과를 보였으며, zero-shot 실험에서는 6개 ETT 전이 방향의 평균 MSE가 모두 비교군보다 낮았습니다. **[P, p.8, Tables 2–3]**
6. ETTm1에서 학습해 ETTm2로 전이하는 문맥 제거 실험에서는 MSE가 문맥 없음의 0.208에서 전체 문맥 사용의 0.168로 낮아져, 문맥 활용의 기여를 직접 보여줍니다. **[P, p.27, Table 17]**
7. 문맥 샘플링과 토큰 검색을 결합하면 특정 설정의 연산량을 88.0G에서 1.51G FLOPs로 줄일 수 있지만, 같은 표의 iTransformer보다 연산량이 적은 것은 아닙니다. **[P, p.9, Table 5]**
8. 주요 결과는 제한된 반복실험, 서로 다른 입력 이력 길이, ETT 계열 중심의 전이 평가라는 제약을 가지며, 일부 수식과 표에는 내부 불일치가 있습니다. **[P, pp.5, 8, 15, 17–19, 27]**
9. 따라서 가장 타당한 결론은 **예측 과제 단위의 토큰화가 일반화 성능을 개선할 유망한 설계라는 것**이며, 다양한 도메인과 가변 예측길이를 처리하는 단일 범용 모델의 성능은 추가 검증이 필요합니다. **[분석자의 해석; P, p.10, §5]**

> **용어 풀이**
>
> - **토큰(token)**: Transformer가 하나의 처리 단위로 받아들이는 벡터.
> - **문맥 내 학습(ICL)**: 입력에 주어진 예제를 이용해 예측을 바꾸는 방식으로, 추론 중 가중치 갱신은 수행하지 않음.
> - **파라미터**: 학습을 통해 조정되는 모델의 가중치와 편향.
> - **Few-shot**: 이 논문에서는 학습 구간의 첫 5% 또는 10%로 파라미터를 학습하는 설정.
> - **Zero-shot**: 이 논문에서는 대상 데이터셋으로 파라미터를 다시 학습하지 않는 전이 설정이며, 대상의 관측된 과거는 입력으로 사용.
> - **MSE**: 평균제곱오차로, 예측과 실제 값의 차이를 제곱해 평균한 값이며 낮을수록 좋음.

### 1.2 연구가 해결하려는 문제

**[저자 보고]** 저자들은 기존 Transformer 시계열 예측 모델의 문제를 **입력을 어떤 단위로 토큰화하는가**에서 찾습니다. 주요 문제는 다음 세 가지입니다. **[P, pp.1–2, 4–7]**

| 문제 | 논문의 설명 | 연구가 지향하는 해결 |
|---|---|---|
| 약한 변수 관계에 대한 과적합 | 같은 시점의 여러 변수 값을 한 토큰에 넣으면, 실제로 약하거나 존재하지 않는 변수 간 관계에 지나치게 의존할 수 있음 | 시간적 예측 관계를 토큰 내부에 명시 |
| 새로운 데이터로의 전이 제약 | 변수 수·순서·의미에 의존하는 입력 구조는 다른 데이터셋에 옮기기 어려움 | 동일한 형식의 예측 예제를 여러 변수에서 구성 |
| LLM 활용의 계산 부담 | 시계열을 언어모델에 맞추는 방식은 많은 파라미터와 계산을 요구 | 시계열 예측 과제에 직접 맞춘 작은 Transformer 사용 |

> **용어 풀이**
>
> - **채널(channel)**: 시계열을 구성하는 개별 변수나 센서 신호.
> - **다변량 시계열**: 여러 채널이 함께 관측되는 시계열.
> - **과적합(overfitting)**: 학습 자료의 우연한 패턴까지 학습하여 새로운 자료에서는 성능이 떨어지는 현상.
> - **시간적 의존성**: 과거 값이 이후 값과 관련되는 관계.
> - **변수 간 의존성**: 서로 다른 채널의 값들이 관련되는 관계.

### 1.3 목적과 필요성

**[저자 보고]** 연구 목적은 과거에 실제로 관측한 예측 문제와 답을 제공하여, Transformer가 현재 과제에 유용한 예측기를 문맥에서 결정하도록 만드는 것입니다. 이를 통해 전체 데이터 학습뿐 아니라 소량 데이터 학습과 데이터셋 간 전이에서도 안정적인 성능을 얻고자 합니다. **[P, p.2, 기여 a–c]**

**[분석자의 해석]** 이 접근이 필요한 이유는 시계열의 예측 규칙이 데이터셋과 시점에 따라 달라질 수 있기 때문입니다. ICTSP는 학습된 가중치에 저장된 규칙과, 현재 관측 이력에서 구성한 예제를 함께 사용하도록 설계합니다. 다만 이 논문은 이러한 결합이 모든 분포 변화에 성공한다는 보장을 제공하지는 않습니다. **[P, pp.5–7; pp.26–27, §A.11]**

### 2.3 예측 문제의 수식화

원문은 다변량 시계열을 관측 과거와 예측 미래로 나눕니다. **[P, p.2, §2.1]**

$$
X=[X_I,X_P],
\qquad
X_I\in\mathbb{R}^{C\times L_I},
\qquad
X_P\in\mathbb{R}^{C\times L_P},
$$

$$
\widehat X_P=f_\theta(X_I).
$$

**기호 설명**

- $C$: 채널 수.
- $L_I$: 현재 이용할 수 있는 전체 과거 길이.
- $L_P$: 예측할 미래 길이.
- $X_I$: 관측된 과거 데이터.
- $X_P$: 실제 미래 값.
- $\widehat X_P$: 모델의 예측값.
- $f_\theta$: 파라미터 $\theta$를 가진 예측 모델.

ICTSP의 특징은 $X_I$를 단순히 긴 입력으로 넣는 데 그치지 않고, 그 안에서 이미 답을 알고 있는 예측 과제들을 추출한다는 것입니다.

### 2.4 핵심: 과거 예측 과제를 토큰으로 만들기

아래 식은 **원문 식 (5)의 의미를 길이와 인덱스가 일관되도록 재표기한 것**입니다. 원문 표기의 불일치는 4.3절에서 별도로 설명합니다.

채널 $j$의 과거 시점 $s$에서 시작하는 예측 예제를 다음과 같이 구성합니다. **[P, pp.4–5; p.16, Figure 6]**

```math
\mathbf{x}_{j,s}
=
\begin{bmatrix}
X_j^{(s)}\\
\vdots\\
X_j^{(s+L_b-1)}
\end{bmatrix}
\in\mathbb{R}^{L_b},
\qquad
\mathbf{y}_{j,s}
=
\begin{bmatrix}
X_j^{(s+L_b)}\\
\vdots\\
X_j^{(s+L_b+L_P-1)}
\end{bmatrix}
\in\mathbb{R}^{L_P}.
```

```math
\mathbf{u}_{j,s}
=
\begin{bmatrix}
\mathbf{x}_{j,s}\\
\mathbf{y}_{j,s}
\end{bmatrix}
\in\mathbb{R}^{L_b+L_P},
\qquad
s+L_b+L_P-1\le L_I.
```

**기호 설명**

- $j$: 채널 번호.
- $s$: 과거 예측 과제의 시작 위치.
- $L_b$: 한 과제에서 입력으로 사용하는 과거 길이.
- $\mathbf{x}_{j,s}$: 과거 입력 구간.
- $\mathbf{y}_{j,s}$: 그 입력 뒤에 실제로 관측된 후속 구간.
- $\mathbf{u}_{j,s}$: 입력과 정답을 연결한 하나의 과제 토큰.
- 마지막 부등식: 과제의 정답 부분까지 현재 관측 이력 안에 있어야 한다는 조건.

현재 예측할 목표 토큰은 다음과 같습니다.

```math
\mathbf{u}_{j,*}
=
\begin{bmatrix}
X_j^{(L_I-L_b+1)}\\
\vdots\\
X_j^{(L_I)}\\
\mathbf{o}
\end{bmatrix},
\qquad
\mathbf{o}\in\mathbb{R}^{L_P}.
```

여기서 $*$는 현재 예측 대상이고, $\mathbf{o}$는 아직 알 수 없는 미래를 대신하는 자리표시자입니다. 여러 채널의 과거 과제 토큰과 목표 토큰을 함께 모델에 제공합니다.

> **용어 풀이**
>
> - **Lookback**: 하나의 예측 과제에서 참조하는 과거 구간.
> - **Context example**: 현재 예측을 돕기 위해 제공하는 과거의 입력–정답 쌍.
> - **Target token**: 지금 풀어야 할 예측 문제를 담은 토큰.
> - **자리표시자(placeholder)**: 아직 알 수 없는 값이 들어갈 위치를 표시하는 입력.

#### 작은 예시

구조 설명을 위해 $L_b=3$, $L_P=2$이고 관측 이력이 $(1,2,3,4,5,6,7)$이라고 가정하면 다음과 같이 구성할 수 있습니다.

| 구분 | 과거 입력 | 이미 관측한 후속값 |
|---|---|---|
| 문맥 예제 1 | $(1,2,3)$ | $(4,5)$ |
| 문맥 예제 2 | $(2,3,4)$ | $(5,6)$ |
| 문맥 예제 3 | $(3,4,5)$ | $(6,7)$ |
| 현재 목표 | $(5,6,7)$ | 미지의 미래 |

이 예시는 논문의 구성 원리를 설명하기 위한 것으로, 실험 결과가 아닙니다.

**중요한 해석:** 문맥 토큰의 “future”는 **과거 예측 문제 안에서의 후속 구간**입니다. 현재 예측 시점에서는 이미 관측한 값이므로, 이를 사용하는 것 자체가 미래 정보 누설은 아닙니다. 다만 실제 평가에서 허용한 관측 범위는 별도로 통제해야 합니다.

### 2.5 임베딩과 Transformer 구조

과제 토큰은 선형 투영으로 잠재 공간에 옮긴 후, 채널과 위치를 구별하는 임베딩을 더합니다. **[P, p.3; p.16, §A.3.1]**

```math
\mathbf{h}_i
=
W_{\text{in}}\mathbf{u}_i
+
\mathbf{b}_{\text{in}}
+
\mathbf{p}_{\text{channel},i}
+
\mathbf{p}_{\text{position},i}.
```

**기호 설명**

- $i$: 채널별 예제를 모두 모았을 때의 토큰 번호.
- $\mathbf{u}_i\in\mathbb{R}^{L_b+L_P}$: 원래 과제 토큰.
- $W_{\text{in}}\in\mathbb{R}^{d\times(L_b+L_P)}$: 입력 선형 투영 행렬.
- $\mathbf{b}_{\text{in}}\in\mathbb{R}^{d}$: 편향.
- $d$: 잠재 표현 차원으로, 주실험에서는 128.
- $\mathbf{p}_{\text{channel},i}$: 토큰의 채널 출처를 구별하는 임베딩.
- $\mathbf{p}_{\text{position},i}$: 입력 내 토큰 위치를 구별하는 임베딩.
- $\mathbf{h}_i\in\mathbb{R}^{d}$: Transformer에 입력되는 표현.

> **용어 풀이**
>
> - **임베딩(embedding)**: 입력을 모델이 처리하기 좋은 숫자 벡터로 표현한 것.
> - **잠재 공간**: 모델 내부에서 특징을 표현하는 벡터 공간.
> - **선형 투영**: 가중치 행렬을 곱해 벡터의 차원이나 표현을 바꾸는 연산.

원문 식 (1)을 두 단계로 나누면 다음과 같습니다. **아래는 PDF에 인쇄된 연산 순서를 따른 식**입니다. **[P, p.2, 식 (1)]**

```math
A_k
=
Z_{k-1}
+
\text{Attn}_k\!\left(\text{LN}(Z_{k-1})\right),
```

```math
Z_k
=
A_k
+
\text{LN}\!\left(\text{FFN}_k(A_k)\right).
```

**기호 설명**

- $Z_0$: 입력 토큰 표현을 모은 행렬.
- $Z_k$: $k$번째 Transformer 층의 출력.
- $A_k$: attention과 첫 잔차 연결을 거친 중간 표현.
- $\text{Attn}_k$: 토큰 사이 정보를 결합하는 자기 주의 연산.
- $\text{FFN}_k$: 각 토큰의 특징을 변환하는 전방향 신경망.
- $\text{LN}$: LayerNorm.
- $k=1,\ldots,K$: 층 번호로, 주실험에서는 $K=3$.

마지막 출력에 선형 투영을 적용하고, **목표 토큰에 해당하는 미래 예측 부분**을 읽습니다. 원문 p.3의 일반 ICL 표현은 이를 다음처럼 나타냅니다.

```math
\widehat U
=
W_{\text{out}}\,
\text{TF}\!\left(W_{\text{in}}U+\mathbf{b}_{\text{in}}+P\right)
+\mathbf{b}_{\text{out}}.
```

여기서 $U$는 원래 토큰들을 모은 행렬, $P$는 더해지는 위치·채널 임베딩, $\text{TF}$는 Transformer 전체, $W_{\text{out}}$과 $\mathbf{b}_{\text{out}}$은 출력 투영의 가중치와 편향입니다. 이는 원문의 일반적인 투영 설명이며, 실제 ICTSP의 출력 텐서 구현 세부까지 확정하는 표현은 아닙니다.

> **용어 풀이**
>
> - **Self-attention**: 현재 토큰이 다른 토큰의 정보를 어느 정도 참조할지 계산하는 연산.
> - **FFN**: 각 토큰 내부 특징을 비선형으로 변환하는 신경망.
> - **LayerNorm**: 토큰의 특징값 규모를 정규화하는 연산.
> - **잔차 연결(residual connection)**: 입력을 후속 출력에 직접 더하는 경로로, 원래 정보를 유지하는 데 도움을 줌.

**재현성 주의:** 저자들은 이 구조를 pre-normalization이라고 부르지만, 식 (1)의 FFN 부분은 일반적인 pre-LN 순서와 다르게 인쇄되어 있습니다. 따라서 표준 구현식으로 조용히 바꿔 설명해서는 안 됩니다.

### 2.6 문맥 샘플링과 토큰 검색

문맥 창을 촘촘히 만들면 토큰 수가 많아지므로, 먼저 $m$스텝마다 하나씩 샘플링합니다. 이후 **Token Retrieval, TR**로 중요한 문맥을 선택합니다. **[P, p.5; p.17, 식 (6)–(11)]**

먼저 토큰 표현을 검색용 저차원 벡터로 바꿉니다.

```math
\widetilde{\mathbf h}_i
=
W_{\text{TR}}\mathbf h_i+\mathbf b_{\text{TR}}.
```

그리고 각 문맥 토큰과 모든 목표 토큰의 코사인 유사도를 평균합니다.

```math
s_{ic}
=
\frac{
\widetilde{\mathbf h}_i^\top\widetilde{\mathbf h}_{*,c}
}{
\|\widetilde{\mathbf h}_i\|_2
\|\widetilde{\mathbf h}_{*,c}\|_2
},
\qquad
\bar s_i=\frac{1}{C}\sum_{c=1}^{C}s_{ic}.
```

**기호 설명**

- $W_{\text{TR}}\in\mathbb{R}^{\delta\times d}$, $\mathbf b_{\text{TR}}\in\mathbb{R}^{\delta}$: 검색용 투영의 가중치와 편향.
- $\delta$: 검색 벡터 차원.
- $\widetilde{\mathbf h}_{*,c}$: 채널 $c$의 목표 토큰을 투영한 벡터.
- $s_{ic}$: 문맥 $i$와 목표 채널 $c$ 사이의 코사인 유사도.
- $\bar s_i$: 모든 목표 채널에 대한 평균 유사도.
- $\|\cdot\|_2$: 벡터의 유클리드 길이.

평균 유사도가 높은 상위 $q$ 비율은 그대로 남기고, 나머지는 $r$개 그룹으로 나누어 가중 평균합니다.

```math
\mathbf h_g^{\text{merged}}
=
\sum_{i\in G_g}\alpha_i\mathbf h_i.
```

- $G_g$: 병합할 $g$번째 그룹.
- $\alpha_i$: 해당 그룹에서 토큰 $i$에 부여하는 softmax 가중치.
- $\mathbf h_g^{\text{merged}}$: 병합된 대표 토큰.

원문에 기재된 최종 문맥 토큰 수는 다음과 같습니다.

```math
M_{\text{context}}
=
\left\lfloor
\frac{q(L_I-L_b-L_P)}{m}
\right\rfloor C+r.
```

여기서 $q=0.1$, $m=8$, $r=30$이 주실험 설정이며, 전체 Transformer 입력에는 목표 토큰 $C$개가 추가됩니다. 경계 창과 반올림 위치는 원문 표기에 모호함이 있어, 이 식을 구현의 정확한 토큰 개수와 동일하다고 단정하기는 어렵습니다.

> **용어 풀이**
>
> - **검색(retrieval)**: 현재 예측에 관련성이 높은 예제를 찾아 선택하는 과정.
> - **코사인 유사도**: 두 벡터의 방향이 얼마나 비슷한지 측정하는 값.
> - **Softmax**: 여러 점수를 양수이며 합이 1인 가중치로 변환하는 함수.

### 2.7 정규화·무작위화·선형 워밍업

**[저자 보고]** 추가 학습 전략은 다음과 같습니다. **[P, pp.16–18]**

1. **마지막 값 기준 중심화:** 각 과제의 lookback 마지막 값을 토큰의 값들에서 빼, 시계열 수준 차이의 영향을 줄입니다.
2. **샘플링 시작점 이동:** 시작 위치를 바꾸어 다양한 과거 과제를 보게 합니다.
3. **채널 순서 무작위화:** 특정 채널이 특정 위치 임베딩과 고정적으로 연결되는 것을 줄입니다.
4. **채널 부분집합 사용:** 일부 채널만 골라 입력을 구성하는 전략을 설명합니다.
5. **선형 층 워밍업:** 처음에는 입력·출력 선형 투영만 학습하고, 이후 Transformer를 포함합니다.

**구분할 설정:** Figure 7의 **선형 층 워밍업 5,000스텝**과 §A.3.2의 **학습률 워밍업 1,000스텝**은 서로 다른 절차입니다. 5,000스텝 설정을 모든 주실험의 기본값으로 해석할 근거는 충분하지 않습니다.

### 2.8 적응적 모델 축소의 의미

저자들은 ICTSP가 더 단순한 예측기를 특수한 경우로 포함한다고 설명합니다. **[P, p.5; pp.22–23, §A.7]**

| 제거되거나 효과가 약해지는 부분 | 남는 모델 형태 |
|---|---|
| 문맥 토큰 | 목표 채널 토큰만 처리하는 series-wise Transformer |
| 토큰 간 attention | 채널별 MLP 예측기 |
| Transformer 블록 전체 | 입력·출력 선형 투영으로 이루어진 예측기 |
| 문맥과 Transformer 전체 유지 | 전체 ICTSP |

> **용어 풀이**
>
> - **MLP**: 여러 선형 변환과 비선형 함수를 연결한 기본 신경망.
> - **Ablation, 구성요소 제거 실험**: 특정 요소를 없애거나 바꾸어 그 기여를 확인하는 실험.

**[분석자의 해석]** 이 결과는 모델 안에 단순한 예측 경로가 있다는 설명을 뒷받침합니다. 그러나 **학습이 언제 어떤 경로를 자동으로 선택하는지**, 또는 **항상 최적 복잡도를 선택해 과적합을 막는지**를 증명하지는 않습니다. Table 13은 구성요소를 수동으로 제거한 실험입니다.

## 3. 주요 결과와 일반화 성능의 근거

### 3.1 평가 지표의 의미

논문은 MSE를 주요 지표로, MAE를 부록의 추가 지표로 보고합니다. **[P, p.7; pp.14–16]**

```math
\text{MSE}
=
\frac{1}{n}\sum_{i=1}^{n}(\widehat y_i-y_i)^2,
\qquad
\text{MAE}
=
\frac{1}{n}\sum_{i=1}^{n}|\widehat y_i-y_i|.
```

- $y_i$: 실제 값.
- $\widehat y_i$: 예측값.
- $n$: 평균에 포함되는 평가 값의 개수.

MSE는 큰 오차를 더 강하게 벌점화합니다. MAE는 오차의 절댓값을 평균합니다. **본문 표의 평균은 주로 예측길이별 결과의 평균이며, 여러 난수 시드 결과의 평균이 아닙니다.**

### 3.2 전체 데이터 학습

| ETTh2 | **0.328** | 0.334 | 0.330 | 0.431 |

| ECL | **0.154** | 0.159 | 0.162 | 0.166 |
| Traffic | **0.386** | 0.388 | 0.391 | 0.434 |

**[분석자의 해석]**

- 데이터셋 평균 기준으로는 **7개 중 6개에서 우세**합니다.

감소율은 **반올림된 표 값으로 계산한 값**입니다.

### 3.5 일반화에 대한 가장 직접적인 근거: 문맥 제거 실험

ETTm1에서 학습해 ETTm2에 적용한 $L_P=96$ 실험에서는 다음과 같습니다. **[P, p.27, Table 17]**

| 추론 시 제공 문맥 | MSE |
|---|---:|
| 문맥 없음 | 0.208 |
| 모든 채널의 문맥 제공 | 0.168 |

**[계산]** 상대 MSE 감소율은 약 **19.23%**입니다.

**[저자 해석]** 대상 데이터의 예측 예제를 통해 문맥에서 예측기를 적응시킨 결과입니다.

**[분석자의 해석]** 이 실험은 단순한 모델 간 순위보다 문맥의 기여를 더 직접적으로 보여줍니다. 그러나 문맥을 추가하면 입력 정보량도 늘어나므로, **올바른 입력–정답 대응의 효과**와 **추가 과거 정보 자체의 효과**를 완전히 분리하지는 못합니다.

이 점에서 저자들이 §A.11.1에서 인정한 내용도 중요합니다. 전체 데이터 학습에서는 문맥 효과가 ICL 때문인지, 이미 가중치에 학습된 채널 관계를 활용한 것인지 구분하기 어렵다고 설명합니다. **[P, p.26]**

### 3.6 다중 원천 학습과 문맥 수의 효과

**[저자 보고]**

- Table 13의 Weather 평균 MSE는 문맥 0%·25%·50%·75%·100%에서 각각 **0.225·0.223·0.220·0.219·0.218**입니다.
- ETTm2는 같은 순서로 **0.254·0.251·0.250·0.248·0.247**입니다.
- 여러 ETT 원천 데이터를 함께 학습한 추가 실험의 전체 문맥 MSE는 **0.167**로, 단일 원천의 **0.168**보다 낮습니다. **[P, p.23, Table 13; p.27, Tables 17–18]**

**[분석자의 해석]**

문맥 증가의 평균적 이점은 관찰됩니다. 하지만 개별 예측길이에서 항상 단조롭게 개선되지는 않으며, 다중 원천 학습의 0.001 개선에는 반복실험의 불확실성이 제시되지 않았습니다. 이를 대규모 사전학습의 확실한 효과로 확대하기는 어렵습니다.

### 3.7 계산 효율

**[저자 보고]** ETTh2 형식, $L_P=96$에서의 비교입니다. **[P, p.9, Table 5]**

> **용어 풀이**
>
> - **난수 시드(seed)**: 초기화와 무작위 처리를 재현하도록 고정하는 값.
> - **신뢰구간**: 반복 표본의 변동을 고려해 추정값의 불확실성을 표현하는 구간.
> - **통계적 유의성**: 관측된 차이가 우연한 변동만으로 설명되기 어려운지를 검토하는 개념.

### 4.2 직접 비교하면 안 되는 수치와 조건

#### ① 기본 ICTSP와 일부 기준모델의 입력 길이

ICTSP는 기본적으로 $L_I=1440$을 사용하지만, 일부 대표 기준모델은 512를 사용합니다. 저자는 기준모델의 입력 길이가 튜닝 대상이라는 이유로 선행 연구의 결과를 재사용합니다. **[P, pp.18–19, §A.3.3]**

따라서 결과를 **동일한 관측정보량·동일한 튜닝 예산으로 완전히 통제된 비교**라고 부르기는 어렵습니다.

별도 **ICTSP (Limited)**는 매 입력의 앞 928개 위치를 평균값으로 채우고 최근 512개 실제 값만 남깁니다. 다만 $L_b$도 512에서 336으로 바꾸므로, 입력 길이만 변경한 실험은 아닙니다. **[P, p.21, §A.6]**

#### ② 주 few-shot 마스킹과 Limited는 다른 설정

원래 few-shot 실험은 검증·시험 구간 시작 이전의 이력을 최대 512스텝으로 제한합니다. 이후 관측값이 쌓이면 유효 이력이 1440까지 늘어납니다. **평가 내내 최근 512개만 사용한 설정은 아닙니다.** **[P, p.22]**

#### ③ 5%와 10% 평균의 구성 차이

ETTh1·ETTh2·Traffic의 5% 평균은 3개 예측길이, 10% 평균은 4개 예측길이를 포함합니다. 두 평균의 단순 대소 비교로 학습량 효과를 판단할 수 없습니다. **[P, p.15, Tables 7–8]**

#### ④ 서로 다른 데이터셋의 MSE 절댓값

표준화된 서로 다른 데이터셋의 MSE를 직접 비교해 어느 실제 업무가 더 쉽거나 정확하다고 판단할 수 없습니다. 같은 데이터·지표·평가 조건 안에서 비교해야 합니다.

#### ⑤ 최신 기반모델과의 수치

사전학습 데이터, 문맥 제공 범위, 확률예측 여부, 평가 지표가 다른 최신 모델의 점수를 ICTSP 표와 합쳐 하나의 순위로 만들 수 없습니다.

## 5. 가장 중요한 그림의 선정과 해석

### 5.1 Figure 2 — 핵심 기여를 가장 잘 보여주는 구조 그림

**위치: p.3**

그림은 세 가지 토큰화 방식을 비교합니다.

| 구조 | 한 토큰이 나타내는 것 |
|---|---|
| Temporal-wise Transformer | 특정 시점 또는 구간의 여러 변수 값 |
| Series-wise Transformer | 특정 변수의 과거 시계열 |
| ICTSP | 과거 입력과 실제 후속값으로 구성된 예측 과제 |

**[분석자의 해석]** ICTSP의 핵심은 attention 연산을 새롭게 만드는 것보다 **attention이 비교하고 조합할 단위를 예측 과제로 바꾸는 것**에 있습니다.

**읽을 때 주의할 점:** 그림은 설명을 위해 $m=L_b+L_P$인 비중첩 창을 사용합니다. 실제 기본 설정 $m=8$에서는 과거 창들이 상당 부분 겹칩니다.

### 5.2 Figure 4 — 구조에 따라 유리한 데이터 관계가 달라짐

**위치: p.9**

- Multi에서는 변수 간 이동 관계가 강합니다.
- ETTm2에서는 비교한 temporal-wise 모델이 더 불안정한 시험 오차를 보입니다.
- ICTSP는 두 사례 모두에서 경쟁력 있는 결과를 보입니다.

**[분석자의 해석]** 이 그림은 토큰화가 데이터의 관계 구조와 맞아야 한다는 주장을 뒷받침합니다.

**해석의 한계:** $L_I=512$, $L_b=256$, $L_P=192$인 별도 설정입니다. 주실험의 모든 기준모델과 데이터셋에 대한 보편적 서열을 보여주는 그림은 아닙니다.

### 5.3 Figure 5 — 어떤 문맥을 참조하는가

**위치: p.10**

저자는 Multi에서 이동 관계에 대응하는 다른 채널 문맥을, ETTm2에서는 미래 모양과 유사한 더 이른 과거 구간을 참조한다고 해석합니다.

**[분석자의 해석]** 문맥과 목표 사이 정보 교환이 일어난다는 시각적 근거입니다. 그러나 attention의 크기만으로 특정 예제가 예측을 인과적으로 결정했다고 단정할 수는 없습니다.

**해석의 한계:** 토큰 검색을 끈 선택 사례이며, 전체 데이터에 대한 기여도 분석은 아닙니다.

**위치: p.18**

ECL의 한 설정에서 선형 층 워밍업 5,000스텝을 사용한 모델이 워밍업 없는 모델 및 선형 경로만 쓰는 모델보다 좋은 학습 곡선을 보입니다.

**[분석자의 해석]** 간단한 예측 경로를 먼저 안정화한 뒤 복잡한 문맥 모델을 학습하는 전략은 빠르게 검증할 가치가 있습니다.

**해석의 한계:** 한 데이터·한 예측길이의 실험이므로, 5,000스텝이 일반적인 최적값이라는 결론은 낼 수 없습니다.

| Few-shot·zero-shot의 표준화 통계는 정확히 어느 범위에서 추정되는가? | 허용 정보량을 재현하는 데 필요 | 각 설정별 상세 명세가 충분하지 않음 |
| 채널 수가 큰 경우 실제 지연시간과 메모리는 어떠한가? | 운영 환경에서 계산 효율 판단 | Table 5는 ETTh2 형식의 FLOPs 중심 |
| 자동 모델 축소가 실제 학습 중 일어나는가? | 논문의 설명 메커니즘을 검증 | 구조 포함 관계와 수동 제거 실험 중심 |

> **용어 풀이**
>
> - **분포 변화(distribution shift)**: 학습할 때와 사용할 때 데이터의 통계적 특성이 달라지는 현상.
> - **확률예측**: 하나의 예상값뿐 아니라 가능한 값의 분포나 구간도 예측하는 방식.
> - **보정(calibration)**: 예측한 불확실성 수준이 실제 발생 빈도와 맞는 정도.

### 7.4 후속 이론 연구를 읽을 때의 주의점

2025년 공개된 *Why Do Transformers Fail to Forecast Time Series In-Context?*는 특정 자기회귀 과정과 선형 self-attention 설정에서 유한 문맥의 한계를 분석합니다. 그러나 핵심 분석의 가정은 ICTSP의 전체 구조와 다르므로, 이를 ICTSP의 일반적 실패 정리로 적용할 수 없습니다. [arxiv.org](https://arxiv.org/html/2510.09776v1?utm_source=chatgpt.com)

> **용어 풀이**
>
> - **AR( $p$ )**: 현재 값을 직전 $p$개 값의 선형 결합과 잡음으로 표현하는 자기회귀 모형.
> - **선형 self-attention, LSA**: 일반적인 softmax attention을 단순화한 이론 분석용 구조.

**[분석자의 해석]** 이 문헌이 주는 유용한 교훈은 **문맥을 늘린다는 사실만으로 단순 예측기의 성능을 반드시 넘어서는 것은 아니라는 점**입니다. 데이터 생성 과정별로 선형 모형과의 비교를 유지해야 합니다.

### 7.5 확인 가능한 후속 영향

2026년의 ICI-Time은 과거–미래 예시와 질의를 시각적 형태로 구성해 이미지 복원 방식으로 예측하며, ICTSP를 관련 연구로 직접 인용합니다.  
이는 ICTSP가 시계열의 문맥 예제 구성에 관한 후속 논의에 포함되었다는 확인 가능한 사례입니다.  
다만 인용 사실만으로 후속 성능 향상의 인과적 원인을 특정할 수는 없습니다. [arxiv.org](https://arxiv.org/html/2608.23855v1?utm_source=chatgpt.com)

## 8. 결론, 일반화 향상 가능성, 우선 검증할 접근법

### 8.1 저자들이 제시한 시사점과 남긴 연구 과제

**[저자 보고]** ICTSP는 예측 과제 토큰을 통해 ICL을 시계열에 활용하고, 기존 토큰화의 문제를 완화하며, 여러 학습 데이터 조건에서 좋은 성능을 보였다고 결론짓습니다.  
범용 시계열 모델의 기반이 될 수 있다는 가능성도 제시합니다. **[P, p.2; p.10, §5]**

후속 과제로는 **더 큰 자료·더 깊은 모델에서의 확장성**, **다양한 과거·예측길이를 처리하는 단일 모델**이 남습니다. 구체적인 개발 일정이나 성능 목표는 제시하지 않습니다.

### 8.2 일반화 성능에 관해 어디까지 말할 수 있는가?

| 일반화의 종류 | 현재 근거 | 판단 |
|---|---|---|
| 같은 데이터셋의 새로운 예측 시점 | 전체 데이터 시험 결과 | 관찰된 성능 개선 |
| 적은 학습 자료로의 예측 | 첫 5%·10% 실험 | 전반적인 개선과 일부 예외 존재 |
| 관련 데이터셋 사이 전이 | ETT 간 zero-shot | 비교적 직접적인 실험 근거 |
| 문맥을 이용한 대상 데이터 적응 | Table 17의 문맥 제거 비교 | 일반화 기여를 지지하는 핵심 근거 |
| 전혀 다른 도메인·채널 의미로의 전이 | 광범위한 직접 실험 부족 | 미검증 |
| 하나의 모델에서 가변 $L_b,L_P$ 처리 | 저자가 미탐구로 명시 | 미검증 |
| 데이터·모델 규모 확대의 지속적 효과 | 대규모 scaling 실험 없음 | 미검증 |

**[분석자의 해석]** 가장 유망한 일반화 경로는 학습된 가중치만으로 새 데이터를 처리하는 부담을 줄이고, **현재 관측 가능한 과거 예측 예제를 이용해 예측을 조정하는 것**입니다.  
이 경로가 성공하려면 문맥에 현재 목표와 관련된 정보가 있어야 하며, 그 관련성을 선택하고 오래된 정보를 걸러내는 능력이 중요합니다.

### 8.3 학계와 실무에 대한 의미

**학계에 대한 의미**

예측 모델의 성능을 attention 구조나 파라미터 수뿐 아니라 **학습 문제의 표현 방식**으로 설명하려는 시도입니다. 특히 “예제와 답을 어떤 단위로 묶어 전달해야 하는가”를 시계열 모델 설계의 중심 질문으로 제시합니다. **[P, pp.2–6]**

**실무에 대한 의미**

관측 이력이 지속적으로 쌓이는 전력·교통·기상 데이터에서, 기존 이력으로 예측 예제를 구성하는 접근을 검토할 근거를 제공합니다. 다만 운영상의 이점은 FLOPs만으로 결정되지 않으므로, 실제 자료에서의 정확도·메모리·응답시간을 함께 평가해야 합니다. **[P, Tables 1–5에 근거한 분석자의 해석]**

| 6 | **선형 경로부터 시작하는 학습** | 선형 모델, MLP, 워밍업 없는 문맥 모델, 선형 워밍업 모델 비교 | 복잡한 구조를 추가하는 시점이 안정성에 영향을 주는가? |

선정 근거는 **[P, p.5; Tables 4, 12–13, 17; Figure 7]**입니다.

특히 **1번과 2번을 먼저 수행하는 것이 합리적**입니다. 첫 번째는 아이디어 자체의 유용성을 저렴하게 확인하고, 두 번째는 올바른 예제–정답 대응이 실제 성능에 기여하는지를 검증합니다.

### 8.5 그다음 진행할 후속 연구

**[추가 연구 제안]**

1. **도메인 단위 제외 평가**  
   한 도메인을 학습에서 통째로 제외하고 평가하여, ETT 내부 전이보다 강한 일반화 조건을 만듭니다.

2. **채널 수·시차·변수 역할을 따로 변화시키는 실험**  
   채널 수만 바꾸는 경우와 변수 의미까지 바꾸는 경우를 구분하고, 미래에 알려진 공변량을 추가할 때의 효과도 평가합니다.

3. **합성 사전학습의 기여 분리**  
   ForecastPFN·Chronos 계열처럼 합성 자료를 활용하되, 자료의 다양성과 과제 토큰화 각각의 기여를 분리합니다.

4. **문맥의 오염과 환경 변화 평가**  
   오래된 예제, 잘못된 후속값, 다른 체제의 예제를 주입해 어떤 조건에서 문맥 사용이 해로운지 측정합니다.

5. **반복실험과 시계열 의존성을 고려한 불확실성 보고**  
   여러 시드와 데이터셋 단위 결과를 함께 보고하고, 시간적으로 연속된 블록을 활용하는 재표본화 등으로 오차 차이의 불확실성을 평가합니다.

6. **정확도와 운영 비용의 공동 평가**  
   같은 문맥 예산에서 예측오차·지연시간·메모리를 함께 측정하여, 검색 문맥 방식과 순환 상태 재사용 방식의 장단점을 비교합니다.

> **용어 풀이**
>
> - **도메인 단위 제외 평가**: 특정 분야의 자료를 학습에서 완전히 빼고 그 분야에서 평가하는 방법.
> - **블록 재표본화**: 시계열의 인접 관측 간 관계를 어느 정도 유지하도록 연속 구간 단위로 다시 표본을 만드는 방법.

**최종 평가:** ICTSP는 **과거의 예측 문제와 답을 재사용하는 토큰 설계가 전이 성능에 기여할 수 있다는 실험적 근거**를 제공합니다. 후속 연구의 우선 목표는 이 효과를 동일 정보량·다양한 도메인·반복실험 조건에서 확인하고, 문맥의 선택과 품질이 일반화에 미치는 영향을 분리하는 것입니다.
