# PETformer: Long-term Time Series Forecasting via Placeholder-enhanced Transformer

**분석 대상:** Shengsheng Lin, Weiwei Lin, Wentai Wu, Songbo Wang, Yongxiang Wang, *PETformer: Long-term Time Series Forecasting via Placeholder-enhanced Transformer*, arXiv:2308.04791v2, 2023년 10월 7일.

**분석 원문:** 2308.04791v2.pdf

첨부본은 총 18쪽이며, 표지에 **“Under review”**라고 표시되어 있습니다. 아래의 페이지 번호는 첨부 PDF에 인쇄된 번호입니다. **[저자 보고]**, **[원문 수치 재계산]**, **[분석·해석]**, **[후속 연구 제안]**을 구분했습니다. 관련 연구 비교는 **2026년 10월 19일까지 확인한 원 논문과 공식 발표**를 별도 출처로 사용했습니다.

## 1. Executive summary — 8문장

1. PETformer는 장기 시계열 예측에서 Transformer의 성능을 개선하기 위해 **시간적 연속성, 입력의 정보 밀도, 다변수 관계의 처리 방식**을 재검토한 연구입니다. **[저자 보고: pp.1–2]**
2. 핵심 제안인 PET는 미래 구간을 나타내는 학습 가능한 placeholder를 과거 패치 토큰 뒤에 붙이고, 동일한 Transformer 인코더 안에서 함께 처리합니다. **[저자 보고: p.4, Figure 2]**
3. 이후 미래 위치의 출력 토큰만 추출하여 작은 공유 선형 예측기로 각 미래 패치를 복원하므로, 전체 과거 표현을 펼치는 Flattening 예측기의 큰 파라미터 부담을 줄입니다. **[저자 보고: pp.3–4, p.8]**
4. 모델은 큰 패치를 사용하는 LSD와 채널 분리 전략을 결합하며, **기본 설정은 채널 간 명시적 상호작용이 없는 NCI**입니다. **[저자 보고: pp.4–5, p.14]**
5. 저자들은 8개 공개 데이터셋의 다변량 예측에서 PatchTST 대비 평균 MSE 4.7%, MAE 3.7% 개선을 보고합니다. **[저자 보고: p.6, Table 2]**
6. 다만 표 2를 직접 확인하면 PETformer의 단독 1위는 32개 설정 중 MSE 25개, MAE 29개이므로, 본문의 “모든 설정에서 최고 성능”이라는 서술에는 예외가 있습니다. **[원문 수치 재계산: p.7, Table 2]**
7. 별도의 효율 실험에서는 예측 헤드 파라미터가 PatchTST의 830만 개에서 약 6,190개로 줄어, **예측 헤드에 한정한 99% 이상의 감소**가 확인됩니다. **[저자 보고: p.8, Table 5]**
8. 여러 채널의 공유학습과 긴 입력 활용은 유망하지만, 첨부 논문은 새로운 데이터셋·미관측 채널·명시적인 분포 변화에 대한 일반화 실험을 제공하지 않으므로, 일반화 향상은 추가 검증이 필요한 가능성으로 평가해야 합니다. **[분석·해석: pp.15–17, Tables 8–10]**

> **용어 풀이**
>
> - **장기 시계열 예측, LTSF:** 과거에 관측한 숫자의 흐름으로 여러 미래 시점의 값을 예측하는 문제입니다.
> - **패치·토큰:** 패치는 연속된 관측값의 묶음이고, 토큰은 그 묶음을 모델이 처리할 수 있는 벡터로 바꾼 표현입니다.
> - **Placeholder:** 앞으로 예측할 구간의 자리를 나타내는 학습 가능한 벡터입니다. 실제 미래 관측값을 담고 있지는 않습니다.
> - **채널:** 온도·전력 사용량·센서값처럼 시계열의 개별 변수입니다.
> - **MSE·MAE:** 각각 오차를 제곱한 값의 평균과 오차 절댓값의 평균이며, 모두 작을수록 좋습니다.

## 2. 연구 배경 및 목표

### 2.1 해결하려는 문제

**[저자 보고]** 연구의 출발점은 단순한 선형 모델인 DLinear가 당시 여러 Transformer 예측 모델보다 좋은 결과를 냈다는 사실입니다. 이어 PatchTST가 패치와 채널 독립 전략으로 Transformer의 성능을 높였지만, 저자들은 **Transformer를 시계열에 적용하는 최적의 입력·출력 구조가 충분히 이해되지 않았다**고 봅니다. **[pp.1–2]**

논문의 문제 진단은 다음 세 가지입니다.

| 문제 | 저자의 진단 | 제안한 대응 |
|---|---|---|
| 시간적 연속성 | 과거와 미래는 이어진 시계열인데, 인코더–디코더 구조의 정보 전달이나 출력 압축 방식이 이를 충분히 활용하지 못할 수 있음 | 과거와 미래 placeholder를 같은 인코더에서 처리하는 **PET** |
| 정보 밀도 | 시계열의 단일 관측값만으로는 의미 있는 시간 패턴을 표현하기 어려움 | 더 긴 부분 시계열을 하나의 토큰으로 만드는 **LSD** |
| 다변수 관계 | 여러 변수를 처음부터 섞으면 변수 내부의 시간 패턴을 훼손할 수 있음 | 채널별 시간 특징을 먼저 추출하고 필요할 때 상호작용하는 **MSI** |

**근거:** pp.1–2, Figures 1–2.

> **용어 풀이**
>
> - **시간적 연속성:** 입력의 마지막 시점과 예측의 첫 시점이 같은 시간 흐름에 속한다는 의미입니다.
> - **정보 밀도:** 여기서는 하나의 입력 단위에 얼마나 유용한 패턴이 담기는지를 뜻하는 직관적 표현입니다. 논문은 이를 별도의 정량 지표로 측정하지 않습니다.
> - **인코더–디코더:** 인코더가 입력을 표현으로 바꾸고, 디코더가 그 표현을 이용해 출력을 만드는 구조입니다.

### 2.2 연구 목적과 필요성

**[저자 보고]** 목적은 예측 정확도와 계산 효율을 함께 개선하는 것입니다. 특히 PatchTST와 같은 Flattening 방식은 모든 과거 토큰을 하나의 긴 벡터로 펼친 뒤 전체 미래를 예측하므로, 출력층이 커질 수 있습니다. 반면 Feature Head 방식은 작은 구조를 유지하지만, 긴 미래에 필요한 정보를 하나의 벡터에 압축해야 합니다. PET는 미래 구간마다 출력 표현을 두어 이 문제에 대응합니다. **[p.2, Figure 1; p.8]**

**[분석·해석]** 이 연구의 필요성은 “더 복잡한 attention을 개발해야 하는가”라는 질문과 함께, **기존 Transformer의 입력 단위와 출력 연결 방식만 바꾸어도 어느 정도 개선할 수 있는가**를 검증한다는 데 있습니다. 실제로 논문의 가장 직접적인 증거는 구조를 비교한 Table 4와 예측 헤드 비용을 비교한 Table 5입니다.

> **용어 풀이**
>
> - **Flattening:** 여러 토큰의 벡터를 이어 붙여 하나의 긴 벡터로 만드는 연산입니다.
> - **Feature Head:** 논문에서 비교한 방식으로, 하나의 대표 토큰에 정보를 모아 전체 미래를 예측합니다.
> - **예측 헤드:** 모델이 추출한 특징을 최종 예측값으로 바꾸는 출력 부분입니다.

### 4.2 학습·평가 설계

**[저자 보고]**

- 데이터를 **시간순**으로 학습·검증·시험 구간으로 나눕니다.
- ETT는 **6:2:2**, 나머지 데이터셋은 **7:1:2** 비율을 사용합니다.
- PETformer의 입력 길이는 ILI에서 $l=72$, 나머지에서는 $l=720$입니다.
- ILI의 예측 길이는 $h\in\{24,36,48,60\}$, 나머지는 $h\in\{96,192,336,720\}$입니다.
- 다변량 예측은 8개 데이터셋, 단변량 예측은 4개 ETT 데이터셋에서 평가합니다.
- 평가 지표는 MSE와 MAE입니다. **[p.7, Tables 2–3; pp.13–14]**

비교모델은 PatchTST, DLinear, MICN, Crossformer, FEDformer, Autoformer, Informer입니다. 앞의 네 모델은 공식 구현을 사용해 입력 길이를 바꾸어 실험했고, **FEDformer·Autoformer·Informer의 결과는 PatchTST 논문에서 가져왔습니다.** 비교모델의 최종 값은 여러 입력 길이 후보 중 가장 좋은 결과입니다. **[Appendix A.1.2, pp.13–14]**

따라서 Table 2는 **모든 모델의 입력 길이와 학습 설정을 동일하게 고정한 실험**으로 해석할 수 없습니다.

### 4.3 전체 구조와 기호

모델의 흐름은 다음과 같습니다.

**입력별 정규화 → 채널 분리 → 패치화·임베딩 → 미래 placeholder 결합 → Transformer 인코더 → 미래 토큰 추출 → 선택적 채널 처리 → 공유 예측기 → 역정규화**

**근거:** pp.3–5, Figures 2–4.

| 기호 | 의미 |
|---|---|
| $l$ | 과거 입력 길이 |
| $h$ | 미래 예측 길이 |
| $d$ | 변수·채널 수 |
| $w$ | 패치 길이 |
| $s$ | 패치 이동 간격 |
| $n$ | 과거 패치 수 |
| $m$ | 미래 placeholder 수 |
| $D=d_{\text{model}}$ | 토큰의 임베딩 차원 |
| $N$ | 인코더 블록 수 |
| $i$ | 채널 인덱스 |

**수식 표기 주의:** 첨부 논문의 수식에는 번호가 없습니다. 아래에서 **“원문 식”**과 **“설명용 재구성”**을 구분합니다. 또한 원문 p.8은 임베딩 차원에도 $d$를 사용하므로, 혼동을 피하기 위해 이 보고서에서는 이를 $D$로 표기합니다.

> **용어 풀이**
>
> - **임베딩:** 원시 입력을 모델이 학습하기 쉬운 벡터 표현으로 변환하는 과정입니다.
> - **역정규화:** 모델 출력의 크기와 기준 수준을 원래 데이터의 척도로 되돌리는 과정입니다.

### 4.4 LSD: 부분 시계열 분할과 토큰화

각 채널의 시계열 $X^{(i)}\in\mathbb R^l$을 길이 $w$의 패치로 나눕니다.

**원문 식:**

$$
n=\left\lfloor\frac{l-w}{s}+1\right\rfloor,
\qquad
m=\left\lfloor\frac{h-w}{s}+1\right\rfloor.
$$

여기서 $n$은 과거 패치 수, $m$은 미래 패치에 대응하는 placeholder 수이며, $\lfloor\cdot\rfloor$는 내림 연산입니다. 나머지 기호는 각각 입력 길이 $l$, 예측 길이 $h$, 패치 길이 $w$, 이동 간격 $s$입니다. **[§3.1, p.4]**

과거 패치는 공유 선형층을 통해 토큰으로 변환됩니다.

**원문 설명의 수식 재구성:**

```math
E^{(i)}
=
X_{\text{patch}}^{(i)}W_E+\mathbf 1_n b_E^\top
\in\mathbb R^{n\times D}.
```

- $X_{\text{patch}}^{(i)}\in\mathbb R^{n\times w}$: $i$번째 채널의 패치 행렬.
- $W_E\in\mathbb R^{w\times D}$: 입력 임베딩 가중치.
- $b_E\in\mathbb R^D$: 편향.
- $\mathbf 1_n$: 길이 $n$의 모든 원소가 1인 벡터.
- $E^{(i)}$: 인코더에 입력할 과거 토큰.

**근거:** §3.1, p.4.

**[분석·해석]** LSD는 완전히 새로운 패치 개념이라기보다, PatchTST에서 이어받은 패치 전략에서 **더 큰 패치의 효과를 조사한 부분**입니다. 저자도 이를 인정합니다. **[p.8, §4.2.2]**

> **용어 풀이**
>
> - **Stride:** 패치 시작점을 몇 시점씩 이동할지를 정하는 간격입니다.
> - **공유 선형층:** 모든 패치에 같은 가중치로 동일한 변환을 적용하는 층입니다.

### 4.5 PET: 미래 placeholder를 입력에 포함

학습 가능한 **하나의 벡터** $p\in\mathbb R^D$를 만들고, 이를 $m$번 복제하여 과거 토큰 뒤에 붙입니다. 여기에 학습 가능한 위치 인코딩을 더합니다. **[§3.1–3.2, p.4, Figure 2]**

**설명용 재구성:**

```math
Z_0^{(i)}
=
\begin{bmatrix}
E^{(i)}\\
\mathbf 1_m p^\top
\end{bmatrix}
+
P_{\text{pos}}
\in\mathbb R^{(n+m)\times D}.
```

- $p$: 학습 가능한 공통 placeholder.
- $\mathbf 1_m p^\top$: 같은 placeholder를 $m$행 복제한 행렬.
- $P_{\text{pos}}$: 과거·미래의 각 위치를 구별하는 위치 인코딩.
- $Z_0^{(i)}$: $i$번째 채널의 전체 인코더 입력.

핵심은 **미래 토큰마다 독립적인 벡터를 처음부터 따로 학습하는 방식이 아니라, 같은 placeholder를 복제한다는 점**입니다. 각 미래 구간은 위치 인코딩과 과거 정보와의 상호작용을 통해 서로 다른 표현을 얻게 됩니다. **[p.4]**

설명용으로 $l=720$, $h=96$, $w=s=48$을 가정하면, 과거 토큰은 15개이고 미래 placeholder는 2개입니다. 인코더는 총 17개 토큰을 처리하고, 마지막 2개 토큰에서 각각 48시점의 미래를 출력하게 됩니다. **이 예시는 위 식에 따른 계산이며, 논문에 실제 stride가 48이라고 명시된 것은 아닙니다.**

> **용어 풀이**
>
> - **위치 인코딩:** 같은 내용의 토큰이라도 어느 시간 위치에 있는지 구별하도록 더하는 정보입니다.
> - **학습 가능한 벡터:** 고정된 값이 아니라, 예측 오차를 줄이는 학습 과정에서 값이 조정되는 벡터입니다.

### 4.6 과거와 미래가 상호작용하는 방식

원문은 표준 Transformer encoder layer를 사용한다고 설명합니다. 그 attention 연산을 이해하기 위한 일반적인 표현은 다음과 같습니다.

**설명용 표준 attention 수식:**

```math
\text{Attention}(Q,K,V;M)
=
\text{softmax}
\left(
\frac{QK^\top}{\sqrt{d_k}}+M
\right)V.
```

- $Q$: 각 토큰이 어떤 정보를 찾는지 나타내는 query.
- $K$: 다른 토큰과의 관련도를 계산하는 key.
- $V$: 실제로 전달할 정보인 value.
- $d_k$: query·key 벡터의 차원.
- $M$: 허용할 attention 연결을 정하는 마스크.
- $\text{softmax}$: 관련도 점수를 합이 1인 가중치로 바꾸는 함수.

이 수식 자체는 PETformer PDF에 그대로 제시되지 않았으며, p.4의 표준 Transformer 설명을 이해하기 위한 표현입니다.

논문이 비교한 네 가지 모드는 다음과 같습니다. 화살표는 **정보가 전달되는 방향**입니다.

| 모드 | 과거→과거 | 과거→미래 | 미래→과거 | 미래 토큰 사이 |
|---|---|---|---|---|
| FA | 허용 | 허용 | 허용 | 허용 |
| NIFA | 허용 | 허용 | 차단 | 차단 |
| NIHA | 차단 | 허용 | 차단 | 허용 |
| OFFH | 차단 | 허용 | 차단 | 차단 |

**근거:** Figure 3, p.4; 모드 정의 p.5. 세부적인 자기 연결이나 마스크 구현까지 명세한 표는 아닙니다.

기본값은 **FA**입니다. 여기서 미래 토큰이 과거 토큰에 정보를 전달한다는 것은 학습된 미래 위치 표현이 상호작용한다는 뜻입니다. **예측 시 알 수 없는 실제 미래값을 입력한다는 뜻은 아닙니다.**

인코더는 $N$개의 블록으로 구성되며, Figure 2에는 표준 인코더 내부의 LayerNorm과 별도의 외부 BatchNorm·잔차 연결이 모두 표시되어 있습니다. 따라서 “LayerNorm을 BatchNorm으로 교체했다”고 설명하면 부정확합니다. **[p.4, Figure 2]**

> **용어 풀이**
>
> - **Self-attention:** 같은 토큰열 안의 토큰들이 서로의 정보를 읽는 방식입니다.
> - **Multi-head attention:** 여러 관점에서 관련도를 계산하도록 attention을 병렬로 수행하는 구조입니다.
> - **잔차 연결:** 변환한 결과에 원래 입력을 더하는 연결입니다.
> - **LayerNorm·BatchNorm:** 각각 토큰의 특징 또는 배치의 통계를 이용해 중간 표현의 규모를 조절하는 정규화 방식입니다. 이 논문은 구현 축의 세부사항까지 제공하지 않습니다.

### 4.7 MSI: 채널 분리와 선택적 상호작용

인코더가 출력한 마지막 $m$개 미래 토큰을 채널별로 모읍니다. 이후 **같은 미래 패치 위치에 속하는 여러 채널의 토큰**을 선택적 채널 모듈에 전달합니다. **[pp.3–5]**

| 모드 | 구조 | 명시적인 채널 간 데이터 혼합 |
|---|---|---|
| **NCI — 기본값** | 채널별로 처리하되 인코더 파라미터 공유 | 없음 |
| SA | 채널 출력 토큰 사이의 self-attention | 있음 |
| CI | 각 채널의 출력 토큰에 학습 가능한 채널 식별자 추가 | 다른 채널 관측값의 직접 혼합은 없음 |
| CA | 채널 식별자를 query, 출력 토큰을 key·value로 사용하는 cross-attention | 있음 |

**근거:** §3.3, p.5, Figure 4; 기본값은 Appendix A.1.3, p.14.

**[분석·해석]** 채널 독립은 변수마다 완전히 별개의 모델을 학습한다는 뜻이 아닙니다. 여러 변수의 데이터가 **같은 모델 가중치를 학습하는 데 사용**되지만, 특정 변수를 예측할 때 다른 변수의 관측값을 직접 읽지는 않는 구조입니다. 이 구분은 일반화 가능성을 이해하는 데 중요합니다.

> **용어 풀이**
>
> - **채널 식별자:** 현재 토큰이 어느 변수에 속하는지 알려 주는 학습 가능한 표식입니다.
> - **Cross-attention:** query와 key·value를 서로 다른 정보원에서 가져오는 attention입니다.

### 4.8 공유 예측기와 파라미터 감소

미래 토큰을 길이 $w$의 예측 패치로 바꾸는 공유 선형층을 적용합니다.

**설명용 재구성:**

```math
\widehat Y_{\text{patch}}^{(i)}
=
F^{(i)}W_O+\mathbf 1_m b_O^\top
\in\mathbb R^{m\times w}.
```

- $F^{(i)}\in\mathbb R^{m\times D}$: 선택적 채널 처리를 마친 미래 토큰.
- $W_O\in\mathbb R^{D\times w}$: 공유 출력 가중치.
- $b_O\in\mathbb R^w$: 출력 편향.
- $\widehat Y_{\text{patch}}^{(i)}$: 예측된 미래 패치들.

원문은 이 패치들을 이어 붙여 최종 출력을 만든다고 설명합니다. **[p.3; Figure 2; p.8]**

편향을 제외한 예측 헤드 가중치 수는 다음과 같습니다.

$$
P_{\text{flatten}}=nDh,
\qquad
P_{\text{PET}}=Dw.
$$

여기서 $P$는 가중치 수이고, $n$은 과거 토큰 수, $D$는 임베딩 차원, $h$는 예측 길이, $w$는 패치 길이입니다. **[원문 p.8의 기호를 정리한 식]**

**[분석·해석]** PET에서는 같은 출력층을 모든 미래 토큰에 재사용하므로, 헤드의 가중치 수가 전체 예측 길이에 직접 비례하지 않습니다. 다만 인코더는 $n+m$개 토큰을 처리하므로, **헤드 파라미터 감소율을 전체 attention 계산량 감소율로 해석할 수는 없습니다.**

### 4.9 RevIN과 손실함수

**[저자 보고]** 전역 데이터 정규화 외에 RevIN을 사용합니다. 개별 입력 구간을 정규화하고 예측 후 원래 척도로 복원하여, 학습·시험 데이터 사이의 분포 변화를 완화하려는 목적입니다. PETformer PDF에는 RevIN의 구체적인 변환식은 없습니다. **[§3.4, p.5]**

> **용어 풀이**
>
> - **RevIN:** 입력 구간의 평균·분산에 따른 차이를 줄이고, 출력에서 원래 수준을 복원하는 가역적 정규화입니다.
> - **분포 변화:** 시간에 따라 데이터의 평균, 변동 폭, 관계 구조 등이 달라지는 현상입니다.

학습에는 다음 Smooth L1 손실을 사용합니다.

**원문 식:**

```math
\mathcal L(Y,\widehat Y)
=
\frac{1}{dh}
\sum_{t=1}^{h}
\sum_{i=1}^{d}
\rho_{\text{smooth}}
\left(y_t^i-\widehat y_t^i\right),
```

```math
\rho_{\text{smooth}}(e)
=
\begin{cases}
0.5e^2, & \text{if } |e|<1,\\
|e|-0.5, & \text{otherwise}.
\end{cases}
```

- $y_t^i$: 미래 $t$번째 시점, $i$번째 채널의 실제값.
- $\widehat y_t^i$: 해당 예측값.
- $e$: 실제값과 예측값의 차이.
- $d,h$: 채널 수와 예측 길이.
- $\rho_{\text{smooth}}$: 작은 오차에는 제곱 형태, 큰 오차에는 절댓값 형태를 적용하는 함수.

**근거:** §3.4, pp.5–6.

**[저자 보고]** 저자들은 이 손실이 안정적인 기울기를 제공한다고 설명합니다. **[분석·해석]** 큰 오차에 대한 손실 증가가 제곱오차보다 완만하다는 점은 식에서 확인되지만, **모델 전체의 기울기 폭발·소실이 방지된다는 증명은 없습니다.**

기본 모델 설정은 인코더 **4층**, $D=512$, attention head **8개**, dropout **0.5**, feedforward factor **2**, $w=48$, FA·NCI·Smooth L1입니다. **[p.14]**

## 6. 모델의 일반화 성능 향상 가능성

### 6.1 원문이 실제로 보여준 일반화 관련 근거

가장 관련성이 높은 실험은 Table 9입니다. 이 표는 **각 데이터셋의 마지막 변수 하나**를 예측합니다.

- **Univariate:** 마지막 변수만 사용해 학습합니다.
- **MSI/NCI:** 모든 변수의 데이터를 사용해 같은 가중치를 학습하고, 마지막 변수를 예측합니다.

| 데이터셋·예측 길이 | 마지막 변수만 학습한 MSE | NCI 공유학습 MSE | 관찰 |
|---|---:|---:|---|
| Electricity–720 | 0.491 | **0.299** | 공유학습의 이득 |
| Traffic–720 | 0.140 | **0.124** | 공유학습의 이득 |
| Weather–96 | 0.0014 | **0.0008** | 공유학습의 이득 |
| ETTh1–720 | **0.079** | 0.092 | 공유학습이 불리한 사례 |

**근거:** Appendix A.4, pp.15–16; Table 9, p.16.

**[저자 해석]** 채널 분리가 학습에 사용하는 시계열 샘플 수를 늘려 개별 변수의 예측 능력을 높인다고 설명합니다.

**[분석·해석]** 결과는 다른 변수에서 학습한 시간 패턴이 목표 변수에 도움을 줄 수 있음을 보여줍니다. 그러나 다음 제한이 있습니다.

1. 목표 변수 자체도 학습에 포함됩니다.
2. 같은 데이터셋 안에서 평가합니다.
3. 마지막 변수 하나의 결과입니다.
4. 채널들의 시계열은 서로 상관될 수 있으므로, 데이터 조각 수가 늘어난 만큼 **독립적인 정보량**이 증가한다고 단정할 수 없습니다.
5. ETTh1의 반례는 공유학습이 불리하게 작용하는 **음의 전이 가능성**을 보여줍니다.

> **용어 풀이**
>
> - **전이:** 한 데이터에서 배운 패턴을 다른 데이터의 예측에 활용하는 것입니다.
> - **음의 전이:** 다른 데이터와 함께 학습한 것이 목표 데이터의 성능을 떨어뜨리는 현상입니다.

다음은 **검증된 일반화 성능을 주장하는 표가 아니라, 원문에 근거한 가설과 검증 범위의 구분**입니다.

> **용어 풀이**
>
> - **과적합:** 학습 데이터의 세부적인 우연까지 익혀 새로운 데이터에서 성능이 떨어지는 현상입니다.
> - **귀납 편향:** 모델 구조가 미리 부여하는 학습 방향입니다. 패치를 사용하거나 가중치를 공유하는 설계가 이에 해당합니다.

### 6.3 이 논문이 아직 입증하지 않은 일반화

첨부본에는 다음 평가가 없습니다.

| 일반화의 종류 | 확인 여부 |
|---|---|
| 데이터셋별로 학습한 모델의 미래 시간 구간 예측 | 있음 |
| 여러 random seed에서의 반복 안정성 | PETformer 7개 데이터셋에서 있음 |
| 새로운 데이터셋에 추가 학습 없이 적용 | 없음 |
| 학습에서 제외한 채널·센서에 적용 | 없음 |
| 명시적으로 정의한 분포 변화·환경 변화에 적용 | 없음 |
| 학습하지 않은 예측 길이를 같은 모델로 처리 | 없음 |
| 결측·센서 고장·이상치 주입에 대한 강건성 | 없음 |

**[분석·해석]** 논문이 지지하는 범위는 **여러 분야의 데이터셋에서 각각 학습했을 때의 예측 성능과 일부 구조적 이점**입니다. 이를 범용 사전학습 모델의 일반화 능력과 동일하게 해석하면 안 됩니다. **[실험 범위: §4, Appendix A]**

> **용어 풀이**
>
> - **제로샷:** 평가 대상 과제에 맞춰 가중치를 추가 학습하지 않고 예측하는 설정입니다. 과거 관측값을 입력으로 제공하는 것은 가능합니다.
> - **분포 밖 일반화, OOD:** 학습 때와 다른 통계적 특성이나 환경에서 성능을 유지하는 능력입니다.
> - **Random seed:** 초기화와 데이터 처리의 무작위성을 재현하도록 정하는 값입니다.

## 7. 통계적 취약점, 비교 제약, 재현성 공백

### 7.1 반복 실험은 있으나, 모델 간 유의성 검증은 부족함

**[저자 보고]** seed 2023·2024·2025의 세 번 실험을 Table 10에 제공합니다. 주표의 값은 seed 2023 결과입니다. 반복표에는 **ILI가 빠져 있고, 비교모델의 대응 반복 결과도 없습니다.** **[p.16, Appendix A.5; p.17, Table 10]**

특히 ETTh1–720의 PETformer MSE는 다음과 같습니다.

$$
0.437,\quad 0.474,\quad 0.436,
$$

논문이 보고한 평균과 표준편차는

$$
0.449\pm0.0216
$$

입니다. 주표의 PatchTST 값은 0.448입니다. **[Tables 2, 10]**

**[분석·해석]** 이 사례에서는 PETformer의 단일 seed 결과만으로 우위를 판단하기 어렵습니다. 그러나 PatchTST의 대응 분산이 없으므로, 반대로 “통계적으로 동률” 또는 “PETformer가 열등하다”고 확정할 수도 없습니다.

> **용어 풀이**
>
> - **표준편차:** 반복 실행 결과가 얼마나 퍼져 있는지를 나타냅니다.
> - **신뢰구간:** 추정하려는 평균이나 차이의 불확실성을 나타내는 구간입니다. 논문의 평균±표준편차는 신뢰구간과 다릅니다.

### 7.2 전체 평균 개선율은 ILI의 영향을 크게 받음

**[원문 수치 재계산]** Table 2의 반올림된 32개 행을 다시 평균하면, PatchTST 대비 평균 MSE 감소율은 약 **4.64%**입니다. 논문의 반올림된 평균값 0.427과 0.448로 계산하면 약 4.69%이므로, 보고된 **4.7%와의 작은 차이는 반올림 범위로 이해할 수 있습니다.**

더 중요한 점은 다음입니다.

- ILI 4개 설정이 PatchTST 대비 **전체 MSE 차이 합의 약 79.1%**를 차지합니다.
- ILI를 제외한 28개 설정에서 평균 MSE의 상대 감소율은 약 **1.64%**입니다.

이는 **새 실험이 아니라 Table 2 표시값의 재계산**입니다.

**[분석·해석]** 전체 평균은 유용하지만, 오차 규모가 큰 데이터셋에 민감합니다. 따라서 4.7%를 “모든 분야에서 대략 그 정도 좋아진다”는 의미로 읽으면 안 됩니다. ILI의 반복 분산이 제공되지 않는 점도 이 해석에서 중요합니다.

## 9. 2020년 이후 관련 연구 비교 분석

### 9.1 구조 설계 측면의 비교

아래의 원문 방법 설명과 PETformer에 대한 비교 해석을 구분했습니다. 최신 모델들의 수치를 PETformer 표에 섞어 순위를 다시 매기지는 않았습니다.

| 연구·발표 | 해당 연구가 제시한 방법 | PETformer와의 비교 및 일반화 관점 |
|---|---|---|
| **Informer, AAAI 2021** | 희소 attention과 입력 길이 축소, 한 번에 여러 미래 시점을 출력하는 디코더. **원문 pp.3–4, Figure 2.** [ojs.aaai.org](https://ojs.aaai.org/index.php/AAAI/article/view/17325?utm_source=chatgpt.com) | 장기 입력의 계산 효율을 다룬 선행 연구. PET의 기여를 “병렬 미래 예측의 최초 제안”으로 확대하면 안 됨. |

> **용어 풀이**

> - **희소 attention:** 가능한 모든 연결 대신 일부 중요한 연결에 계산을 집중하는 방식입니다.
> - **추세·계절 분해:** 장기적인 수준 변화와 반복 패턴을 나누어 처리하는 방법입니다.

### 9.3 관련 연구의 수치를 직접 비교할 수 없는 이유

**사전학습 자료의 중복 여부가 특히 중요합니다.** TimesFM 원문의 §5·Table 1에는 Electricity, Traffic, Weather가 사전학습 자료로 포함되어 있습니다. 따라서 같은 이름의 데이터셋에서 얻은 PETformer 결과와 TimesFM 결과를 그대로 비교해 “미학습 데이터에 대한 일반화 순위”로 해석하면 안 됩니다. 데이터 버전·시간 구간·변수 구성까지 확인해야 합니다. [arxiv.org](https://arxiv.org/html/2310.10688v4?utm_source=chatgpt.com)

후속 비교에서는 최소한 다음 조건을 맞춰야 합니다.

- 학습·검증·시험 구간과 사전학습 자료 중복 여부.
- 입력 길이와 예측 길이.
- 정규화와 평가 지표.
- 미래 공변량의 사용 가능 여부.
- 추가 학습을 허용하는지 여부.
- 학습·추론 계산 예산.

2026년의 *Position: Time-Series Foundation Models Require Explicit Domain-Level Benchmarks*도 여러 분야를 불균등하게 섞은 종합 점수가 개별 응용 분야의 성능을 가릴 수 있다고 지적합니다. **[분석·해석]** PETformer의 후속 일반화 평가에서도 전체 평균과 함께 에너지·교통·기상 등 분야별 결과를 보고하는 것이 적절합니다. [proceedings.mlr.press](https://proceedings.mlr.press/v306/syed26a.html?utm_source=chatgpt.com)

## 11. 결론, 제한사항, 빠르게 검증할 후속 연구

### 11.1 연구자들이 제시한 시사점과 후속 방향

**[저자 보고]** 저자들은 시간적 연속성, 정보 밀도, 다채널 관계의 관점에서 Transformer의 활용 방식을 재설계하면 정확도와 효율을 함께 개선할 수 있다고 결론짓습니다. 특히 **다변수 사이의 관계를 더 효과적으로 모델링하는 기술**을 중요한 후속 연구 방향으로 제시합니다. **[Conclusion, p.9]**

**[분석·해석]** 학술적으로 가장 분명한 기여는 **미래 구간을 명시적인 토큰으로 두고 작은 공유 예측기로 복원하는 구조**입니다. 실용적으로는 Table 5에서 확인한 헤드·메모리·학습 시간 절감이 의미 있습니다. 실제 서비스의 비용 절감이나 운영 신뢰성은 배포 실험이 추가되어야 평가할 수 있습니다.

### 11.2 논문에서 직접 인정한 한계

첨부본에는 별도의 “Limitations” 절이 없습니다. 다만 다음 제약을 본문과 부록에서 인정합니다.

- **더 큰 패치 미검토:** $w=48$을 넘는 실험은 선택한 예측 길이들의 최대공약수 제약 때문에 수행하지 못했습니다. 이는 실험 설계상의 제약입니다. **[p.8]**
- **채널 상호작용의 일관된 이득 부재:** SA·CI·CA가 NCI보다 뚜렷한 우위를 제공하지 않았으며, 복잡한 다변수 관계 모델링이 남은 과제입니다. **[p.9]**
- **RevIN 제거 시 큰 오차:** Traffic에서 MSE가 악화하는 현상을 패치 경계 진동 가능성과 연결하며, 추가 조사가 필요하다고 설명합니다. **[p.14]**
- **계산자원 제약:** 일부 비교 결과를 다른 논문에서 가져왔고, Traffic의 point-wise 실험에서는 메모리 부족이 발생했습니다. **[Table 6, p.9; pp.13–14]**

| **3** | 채널 독립 공유학습 | 목표 채널 단독, 유사 채널 묶음, 전체 채널 공유 비교 | 다른 채널이 언제 도움이 되고 언제 음의 전이를 만드는가? |
| **4** | 패치 크기 선택 | $w=12,24,48$에서 같은 시간 분할·입력 길이를 사용하고 계산 비용도 기록 | 큰 패치의 평균 이득과 데이터별 예외가 재현되는가? |
| **5** | 정규화와 경계 오차 | RevIN 유무를 바꾸고 패치 경계·내부 오차를 별도 측정 | Traffic의 MSE 악화가 실제로 경계 진동과 관련되는가? |

초기에는 ETTh1과 Weather처럼 특성이 다른 작은 데이터셋에서 구조적 효과를 확인하고, 효과가 확인된 구성만 Traffic으로 확장하는 순서가 적절합니다. 이는 원문 실험을 재현하고 남은 질문을 좁히기 위한 제안이며, 성능 향상을 예고하는 주장은 아닙니다.

### 11.4 일반화 향상을 위한 추가 연구 방향

**첫째, 미관측 채널 평가를 추가해야 합니다.** 일부 채널을 학습에서 완전히 제외하고, 그 채널의 과거 관측만 제공하여 미래를 예측하게 하면 Table 9보다 직접적인 변수 일반화 검증이 됩니다. iTransformer의 변수 분할 평가가 참고할 만한 설계입니다. [arxiv.org](https://arxiv.org/html/2310.06625v4?utm_source=chatgpt.com)

**둘째, 시간에 따른 환경 변화에서 평가해야 합니다.** 하나의 고정 시험 구간 외에 여러 시간 구간을 순차적으로 평가하고, 평균 수준 변화·계절 변화·큰 변동이 발생한 구간의 오차를 분리할 필요가 있습니다. 이는 RevIN과 긴 입력 활용의 실제 적용 범위를 검증하는 과제입니다. **[제안의 원문 근거: Tables 7–8]**

**셋째, 공유학습의 대상 선택을 검증해야 합니다.** Table 9의 개선과 악화가 공존하므로, 모든 채널을 일괄 공유하는 방식과 관련 채널만 공유하는 방식을 비교할 가치가 있습니다. Chronos-2의 그룹별 정보 공유는 이 질문과 연결되는 외부 연구 사례입니다. [arxiv.org](https://arxiv.org/html/2510.15821v1?utm_source=chatgpt.com)

**넷째, 가변 예측 길이와 불확실성 예측을 확장 과제로 다룰 수 있습니다.** 첨부 논문은 미학습 길이에서의 성능이나 확률 예측을 검증하지 않았습니다. 따라서 위치 표현·패치 복원·예측구간을 확장하더라도, 먼저 고정 길이의 기본 PET와 비교해 어떤 기능과 비용이 추가되는지 확인해야 합니다. **[원문 범위: §3, Tables 2–3]**

**최종 평가:** PETformer는 **미래 토큰을 활용한 출력 구조와 예측 헤드 효율성**에서 검증할 가치가 높은 연구입니다. 일반화에 대한 가장 유망한 출발점은 **채널 간 가중치 공유와 입력 구간 정규화**이지만, 현재 증거는 데이터셋 내부의 예측 실험에 집중되어 있습니다. 후속 연구의 우선 과제는 더 복잡한 모델을 만드는 것보다, **동일 조건에서 PET의 고유 효과를 재현하고 미관측 변수·시간 변화·새로운 데이터셋에서 그 효과가 유지되는지 확인하는 것**입니다.
