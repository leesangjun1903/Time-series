# Learning Novel Transformer Architecture for Time-series Forecasting

이 논문은 데이터셋에 맞춰 Transformer의 내부 연산을 선택하는 접근이 예측 성능 개선에 유용할 수 있음을 보여줍니다.  
다만 **서로 다른 데이터셋에서도 안정적으로 작동하는 일반화 성능, 탐색 알고리즘 자체의 신규성, 보고된 성능 차이의 통계적 유의성은 추가 검증이 필요합니다.**

분석 대상은 Juyuan Zhang, Wei Zhu, Jiechao Gao의 **2025년 2월 19일 공개 arXiv v1**입니다. 아래 페이지 번호는 첨부 PDF의 실제 페이지 순서인 **1–11쪽**을 기준으로 합니다. 공식 arXiv 등록 정보에서도 해당 버전을 확인했습니다. [arxiv.org](https://arxiv.org/abs/2502.13721?utm_source=chatgpt.com)

주요 분석 자료: 2502.13721v1.pdf

보고서에서는 **[저자 보고]**, **[검토·해석]**, **[후속 연구 제안]**을 구분합니다. 원문에서 서로 충돌하는 수치나 수식은 임의로 수정해 확정하지 않았습니다.

## 1. Executive summary — 10문장

1. 이 논문은 시계열 예측에 적합한 Transformer 구조를 자동으로 찾는 **AutoFormer-TS**를 제안하며, 기존 연구가 토큰 구성이나 주의집중 연산의 효율화에 집중한 데 비해 내부 구조의 대안은 충분히 탐색하지 않았다는 문제의식에서 출발합니다. **[pp.1–2]**
2. 탐색 대상은 주의집중 점수 함수, 활성화 함수, FFN의 중간 차원, 두 인코딩 경로이며, 세 블록을 독립적으로 구성할 때 가능한 구조 조합은 약 $1.56\times10^{10}$개입니다. **[pp.3–4, Figure 1]**
3. 제안 알고리즘 **AB-DARTS**는 구조 가중치를 고정한 초망을 학습하고, 후보 연산을 제거했을 때 검증 성능이 가장 크게 떨어지는 연산을 선택합니다. **[pp.4–5, Eq.12, Algorithm 1]**
4. 장기 예측에서는 여덟 데이터셋의 네 예측 길이 평균을 보고하며, Table 2에 인쇄된 MSE 기준으로 일곱 데이터셋에서 단독 최저, Weather에서 공동 최저를 기록합니다. **[p.6, Table 2]**
5. 대표적으로 ETTm1의 MSE는 0.329로 PatchTST의 0.351보다 낮으며, 이는 표의 수치로 직접 계산하면 약 6.27% 감소입니다. **[p.6, Table 2; 개선율은 본 보고서 계산]**
6. M4의 전체 평균 행에서도 가장 낮은 세 지표를 보고하지만, 월별 데이터의 스케일 조정 오차에서는 PatchTST보다 나쁘므로 모든 조건에서 우월하다는 해석은 성립하지 않습니다. **[p.7, Table 3]**
7. ETTh1과 ETTm1 사이에서는 구조 전이의 가능성을 보이지만, M4와 장기 예측 과제 사이의 전이는 PatchTST보다 나빠 일반화 범위가 제한됩니다. **[p.8, Table 6]**
8. ETTh1에서 AB-DARTS의 탐색·기여도 계산·최종 재학습 시간은 합계 30.87분으로, DARTS의 41.1분보다 짧지만 PatchTST 학습 시간 10.2분의 약 세 배입니다. **[p.8, §5.5; 합계는 본 보고서 계산]**
9. 과제당 구조 탐색은 한 번만 수행하고 선택된 구조의 학습만 다섯 시드로 반복했으며, 표준편차·신뢰구간과 일부 재현 세부사항을 제공하지 않아 탐색 안정성과 작은 성능 차이를 확정하기 어렵습니다. **[p.6, §5.3]**
10. 따라서 이 연구의 가장 설득력 있는 가치는 **시계열에 맞춘 구조 선택의 실험적 가능성**이며, 광범위한 일반화 향상과 선택 알고리즘의 독창성은 별도의 검증 과제로 남습니다. **[pp.4–8; 관련 선행연구 비교는 §10]**

## 2. 연구 배경·문제·목적과 필요성

### 2.1 해결하려는 문제

**[저자 보고]** 연구의 출발점은 두 가지입니다.

- 기존 Transformer 계열 연구는 주의집중 계산을 효율화하는 데 많은 노력을 들였지만, 이러한 수정이 항상 시계열 예측 정확도 향상으로 이어지지는 않았습니다.
- PatchTST와 iTransformer는 입력을 어떻게 토큰으로 구성하는지가 중요하다는 점을 보여주었지만, Transformer 내부의 활성화·FFN 크기·잔차 경로·주의집중 함수에 대한 체계적인 탐색은 충분하지 않았다고 저자들은 주장합니다. **[p.1, Introduction; p.2, §2.2]**

> **용어 설명 — 토큰화(tokenization):** 원자료를 모델이 처리하는 단위로 바꾸는 과정입니다. 시계열에서는 한 시점, 여러 시점을 묶은 구간, 하나의 변수 전체 등을 토큰으로 만들 수 있습니다.  
> **주의집중(attention):** 예측에 필요한 정보를 찾기 위해 입력 요소 사이의 관련성을 계산하고 정보를 모으는 연산입니다.

또한 기존 DARTS가 사용하는 **“구조 가중치가 큰 연산이 좋은 연산”**이라는 선택 기준이 실제 성능을 제대로 반영하지 않을 수 있다는 문제가 제기됩니다. **[p.4, §4.2]**

> **용어 설명 — 신경망 구조 탐색(NAS):** 층이나 연산의 구성을 사람이 모두 정하는 대신, 후보들 가운데 좋은 구성을 자동으로 찾는 방법입니다.  
> **DARTS:** 여러 후보 연산을 가중합으로 연결하여 학습한 뒤, 구조 가중치가 큰 연산을 선택하는 대표적인 미분 가능 구조 탐색 방법입니다.

### 2.2 연구 목적

**[저자 보고]** 목적은 다음 세 가지로 정리됩니다.

1. Transformer의 기본 골격을 유지하면서 시계열 예측에 유용한 대안 연산을 포함하는 탐색 공간을 만든다.
2. 구조 가중치의 크기 대신, 연산의 실제 성능 기여를 기준으로 최종 구조를 선택한다.
3. 과제별 예측 정확도를 개선하면서 탐색 비용을 감당할 수 있는 수준으로 유지한다. **[pp.1–2, Contributions; pp.3–5]**

### 2.3 연구의 필요성에 대한 해석

**[검토·해석]** 이 연구가 제기하는 유용한 질문은 **“Transformer를 쓸 것인가?”보다 “해당 데이터에 어떤 Transformer 내부 구성이 적합한가?”**입니다.

다만 데이터셋마다 구조를 따로 선택하면 해당 데이터에 대한 적합성은 높아질 수 있어도, 새 데이터셋에 대한 일반화가 자동으로 좋아지는 것은 아닙니다.  
논문 자체에서도 과제별 최적 구조가 다르고, 일부 과제 간 전이에서 성능이 떨어집니다. **[p.6, §5.4; p.8, Table 6]**

> **용어 설명 — 일반화:** 학습이나 모델 선택에 직접 사용하지 않은 데이터에서도 성능을 유지하는 능력입니다. 같은 데이터셋의 미래 구간, 새로운 변수, 다른 도메인의 데이터셋은 서로 다른 일반화 조건입니다.

> **과제 특이성(task specificity):** 한 과제에 유리한 구성이 다른 과제에도 똑같이 유리하지 않을 수 있다는 뜻입니다.

### 4.3 평가 지표와 해석

장기 예측의 기본 지표는 다음과 같습니다.

```math
\text{MSE}
=
\frac{1}{H}\sum_{h=1}^{H}(y_h-\hat y_h)^2
```

```math
\text{MAE}
=
\frac{1}{H}\sum_{h=1}^{H}|y_h-\hat y_h|
```

- $H$: 예측 길이.
- $h$: 예측 구간 내 위치.
- $y_h$: 실제값.
- $\hat y_h$: 예측값.
- MSE는 큰 오차에 더 큰 벌점을 주며, MAE는 절대 오차를 평균합니다.

**근거: p.10, Eqs.13–14.** 위 MSE는 이해를 위해 합의 상한을 $H$로 통일했습니다. 원문 Eq.13은 분모에는 $H$, 합의 상한에는 $T$를 사용하여 표기가 일치하지 않습니다.

M4에서 사용하는 SMAPE와 OWA는 다음과 같이 기재되어 있습니다.

```math
\text{SMAPE}
=
\frac{200}{H}
\sum_{h=1}^{H}
\frac{|y_h-\hat y_h|}
{|y_h|+|\hat y_h|}
```

```math
\text{OWA}
=
\frac{1}{2}
\left(
\frac{\text{SMAPE}}{\text{SMAPE}_{\text{Naive}}}
+
\frac{\text{MASE}}{\text{MASE}_{\text{Naive}}}
\right)
```

- SMAPE: 실제값과 예측값의 크기로 나누어 계산하는 상대 오차.
- MASE: 단순한 기준 예측의 오차로 크기를 조정한 절대 오차.
- 아래첨자 $\text{Naive}$: 원문이 사용하는 기준 예측 모델.
- OWA: 두 종류의 정규화된 오차를 평균한 값으로, 낮을수록 좋습니다.

**근거: p.10, Eqs.15·17–18.**

**명칭·구현 주의:** 본문과 표는 주로 **MSAE**, 부록과 수식은 **MASE**라고 표기합니다. 또한 Eq.17의 스케일 계산에 어떤 훈련 구간을 사용했는지 명확하지 않습니다.  
이하 표에서는 원문 숫자를 보존하기 위해 “MSAE/MASE”라고 표시합니다.

### 5.2 Attention 점수 함수

#### 공통 기호

- $x_i$: $i$번째 토큰의 은닉 표현.
- $q_i$: $i$번째 토큰의 query.
- $k_j$: $j$번째 토큰의 key.
- $W_Q,W_K$: query와 key를 만드는 학습 가능한 선형 투영.
- $s_{ij}$: 두 토큰의 관련성 점수.
- $d_m$: 은닉 차원.
- $W_d$: 각 점수 함수에서 사용하는 학습 가능한 가중치.

> **용어 설명 — query와 key:** query는 “어떤 정보를 찾는가”, key는 “어떤 정보를 제공하는가”를 나타내는 벡터로 이해할 수 있습니다.

원문은 다음과 같이 투영을 정의합니다.

$$
q_i=x_iW_Q,
\qquad
k_j=x_jW_K
$$

**근거: p.2, Eq.1.** 원문의 개별 토큰 차원 표기에는 전체 토큰 행렬의 차원과 혼동되는 부분이 있으므로, 위 식은 원문의 투영 관계로 읽는 것이 안전합니다.

#### ① Dot attention

원문 Eq.1에 인쇄된 식은 다음과 같습니다.

$$
s_{ij}=q_i^\top\odot k_j
$$

그러나 저자는 이를 내적이라고 설명하면서, 다음 페이지에서는 $\odot$를 원소별 곱으로 정의합니다. **정상적인 내적의 표현은 $q_i^\top k_j$**이지만, 실제 코드가 어떤 식을 사용했는지는 원문만으로 확인할 수 없습니다. **[pp.2–3, Eqs.1–2]**

#### ② 나머지 네 가지 후보

| 함수 | 원문 수식 | 의미 |
|---|---|---|
| Elementwise Product | $s_{ij}=\text{tanh}(q_i\odot k_j)^\top W_d$ | 같은 위치의 특징끼리 곱한 후 점수로 변환 |
| Bilinear | $s_{ij}=q_i^\top W_dk_j$ | 두 벡터의 특징 사이 상호작용을 행렬로 학습 |
| Concat | $s_{ij}=\text{tanh}(\text{concat}([q_i,k_j]))^\top W_d$ | 두 벡터를 연결한 후 점수로 변환 |
| Minus | $s_{ij}=\text{tanh}(q_i-k_j)^\top W_d$ | 두 벡터의 차이를 점수로 변환 |

**근거: p.3, Eqs.2–5.**

> **용어 설명 — 원소별 곱(Hadamard product):** 같은 위치의 숫자끼리 곱하는 연산입니다.  
> **쌍선형(bilinear):** 두 입력 벡터 사이의 관계를 가운데 행렬로 표현하는 방식입니다.  
> **$\text{tanh}$:** 입력을 $-1$과 $1$ 사이로 압축하는 비선형 함수입니다.  
> **concat:** 벡터를 이어 붙이는 연산입니다.

가중치의 크기는 EP·Minus에서 $d_m\times1$, Bilinear에서 $d_m\times d_m$입니다.

**Concat의 차원 문제:** 두 $d_m$차원 벡터를 연결하면 $2d_m$차원이 되지만, 논문은 이 경우에도 $W_d\in\mathbb R^{d_m\times1}$이라고 적습니다.  
별도 변환이 없다면 차원이 맞지 않으므로 구현 확인이 필요합니다. **[p.3, Eq.4]**

또한 이 식들은 **점수 계산 부분**을 설명합니다. 점수를 어떻게 정규화하고 value를 어떻게 합산하는지까지 완전하게 명세하지는 않습니다.  
저자는 다중 헤드 구조를 수식에서 생략하고 실험에서는 사용한다고 설명합니다. **[p.2, 각주 2]**

> **용어 설명 — 다중 헤드 attention:** 여러 개의 attention을 병렬로 계산하여 서로 다른 관계를 포착하도록 하는 방식입니다.  
> **value:** attention 가중치에 따라 실제로 모아 오는 정보 벡터입니다.

#### 추가 수식 검토: Concat이 query를 구분하는가?

**[조건부 수학적 해석]** Eq.4의 차원을 맞추어 $W_d=[w_q;w_k]$로 놓고 $\text{tanh}$를 원소별로 적용하면 다음과 같이 분리됩니다.

```math
s_{ij}
=
\text{tanh}(q_i)^\top w_q
+
\text{tanh}(k_j)^\top w_k
=
a_i+b_j
```

여기에 일반적인 key 방향 softmax를 적용한다고 가정하면,

```math
\frac{e^{s_{ij}}}{\sum_t e^{s_{it}}}
=
\frac{e^{b_j}}{\sum_t e^{b_t}}
```

가 되어 query $i$에 대한 의존성이 사라집니다.

- $w_q,w_k$: 연결된 가중치의 query 부분과 key 부분.
- $a_i,b_j$: 각각 query와 key에만 의존하는 점수.
- $t$: 정규화할 key 위치를 순회하는 인덱스.

> **용어 설명 — softmax:** 여러 점수를 합이 1인 양의 가중치로 바꾸는 함수입니다.

이 결과는 **원문 식을 문자 그대로 사용하고 통상적인 softmax를 가정했을 때의 분석**입니다.  
실제 구현의 결함이 확인되었다는 의미는 아닙니다. 다만 Concat 후보를 재현하기 전에 반드시 확인할 사항입니다.

### 5.3 FFN의 차원과 활성화 함수 탐색

원문의 FFN은 다음과 같습니다.

```math
\text{FFN}(X)
=
\text{Proj}_{\text{down},k}
\left(
g\left(\text{Proj}_{\text{up},k}(X)\right)
\right)
```

$$
d_{\text{ffn}}=k\,d_m,
\qquad
k\in\{0.5,1,2,4\}
$$

- $X$: 입력 은닉 표현.
- $d_m$: 모델 은닉 차원.
- $d_{\text{ffn}}$: FFN 중간 차원.
- $\text{Proj}\_{\text{up},k}$: $d_m$에서 $d_{\text{ffn}}$으로의 선형 변환.
- $\text{Proj}\_{\text{down},k}$: 다시 $d_m$으로 되돌리는 선형 변환.
- $g$: 활성화 함수.
- $k$: 중간 차원의 배수.

**근거: p.3, Eqs.6–7.**

> **용어 설명 — FFN:** 각 토큰의 특징을 선형 변환과 비선형 함수로 가공하는 신경망입니다.  
> **활성화 함수:** 선형 계산만으로 표현하기 어려운 관계를 학습하도록 만드는 비선형 변환입니다.

$k=0.5$이면 중간 차원이 오히려 작아집니다. 따라서 이 논문의 $k$는 항상 “확장 비율”로만 설명하기보다 **차원 배수**라고 부르는 편이 정확합니다.

활성화 함수 후보는 다음과 같습니다.

$$
\begin{aligned}
\text{ReLU}(x)
&=\text{max}(x,0),\\
\text{LeakyReLU}(x)
&=
\begin{cases}
x,&x\ge0,\\
0.01x,&x<0,
\end{cases}\\
\text{ELU}(x)
&=
\begin{cases}
x,&x\ge0,\\
e^x-1,&x<0,
\end{cases}\\
\text{SWISH}(x)
&=x\,\text{Sigmoid}(x),\\
\text{GeLU}(x)
&=
\frac{x}{2}
\left(
1+\text{erf}\left(\frac{x}{\sqrt2}\right)
\right).
\end{aligned}
$$

- $x$: 활성화 함수의 입력값.
- $\text{Sigmoid}(x)=1/(1+e^{-x})$: 값을 0과 1 사이로 바꾸는 함수.
- $\text{erf}$: 정규분포와 관련된 오차함수로, GeLU의 매끄러운 변환에 사용됩니다.

**근거: p.4, Table 1.** 이들 함수의 핵심 차이는 음수 입력을 처리하는 방식과 곡선의 매끄러움입니다.

### 5.4 잔차 연결을 인코딩 경로로 확장

기존 구조는 다음과 같습니다.

$$
X^{(1)}=\text{Attn}(X)+X
$$

$$
X'=\text{FFN}(X^{(1)})+X^{(1)}
$$

제안 탐색 공간에서는 이를 다음과 같이 바꿉니다.

```math
X^{(1)}
=
\text{Attn}(X)+\text{Enc}_{A}(X)
```

```math
X'
=
\text{FFN}(X^{(1)})
+
\text{Enc}_{F}(X^{(1)})
```

- $X^{(1)}$: attention 하위 블록을 통과한 표현.
- $X'$: 전체 블록 출력.
- $\text{Enc}_{A}$: attention과 병렬로 연결되는 인코딩 연산.
- $\text{Enc}_{F}$: FFN과 병렬로 연결되는 인코딩 연산.
- 각 인코딩 연산은 Null·Skip·Conv_1·Conv_3·Conv_5 중 선택합니다.

**근거: p.4, Eqs.8–9.**

> **용어 설명 — 잔차 연결:** 처리 전의 입력을 처리 후의 출력에 더하는 연결입니다.  
> **Skip:** 입력을 그대로 전달하는 연산입니다.  
> **Null:** 0을 출력하여 해당 경로를 없애는 연산입니다.  
> **1차원 합성곱:** 인접한 위치의 정보를 작은 필터로 모으는 연산이며, Conv의 숫자는 필터 크기입니다.

**[검토·해석]** 합성곱이 지역적 패턴을 보완할 수 있다는 저자의 설명은 합리적인 가설입니다.  
그러나 “합성곱 때문에 일반화가 향상되었다”는 인과 효과를 직접 분리한 실험은 부족합니다.  
또한 Figure 1에는 정규화가 있지만 Eq.9에는 생략되어 있어, 이 식은 완전한 구현 명세가 아니라 구조의 골격으로 읽어야 합니다.

### 5.5 AB-DARTS: 무엇을 기준으로 연산을 선택하는가?

#### 기존 DARTS의 혼합 연산

```math
\text{Node}_{i}(x)
=
\sum_{j=1}^{n_i}w_{ij}o_{ij}(x)
```

```math
w_{ij}
=
\frac{\exp(\alpha_{ij})}
{\sum_{r=1}^{n_i}\exp(\alpha_{ir})}
```

- $i$: 선택 지점의 번호.
- $j$: 후보 연산의 번호.
- $n_i$: 해당 지점의 후보 수.
- $o_{ij}$: 후보 연산.
- $\alpha_{ij}$: 구조 가중치를 결정하는 매개변수.
- $w_{ij}$: 실제 혼합 비율.
- $x$: 해당 지점의 입력.

**근거: p.4, Eqs.10–11.**

> **용어 설명 — 초망(super-network):** 여러 후보 연산을 한 네트워크 안에 함께 넣은 모델입니다. 각 후보 구조를 처음부터 따로 훈련하는 비용을 줄이는 데 사용합니다.  
> **이중 수준 최적화(bi-level optimization):** 모델의 수치 가중치와 구조를 결정하는 매개변수를 서로 다른 목적·데이터로 번갈아 갱신하는 방식입니다.

기존 DARTS는 모델 가중치와 $\alpha$를 학습하고, 최종적으로 $\alpha$가 큰 연산을 남깁니다.  
반면 AB-DARTS는 **균일하게 초기화한 구조 가중치를 고정하고 모델 가중치만 학습**합니다. **[pp.4–6]**

#### 제거에 따른 기여도

```math
\text{CS}(o_{ij})
=
S(M)-S(M\setminus o_{ij})
```

```math
j_i^*
=
\text{arg max}_{j}\,
\text{CS}(o_{ij})
```

- $M$: 현재 초망.
- $M\setminus o_{ij}$: 연산 $o_{ij}$만 제거한 초망.
- $S$: 고정된 검증 데이터에서 계산한, **클수록 좋은** 성능 점수.
- $\text{CS}$: 연산을 제거했을 때 감소한 성능.
- $j_i^*$: 최종적으로 남길 연산의 번호.

**근거: p.5, Eq.12·Algorithm 1.**

즉, **없앴을 때 가장 큰 손해가 발생하는 연산을 남깁니다.**

손실 함수 $L$을 이용해 $S=-L$로 정의한다면,

```math
\text{CS}(o_{ij})
=
L(M\setminus o_{ij})-L(M)
```

이 됩니다. 여기서 $L$은 낮을수록 좋은 오차이므로, 제거했을 때 오차가 가장 크게 증가하는 연산을 선택합니다.

**중요한 원문 불명확성:** §4.3은 실제 실험에서 $S$를 **교차엔트로피 손실의 음수**로 두었다고 적습니다.  
하지만 연속값 시계열 예측을 어떤 분류 문제로 바꾸었는지 설명하지 않습니다. 따라서 이를 “실제로는 MSE를 사용했을 것”이라고 바꾸어 설명할 수 없습니다. **[p.5, §4.3]**

> **용어 설명 — 교차엔트로피:** 주로 예측한 확률분포와 정답 분포의 차이를 평가하는 손실입니다. 연속값 회귀에 사용하려면 값의 확률적 표현이나 이산화 방식 등을 설명해야 합니다.

또한 원문이 $S(M)$을 상수로 제거하는 것은 **연산 선택 순위에 대해서만 동등**합니다. 기여도 점수 자체가 같은 값으로 유지되는 것은 아닙니다.

#### 전체 절차

1. 모든 후보 연산을 포함한 초망을 학습한다.
2. 한 선택 지점에서 후보를 하나씩 제거하여 검증 기여도를 구한다.
3. 기여도가 가장 큰 연산만 남긴다.
4. 변경된 초망을 추가 학습하여 성능을 회복시킨다.
5. 모든 선택 지점에 대해 반복한다.
6. 완성된 구조를 무작위 초기화하여 다시 학습한다. **[p.5, Algorithm 1]**

**[검토·해석]** 초망에서 한 연산을 제거한 영향과, 그 연산만 남긴 모델을 처음부터 학습했을 때의 성능은 서로 다른 대상입니다.  
따라서 이 선택 기준이 항상 최적 구조를 찾는다고 보장되지는 않습니다.

### 5.6 실제로 보고된 구조의 예: ETTh1

Table 8에 기재된 ETTh1 구조는 다음과 같습니다.

| 층 | Attention | Attention 인코딩 | FFN 인코딩 | 활성화 | $k$ |
|---|---|---|---|---|---:|
| 1 | Concat | Conv_3 | Skip | Leaky_ReLU | 1 |
| 2 | Minus | Skip | Skip | SWISH | 0.5 |
| 3 | Dot | Conv_3 | Skip | ReLU | 1 |

**근거: p.11, Table 8.**

이 예시는 각 층에서 같은 구성을 반복하지 않고, **서로 다른 연산과 FFN 크기를 선택한다**는 특징을 보여줍니다. 다만 Concat의 실제 계산 방식은 앞서 설명한 수식 문제를 해결해야 정확히 재현할 수 있습니다.

### 6.4 일반화의 핵심 증거: 과제 간 구조 전이

| 구조를 찾은 과제 | 대상 ETTh1 MSE | 대상 ETTm1 MSE | 대상 M4-Yearly SMAPE | 대상 M4-Yearly MSAE |

**근거: p.8, Table 6.**

**[저자 보고]** 대상 과제에서 직접 구조를 찾는 것이 가장 좋고, 장기 예측 과제끼리는 일정한 전이 가능성이 있으나 장기·단기 예측 사이에서는 전이가 잘되지 않는다고 설명합니다.

**[검토·해석]**

1. **ETTh1↔ETTm1의 전이는 긍정적입니다.**  
   ETTh1 구조를 ETTm1에 적용한 0.335는 PatchTST의 0.351보다 낮고, 반대 방향의 0.411도 0.413보다 낮습니다.

3. **가중치의 zero-shot 일반화 증거로 해석할 수 없습니다.**  
   이 실험은 구조 이전을 다루지만, 이전 시 가중치 재초기화·재학습·미세조정 절차가 충분히 명시되어 있지 않습니다.

4. **대각선 수치에 불일치가 있습니다.**  
   ETTm1 자체 과제의 0.321은 Tables 2·4·5의 0.329와 다릅니다. 어느 값이 맞는지 확정할 수 없습니다.

> **용어 설명 — 구조 전이:** 다른 과제에서 찾은 모델의 구성 방식을 가져오는 것입니다.  
> **가중치 전이:** 이미 학습된 수치 매개변수를 가져오는 것입니다.  
> **Zero-shot 예측:** 대상 과제에 대해 추가 학습이나 미세조정을 하지 않고 예측하는 방식입니다.

> **공변량:** 예측 대상과 함께 사용하는 보조 변수입니다. 예를 들어 매출 예측의 휴일·가격·프로모션 정보입니다.

### 10.2 AB-DARTS의 신규성: DARTS-PT와 직접 비교가 필요하다

**[외부 원문에서 확인한 사실]** DARTS-PT의 「Rethinking Architecture Selection in Differentiable NAS」는 이미 다음을 제시했습니다.

- 연산 하나를 제거하고 검증 성능의 하락을 측정.
- 하락이 가장 큰 연산을 선택.
- 선택 후 남은 초망을 추가 학습.
- 구조 가중치를 균등하게 고정한 변형도 평가.

이는 해당 논문의 **p.5, Algorithm 1·§4.1–4.2 및 p.8, §6.3**에 있습니다. [arxiv.org](https://arxiv.org/pdf/2108.04392?utm_source=chatgpt.com)

**[검토·해석]** 따라서 AB-DARTS의 제거 기반 선택 원리 자체를 새로운 발명으로 설명하기는 어렵습니다. AutoFormer-TS의 가치는 **시계열 Transformer에 맞춘 탐색 공간과 적용 결과**에서 따져야 하며, 동일 탐색 공간에서 DARTS-PT보다 어떤 추가 이득이 있는지 검증해야 합니다. 이것은 두 구현이 완전히 동일하다는 판정은 아닙니다.

### 10.3 “일반화”라는 이름 아래 서로 다른 실험이 있다

관련 연구를 비교할 때 다음을 분리해야 합니다.

| 일반화 유형 | 실제 예 | AutoFormer-TS와의 차이 |
|---|---|---|
| 다른 과제의 구조 활용 | AutoFormer-TS Table 6 | 구조 이전을 조사하지만 학습 절차가 충분히 명시되지 않음 |
| 사전학습 가중치의 이전 | PatchTST는 Electricity 사전학습 후 다른 데이터에서 미세조정 | 구조 선택과 가중치 이전은 별개 |
| 미관측 변수에 대한 예측 | iTransformer는 변수 20%로 학습하고 전체 변수를 예측 | 같은 데이터셋 안의 변수 일반화 |
| 대상 과제 추가 학습 없는 예측 | Chronos·TimesFM·Moirai 계열 | 과제별 탐색·재학습과 다른 평가 조건 |

PatchTST의 전이 실험은 원 논문 **pp.7–8, Table 5**, iTransformer의 미관측 변수 실험은 **p.7, Figure 5**에 명시되어 있습니다. [arxiv.org](https://arxiv.org/pdf/2211.14730?utm_source=chatgpt.com)

또한 zero-shot이라는 이름만으로 평가 데이터 전체가 사전학습에서 완전히 배제되었다고 가정하면 안 됩니다. 예를 들어 Chronos-2는 GIFT-Eval의 테스트 구간은 제외했지만 일부 **훈련 구간은 사전학습 자료와 겹친다**고 밝히며, 엄격한 조건은 합성 데이터만 사용한 변형으로 별도 확인하도록 안내합니다. **[Chronos-2, §5.1·§5.4]** [arxiv.org](https://arxiv.org/html/2510.15821v1?utm_source=chatgpt.com)

**[검토·해석]** 최신 연구와의 비교에서 필요한 것은 여러 논문의 MSE를 한데 모은 순위가 아니라, **모델이 어떤 데이터를 보았고 대상 과제에서 얼마만큼 적응했는지 맞춘 평가**입니다.

## 11. 결론·시사점·제한사항과 후속 연구

### 11.1 저자가 직접 제시한 결론과 한계

**[저자 보고]** 결론은 시계열 Transformer의 내부 연산을 탐색하면 예측 성능을 개선할 수 있고, AB-DARTS가 적절한 연산 선택에 도움이 되며, 추가 학습 비용도 감당할 수 있다는 것입니다. **[p.8, Conclusion]**

저자가 실험에서 직접 인정한 제약은 다음과 같습니다.

- 최적 구조가 과제마다 다릅니다.
- 다른 과제에서 찾은 구조를 적용하면 직접 탐색한 구조보다 성능이 떨어집니다.
- 특히 장기 예측과 단기 예측 사이의 전이 성능이 좋지 않습니다. **[pp.6·8, §5.4·Table 6]**

**원문에는 별도의 Limitations 절이나 구체적인 후속 연구 계획이 없습니다.** 코드에 대해서는 게재 승인 후 공개하겠다는 문구만 있습니다. 따라서 아래의 후속 방향은 저자의 계획이 아니라 본 보고서의 제안입니다. **[p.1, 각주 1; p.8, Conclusion]**

### 11.2 학계·실무에 대한 시사점

**[검토·해석 — 학술적 의미]** 연구의 가치 있는 질문은 큰 모델이나 새로운 attention만 추가하는 대신, **기존 구성 요소의 조합과 용량을 데이터에 맞춰 선택하는 것이 얼마나 중요한가**입니다. Table 5는 이를 탐색할 근거를 제공하지만, 어떤 요소가 어떤 데이터 특성에 유리한지까지 설명하지는 못합니다.

**[검토·해석 — 실무적 의미]** 고정된 데이터셋에서 반복적으로 예측하는 환경이라면 초기 구조 탐색 비용을 감수할 여지가 있습니다. 다만 이 논문은 실제 서비스의 지연·유지보수·데이터 변화 대응 비용을 측정하지 않았으므로, 운영 효율 향상까지 입증했다고 볼 수는 없습니다. **[p.8, 효율 분석]**

### 11.3 일반화 성능 향상 가능성: 어떤 근거가 있고 무엇이 부족한가?

| 가능성 | 논문이 제공하는 단서 | 아직 검증되지 않은 부분 |
|---|---|---|
| 데이터 규모에 맞춘 모델 용량 조절 | ETTh1에서 작은 FFN 차원 선택 | 작은 FFN이 과적합을 줄였는지에 대한 독립 실험 |
| 지역적 패턴과 장거리 관계의 결합 | 여러 과제에서 합성곱 인코딩 선택 | 합성곱이 분포 변화에 대한 강건성을 높이는지 |
| 유사한 과제 사이의 구조 재사용 | ETTh1↔ETTm1 전이 결과 | 서로 다른 산업·관측 환경으로의 확장 |
| 더 좋은 연산 선택 | Table 4의 오차 개선 | 탐색 시드·선택 순서 변화에 대한 안정성 |
| 범용 구조 탐색 | 과제마다 서로 다른 구조가 선택됨 | 여러 과제에 공통으로 좋은 구조를 찾는 학습·평가 |

**근거: pp.6–8, Tables 4–6; p.11, Table 8.**

> **용어 설명 — 과적합:** 학습·검증에 사용한 자료의 특징에 지나치게 맞춰져 새로운 자료에서 성능이 나빠지는 현상입니다.  
> **강건성:** 잡음, 결측, 관측 조건이나 데이터 분포 변화가 있을 때 성능을 유지하는 능력입니다.

이 논문으로 가장 조심스럽게 말할 수 있는 것은 **“과제별 구조 적응과 일부 유사 과제 사이의 전이가 가능하다”**는 수준입니다. **“범용 일반화 능력이 향상되었다”는 결론에는 더 넓은 외부 검증이 필요합니다.**

### 11.4 가장 유망한 접근과 빠른 검증 실험

다음은 **실행하지 않은 후속 연구 제안**입니다. 복잡한 전체 모델을 구현하기 전에 핵심 아이디어를 분리해 확인하는 순서입니다.

| 우선순위 | 검증할 아이디어 | 작은 실험 설계 | 판단 기준 |
|---|---|---|---|
| 1 | **FFN 차원 조절** | 같은 PatchTST 골격에서 $k\in\{0.5,1,2,4\}$만 변경 | 오차뿐 아니라 매개변수 수·학습 시간·시드 변동을 함께 비교 |
| 2 | **합성곱 인코딩 경로** | attention과 활성화는 고정하고 Skip 대 Conv_3만 비교 | 여러 시간 분할에서 개선이 반복되는지 확인 |
| 3 | **제거 기여도에 의한 선택** | 작은 후보 공간에서 구조 가중치 선택·제거 기반 선택·무작위 선택 비교 | 동일한 총 계산 예산에서 최종 재학습 성능을 비교 |
| 4 | **DARTS-PT와의 차이** | 같은 시계열 탐색 공간·손실·재학습 조건으로 비교 | AB-DARTS만의 추가 이득이 있는지 확인 |
| 5 | **구조의 외부 전이** | ETT에서 선택한 구조를 다른 계열 데이터에도 적용 | 대상 데이터 직접 탐색·고정 기준 구조·이전 구조를 분리 비교 |

**선행 조건:** attention 수식, 실제 손실, M4 검증 분할, Figure 2와 Table 8의 차이를 먼저 해결해야 합니다. 불명확한 구현을 그대로 확장하면 성능 차이의 원인을 해석하기 어렵습니다.

### 11.5 추가 후속 연구 방향

**첫째, 탐색의 일반화를 직접 평가해야 합니다.** 여러 데이터셋 중 일부만 구조 선택에 사용하고, 선택에 사용하지 않은 데이터셋에서 평가하는 방식이 필요합니다. 구조 전이와 가중치 전이를 별도 실험으로 보고해야 합니다.

**둘째, 탐색 안정성과 통계적 불확실성을 함께 보고해야 합니다.** 구조 탐색 시드와 최종 학습 시드를 구분하고, 시간순 평가 구간을 바꿔 결과가 반복되는지 확인해야 합니다. 시계열 평가에서는 겹치는 관측 창을 독립 표본처럼 취급하지 않는 검정 설계가 필요합니다.

**셋째, 입력 표현도 탐색 축으로 검토할 수 있습니다.** 현재 연구는 패치 구성을 고정합니다. 후속 실험에서는 시간 패치, 변수 토큰, 여러 시간 해상도 중 무엇이 데이터 특성에 적합한지 작은 대조 실험으로 확인할 수 있습니다. 이는 PatchTST·iTransformer·TimeMixer 비교에서 도출되는 연구 질문입니다. [arxiv.org](https://arxiv.org/abs/2211.14730?utm_source=chatgpt.com)

**넷째, 정확도와 적응 비용을 동시에 평가해야 합니다.** 데이터별 탐색·훈련 비용, 사전학습 모델의 대상 과제 적용 비용, 최종 추론 비용을 나누어 보고하면 실무 선택에 더 유용합니다. 최신 기반 모델과의 비교에서는 사용 가능한 공변량과 사전학습 데이터의 중복 여부도 맞춰야 합니다.

**다섯째, 새로운 연구에 대한 영향은 검증된 인용 관계와 연구 제안을 구분해야 합니다.** 이번에 확인한 자료만으로 Chronos-2나 TimesFM-3가 AutoFormer-TS를 직접 계승했다고 말할 수는 없습니다. 이 논문의 향후 가치는 **재현 가능한 시계열 구조 탐색 문제를 정립하고, 어떤 구조 선택이 미관측 데이터에서도 유효한지 밝히는 후속 연구**에서 평가하는 것이 타당합니다.
