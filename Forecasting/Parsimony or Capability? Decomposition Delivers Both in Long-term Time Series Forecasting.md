# Parsimony or Capability? Decomposition Delivers Both in Long-term Time Series Forecasting

**분석 기준:** 첨부된 arXiv v4, 2024년 10월 16일자, NeurIPS 2024 논문입니다. 아래의 페이지 번호는 **첨부 PDF에 인쇄된 페이지 번호**를 뜻합니다.  
관련 연구는 2026년 10월 22일을 기준으로 확인한 원문·공식 자료 중 주제와 직접 관련된 연구를 선정했습니다.

**표기 원칙:** **[저자 보고]**는 논문에 직접 제시된 내용, **[검토]**는 원문에 대한 해석·수학적 검산, **[제안]**은 아직 검증되지 않은 후속 연구 설계입니다. 원문의 표기 오류나 설명이 부족한 부분은 해당 위치에서 표시합니다.

## 1. Executive summary — 9문장

1. 이 논문은 **장기 시계열 예측에서 정확도를 높이기 위해 반드시 모델의 학습 가중치, 즉 파라미터 수를 늘려야 하는가**라는 문제를 다룹니다. **[pp. 1–2]**
2. 저자들이 제안한 **SSCNN, Selective Structured Components-based Neural Network**은 시계열의 장기·주기·단기·변수 간 공통 성분을 순차적으로 분리하고, 각 성분에 맞는 방식으로 미래를 예측합니다. **[pp. 3–6, Fig. 1]**
3. 핵심 설계는 같은 주기 위치, 가까운 과거, 시간 성분을 제거한 변수 간 관계처럼 **필요한 연결을 구조적으로 선택하여 적은 파라미터를 효율적으로 사용하는 것**입니다. **[pp. 4–7, 식 (1)–(10)]**
4. 저자들은 전력·교통·기상·변압기 자료로 구성된 7개 벤치마크에서 8개 비교 모델을 평가하고, 비교 모델들의 입력·예측 길이를 동일하게 설정했다고 보고합니다. **[p. 7, §5.1; p. 16, Appendix B]**
5. 예를 들어 Electricity의 96-step 예측에서 SSCNN의 평균제곱오차인 MSE는 **0.128**로, iTransformer의 **0.133**, PatchTST의 **0.136**보다 낮습니다. **[p. 17, Table 2]**
6. 본문에 제시된 모델 규모는 Electricity·Traffic에서 약 **25,000개**, 나머지 5개 데이터셋에서 약 **5,000개**의 파라미터이며, ECL 실험에서는 큰 비교 모델들 대비 약 99%, 예측 길이 336에서는 DLinear 대비 87%의 파라미터 감소를 보고합니다. **[p. 8, §5.1–5.2, Fig. 2]**
7. 다만 저자들은 SSCNN의 연산 횟수인 FLOPs가 iTransformer보다 불리할 수 있음을 인정하므로, 파라미터 감소를 동일한 비율의 속도 향상으로 해석할 수 없습니다. **[pp. 8–10, Fig. 2, §6]**
8. 또한 일부 조건에서는 SCNN이나 다른 모델이 더 좋은 결과를 보이고, 본문의 평균표와 부록의 상세표 사이에 수치 불일치가 있어 “모든 조건에서 우월하다”는 표현은 제한해서 받아들여야 합니다. **[p. 8, Table 1; p. 17, Table 2]**
9. 이 연구는 **데이터의 구조를 반영한 작은 모델이 높은 예측 성능을 낼 수 있다는 근거**를 제공하지만, 학습하지 않은 도메인으로의 전이나 분포 변화 전반에 대한 일반화 성능까지 입증한 것은 아닙니다. **[pp. 7–10, §5–6; pp. 15–16, Appendix A]**

## 2. 연구 배경·문제·목표

### 2.1 해결하려는 문제

**[저자 보고]** 저자들은 최근 장기 시계열 예측 연구가 긴 입력을 처리하고 복잡한 관계를 학습하기 위해 모델을 크게 만드는 경향을 지적합니다.  
그러나 파라미터 증가에 비해 성능 향상이 제한적이고, 데이터가 충분하지 않은 환경에서는 과적합 위험도 커질 수 있다고 주장합니다. **[pp. 1–2]**

> **용어 설명 — 과적합:** 학습 자료의 우연한 특성까지 지나치게 학습하여, 새로운 자료에서 성능이 떨어지는 현상입니다.

논문이 특히 문제 삼는 것은 **패칭과 고차원 표현에 의존하는 설계**입니다.  
저자들의 관점에서는 서로 다른 시간·변수의 정보를 묶은 뒤 그 관계를 다시 학습하는 과정에 많은 파라미터가 사용됩니다.  
따라서 시간적·변수 간 규칙성을 처음부터 보존하고 활용하면 이러한 부담을 줄일 수 있다는 것이 출발점입니다. **[p. 2]**

> **용어 설명 — 패칭(patching):** 연속된 여러 관측값을 하나의 묶음으로 만들어 모델의 입력 단위로 사용하는 방법입니다.  
> **고차원 표현:** 하나의 관측값이나 입력 묶음을 많은 숫자로 이루어진 내부 특징 벡터로 바꾸는 것입니다.

**[검토]** 위 설명은 저자들의 문제 설정입니다. 패칭이 모든 상황에서 정보를 훼손하거나 불필요한 방법이라는 보편적 결론으로 받아들이면 안 됩니다.  
PatchTST 원문은 패칭의 장점으로 국소 정보 보존과 긴 입력 처리 능력을 제시합니다. **[PatchTST, Fig. 1, §3.1]** [arxiv.org](https://arxiv.org/html/2211.14730v2?utm_source=chatgpt.com)

연구 목적은 다음 세 가지로 정리할 수 있습니다.

| 목적 | 논문이 취한 접근 | 근거 |
|---|---|---|
| 정확도와 소형화를 함께 달성 | 시계열을 구조 성분으로 나누고, 각 성분에 필요한 연결만 학습 | pp. 2–6 |
| 분해가 유효한 이유 설명 | 성분이 섞일 때 발생하는 표현공간의 거리 왜곡을 분석 | pp. 6–7, 15–16 |
| 실제 유용성 검증 | 성능·파라미터·FLOPs·입력 길이·구성요소 제거 실험 비교 | pp. 7–10, Figs. 2–5 |

## 4. 연구 수행 방식과 주요 데이터 소스

### 4.1 데이터와 예측 설정

**[저자 보고]** 데이터는 공개 벤치마크이며, 저자들은 자료 제공 경로로 Time-Series-Library를 안내합니다. **[p. 16, Appendix B.1]**

| 데이터셋 | 원문에 제시된 자료의 의미 | 관측 간격 | 입력 길이 $T_{\text{in}}$ |
|---|---|---:|---:|
| Electricity, ECL | 321개 고객의 전력 소비 | 1시간 | 168 |
| Traffic | 샌프란시스코 고속도로 센서의 도로 점유율 | 1시간 | 168 |
| ETTh1·ETTh2 | 두 변압기에서 수집한 자료의 시간별 버전 | 1시간 | 168 |
| ETTm1·ETTm2 | 같은 두 변압기 자료의 더 촘촘한 버전 | 15분 | 384 |
| Weather | 독일에서 수집한 기온·습도 등 21개 기상 지표 | 10분 | 432 |

**근거: p. 16, Appendix B.1–B.2.**

예측 길이는 모든 비교 모델에 대해 다음과 같이 설정합니다.

$$
T_{\text{out}}\in\{3,24,96,192,336\}.
$$

여기서 $T_{\text{out}}$은 **미래 관측 시점의 개수**입니다. 예를 들어 336-step은 시간별 자료에서는 14일, 15분 자료에서는 84시간, 10분 자료에서는 56시간입니다. 이 시간 환산은 원문의 관측 간격으로부터 계산한 값입니다. **[p. 16, Appendix B.2]**

**[검토]** 따라서 서로 다른 데이터셋의 “336-step”을 동일한 물리적 예측 기간으로 비교하면 안 됩니다. 또한 Table 1의 평균에는 3-step과 24-step도 포함되므로, 이를 장기 구간만의 평균 성능이라고 부르는 것은 부정확합니다.

### 4.2 비교 모델과 학습 조건

비교 모델은 **SCNN, iTransformer, TimeMixer, PatchTST, TimesNet, Crossformer, DLinear, Autoformer**입니다. 저자들은 비교 모델에 Time-Series-Library의 기본 설정을 적용했다고 설명합니다. **[p. 7, §5.1]**

SSCNN의 주요 학습 설정은 다음과 같습니다.

- PyTorch와 NVIDIA 2080Ti 11GB GPU 1대를 사용합니다.
- L2 손실, Adam 최적화, 학습률 0.0005, 배치 크기 8을 사용합니다.
- ECL·Traffic은 4층, 은닉 채널 수 $d=8$, 약 25,000개 파라미터로 구성합니다.
- 나머지 5개 데이터셋에서는 공간 성분을 끄고 2층으로 구성하여 약 5,000개 파라미터를 사용합니다. **[pp. 7–8, §5.1]**

> **용어 설명 — 은닉 채널:** 모델 내부에서 정보를 표현하는 특징의 수입니다. 입력 변수의 수 $N$과 내부 특징의 수 $d$는 서로 다릅니다.  
> **Adam:** 학습 과정에서 각 파라미터의 갱신 크기를 조절하는 최적화 알고리즘입니다.

### 4.3 평가 지표

논문은 MSE와 MAE를 사용합니다. 이해를 위한 표준 정의는 다음과 같습니다. 원문에 아래 식이 별도 번호로 인쇄된 것은 아닙니다. **[p. 7, Evaluation Metrics]**

```math
\text{MSE}
=
\frac{1}{M}\sum_{r=1}^{M}(y_r-\hat y_r)^2,
\qquad
\text{MAE}
=
\frac{1}{M}\sum_{r=1}^{M}|y_r-\hat y_r|.
```

- $M$: 평가에 포함된 예측값의 총개수
- $y_r$: 실제 관측값
- $\hat y_r$: 해당 관측값에 대한 예측값
- MSE: 오차를 제곱하므로 큰 오류에 더 큰 벌점을 주는 지표
- MAE: 오차의 절댓값을 평균한 지표

두 지표 모두 낮을수록 좋습니다.

## 5. 제안 방법과 모델 구조 — 수식 중심 해설

### 5.1 전체 구조와 기호

입력과 출력은 다음과 같습니다.

$$
X\in\mathbb{R}^{N\times T_{\text{in}}},
\qquad
\hat X\in\mathbb{R}^{N\times T_{\text{out}}}.
$$

- $N$: 예측 대상 변수의 수
- $T_{\text{in}}$: 과거 입력 길이
- $T_{\text{out}}$: 미래 예측 길이
- $X$: 과거 관측
- $\hat X$: 미래 예측

SSCNN에는 **과거 성분을 추론하는 경로**와 **그 성분을 미래로 외삽하는 경로**가 있습니다. 과거 경로에서 얻은 성분·잔차를 결합한 표현은 다음 층의 입력으로 사용되고, 미래 경로의 표현은 결합과 최종 투영을 거쳐 예측값이 됩니다. **[pp. 3–4, Fig. 1]**

> **용어 설명 — 임베딩:** 관측값을 모델이 처리하기 좋은 내부 특징으로 변환하는 과정입니다.  
> **외삽(extrapolation):** 관측 구간 밖에 있는 미래의 값을 추정하는 것입니다.  
> **투영(projection):** 내부 특징을 최종 예측값의 형태와 차원으로 변환하는 연산입니다.

아래 표가 모델의 핵심 흐름입니다.

| 단계 | 무엇을 추출하는가 | 다음 단계로 전달하는 것 |
|---|---|---|
| 장기 분해 | 입력 구간의 장기 수준 | 장기 성분을 제거·정규화한 잔차 |
| 주기 분해 | 동일한 주기 위치에서 반복되는 패턴 | 주기 성분을 제거·정규화한 잔차 |
| 단기 분해 | 가까운 시점의 일시적 변화 | 단기 성분을 제거·정규화한 잔차 |
| 공간 분해 | 시간 성분을 제거한 뒤 남은 변수 간 공통 패턴 | 공간 성분과 최종 잔차 |
| 성분 융합 | 성분 사이의 가산·곱셈 관계 | 다음 층의 표현 또는 미래 예측 표현 |

**근거: pp. 4–6, 식 (1)–(10), Fig. 1.**

아래에서는 원문에서 혼용되는 첨자를 구별하기 위해 **변수 번호는 $n,m$, 과거 시점은 $t,s$, 미래 시점은 $h$**로 표시합니다.

### 5.2 공통 연산: 선택적 정규화로 성분과 잔차 분리

시간 성분의 종류를 $q\in\{\text{lt},\text{se},\text{st}\}$로 표시합니다. 각각 장기, 주기, 단기를 뜻합니다.

원문 식 (1)의 정의를 풀어 쓰면 다음과 같습니다.

$$
\mu_n^q=\mathcal I^q H_n^q,
$$

```math
(\sigma_n^q)^2
=
\mathcal I^q(H_n^q)^{\odot 2}
-
(\mu_n^q)^{\odot 2}
+\epsilon,
```

```math
R_n^q
=
\frac{H_n^q-\mu_n^q}{\sigma_n^q}.
```

**기호 설명**

- $H_n^q\in\mathbb{R}^{T_{\text{in}}\times d}$: 해당 분해 단계에 들어오는 변수 $n$의 내부 표현
- $\mathcal I^q\in\mathbb{R}^{T_{\text{in}}\times T_{\text{in}}}$: 어떤 과거 시점을 얼마나 반영할지 지정하는 선택 행렬
- $\mu_n^q$: 선택된 관측들의 가중평균으로 얻은 성분
- $\sigma_n^q$: 가중 분산식으로 계산한 표준편차
- $R_n^q$: 평균을 제거하고 표준편차로 나눈 잔차
- $\odot 2$: 원소별 제곱
- $\epsilon$: 0으로 나누는 문제 등을 줄이기 위한 작은 양수
- 나눗셈은 원소별로 수행합니다.

**근거: p. 4, 식 (1).**

> **용어 설명 — 정규화:** 값의 중심과 크기를 조정하여 비교·학습하기 쉬운 형태로 바꾸는 처리입니다. 이 식에서는 평균을 빼고 표준편차로 나눕니다.  
> **선택 행렬:** 모든 과거 관측을 똑같이 사용하는 대신, 특정 구조에 맞는 관측에 가중치를 부여하는 표입니다.

각 단계의 잔차는 다음 단계의 입력입니다.

$$
H^{\text{se}}=R^{\text{lt}},
\qquad
H^{\text{st}}=R^{\text{se}},
\qquad
H^{\text{si}}=R^{\text{st}}.
$$

**[검토]** 이는 단순히 여러 성분을 더해서 원래 시계열을 복원하는 가산 분해와는 구별해야 합니다. 식 (1)에서의 관계는

$$
H_n^q=\mu_n^q+\sigma_n^q\odot R_n^q
$$

이므로, 각 단계에서 추출한 평균 성분들을 단순 합산하는 것만으로 원래 입력이 복원된다고 말할 수 없습니다. 여기서 $\odot$은 원소별 곱입니다. **[p. 4, 식 (1)에서 직접 정리]**

### 5.3 공통 외삽 연산

원문 식 (2)는 성분과 잔차를 미래 길이로 변환합니다.

$$
\hat\mu_n^q=\mathcal E^q\mu_n^q,
\qquad
\hat R_n^q=\mathcal E^qR_n^q.
$$

- $\mathcal E^q\in\mathbb{R}^{T_{\text{out}}\times T_{\text{in}}}$: 과거 위치를 미래 위치에 연결하는 외삽 행렬
- $\hat\mu_n^q,\hat R_n^q\in\mathbb{R}^{T_{\text{out}}\times d}$: 미래 성분과 미래 잔차의 표현

핵심은 **모든 성분에 같은 연결 구조를 사용하는 대신, 성분의 특성에 따라 $\mathcal I^q$와 $\mathcal E^q$를 다르게 설계한다는 점**입니다. **[p. 4, 식 (2)]**

### 5.4 장기 성분: 전체 입력 구간의 평균

장기 성분의 추론·외삽 가중치는 모두 동일합니다.

$$
\mathcal I^{\text{lt}}(t,s)=\frac{1}{T_{\text{in}}},
\qquad
\mathcal E^{\text{lt}}(h,s)=\frac{1}{T_{\text{in}}}.
$$

- $t,s$: 입력 구간의 시점
- $h$: 미래 구간의 시점
- $\text{lt}$: 장기 성분

여러 주기의 관측을 평균하여 국소적인 주기·단기 영향을 줄이려는 설계입니다. 저자들은 자신의 데이터셋에서는 장기 성분에 어텐션을 추가해도 예측 정확도가 개선되지 않았다고 설명합니다. **[p. 5, 식 (3)]**

> **용어 설명 — 어텐션(attention):** 여러 정보 가운데 관련성이 높은 정보에 더 큰 가중치를 주어 결합하는 방식입니다.

**[검토]** 저자들은 이를 추세를 나타내는 성분으로 설명하지만, 이 식 자체는 **현재 입력 구간의 일정한 평균 수준**을 계산합니다. 선형 기울기를 추정하여 미래 추세를 연장하는 회귀식은 아닙니다.

### 5.5 주기 성분: 같은 위상끼리 선택적으로 결합

주기 길이를 $c$라고 합니다. 표기를 단순하게 하기 위해 원문은 다음을 가정합니다.

```math
T_{\text{in}}=\tau_{\text{in}}c,
\qquad
\tau_{\text{out}}
=
\left\lceil\frac{T_{\text{out}}}{c}\right\rceil.
```

- $c$: 한 주기의 관측 시점 수
- $\tau_{\text{in}}$: 입력에 포함된 주기 수
- $\tau_{\text{out}}$: 출력 구간을 덮는 데 필요한 최소 주기 수
- $\lceil\cdot\rceil$: 올림

추론 행렬은 다음과 같습니다.

$$
\mathcal I^{\text{se}}(t,s)=
\begin{cases}
\displaystyle
\frac{\exp(W^{\text{se}}_{u,v})}
{\sum_{k=0}^{\tau_{\text{in}}-1}
\exp(W^{\text{se}}_{u,k})},
&
t-s\equiv0\pmod c,
\\[6pt]
0,&\text{그 외},
\end{cases}
$$

$$
u=\left\lfloor\frac{t}{c}\right\rfloor,
\qquad
v=\left\lfloor\frac{s}{c}\right\rfloor.
$$

외삽 행렬도 같은 방식으로 만듭니다.

$$
\mathcal E^{\text{se}}(h,s)=
\begin{cases}
\displaystyle
\frac{\exp(\hat W^{\text{se}}_{u,v})}
{\sum_{k=0}^{\tau_{\text{in}}-1}
\exp(\hat W^{\text{se}}_{u,k})},
&
h-s\equiv0\pmod c,
\\[6pt]
0,&\text{그 외},
\end{cases}
$$

$$
u=\left\lfloor\frac{h}{c}\right\rfloor,
\qquad
v=\left\lfloor\frac{s}{c}\right\rfloor.
$$

**기호 설명**

- $W^{\text{se}}\in\mathbb{R}^{\tau_{\text{in}}\times\tau_{\text{in}}}$: 입력 주기 사이의 학습 가중치
- $\hat W^{\text{se}}\in\mathbb{R}^{\tau_{\text{out}}\times\tau_{\text{in}}}$: 미래 주기와 과거 주기 사이의 학습 가중치
- $\lfloor\cdot\rfloor$: 내림
- $t-s\equiv0\pmod c$: 두 시점이 주기 안에서 동일한 위치에 있다는 조건
- $\exp$: 지수함수

**근거: p. 5, 식 (4)–(5).**

> **용어 설명 — 주기·계절성:** 일정한 간격으로 반복되는 패턴입니다. 여기서 계절성은 사계절뿐 아니라 하루 단위의 교통·전력 패턴도 포함합니다.  
> **위상:** 한 주기 안에서의 위치입니다. 일주기 자료에서는 “각 날짜의 오전 9시”가 같은 위상에 해당합니다.  
> **소프트맥스(softmax):** 위 식처럼 지수값을 전체 합으로 나누어 가중치를 양수로 만들고, 그 합을 1로 만드는 연산입니다.

예를 들어 시간별 전력 자료에서 $c=24$라면, 같은 시간대의 여러 날짜를 서로 다른 비중으로 결합하는 방식입니다. 연결을 주기 단위로 공유하므로 모든 시점 쌍의 관계를 독립적으로 학습하는 것보다 파라미터가 줄어듭니다.

**중요한 구별:** 이 시간 선택 가중치는 **학습되는 파라미터**입니다. 입력마다 쿼리·키를 만들어 계산하는 일반적인 자기어텐션과 동일하지 않습니다. 반면 뒤에서 설명하는 공간 선택 행렬은 실제 입력 잔차에 따라 달라집니다. **[p. 5, 식 (4)–(7); p. 6, 식 (9)]**

### 5.6 단기 성분: 최근 관측만 사용하고 먼 미래에서는 0으로 처리

**[저자 보고]** 단기 성분은 장기·주기 성분으로 설명되지 않는 일시적 변화를 나타내며, 최근 $\delta$개 관측만 이용합니다. 가까운 미래에는 최근 단기 성분을 가중합하고, 더 먼 미래에서는 0으로 처리합니다. **[p. 5, 식 (6)–(7)]**

**표기상 주의:** 원문 식 (6)은 지연별 가중치를 설명하면서 분자에 $w_i^{\text{st}}$를 사용합니다. 식 (7) 역시 $\delta\times\delta$ 가중치에 전체 입력 시점 첨자를 직접 사용하는 형태입니다. 아래는 **원문의 설명을 이해하기 위해 지연과 지역 첨자를 명시한 재표기**이며, 원문 그대로의 전사는 아닙니다.

먼저 지연별 가중치를 정의합니다.

```math
\alpha_\ell
=
\frac{\exp(w_\ell^{\text{st}})}
{\sum_{r=0}^{\delta-1}\exp(w_r^{\text{st}})},
\qquad
\ell=0,\ldots,\delta-1.
```

$$
\mathcal I^{\text{st}}(t,s)=
\begin{cases}
\alpha_{t-s},&0\le t-s<\delta,\\
0,&\text{그 외}.
\end{cases}
$$

- $\delta$: 단기 정보로 사용할 관측 범위
- $\ell=t-s$: 현재 시점과 과거 시점 사이의 지연
- $w^{\text{st}}\in\mathbb{R}^{\delta}$: 지연별 학습 파라미터
- $\alpha_\ell$: 정규화된 지연별 가중치

입력 시작 부분처럼 과거 관측이 $\delta$개보다 적은 경계에서의 처리 방식은 본문 식만으로 명확하지 않습니다.

외삽은 다음과 같이 설명할 수 있습니다.

$$
\mathcal E^{\text{st}}(h,s)=
\begin{cases}
\displaystyle
\frac{\exp(\hat w^{\text{st}}_{h,r})}
{\sum_{q=0}^{\delta-1}\exp(\hat w^{\text{st}}_{h,q})},
&
0\le h<\delta,\quad
s=T_{\text{in}}-\delta+r,\quad
0\le r<\delta,
\\[6pt]
0,&\text{그 외}.
\end{cases}
$$

- $h$: 미래 시점의 지역 첨자
- $r$: 입력의 마지막 $\delta$개 위치 중 하나를 가리키는 첨자
- $\hat w^{\text{st}}\in\mathbb{R}^{\delta\times\delta}$: 가까운 미래와 최근 과거를 연결하는 학습 가중치

**[검토]** 이 설계는 먼 미래의 단기 변동을 복잡한 가중치로 추정하지 않도록 제약합니다. 다만 이 제약이 장기간 지속되는 사건에서도 유리한지는 논문에서 별도로 검증하지 않습니다. 또한 0으로 채운 행은 행합이 0이므로, p. 4의 “외삽 행렬의 모든 행합은 1”이라는 설명에는 예외가 필요합니다.

### 5.7 공간 성분: 시간 성분을 제거한 뒤 변수 간 관계 추출

여기서 **공간**은 주로 여러 변수·시계열 사이의 관계를 뜻합니다. 모델에 반드시 지리적 좌표를 제공한다는 의미는 아닙니다.

시간 성분을 제거한 내부 표현 $H_n^{\text{si}}$를 펼쳐 변수 간 유사도를 계산합니다.

```math
\mathcal I^{\text{si}}(n,m)
=
\frac{
\exp\!\left(
\text{vec}(H_n^{\text{si}})^\top
\text{vec}(H_m^{\text{si}})
\right)}
{\sum_{k=1}^{N}
\exp\!\left(
\text{vec}(H_n^{\text{si}})^\top
\text{vec}(H_k^{\text{si}})
\right)}.
```

- $\mathcal I^{\text{si}}\in\mathbb{R}^{N\times N}$: 변수 간 선택 행렬
- $\text{vec}$: $T_{\text{in}}\times d$ 행렬을 하나의 긴 벡터로 펼치는 연산
- ${}^\top$: 전치
- 두 벡터의 곱: 잔차 표현 사이의 내적 유사도

각 시점에서 변수 축을 따라 정규화합니다.

```math
\mu_{:,t}^{\text{si}}
=
\mathcal I^{\text{si}}H_{:,t}^{\text{si}},
```

```math
(\sigma_{:,t}^{\text{si}})^2
=
\mathcal I^{\text{si}}(H_{:,t}^{\text{si}})^{\odot2}
-
(\mu_{:,t}^{\text{si}})^{\odot2}
+\epsilon,
```

```math
R_{:,t}^{\text{si}}
=
\frac{H_{:,t}^{\text{si}}-\mu_{:,t}^{\text{si}}}
{\sigma_{:,t}^{\text{si}}}.
```

여기서 $:$는 모든 변수를 뜻합니다. 저자들은 공간 성분의 시간적 변화는 예측하기 어렵다고 보고 미래 공간 성분과 잔차를 다음과 같이 둡니다.

$$
\hat\mu^{\text{si}}=0,
\qquad
\hat R^{\text{si}}=0.
$$

**근거: p. 6, 식 (8)–(9) 및 직후 설명.**

> **용어 설명 — 편상관·조건부 상관:** 다른 요인으로 설명되는 부분을 제거한 뒤, 두 변수 사이에 남는 관계를 조사하는 개념입니다.

**[검토]** 저자들은 식 (9)를 조건부 상관으로 설명하지만, 실제 연산은 **잔차 내적의 소프트맥스**입니다. Appendix D에서 정의하는 통계적 상관계수와 식 (9)의 어텐션 점수를 동일한 통계량이라고 설명하면 안 됩니다.

### 5.8 성분 결합: 다항 회귀로 상호작용 표현

각 단계의 성분과 잔차를 연결합니다.

$$
S_n=
[
R_n^{\text{lt}},\mu_n^{\text{lt}},
R_n^{\text{se}},\mu_n^{\text{se}},
R_n^{\text{st}},\mu_n^{\text{st}},
R_n^{\text{si}},\mu_n^{\text{si}}
].
$$

이후 원문 식 (10)을 적용합니다.

```math
H_n
=
\text{Conv}_{k=1}
\left(
\text{Conv}_{k}(S_n)
\otimes
\text{Conv}_{k}(S_n)
\right)
+
\text{Conv}_{k}(S_n).
```

- $[\cdots]$: 특징을 이어 붙이는 연산
- $\text{Conv}_{k}$: 커널 크기 $k$인 합성곱
- $\text{Conv}_{k=1}$: 커널 크기 1인 합성곱
- $\otimes$: 원문이 곱셈 결합에 사용하는 기호
- $H_n$: 융합된 내부 표현으로, 다음 층의 장기 분해 입력이 됨

곱셈 경로는 성분 사이의 상호작용을, 덧셈 경로는 가산적인 관계를 표현합니다. **[p. 6, 식 (10); p. 4, Fig. 1]**

> **용어 설명 — 합성곱:** 주변의 여러 값을 같은 규칙으로 결합하여 특징을 추출하는 연산입니다.  
> **다항 상호작용:** 두 특징을 곱한 항처럼, 한 특징의 효과가 다른 특징의 값에 따라 달라질 수 있도록 표현하는 방식입니다.

**원문만으로 확정하기 어려운 부분:** 동일하게 표기된 합성곱들의 가중치 공유 여부, $\otimes$의 세부 구현, 최종 Projection의 정확한 수식은 본문에서 충분히 정의되지 않습니다. 따라서 이 부분을 임의의 구현식으로 확정해서 설명하지 않습니다.

### 5.9 왜 분해가 관계 학습에 유리하다는 것인가?

저자들은 두 성분이 섞인 자료를 가정합니다.

$$
x_t=a_t+b_t.
$$

세 시점이 다음 조건을 만족한다고 둡니다.

$$
a_{t_1}=a_{t_2},
\qquad
b_{t_2}=b_{t_3},
\qquad
a_{t_1}\ne a_{t_3}.
$$

원래 관측 공간에서는 거리 차이가 다음과 같습니다.

```math
\begin{aligned}
&\|x_{t_1}-x_{t_2}\|^2
-
\|x_{t_1}-x_{t_3}\|^2\\
&=
-\|a_{t_1}-a_{t_3}\|^2
-
2\left\langle
a_{t_1}-a_{t_3},
b_{t_1}-b_{t_2}
\right\rangle.
\end{aligned}
```

- $a_t,b_t$: 시계열을 구성하는 두 성분
- $\|\cdot\|$: 유클리드 거리
- $\langle\cdot,\cdot\rangle$: 내적
- 마지막 항: 서로 다른 성분이 섞이면서 생기는 교차항

이 교차항 때문에 동일한 성분을 공유하는 관측끼리 오히려 더 멀어질 수 있습니다. **[p. 15, 식 (11)]**

이상적으로 성분을 분리하는 함수 $D(x_t)=(a_t,b_t)$를 얻으면 다음과 같이 됩니다.

```math
\|D(x_{t_1})-D(x_{t_2})\|^2
-
\|D(x_{t_1})-D(x_{t_3})\|^2
=
-\|a_{t_1}-a_{t_3}\|^2
\le0.
```

이는 원문의 분해 논증을 동치 형태로 정리한 식입니다. **[pp. 6–7; pp. 15–16, Appendix A]**

**[검토]** 이 분석이 보여 주는 것은 **성분을 정확히 분리했을 때 표현공간의 관계가 개선될 수 있다**는 점입니다. 다음 사항까지 증명하지는 않습니다.

- 학습된 SSCNN이 실제 성분을 항상 정확히 복원한다는 것
- 분해가 모든 패칭 방법보다 항상 우월하다는 것
- 미지의 도메인에서 예측 오차가 일정 범위 이하라는 것
- 작은 파라미터 수만으로 일반화 성능이 보장된다는 것

### 5.10 파라미터가 줄어드는 이유

저자가 제시한 파라미터 증가 차수는 다음과 같습니다.

```math
P_{\text{patch}}
=
O\!\left(
d_{\text{patch}}T_{\text{in}}T_{\text{out}}
+
d_{\text{patch}}^2
\right),
```

```math
P_{\text{SSCNN}}
=
O\!\left(
d_{\text{step}}^2
+
\frac{
T_{\text{in}}T_{\text{out}}+T_{\text{in}}^2
}{c^2}
+
d_{\text{step}}T_{\text{out}}
\right).
```

- $P$: 파라미터 수
- $d_{\text{patch}}$: 패칭 기반 표현 차원
- $d_{\text{step}}$: SSCNN의 시점별 표현 차원
- $c$: 주기 길이
- $O(\cdot)$: 입력 크기가 커질 때 필요한 양의 증가 차수를 나타내는 표기

주기 단위 가중치 공유로 시간 길이에 관련된 항에 $1/c^2$가 붙고, 작은 표현 차원으로 특징 변환의 파라미터도 줄입니다. 저자들은 비교 모델의 표현 차원 64–256과 SSCNN의 예시 $d=8$을 대비합니다. **[p. 7, §4]**

**[검토]** 이는 저자가 분석한 구조의 증가 차수입니다. 모든 패칭 모델에 적용되는 보편적인 최소 파라미터 하한은 아닙니다. 또한 적은 파라미터를 여러 시점에 반복 적용하면 연산량은 여전히 클 수 있습니다.

> **용어 설명 — 일반화:** 학습할 때 사용하지 않은 자료에서도 모델이 잘 작동하는 능력입니다.  
> **제로샷(zero-shot) 전이:** 새로운 목표 데이터셋에 맞춰 추가로 학습하지 않고 바로 예측하는 평가입니다.  
> **분포 변화:** 학습 자료와 실제 예측 환경의 통계적 성질이나 입력–출력 관계가 달라지는 현상입니다.

### 8.2 일반화에 유리할 수 있는 설계상의 이유

다음은 **실험 결과 자체가 아니라, 구조에 근거한 해석**입니다.

**첫째, 학습해야 할 관계를 제한합니다.** 같은 위상·짧은 지연 등 의미 있는 연결만 허용하면, 데이터와 무관한 연결까지 학습해야 하는 부담을 줄일 수 있습니다. 다만 실제 자료의 주기나 시간 규모가 이 구조와 맞아야 합니다. 주기 설정에 민감한 Fig. 4는 이 조건의 중요성을 보여 줍니다. **[p. 5, 식 (4)–(7); p. 9, Fig. 4]**

> **용어 설명 — 귀납편향:** 모델이 어떤 규칙을 더 쉽게 학습하도록 구조에 넣어 둔 사전 가정입니다. SSCNN의 “같은 주기 위치를 연결한다”는 설계가 그 예입니다.

**둘째, 수준·변동 크기와 잔차를 구분합니다.** 평균과 표준편차를 이용한 분리는 서로 다른 크기와 수준을 가진 입력을 처리하는 데 도움이 될 가능성이 있습니다. 그러나 SSCNN 논문은 평균 이동, 진폭 변화, 입력–출력 관계 변화 등을 나누어 시험하지 않았으므로, 이 정규화가 어떤 종류의 변화에 강한지는 추가 검증이 필요합니다. **[p. 4, 식 (1); p. 6, 식 (8)]**

**셋째, 공통 시간 패턴과 변수 고유의 관계를 구별하려고 합니다.** 원자료에서 두 변수가 함께 움직이는 이유가 동일한 일주기 때문이라면, 그 관계를 별도 변수 간 연결로 다시 학습하는 것은 중복일 수 있습니다. 시간 성분을 제거한 잔차에서 관계를 찾는 방식은 이러한 중복을 줄이려는 접근입니다. **[pp. 18–19, Appendix D, Fig. 7]**

### 8.3 일반화 가능성을 제한하는 조건

**[검토]** 다음 세 가지를 특히 주의해야 합니다.

1. **시간 선택 가중치는 학습 후 고정됩니다.** 주기 변화에 따라 선택 규칙 자체를 즉시 다시 추정하는 방식이라고 볼 수 없습니다. **[p. 5, 식 (4)–(7)]**
2. **주기 길이와 공간 성분 사용 여부가 중요합니다.** 구조를 잘 선택한 효과와 모델 자체의 범용성을 구분해야 합니다. **[p. 8, Network Setting; p. 9, Fig. 4]**
3. **작은 모델의 이점이 소량 데이터에서도 유지되는지는 미확인입니다.** 이 논문에는 체계적인 학습 데이터 축소 실험이나 데이터셋 간 전이 평가가 없습니다. **[§5, Appendices B–C]**

따라서 이 논문의 일반화 관련 기여는 **“적절한 구조적 가정을 가진 작은 모델이 여러 벤치마크에서 좋은 예측을 보였다”**는 수준으로 평가하는 것이 타당합니다.

## 9. 제한사항·통계적 취약점·비교 불가능한 수치

### 9.1 저자가 직접 언급한 한계

**[저자 보고]**

- 파라미터 수를 줄였지만 계산 복잡도 측면에서는 약점이 남습니다.
- 각 층에서 전체 입력·예측 구간을 처리하는 것이 연산 부담의 원인입니다.
- 새로운 데이터셋마다 적절한 구조 조합을 수동으로 찾아야 하는 부담이 있습니다. **[pp. 8–10, Fig. 2, §6]**

저자가 제시한 후속 계획은 **다운샘플링으로 중복 계산을 제거하는 것**과 **기본 모듈을 조합하여 신경망 구조를 자동 탐색하는 것**입니다. **[p. 10, §6]**

| ETTh1, DLinear MAE | 0.393 | 0.3790 |
| Traffic, Autoformer MAE | 0.420 | 0.3606 |

예를 들어 다음과 같습니다.

```math
\frac{0.170+0.319+0.383+0.429+0.464}{5}
=
0.353.
```

이는 Table 2의 ETTh1 DLinear MSE 평균이며, Table 1의 0.368과 다릅니다.

### 9.4 수학적 표현에서의 주의점

원문은 선택 행렬의 행합이 1이면 평균과 표준편차의 불편성이 확보된다는 취지로 설명합니다. **[p. 4, 식 (1) 직후]**

> **용어 설명 — 불편성:** 같은 조건에서 추정을 반복했을 때 추정값의 평균이 실제 모수와 일치하는 성질입니다.

**[검토]** 행합 1은 정규화된 가중평균을 만드는 조건이지만, 일반적인 불편 추정을 보장하지는 않습니다. 예를 들어 서로 독립이고 같은 분포를 따르는 $z_j$의 분산이 $v$이고, 고정 가중치 $\alpha_j$의 합이 1이면, 수치 안정화 항을 제외한 가중 분산식은 다음을 만족합니다.

```math
\mathbb{E}
\left[
\sum_j\alpha_jz_j^2
-
\left(\sum_j\alpha_jz_j\right)^2
\right]
=
v\left(1-\sum_j\alpha_j^2\right).
```

- $\mathbb{E}$: 반복 관측에 대한 평균, 즉 기댓값
- $z_j$: 관측값
- $v$: 실제 분산
- $\alpha_j$: 합이 1인 고정 가중치

따라서 행합 1만으로 분산의 불편성까지 확보되는 것은 아닙니다. 이는 **분석자의 수학적 검산이며, 저자가 보고한 실험 결과와는 별개**입니다.

### 9.5 직접 비교하면 안 되는 수치

- **파라미터 감소율과 속도 향상률:** 99% 적은 파라미터가 99% 적은 실행 시간이나 메모리를 뜻하지 않습니다. **[Fig. 2]**
- **서로 다른 데이터셋의 MSE 절댓값:** 자료의 단위·변동·전처리·난도가 달라 단순 서열화할 수 없습니다. **[Appendix B]**
- **다른 논문에서 가져온 평균 성능:** 입력 길이, 예측 길이 집합, 전처리, 학습 조건이 다르면 직접 비교할 수 없습니다.
- **지도학습 모델과 사전학습 제로샷 모델:** 목표 데이터에서의 학습 여부와 사전학습 데이터·비용이 다르므로, 같은 평가 설계에서 별도로 측정해야 합니다.
- **논문에 없는 실행 시간·최대 메모리·에너지:** FLOPs만으로 이 값들을 복원할 수 없습니다. **[§5.2]**

학습·검증·시험 분할의 구체적 비율·날짜, 정규화 통계의 산출 구간, 조기 종료 규칙 등도 본문·부록에서 충분히 명시되지 않습니다. 이는 **문서만으로 재현하기 어려운 부분**이라는 뜻이며, 데이터 누출이나 잘못된 분할이 있었다는 증거는 아닙니다.

### 11.2 이 비교가 일반화 연구에 주는 시사점

**첫째, 일반화의 종류를 나누어 평가해야 합니다.** TimeMixer++의 Table 6은 한 데이터셋에서 학습한 모델을 다른 데이터셋에 추가 학습 없이 적용합니다. 이러한 실험은 SSCNN의 데이터셋별 학습 결과와 서로 다른 질문에 답합니다. **[TimeMixer++, §4.1.6, Table 6]** [arxiv.org](https://arxiv.org/html/2410.16032v5?utm_source=chatgpt.com)

**둘째, 정규화가 해결하는 변화와 해결하지 못하는 변화를 분리해야 합니다.** 2026년 RevIN 분석은 PatchTST를 고정한 실험에서 정규화 구성요소의 효과가 자료와 학습 방식에 따라 달라짐을 보고합니다. 이를 SSCNN의 입증된 약점으로 옮길 수는 없지만, SSCNN을 평가할 때 사용할 변화 유형과 실험 통제를 제공합니다. **[해당 논문, Table 1, §4.1–4.2]** [arxiv.org](https://arxiv.org/html/2603.11869v1?utm_source=chatgpt.com)

**셋째, 비용과 사용 목적을 함께 비교해야 합니다.** Chronos-2는 목표 자료에서 작업별 학습 없이 사용하는 예측을 다룹니다. 따라서 SSCNN과 비교하려면 정확도뿐 아니라 목표 데이터에서의 학습 시간, 추론 비용, 사전학습 비용의 취급을 구분해야 합니다. **[Chronos-2, §3–5]** [arxiv.org](https://arxiv.org/abs/2510.15821?utm_source=chatgpt.com)

**직접 수치 비교의 제한:** TimeMixer++의 제로샷 표는 $\{96,192,336,720\}$ 예측 길이의 평균이고, SSCNN Table 1은 $\{3,24,96,192,336\}$의 평균입니다. 평균값을 그대로 나란히 놓아 우열을 판단할 수 없습니다. **[SSCNN, Table 1; TimeMixer++, Table 6]** [arxiv.org](https://arxiv.org/html/2410.16032v5?utm_source=chatgpt.com)

또한 위의 후속 연구들이 SSCNN을 직접 계승하거나 SSCNN 때문에 등장했다고 확인한 것은 아닙니다. 확인할 수 있는 것은 **연구 주제와 평가 방법의 비교 가능성**입니다.

## 12. 결론·시사점·유망한 후속 연구

### 12.1 저자들이 제시한 시사점과 후속 계획

**[저자 보고]** 논문의 중심 메시지는 시계열의 규칙성을 활용하면 제한된 파라미터로도 높은 예측 성능을 얻을 수 있다는 것입니다. 후속 연구로는 다음을 명시합니다. **[p. 10, §6]**

1. **다운샘플링 등을 이용한 중복 연산 제거**
2. **기본 구성요소를 조합하는 자동 구조 탐색**

저자들은 기상·경제·교통·의료 등에서 예측의 활용 가능성을 언급하지만, 잘못된 예측에 따른 운영 손실과 데이터 프라이버시 문제도 함께 논의합니다. 이는 해당 모든 분야에서 실제 적용 효과를 검증했다는 뜻은 아닙니다. **[p. 10, Broader Impacts]**

### 12.2 학계와 실무에 대한 의미

**[검토] 학계에 대한 의미:** 이 논문은 모델을 평가할 때 정확도뿐 아니라 **어떤 구조를 가정했고, 그 가정이 얼마나 적은 파라미터로 표현되는지**를 함께 검토할 필요성을 보여 줍니다. 특히 SCNN·DLinear처럼 작은 기준선을 포함하고, 성분별 기여를 확인하는 실험 설계가 중요합니다. **[§4–5, Tables 1–2, Fig. 5]**

**[검토] 실무에 대한 의미:** 규칙적인 전력·교통 자료에서 작은 모델을 우선 검토할 근거를 제공합니다. 다만 배포 적합성을 판단하려면 파라미터 수와 함께 실제 추론 시간, 최대 메모리, 오류가 커지는 상황을 측정해야 합니다. 원문의 연산량 한계 때문에 소형 모델이라는 사실만으로 저지연 배포를 보장할 수 없습니다. **[pp. 8–10, Fig. 2, §6]**

### 12.3 핵심 아이디어를 빠르게 검증할 유망 접근법

아래는 **효과가 입증된 결과가 아니라 후속 실험 제안**입니다.

| 우선순위·접근법 | 원문에 있는 근거 | 최소한의 검증 실험 |
|---|---|---|
| **1. 같은 위상끼리 선택하는 주기 모듈** | 식 (4)–(5), Fig. 5 | 같은 위상 관측의 균등 평균과 학습 가중치를 비교하고, 나머지 예측기는 동일하게 유지 |
| **2. 시간 성분 제거 후 변수 관계 학습** | 식 (9), Fig. 7 | 원자료에서 관계 계산, 분해 후 잔차에서 계산, 변수별 독립 처리의 세 조건 비교 |
| **3. 단기 예측 범위 제한** | 식 (6)–(7) | $\delta$ 이후 0 처리와 완만한 감쇠 처리를 비교하여 오래 지속되는 사건에서의 차이 조사 |
| **4. 가산·곱셈 성분 결합** | 식 (10), Fig. 1 | 덧셈만 사용하는 결합과 곱셈 경로를 포함한 결합을 비슷한 파라미터 예산으로 비교 |
| **5. 분해 후 다운샘플링** | §6의 저자 후속 계획 | 하나의 단계에만 다운샘플링을 추가하고 MSE·MAE·FLOPs·실제 지연시간을 함께 측정 |

처음에는 **규칙성이 강한 ECL과 선택 기제의 이득이 작은 ETTm2**처럼 성격이 다른 두 데이터셋에서 시작하는 것이 적절합니다. 이는 좋은 조건과 불리한 조건을 함께 확인하기 위한 제안입니다. **[선정 근거: p. 8, Forecasting Accuracy; p. 17, Table 2]**

### 12.4 일반화 성능을 중심으로 한 후속 평가 설계

**[제안]** 가장 먼저 추가할 평가를 다음 순서로 권합니다.

1. **시간 구간을 바꾸는 반복 평가:** 한 번의 시험 구간에만 의존하지 않고, 학습 종료 시점을 순차적으로 이동시키며 미래를 예측합니다.
2. **주기 변화에 대한 통제 실험:** 주기 길이·위상·진폭 중 하나씩 바꾸어 어떤 구조 가정이 성능을 좌우하는지 확인합니다.
3. **데이터셋 간 직접 전이:** 예를 들어 ETTh1에서 학습한 뒤 ETTh2에 추가 학습 없이 적용하고, 반대 방향도 평가합니다.
4. **구조 선택의 분리 평가:** 모든 자료에 같은 구조를 사용한 결과와 데이터셋별 조정 결과를 별도로 보고합니다.
5. **공정한 비용 비교:** 입력·예측 길이, 전처리, 조정 예산, 시드를 맞추고 SSCNN·SCNN·DLinear·FITS 등을 비교합니다.

> **용어 설명 — 순차적 학습 종료 시점 평가(rolling-origin evaluation):** 과거 자료로 학습하고 그다음을 예측하는 과정을 시간축을 따라 여러 번 반복하는 평가입니다.

비교 모델들도 여러 시드로 실행하고, 시간적으로 연속된 구간의 의존성을 반영해 오차 차이의 불확실성을 평가해야 합니다. 주기 선택과 정규화 통계의 추정은 학습·검증 자료 안에서 이루어지도록 명확히 기록하는 것이 필요합니다.

**최종 판단:** SSCNN의 가장 유망한 기술은 **성분에 따라 필요한 연결만 학습하는 선택적 분해**입니다. 현재 원문은 이 접근의 파라미터 효율과 여러 벤치마크에서의 예측 경쟁력을 뒷받침합니다. 연구를 확장할 때의 핵심 과제는 **그 구조적 가정이 다른 자료와 변화한 환경에서도 유효한지, 그리고 파라미터 효율이 실제 계산 효율로 이어지는지**를 직접 검증하는 것입니다.
