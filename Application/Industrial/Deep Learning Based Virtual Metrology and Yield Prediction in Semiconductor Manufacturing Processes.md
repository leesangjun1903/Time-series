# Deep Learning Based Virtual Metrology and Yield Prediction in Semiconductor Manufacturing Processes

> **⚠️ 투명성 공지**: 본 논문은 2017년 APPHm Society Conference의 2페이지 단편 논문입니다. 수식·구조 설명은 논문 원문 기반이며, 일부 세부사항(하이퍼파라미터, 구체적 네트워크 깊이 등)은 논문에 명시되지 않아 해당 부분을 명확히 표기합니다.

---

## 1. Executive Summary (10문장 이내)

1. 반도체 제조 공정에서 웨이퍼 품질을 **사전 예측**하는 Virtual Metrology(VM) 및 수율(Yield Rate, YR) 예측의 정확도를 높이기 위해 딥러닝 기반 지도 오토인코더(Supervised Autoencoder)를 제안한다.
2. 200개 이상의 인라인 센서에서 수집된 고차원 기능적 신호 데이터를 별도의 정렬(alignment) 전처리 없이 직접 모델에 입력한다.
3. 스택 오토인코더 구조에 개별 가중치 희소성($\ell_1$ 정규화)과 센서 그룹 수준 희소성(그룹 정규화)을 동시에 적용한다.
4. 비지도 재구성 손실에 지도 학습 예측 손실을 결합하여 목표값 예측에 유용한 잠재 특징을 추출한다.
5. 실험 데이터셋은 298개 웨이퍼 샘플, 85개 센서, 64개 서브 오퍼레이션, 최대 654 타임스탬프로 구성된다.
6. 추출된 특징에 Lasso·PCR 등 다양한 예측기를 결합하여 비교 실험을 수행하였다.
7. AE-Lasso 조합이 CD1(MSE=0.0369)과 YR(MSE=0.0017) 예측에서 대부분의 비교 모델을 능가하였다.
8. 기존 PCA·KPCR 등 전통 방법 대비 CD1 MSE 기준 최대 약 56% 감소를 달성하였다.
9. 본 연구는 딥러닝이 반도체 VM 분야에서 분류 문제뿐 아니라 **연속값 회귀** 문제에도 효과적임을 실증하였다.
10. 데이터 규모(298샘플)와 단일 공정·단일 CD 평가라는 실험 범위의 제한이 존재한다.

### 1-1. 연구의 목적과 필요성

| 구분 | 내용 |
|------|------|
| **산업적 필요성** | 반도체 제조에서 물리적 계측(Physical Metrology)은 비용·시간이 크며, 전수 검사가 불가능 |
| **기술적 필요성** | 200개 이상의 센서 신호는 고차원·가변 길이(Variable-length)로 전통적 통계 기법 적용이 어려움 |

> 💡 **Critical Dimension(CD)**: 반도체 패턴의 선폭·간격 등 품질을 결정하는 핵심 치수. 나노미터 단위로 측정되며 수율에 직결됨.

## 2-1. 상세 설명

### 🔴 해결하고자 하는 문제

1. **고차원 가변 길이 신호 처리**: 센서별로 서브 오퍼레이션 처리 시간이 달라 신호 길이가 상이함
2. **수동 전처리 의존 탈피**: 기존 VM은 신호 정렬 등 도메인 전문 지식 기반 전처리 필요
3. **연속값 예측**: 기존 딥러닝 제조 연구의 분류 중심 한계 극복
4. **센서 선택 자동화**: 200개 이상 센서 중 유의미한 센서 자동 식별

### 🔵 제안하는 방법 (수식 포함)

#### (A) 스택 오토인코더 기본 구조

$K$개 층을 가진 스택 오토인코더에서 $k$번째 층의 $d_k$차원 활성화 벡터 $\mathbf{y}^{(k)} \in \mathbb{R}^{d_k}$는:

$$\mathbf{y}^{(k)} = f_{(k)}\left(\mathbf{z}^{(k)}\right) $$

$$\mathbf{z}^{(k)} = \mathbf{W}^{(k)}\mathbf{y}^{(k-1)} + \mathbf{b}^{(k)} $$

**기호 설명:**
- $f_{(k)}$: $k$번째 층의 원소별(element-wise) 활성화 함수 (예: ReLU, sigmoid)
- $\mathbf{W}^{(k)} \in \mathbb{R}^{d_k \times d_{k-1}}$: $k$번째 층의 가중치 행렬
- $\mathbf{b}^{(k)} \in \mathbb{R}^{d_k}$: $k$번째 층의 편향(bias) 벡터
- $\mathbf{y}^{(0)}$: 입력 벡터 $\mathbf{x}$

> 💡 **활성화 함수(Activation Function)**: 신경망 각 뉴런의 출력에 비선형성을 부여하는 함수. ReLU( $\max(0,x)$ ), sigmoid 등이 있으며, 이를 통해 복잡한 패턴 학습이 가능해짐.

#### (B) 재구성 손실 함수

$$\mathcal{L}(\theta) = \frac{1}{2}\sum_{i=1}^{N}\|\mathbf{x}_i - \hat{\mathbf{x}}_i\|^2 $$

**기호 설명:**
- $\theta$: 모델의 모든 파라미터 집합
- $N$: 학습 샘플 수
- $\mathbf{x}_i$: $i$번째 관측의 원본 입력 벡터
- $\hat{\mathbf{x}}_i$: $i$번째 관측의 오토인코더 재구성 벡터
- $\|\cdot\|^2$: $\ell_2$ 노름의 제곱 (유클리드 거리 제곱)

#### (C) 그룹 정규화 (센서 그룹 희소성)

첫 번째 은닉층에서 $R$개 센서 그룹에 대한 가중치 행렬 $\mathbf{W}^{(1)} = [\mathbf{V}_1^{(1)} | \cdots | \mathbf{V}_R^{(1)}]$에 대해:

$$\text{Group Penalty} = \sum_{r=1}^{R}\left\|\mathbf{V}_r^{(1)}\right\|_F \{4}$$

**기호 설명:**
- $R$: 입력 변수의 그룹(센서) 수
- $\mathbf{V}_r^{(1)}$: $r$번째 센서 그룹에 해당하는 첫 번째 층 가중치 부분 행렬
- $\|\cdot\|_F$: 프로베니우스 노름(Frobenius norm) — 행렬의 모든 원소 제곱합의 제곱근
- $|$: 행렬 열 방향 연결(concatenation)

> 💡 **프로베니우스 노름(Frobenius Norm)**: 행렬의 크기를 측정하는 방법으로 $\|\mathbf{A}\|\_F = \sqrt{\sum_{i,j} a_{ij}^2}$. 이를 패널티로 사용하면 특정 센서 그룹 전체의 가중치를 0으로 수축시켜 센서 선택 효과를 냄.

> 💡 **그룹 Lasso(Group LASSO)**: 개별 변수가 아닌 변수 그룹 단위로 희소성(sparsity)을 부과하는 정규화 기법. 관련 변수들을 함께 선택하거나 제거함.

#### (D) 전체 손실 함수 (지도 오토인코더)

논문에 명시적 통합 수식은 없으나, 설명에 따르면:

$$\mathcal{L}_{\text{total}}(\theta) = \mathcal{L}_{\text{recon}}(\theta) + \lambda_1 \mathcal{L}_{\text{pred}}(\theta) + \lambda_2 \sum_{k}\|\mathbf{W}^{(k)}\|_1 + \lambda_3 \sum_{r=1}^{R}\|\mathbf{V}_r^{(1)}\|_F $$

> ⚠️ **식 (5)는 논문에 명시적으로 표현된 수식이 아니며**, 본문 설명("재구성 손실 + 예측 손실 + 개별 가중치 정규화 + 그룹 정규화")을 기반으로 재구성한 것입니다.

**기호 설명 (식 5*):**
- $\mathcal{L}_{\text{recon}}$: 식 (3)의 재구성 손실
- $\mathcal{L}_{\text{pred}}$: 예측값과 실제 목표값 간의 손실 (예: MSE)
- $\lambda_1, \lambda_2, \lambda_3$: 각 항의 가중치를 조절하는 하이퍼파라미터 (논문에 구체값 미기재)
- $\|\mathbf{W}^{(k)}\|_1$: $\ell_1$ 노름 — 개별 가중치 희소성 유도

### 🟢 모델 구조

```
원시 센서 신호 (85 센서 × 최대 654 타임스탬프)
        ↓ [Zero Padding으로 길이 통일]
   입력층 (고차원 벡터)
        ↓ [W^(1) + 그룹 정규화 + ℓ₁ 정규화]
   첫 번째 은닉층 (센서 그룹 희소성 적용)
        ↓ [W^(2) + ℓ₁ 정규화]
   두 번째 은닉층 (잠재 특징 공간)  ──→ [예측 손실 연결: 지도 신호]
        ↓
   디코더 층들 (재구성 경로)
        ↓
   재구성 출력
        
   추출된 잠재 특징
        ↓
   Lasso / PCR / PC-Lasso (예측기)
        ↓
   CD1 예측값 / YR 예측값
```

> ⚠️ 은닉층의 정확한 뉴런 수, 층 수(2개 은닉층으로만 언급), 활성화 함수 종류는 논문에 명시되지 않음.

> 💡 **오토인코더(Autoencoder)**: 입력을 압축(인코딩)하여 저차원 잠재 표현을 만들고, 이를 다시 원본과 유사하게 복원(디코딩)하도록 학습하는 신경망. 비지도 방식으로 데이터의 핵심 특징을 자동 추출함.

## 4. 저자 보고 결과 vs. 분석자 해석 분리

### 저자가 직접 보고한 결과

- **연구 주제** (p.20, Abstract): "심층 지도 오토인코더를 통해 반도체 제조 공정의 인라인 센서 신호에서 유의미한 특징을 추출하여 VM 및 수율 예측 모델 구축"
- **방법** (p.20–21, Sec.2): 식 (1)~(3) 및 그룹 정규화 패널티를 이용한 지도 오토인코더
- **결과** (p.21, Table 1): AE-Lasso의 CD1 MSE=0.0369, YR MSE=0.0017로 비교 모델 대비 우수

### 분석자(본 AI)의 해석

- **통계적 신뢰성 우려**: 98개 테스트 셋은 딥러닝 모델 평가에 충분하지 않을 수 있으며, 단일 분할(single split) 방식은 분산이 높음
- **제로 패딩의 영향**: 가변 길이 신호를 최장 길이(654)에 맞춰 패딩하는 방식은 짧은 신호의 모델이 패딩된 0값에 과적합될 위험이 있음
- **AE-PCR의 YR MSE=0.0171 이상치**: 동일한 AE 특징을 사용함에도 AE-PCR이 단순 Lasso보다 YR에서 크게 낮은 성능을 보이는 점은 PCR이 해당 특징 공간에서 부적합할 가능성을 시사하나, 논문에서 분석 없음
- **일반화 미검증**: 동일 공장·동일 장비의 단일 데이터셋만 사용하여 타 공정·타 장비로의 전이 가능성 미검증

## 7. 가장 중요한 그림 해석

> ⚠️ 본 논문에는 **Figure 1 (1개)와 Table 1 (1개)** 만 수록되어 있습니다. 5개의 독립 Figure가 존재하지 않으므로, 논문 내 핵심 시각 자료와 개념적으로 중요한 요소를 확장 해석합니다.

### Figure 1 (p.21) — 5개 센서의 샘플 신호 데이터

- **내용**: Sensor A~E의 3개 웨이퍼(wafer a, b, c)에 대한 시간에 따른 센서값 변화
- **해석**:
  - **가변성**: 동일 센서라도 웨이퍼 간 신호 패턴에 차이가 있으며, 서브 오퍼레이션 단위로 신호가 변화함
  - **센서별 다양성**: Sensor A는 넓은 진폭(0.04~0.12), Sensor E는 이진적 패턴(0~0.6)으로 이질적인 센서 특성을 보임
  - **모델 도전과제**: 이러한 이질적·가변 길이 신호를 수동 정렬 없이 처리해야 하는 어려움을 시각적으로 보여줌
  - **제로 패딩 필요성**: 시간축(~80 visible vs 654 max)의 차이로 패딩의 필요성이 암시됨

### Table 1 (p.21) — MSE 비교 결과 (핵심 성능 표)

- **내용**: 7개 모델의 CD1 및 YR MSE 비교
- **해석 (저자 보고)**:
  - AE 기반 특징이 전통적 특징 추출(PCA, Kernel PCA) 대비 우수함
  - AE-Lasso가 CD1에서 최고 성능, AE-PC-Lasso가 YR에서 미세하게 최고 성능
- **분석자 추가 해석**:
  - AE-PCR(YR=0.0171)의 이상치는 PCR이 AE 특징의 비선형 구조에 부적합함을 시사
  - CD1과 YR 간 최적 모델이 다른 점은 두 목표값의 특성 차이를 반영 (CD1: 연속 공정 특성, YR: 복합 공정 결과)
  - KPCR(YR=0.0019)이 AE-Lasso(0.0017)와 근소한 차이임을 고려하면 개선폭은 제한적

### 8-1. 모델의 일반화 성능 향상 가능성

#### 현재 한계

1. **데이터 규모**: 298 샘플은 딥러닝 일반화에 불충분
2. **단일 공정/장비**: 동일 장비에서 수집한 동질적 데이터로 외부 타당도 미검증
3. **단일 CD**: 14개 CD 중 1개만 검증

#### 일반화 향상을 위한 방향

| 전략 | 방법 | 기대 효과 |
|------|------|-----------|
| **데이터 증강** | 시계열 신호 변환(Time Warping, Jitter) | 소규모 데이터 한계 극복 |
| **전이 학습** | 유사 공정에서 사전 학습 후 Fine-tuning | 신규 공정 적응 가속화 |
| **도메인 적응** | Domain Adversarial Training | 장비 간/공정 간 특징 분포 차이 극복 |
| **교차 검증** | k-fold 또는 Leave-One-Out CV | 성능 추정의 통계적 신뢰성 향상 |
| **베이지안 최적화** | 하이퍼파라미터 자동 탐색 | 최적 정규화 강도 발견 |
| **다중 CD 동시 예측** | Multi-task Learning | 14개 CD를 공동 학습으로 상호 정보 활용 |

> 💡 **Transfer Learning(전이 학습)**: 한 도메인에서 학습한 모델 지식을 다른 도메인에 적용하는 기법. 데이터가 부족한 신규 공정에서 특히 유용함.

> 💡 **Multi-task Learning(다중 작업 학습)**: 여러 관련 목표를 동시에 학습하여 각 작업의 성능을 상호 향상시키는 학습 패러다임.

### 8-2. 2020년 이후 관련 최신 연구 비교 분석

> ⚠️ **중요 주의사항**: 아래 언급하는 2020년 이후 논문들은 제가 직접 원문을 확인한 것이 아닙니다. 제 학습 데이터 기반 정보이므로 **세부 수치의 정확성을 100% 보장할 수 없습니다**. 논문 제목 및 연구 방향 정도는 신뢰할 수 있으나, 구체적 결과 인용 시 반드시 원문을 확인하시기 바랍니다.

#### 관련 연구 흐름 비교

| 연구 방향 | 2017년 본 논문 | 2020년 이후 주요 동향 |
|-----------|--------------|----------------------|
| **모델 구조** | 지도 오토인코더 + Lasso | Transformer 기반 시계열 처리, Graph Neural Network |
| **신호 처리** | 제로 패딩 | Dynamic Time Warping + Attention, Temporal Convolutional Network |
| **설명 가능성** | 없음 | SHAP, LIME 기반 XAI 적용 VM 연구 증가 |
| **데이터 효율** | 298 샘플 | Few-shot learning, Semi-supervised VM |
| **다중 공정** | 단일 스테이지 | Run-to-Run (R2R) 제어 통합 VM |
| **불확실성 정량화** | 없음 | Bayesian Neural Network, Conformal Prediction |

#### 주목할 연구 방향 (일반적 동향 기술)

1. **Transformer/Attention 기반 VM**: 자기 주의 메커니즘이 센서 신호의 시간적 의존성을 명시적으로 포착하여 제로 패딩 문제를 우회
2. **Graph-based Sensor Modeling**: 센서 간 물리적 관계를 그래프로 모델링하여 그룹 정규화보다 정교한 센서 선택
3. **Federated Learning**: 장비/공장 간 데이터 공유 없이 모델 통합 — 본 논문의 단일 데이터셋 한계 극복 가능
4. **Physics-Informed Neural Networks**: 공정 물리 법칙을 신경망에 통합하여 소규모 데이터 문제 완화

> 💡 **Transformer**: 자기 주의 메커니즘(Self-Attention)을 핵심으로 하는 딥러닝 구조. 시계열에서 임의 위치 간 의존성을 효율적으로 모델링함.

> 💡 **Federated Learning(연합 학습)**: 각 장비/공장의 원시 데이터를 공유하지 않고 모델 파라미터만 공유하여 분산 학습하는 기법. 데이터 프라이버시 보호에 유리함.

#### 본 논문이 이후 연구에 미치는 영향

- **방법론적 기여**: 지도 오토인코더 + 그룹 정규화의 결합이 이후 반도체 VM 딥러닝 연구의 기초 프레임워크로 기능
- **문제 정의 기여**: 가변 길이 신호 처리와 센서 자동 선택 문제를 명확히 정의하여 후속 연구의 연구 질문 설정에 기여
- **한계의 연구 촉진**: 소규모 데이터·단일 공정 한계가 전이 학습, 반지도 학습 기반 VM 연구를 촉진

#### 앞으로 연구 시 고려할 점

1. **재현 가능성 확보**: 하이퍼파라미터, 네트워크 구조, 난수 시드를 완전 공개 (본 논문의 주요 미비점)
2. **통계적 엄밀성**: 단일 train/test 분할 대신 k-fold CV 또는 부트스트랩으로 신뢰구간 보고
3. **다중 공정 검증**: 최소 3개 이상의 공정/장비에서 성능 검증으로 일반화 주장 뒷받침
4. **설명 가능성 통합**: 선택된 센서 및 잠재 특징의 공정 도메인 해석 제공
5. **실시간 적용 가능성**: 추론 지연(Latency) 측정 및 엣지 디바이스 배포 가능성 검토
6. **불확실성 정량화**: 예측 신뢰구간 제공으로 공정 엔지니어의 의사결정 지원
