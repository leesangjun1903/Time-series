
# Control relevant issues in semiconductor manufacturing: Overview with some new results
**Su et al., Control Engineering Practice 15 (2007) 1268–1279**

---

## 1. Executive Summary (10문장 이내)

반도체 IC 제조 공정은 300단계 이상의 복잡한 공정으로 구성되며, 품질 측정이 희소하고 어렵다는 근본적인 한계를 가진다.  
웨이퍼 크기가 200mm에서 300mm로 확대되고 피처 크기가 350nm에서 90nm로 축소됨에 따라 정밀 품질 제어의 중요성이 급격히 증가하고 있다.  
본 논문은 반도체 제조의 고유한 공정 제어 문제(측정 지연, 다층 공정, 도구 열화 등)를 체계적으로 분석하고 다층 계층적 제어 아키텍처를 제안한다.  
가상 계측(Virtual Metrology, VM)과 가상 WAT(V-WAT)를 핵심 추정 도구로 활용하는 피드포워드/피드백(FF/FB) 제어 구조를 제안한다.  
급속 열처리(RTP) 공정을 사례로 열응력 기반 온도 레시피 생성과 다변수 PI²D 제어기 설계를 구체적으로 시연하였다.  
런-투-런(R2R) 제어에서 효과적 지연 단위($D_{eff}$) 계산 공식을 도출하여 계측 큐 우선순위 결정에 활용하는 방법을 제시한다.  
공정 모니터링을 위해 핵심 민감 지수(KSI) 기반 접근법을 제안하여 ARMA/ARIMA 모델의 잔차 차이로 예방 유지보수 시점을 예측한다.  
삼각형 온도 프로그램 대비 평활화된 온도 프로그램 사용 시 피크 온도 편차가 11.8°C에서 6.9°C로 감소하는 성능 개선을 실증하였다.  
단일 공정 단계의 성공이 수율 향상을 보장하지 않으므로, VM-V-WAT 통합 추정 시스템의 구축이 필수적임을 강조한다.  
향후 연구 과제로 분산 파라미터 시스템 제어, 가변 모델 파라미터 처리, 혼합 제품 대응 APC 개선이 제시된다.

> **📌 용어 설명**
> - **Virtual Metrology (VM, 가상 계측)**: 실제 측정 없이 공정 데이터(온도, 압력 등)로부터 품질 지표(두께, 저항 등)를 예측하는 소프트 센서
> - **WAT (Wafer Acceptance Test, 웨이퍼 수락 테스트)**: 웨이퍼의 전기적 특성을 검사하는 최종 품질 테스트 (결과까지 약 1주일 소요)
> - **R2R (Run-to-Run) 제어**: 배치(웨이퍼/로트) 단위로 공정 파라미터를 조정하는 피드백 제어 방식
> - **KSI (Key Sensitive Index, 핵심 민감 지수)**: 공정 도구의 열화 추세를 포착하는 단일 지표

### 2-1. 상세 설명: 해결 문제 / 제안 방법 / 모델 구조 / 성능 및 한계

#### ① 해결하고자 하는 문제

```
[문제 1] 측정 지연 및 희소성 → 품질 추정 불가
[문제 2] RTP에서 비균일 온도 분포 → 웨이퍼 열응력 파손
[문제 3] R2R 제어에서 유효 지연 오계산 → 제어 성능 저하
[문제 4] 도구 열화 추세 파악 곤란 → 예방 유지보수 타이밍 미흡
```

#### ② 제안하는 방법 및 수식

**[방법 1] RTP 열전달 모델 (Eq. 1–3)**

$$k \left( \frac{1}{r} \frac{\partial T}{\partial r} + \frac{\partial^2 T}{\partial r^2} \right) - q^{rad} - q^{conv} = \rho C_p \frac{\partial T}{\partial t} $$

경계 조건:

$$\frac{\partial T}{\partial r} = 0 \quad \text{at } r = 0 $$

$$-k \frac{\partial T}{\partial r} = q_{edge} \quad \text{at } r = r_o $$

> **기호 설명**
> - $k$: 실리콘의 열전도율 (W/m·K)
> - $T$: 온도 (°C)
> - $r$: 웨이퍼 반경 방향 위치 (m)
> - $r_o$: 웨이퍼 최대 반경 (m)
> - $q^{rad}$: 단위 웨이퍼 부피당 복사열 손실 (W/m³)
> - $q^{conv}$: 단위 웨이퍼 부피당 대류열 손실 (W/m³)
> - $\rho$: 실리콘 밀도 (kg/m³)
> - $C_p$: 비열 (J/kg·K)
> - $q_{edge}$: 웨이퍼 엣지에서의 열유속 (W/m²)

**[방법 2] 열응력 계산 (Eq. 4–6)**

$$\sigma_{rr} = \alpha E \left( \frac{1}{r_o^2} \int_0^{r_o} T(\eta)\eta \, d\eta - \frac{1}{r^2} \int_0^{r} T(\eta)\eta \, d\eta \right) $$

$$\sigma_{\theta\theta} = \alpha E \left( -T + \frac{1}{r_o^2} \int_0^{r_o} T(\eta)\eta \, d\eta + \frac{1}{r^2} \int_0^{r} T(\eta)\eta \, d\eta \right) $$

$$\sigma_{r\theta} = 0 $$

> **기호 설명**
> - $\sigma_{rr}$: 반경 방향 응력 성분 (Pa)
> - $\sigma_{\theta\theta}$: 접선 방향 응력 성분 (Pa)
> - $\alpha$: 선형 열팽창계수 (1/K)
> - $E$: 영률 (Young's Modulus, Pa) — 재료의 탄성 강도를 나타내는 상수

**[방법 3] 최대 전단 응력 파손 기준 (Eq. 7–9)**

$$S = \frac{\tau_{max} \cdot F_s}{\tau_{yp}} > 1 $$

$$\tau_{max} = \frac{1}{2} |\sigma_{rr} - \sigma_{\theta\theta}| $$

$$\tau_{yp} = 23.17 \exp(16.1 - 0.00916T) \left( \frac{d\tau}{dt} \right)^{0.4} $$

> **기호 설명**
> - $S$: 정규화된 최대 분해 응력 (무차원)
> - $F_s$: 안전계수 (통상 2)
> - $\tau_{max}$: 최대 전단 응력 (Pa)
> - $\tau_{yp}$: 항복 전단 응력 (Pa) — 재료가 소성 변형을 시작하는 응력 한계
> - $T$: 온도 (°C)
> - $d\tau/dt$: 응력 변화율 (Pa/s)

> **📌 용어 설명**
> - **Mohr's Circle (모어의 원)**: 응력 상태를 기하학적으로 표현하는 방법으로, 최대/최소 전단 응력을 시각적으로 계산
> - **항복 응력 (Yield Stress)**: 재료가 영구적 변형을 시작하는 응력 값. 고온에서는 낮아짐 (1000°C에서 ~1.5MPa, 27°C에서 ~310MPa)

**[방법 4] 다변수 PI²D 제어기 (Eq. 10–13)**

공정 전달 함수 행렬:

$$G(s) = K \cdot \text{diag}\left(\frac{1}{\tau_i s + 1}\right) $$

제어기 구조:

$$C(s) = K^{-1} \text{diag}(K_{ii}) $$

$$K_{ii} = K_{c,i} \left(1 + \frac{1}{\tau_{I,i} s} + \tau_{D,i} s \right) \frac{1}{s} $$

IMC 기반 파라미터 튜닝:

$$K_{c,i} = \frac{\tau_i + 2\tau_f}{\tau_f^2}, \quad \tau_{I,i} = \tau_i + 2\tau_f, \quad \tau_{D,i} = \frac{2\tau_i \tau_f}{\tau_i + 2\tau_f} $$

> **기호 설명**
> - $K$: 정상 상태 이득 행렬 (Steady-state gain matrix)
> - $\tau_i$: $i$번째 루프의 시간 상수 (s)
> - $K_{c,i}$: 비례 이득 (Proportional gain)
> - $\tau_{I,i}$: 적분 시간 상수 (Integral time constant, s)
> - $\tau_{D,i}$: 미분 시간 상수 (Derivative time constant, s)
> - $\tau_f$: IMC 필터 시간 상수 (s) — 본 논문에서 개루프 시간 상수의 1/4로 설정

> **📌 용어 설명**
> - **IMC (Internal Model Control)**: 공정 모델을 제어기 내부에 포함시켜 설계하는 방법으로, 단일 튜닝 파라미터($\tau_f$)로 제어기를 설정 가능
> - **PI²D 제어기**: PID에 추가 적분기($1/s$)를 더한 형태로, 램프 형태의 설정점 추종 시 정상 상태 오차를 제거

**[방법 5] R2R 유효 지연 (Eq. 14)**

$$D_{eff} = \text{roundup}(N_m / N_s) $$

> **기호 설명**
> - $D_{eff}$: 유효 지연 단위 (정수)
> - $N_m$: 계측 지연 (측정된 런으로부터 피드백까지 걸리는 런 수)
> - $N_s$: 샘플링 간격 (N_s 런 중 1회 측정)
> - $\text{roundup}(\cdot)$: 올림 함수

**[방법 6] 공정 추세 모니터링 — ARMA/ARIMA 모델 (Eq. 15–17)**

ARMA 모델:

$$(1 - 1.744q^{-1} + 0.776q^{-2})A'_{max}(t) = (1 - 1.346q^{-1} + 0.476q^{-2})e(t) $$

ARIMA 모델:

$$(1 + 0.942q^{-1})\nabla A'_{max}(t) = (1 + 0.452q^{-1} - 0.553q^{-2})e(t) $$

$$\nabla = (1 - q^{-1})$$

KSI 정의:

$$KSI = |Residual_{ARMA} - Residual_{ARIMA}| $$

> **기호 설명**
> - $q^{-1}$: 후방 이동 연산자 (Backward shift operator, $q^{-1}x(t) = x(t-1)$ )
> - $A'_{max}(t)$: 제품 지수로 보정된 핵심 민감 변수의 최댓값
> - $e(t)$: 백색 잡음 (White noise)
> - $\nabla$: 차분 연산자 (Differencing operator)
> - $KSI$: 핵심 민감 지수

> **📌 용어 설명**
> - **ARMA (Auto-Regressive Moving Average)**: 과거 값과 과거 오차의 선형 결합으로 현재 값을 예측하는 시계열 모델
> - **ARIMA (Auto-Regressive Integrated Moving Average)**: ARMA에 차분(differencing)을 추가하여 비정상(non-stationary) 시계열을 처리하는 모델
> - **비정상(Non-stationary) 시계열**: 평균이나 분산이 시간에 따라 변화하는 시계열 (공정 열화 추세가 대표적 예)

#### ③ 모델 구조

```
[계층 1 - 도구 수준 (Tool Level)]
  ├── 온도 레시피 생성 (열응력 기반, Eq. 1-9)
  ├── 측정점 선택 (SSV 기반, Huang et al. 2000c)
  └── 다변수 PI²D 제어기 (Eq. 10-13) + 정적 분리기

[계층 2 - 공정 수준 (Process Level)]
  ├── 가상 계측 (VM): 인라인 측정 → 계측량 추정
  ├── R2R 제어 (EWMA/d-EWMA) + 유효 지연 계산 (Eq. 14)
  └── 피드포워드/피드백 구조

[계층 3 - 제품 수준 (Product Level)]
  ├── 가상 WAT (V-WAT): 계측 데이터 → 전기적 특성 추정
  └── 수율 관리

[계층 4 - 유지보수 (Maintenance Level)]
  └── KSI 기반 예방 유지보수 시점 결정 (Eq. 15-17)
```

> **📌 용어 설명**
> - **SSV (Structured Singular Value, 구조적 단수값)**: 다변수 제어 시스템의 강건성을 평가하는 수학적 도구
> - **EWMA (Exponentially Weighted Moving Average)**: 최근 데이터에 더 높은 가중치를 부여하는 이동 평균 — R2R 제어의 기본 알고리즘

| 온도 제어 | 피크 온도 편차: 삼각형 11.8°C, 평활화 6.9°C | Table 1, p.1275 |

### 분석자(본 보고서)의 해석

| 구분 | 분석자 해석 |
|------|------------|
| 일반화 한계 | 단일 RTP 장비, 단일 fab 환경의 데이터만 사용 → 다른 장비·공정으로의 일반화 근거 부족 |

## 7. 가장 중요한 그림 5개 해석

### 📊 Fig. 1 — 다중 시간 척도의 측정 복잡성 (p.1270)

**해석**: X축(시간 척도: ms~월)과 Y축(측정 복잡성)으로 반도체 제조의 핵심 딜레마를 시각화. 온도/압력 같은 인라인 변수는 ms 단위로 측정 가능하나 제어에 직접 활용하기 어렵고, 실제 품질 지표(WAT, 수율)는 수일~수개월 후에야 파악 가능. 이 그림은 논문 전체의 동기를 함축하며, 추론 제어(VM, V-WAT)의 필요성을 직관적으로 보여줌.

---

### 📊 Fig. 3 — 상세 FF/FB 제어 구조 (p.1271)

**해석**: CVD → CMP → Photo → Etch → WAT로 이어지는 직렬 공정에서, 각 단계마다 VM과 실제 계측(M)이 병행되고, 피드포워드(FF)로 다음 단계에 정보를 전달하며 피드백(FB)으로 자기 단계를 보정. V-WAT가 최상위에서 전체를 조율. 이 구조가 논문의 핵심 아키텍처로, 추론 제어의 구체적 구현 방식을 제시.

---

### 📊 Fig. 9 — 온도 프로그램별 설정점 추종 비교 (p.1275)

**해석**: 삼각형 프로그램(A)에서 PI 제어기는 램프 구간에서 명확한 오프셋 발생 반면, PI²D는 훨씬 개선되나 피크 추종 여전히 어려움. 평활화 프로그램(B)에서 PI²D는 설정점을 효과적으로 추종. 이 그림은 제어기 선택(PI vs. PI²D)과 온도 프로그램 설계(삼각형 vs. 평활화)의 중요성을 동시에 증명.

> **📌 용어 설명**
> - **오프셋 (Offset)**: 설정점과 실제 값 사이의 지속적 차이. PI 제어기는 램프 입력에 대해 구조적으로 오프셋이 발생

---

### 📊 Fig. 12 — ARMA vs. ARIMA 예측 비교 (p.1277)

**해석**: 상단(ARMA): PM 전 구간 말미에 예측값이 실측값에서 이탈하는 발산 현상 명확히 관찰. 하단(ARIMA): 동일 구간에서 실측값을 안정적으로 추종. PM 후 양 모델 모두 초기화되어 다시 정확해짐. 이 패턴이 3번의 PM 주기에 걸쳐 반복적으로 나타나 ARIMA의 우수성을 실증. 그러나 1/20 샘플만 표시된 점은 데이터 밀도 평가를 제한.

---

### 📊 Fig. 13 — KSI 및 PM 시점 (p.1277)

**해석**: KSI가 3번의 PM 시점 직전 모두 급격히 상승하여 뚜렷한 임계값 초과를 보임. PM 후 KSI가 0 근처로 복귀하며 패턴이 반복. 이는 KSI가 도구 열화를 조기에 포착할 수 있음을 시사. 단, 임계값 선 자체가 그림에 명시되어 있지 않아 정확한 판단 기준 파악이 어려운 점이 한계.

### 모델 일반화 성능 향상 가능성 (8-1 중점)

저자들이 제안한 모델들(VM, KSI-ARIMA, PI²D)은 단일 fab의 특정 공정 조건에서 검증되었기 때문에 일반화 성능에 관한 중요한 질문이 남는다.

**현재 일반화의 한계**:
- KSV "변수 A"가 익명 처리되어 다른 fab에서 동일 변수를 식별할 방법 불명확
- ARMA/ARIMA 파라미터(Eq. 15, 16)가 특정 공정 조건에서 추정 → 장비 교체 또는 공정 변경 시 재학습 필요
- PI²D 제어기의 $\tau_f = \tau_i/4$ 규칙은 경험적 근거로, 다른 RTP 시스템에서 최적이 아닐 수 있음

**일반화 성능 향상을 위한 방향**:

1. **전이 학습(Transfer Learning) 적용**: 소스 fab의 VM 모델을 기반으로 타겟 fab에서 소량 데이터로 미세 조정
2. **Bayesian 업데이트 통합**: Kalman 필터(논문에서 언급)를 체계적으로 확장하여 실시간 모델 파라미터 적응
3. **물리 기반 하이브리드 모델(Physics-Informed ML)**: Eq. 1–9의 열역학적 원리를 제약으로 활용하여 데이터 요구량 감소
4. **다중 fab 교차 검증**: 동일 장비 유형에 대해 여러 fab 데이터를 통합한 앙상블 모델 구축
5. **도메인 적응(Domain Adaptation)**: 제품 지수(Fig. 11B)를 일반화하여 제품 유형 변화에 자동 대응

### 8-2. 2020년 이후 관련 최신 연구 비교 분석

> ⚠️ **중요 고지**: 아래 내용은 본 논문(2007)의 연구 방향성을 토대로 AI 학습 데이터(2024년 초까지) 기반으로 파악된 연구 트렌드를 서술한 것입니다. 개별 논문의 구체적 수치나 세부 결과는 직접 원문 확인을 권장합니다.

| 연구 방향 | 2007년 본 논문 | 2020년 이후 연구 트렌드 |
|-----------|---------------|------------------------|
| **가상 계측 (VM)** | 핵심 변수 식별 + 시계열 모델 | 딥러닝(LSTM, Transformer) 기반 VM — 복잡한 비선형 관계 학습 |
| **R2R 제어** | EWMA/d-EWMA + 유효 지연 공식 | 강화학습(RL) 기반 R2R — 가변 파라미터 환경 자동 적응 |
| **공정 모니터링** | KSI(단변량 지수) | 그래프 신경망(GNN) 기반 다변량 FDC — 공정 단계 간 의존성 모델링 |
| **온도 제어 (RTP)** | PI²D + IMC | 모델 예측 제어(MPC) + 신경망 보상 — 비선형 동특성 처리 |
| **수율 예측** | V-WAT (rule-based) | 인과 추론(Causal Inference) + XAI — 수율 저하 근본 원인 파악 |

**본 논문이 미치는 영향**:
- 다층 계층적 제어 아키텍처 개념은 현재 APC 시스템의 표준 설계 원칙으로 자리잡음
- VM과 R2R의 통합 필요성을 초기에 명시적으로 제시한 선구적 연구
- KSI 개념은 이후 더 정교한 건강지수(Health Index) 연구의 토대

**앞으로 연구 시 고려할 점**:

1. **데이터 프라이버시**: fab 간 데이터 공유가 어려우므로 연합 학습(Federated Learning) 접근 필요
2. **설명 가능성(XAI)**: 딥러닝 VM 모델의 블랙박스 문제 — 공정 엔지니어가 이해 가능한 해석 제공 필요
3. **디지털 트윈(Digital Twin)**: Eq. 1–9와 같은 물리 모델을 실시간 디지털 트윈으로 확장하여 가상 검증
4. **극자외선(EUV) 공정**: 2nm 이하 피처에서의 새로운 측정 불확실성 — 기존 VM 패러다임 재검토 필요
5. **에너지 효율 통합**: 탄소 중립 요구에 따라 수율 최적화와 에너지 소비 최적화의 동시 고려 필요
