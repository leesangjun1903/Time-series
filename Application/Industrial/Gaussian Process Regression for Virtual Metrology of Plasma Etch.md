## 1. Executive Summary (10문장 이내)

1. 본 논문은 반도체 플라즈마 식각(Plasma Etch) 공정에서 식각률(Etch Rate)을 실시간으로 예측하기 위해 **가우시안 프로세스 회귀(GPR)**를 가상 계측(Virtual Metrology, VM) 기법으로 적용한 연구이다.
2. 식각률은 공정 중 또는 공정 후 직접 측정이 어렵고 비용과 시간이 많이 소요되므로, 챔버 온도·압력·가스 유량 등 쉽게 측정 가능한 공정 변수로부터 예측하는 VM이 필수적이다.
3. GPR은 비모수적(non-parametric) 기법으로, 베이지안 프레임워크 내에서 예측값의 신뢰구간(Confidence Interval, CI)을 자동으로 제공하는 장점이 있다.
4. 연구는 산업용 반도체 제조 공장의 6개월치 데이터(총 12,133장 웨이퍼)를 사용하였으며, SE·Linear·Matérn·RQ·NN 등 5가지 공분산 함수를 비교 평가하였다.
5. 시간순(Chronological) 데이터에서 최고 성능은 Stepwise 선택된 EP 데이터 + SE 공분산 함수 조합(R²=0.26, MAPE=1.17%)으로 나타났다.
6. 인터리브(Interleaved) 데이터에서 최고 성능은 PCA 축소된 PIM 데이터 + Matérn 공분산 함수 조합(R²=0.73, MAPE=1.10%)으로 나타났다.
7. 전반적으로 GPR의 예측 성능은 공분산 함수 선택에 비교적 둔감하였으며, 단 SE 함수는 고차원 입력(PIM, XR)에서 실패하는 예외를 보였다.
8. GPR은 신경망(ANN) 대비 동등하거나 우수한 성능(ANN: 시간순 MAPE=1.37%, 인터리브 MAPE=1.21%)을 달성하면서도 CI를 자동 산출하는 이점이 있다.
9. 예측 분포 형태의 CI는 공정 엔지니어가 식각률 규격 이탈을 감지하는 데 실용적으로 활용될 수 있다.
10. 연구진은 GPR이 향후 반도체 제조 현장에서 ANN 등 기존 통계 방법과 경쟁하는 VM 기법으로 부상할 가능성이 높다고 결론짓는다.

### 2-1. 해결 문제 · 제안 방법 · 모델 구조 · 성능 · 한계 상세 설명

#### ① 해결하고자 하는 문제

- 식각률의 **직접 측정 불가** 문제: 측정이 비용·시간·파괴적
- **PM 이벤트 전후 공정 특성 변화**로 인한 모델 정확도 저하
- **고차원 공정 변수**(EP 131개 + PIM 159개)에서 유효 변수 선별 필요
- 기존 ANN·PLS 방법 대비 **예측 불확실성 정량화** 부재

#### ② 제안하는 방법 (수식 포함)

**[Step 1] 가우시안 프로세스 정의**

$$f(x_1), f(x_2), \cdots, f(x_n) \sim \mathcal{N}(0, \Sigma)$$

- $f(x_i)$: 입력 $x_i$에서의 함수값 (확률변수)
- $\Sigma_{ij} = k(x_i, x_j)$: 공분산 행렬의 $(i,j)$ 원소

> 💡 **가우시안 프로세스(GP)**: 무한 차원의 다변량 정규분포로 볼 수 있는 확률 과정. 함수 자체를 확률변수로 취급하여 불확실성을 자연스럽게 표현한다.

---

**[Step 2] 노이즈 포함 관측 모델**

$$y = f(x) + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma_n^2)$$

$$y_1, y_2, \cdots, y_n \sim \mathcal{N}(0, K) \quad \cdots (2)$$

$$K = \Sigma + \sigma_n^2 I \quad \cdots (3)$$

- $y$: 관측 출력값 (식각률)
- $\epsilon$: 가우시안 백색 잡음
- $\sigma_n^2$: 잡음 분산
- $K$: 전체 공분산 행렬 ($n \times n$)
- $I$: $n \times n$ 단위 행렬

---

**[Step 3] 공분산 함수 (Covariance/Kernel Functions)**

**① Squared Exponential (SE)**

$$k_{SE}(r) = \nu^2 \exp\!\left(-\frac{(x_i - x_j)^2}{2l^2}\right) \quad \cdots (1)$$

- $\nu$: 출력 스케일 (신호 분산의 제곱근)
- $l$: 길이 스케일(length scale) — 입력 변화에 대한 출력 변화 민감도
- $r = |x_i - x_j|$: 입력 간 거리

> 💡 **길이 스케일(Length Scale)**: 입력 공간에서 얼마나 멀리 떨어진 점들이 서로 상관되는지를 결정. 작을수록 함수가 더 빠르게 변화(높은 유연성), 클수록 더 부드러운 함수를 의미.

**② Linear 공분산**

$$k_{lin}(\mathbf{x}_i, \mathbf{x}_j) = \mathbf{x}_i^T P^{-1} \mathbf{x}_j \quad \cdots (8)$$

- $P \in \mathbb{R}^{d \times d}$: ARD 파라미터를 대각 원소로 갖는 대각 행렬 ($p_{11}, p_{22}, \cdots, p_{dd}$)
- $d$: 입력 공간의 차원 수

**③ Matérn 공분산**

$$k_{Matern}(r) = \frac{2^{1-\nu}}{\Gamma(\nu)} \left(\frac{\sqrt{2\nu}\, r}{l}\right)^{\nu} K_{\nu}\!\left(\frac{\sqrt{2\nu}\, r}{l}\right) \quad \cdots (9)$$

- $\nu$: 미분 가능성 제어 파라미터 ($\nu-1$회 미분 가능)
- $l$: 길이 스케일
- $K_\nu$: 수정된 베셀 함수(Modified Bessel Function)
- $\Gamma(\nu)$: 감마 함수

> 💡 **수정된 베셀 함수(Modified Bessel Function)**: 미분방정식의 해로 등장하는 특수 함수. Matérn 커널에서 함수의 거칠기(roughness)를 제어하는 데 활용된다.

**④ Rational Quadratic (RQ) 공분산**

$$k_{RQ}(r) = \left(1 + \frac{r^2}{2\alpha l^2}\right)^{-\alpha} \quad \cdots (10)$$

- $\alpha$: 스케일 혼합 파라미터 ($\alpha \to \infty$이면 SE와 동일)
- $l$: 길이 스케일

**⑤ Neural Network (NN) 공분산**

$$k_{NN}(\mathbf{x}_i, \mathbf{x}_j) = \sigma \sin^{-1}\!\left(\frac{\tilde{\mathbf{x}}_i^T P^{-1} \tilde{\mathbf{x}}_j}{\sqrt{(1 + \tilde{\mathbf{x}}_i^T P^{-1} \tilde{\mathbf{x}}_i)(1 + \tilde{\mathbf{x}}_j^T P^{-1} \tilde{\mathbf{x}}_j)}}\right) \quad \cdots (11)$$

- $\tilde{\mathbf{x}} = (1, x_1, x_2, \cdots, x_d)^T$: 바이어스 항이 추가된 증강 벡터
- $P = cI$: $c$를 상수로 갖는 스케일 행렬
- $\sigma$: 신호 분산 제어 파라미터

---

**[Step 4] 하이퍼파라미터 최적화 — 로그 주변 우도 최대화**

$$\log p(y|X) = -\frac{1}{2}\mathbf{y}_{tr}^T K^{-1} \mathbf{y}_{tr} - \frac{1}{2}\log|K| - \frac{N}{2}\log(2\pi) \quad \cdots (4)$$

- $\mathbf{y}_{tr}$: 훈련 출력 벡터
- $K^{-1}$: 공분산 행렬의 역행렬
- $|K|$: 공분산 행렬의 행렬식(determinant)
- $N$: 훈련 데이터 수
- 첫째 항 $-\frac{1}{2}\mathbf{y}\_{tr}^T K^{-1} \mathbf{y}_{tr}$: **데이터 적합도(data fit)** 항
- 둘째 항 $-\frac{1}{2}\log|K|$: **모델 복잡도 패널티(complexity penalty)** 항

> 💡 **로그 주변 우도(Log Marginal Likelihood)**: 하이퍼파라미터가 주어졌을 때 관측 데이터가 얼마나 그럴듯한지를 측정하는 값. 이를 최대화하면 과적합 없이 데이터를 가장 잘 설명하는 하이퍼파라미터를 찾을 수 있다.

> 💡 **ARD (Automatic Relevance Determination, 자동 관련성 결정)**: 각 입력 차원마다 별도의 길이 스케일을 부여하여, 중요하지 않은 변수는 자동으로 긴 길이 스케일을 갖게 되어 사실상 무시되는 자동 변수 선택 메커니즘.

---

**[Step 5] 예측 (Posterior Prediction)**

```math
\mu(x_*) = \mathbf{k}_* K^{-1} \mathbf{y}_{tr} \quad \cdots (5)
```

```math
\sigma^2(x_*) = k_{**} - \mathbf{k}_* K^{-1} \mathbf{k}_*^T + \sigma_n^2 \quad \cdots (6)
```

- $x_\*$: 테스트(미관측) 입력점
- $\mathbf{k}\_\* = [k(x_\*, x\_1), k(x_\*, x_2), \cdots, k(x_\*, x_n)]$: 테스트-훈련 간 공분산 벡터
- $k_{**} = k(x_\*, x_*)$: 테스트 입력의 자기 공분산(prior variance)
- $\mathbf{k}\_\* K^{-1} \mathbf{k}_*^T$: 사후 분산 감소량 (훈련 데이터로 인한 불확실성 감소)

---

#### ③ 모델 구조

```
[입력 변수 선택]
    EP (131→28개) / PIM (159개) / XR (104개) / EP+
         ↓
[전처리: PCA 또는 Stepwise Selection]
         ↓
[GPR 모델 학습]
    - 5가지 공분산 함수 (ARD 버전)
    - 하이퍼파라미터: 랜덤 초기화 5회 → 로그 주변 우도 최대화
         ↓
[예측 출력]
    - 식각률 예측값 μ(x*)
    - 예측 분산 σ²(x*) → 95% CI 제공
```

| 계측 희소성(4.4%) | 전체 웨이퍼 중 4.4%만 계측된 상황에서 R²=0.73이 실제 공정 전체를 대표하기 어려울 수 있음 |

| CI의 실용적 가치 | ANN이 제공하지 못하는 **불확실성 정량화**는 SPC(통계적 공정 관리) 관점에서 독보적 장점 |

> 💡 **데이터 누수(Data Leakage)**: 테스트 데이터의 정보가 훈련 과정에 의도치 않게 유입되어 모델 성능이 과대평가되는 현상. 인터리브 방식에서 동일 PM 사이클 데이터가 훈련/테스트에 혼재되면 발생 가능.

### 📊 Figure 1 — 길이 스케일에 따른 GP 출력 예시 (p.2)

**내용**: 동일 GP 모델에서 길이 스케일 $l = 0.5, 1.5, 5$일 때의 출력 함수 형태 비교

**해석**:
- $l=0.5$ (짧은 길이 스케일): 출력 함수가 급격히 진동 → **과적합 위험** 높음

- GPR의 ARD 메커니즘이 각 입력 변수마다 최적 $l$을 자동 탐색함을 시각적으로 설명
- 플라즈마 식각처럼 비선형 공정에서 적절한 $l$ 선택이 핵심임을 보여줌

### 📊 Figure 2 — 1차원 GP 예측과 95% 신뢰구간 (p.3)

**내용**: 훈련 데이터 포인트 주변은 CI가 좁고, 훈련 데이터에서 먼 영역은 CI가 넓어지는 모습

**해석**:
- 수식 (6): $\sigma^2(x_\*) = k_{**} - \mathbf{k}\_\* K^{-1} \mathbf{k}\_\*^T + \sigma_n^2$에서 $\mathbf{k}_*$가 작아질수록 $\sigma^2$이 커짐을 직관적으로 보여줌
- **실용적 의미**: 식각 공정에서 모델이 본 적 없는 공정 조건 구간에서는 CI가 자동으로 넓어져 엔지니어에게 경고 역할
- ANN은 이러한 불확실성 정량화를 제공하지 못함 → GPR의 핵심 차별점

### 📊 Figure 3 — 정규화된 식각률 예측과 CI (p.6)

**내용**: 인터리브 PIM 데이터로 학습된 GPR 모델의 예측값, 실측값, 95% CI를 웨이퍼 번호 기준으로 도시

**해석**:
- **파란 음영(CI)**: 예측 불확실성 범위 — 고주파 변동이 CI 내에 포함됨
- 예측값(점선)이 실측값(실선)의 전반적 추세를 따르나, **급격한 국소 변동은 추적 못함**
- 논문 저자는 이 변동이 "수집 데이터에 반영되지 않은 외부 교란"이라고 해석 → **관측되지 않은 변수 존재 가능성**
- CI가 실측값을 대부분 포함 → GPR CI의 **현실적 보정(calibration)** 품질 시각적 확인
- 공정 엔지니어는 이 CI를 SPC 관리 한계로 활용 가능

> 💡 **SPC (Statistical Process Control, 통계적 공정 관리)**: 공정의 품질 특성을 통계적으로 모니터링하고 관리 한계를 벗어나는 이상 신호를 탐지하는 방법론.

### 8-1. 모델의 일반화 성능 향상 가능성 (중점)

#### 현재 일반화 한계

시간순 데이터에서 R²=0.26(최고)는 **PM 이벤트 이후 공정 변화**에 GPR이 적응하지 못함을 의미한다. 일반화 성능 향상을 위한 방향:

**① 도메인 적응형 GPR (Domain Adaptive GPR)**

PM 이벤트를 경계로 데이터를 세그멘트하고, 각 세그멘트에 대한 로컬 GP 모델을 구성:

```math
\mu_{local}(x_*) = \mathbf{k}_{*, local} K_{local}^{-1} \mathbf{y}_{tr, local}
```

- PM 이전/이후 데이터를 별도 GP로 모델링하여 도메인 시프트 대응

**② 스파스 GP (Sparse GP / Inducing Point Methods)**

$$p(\mathbf{f} | \mathbf{u}) \approx \prod_{i} p(f_i | \mathbf{u})$$

- 유도점(Inducing Points) $m \ll n$개를 사용하여 $O(nm^2)$로 복잡도 감소
- 대규모 데이터셋에서의 일반화 가능

**③ 전이 학습 기반 GPR (Transfer Learning GPR)**

여러 챔버·장비의 데이터를 공유 GP 커널로 학습:

$$k_{transfer}(x_i, x_j) = k_{shared}(x_i, x_j) + k_{local}(x_i, x_j)$$

- 공유 공분산: 장비 공통 특성 포착
- 로컬 공분산: 장비별 개별 특성 포착

**④ 온라인/재귀적 GPR (Online/Recursive GPR)**

새로운 계측 데이터 수신 시 하이퍼파라미터를 점진적으로 갱신:

$$K_{n+1} = \begin{pmatrix} K_n & \mathbf{k}_n \\ \mathbf{k}_n^T & k_{nn} \end{pmatrix}$$

- 계측 주기(4.4%)가 낮은 환경에서도 점진적 모델 갱신으로 일반화 유지

### 8-2. 2020년 이후 최신 연구 비교 분석

> ⚠️ **주의**: 이하 최신 연구 정보는 제 학습 데이터(2023년 초까지) 기반 지식에서 제공되며, 개별 논문의 구체적 수치는 직접 원문 확인이 필요합니다.

#### 관련 최신 연구 동향

| 연구 방향 | 내용 | 본 논문과의 관계 |
|----------|------|-----------------|
| **Deep GP** (Damianou & Lawrence, 2013; 이후 확장) | GP를 여러 층으로 쌓아 복잡한 비선형 관계 포착 | 본 논문의 단층 GP 한계 극복 가능 |
| **Sparse GP/Inducing Methods** (Titsias, 2009; 이후 산업 적용) | 대규모 반도체 데이터에서 $O(n^3)$ 극복 | 본 논문의 계산 복잡도 한계 해결 |
| **Bayesian Neural Networks** | BNN으로 CI 제공 — GP와 경쟁 | GPR의 핵심 장점(CI)이 BNN으로도 가능해짐 |
| **Physics-informed ML** | 플라즈마 물리 방정식을 GP prior에 통합 | 본 논문은 순수 데이터 기반 — 물리 지식 활용 시 일반화 향상 가능 |
| **Multi-output GP** | 식각률, 식각 깊이, 균일도를 동시 예측 | 본 논문은 식각률 단일 출력 — 다출력 확장 필요 |
| **Transformer 기반 VM** (2021~) | 시계열 공정 데이터에 Attention 메커니즘 적용 | GPR 대비 대규모 데이터에서 유리할 수 있음 |

#### 본 논문이 이후 연구에 미치는 영향

1. **GPR의 VM 적용 선구적 시연**: 반도체 공정 VM 분야에서 GPR 활용의 초기 증거 제공
2. **CI 제공의 중요성 부각**: 이후 연구들이 불확실성 정량화를 핵심 요구사항으로 인식하는 데 기여
3. **공분산 함수 비교 프레임워크**: 다양한 커널 함수의 체계적 비교 방법론 제시
4. **한계 노출**: 시간순 일반화 문제, SE 고차원 실패, 계산 복잡도 → 이후 Sparse GP, Transfer Learning GP 연구를 촉진

#### 앞으로 연구 시 고려할 점

| 고려 사항 | 구체적 내용 |
|----------|-----------|
| **데이터 분할 방법** | 인터리브 방식의 데이터 누수 가능성을 항상 검토; 실제 배포 시나리오와 동일한 시간순 분할 우선 사용 |
| **계산 확장성** | 웨이퍼 수가 수만 개 이상일 때 Sparse GP(SVGP, FITC 등) 적용 필수 |
| **도메인 시프트 대응** | PM 이벤트, 챔버 교체 등 비정상성(non-stationarity) 처리를 위한 적응형 커널 또는 온라인 학습 메커니즘 필요 |
| **물리 정보 통합** | 플라즈마 식각 물리(Bohm velocity, ion flux 등)를 GP prior에 통합하여 소량 데이터 환경에서 일반화 향상 |
| **다출력 GP** | 식각률, 균일도, 선택비 등 여러 공정 결과물을 동시 예측하는 Multi-output GP 구축 |
| **통계적 유의성 검증** | 모델 간 성능 비교 시 반드시 통계적 가설 검정(paired t-test, Wilcoxon 검정 등) 적용 |
| **CI 보정(Calibration) 평가** | 예측 CI가 실제로 명목 확률을 달성하는지 ECE(Expected Calibration Error) 등으로 평가 필요 |
| **실시간 적용 가능성** | 웨이퍼당 추론 시간이 생산 Takt time 내에 수행 가능한지 평가 |
