# Machine Learning based CVD Virtual Metrology in Mass Produced Semiconductor Process
**저자:** Yunsong Xie, Ryan Stearrett (Samsung Austin Semiconductor, 2021)
**출처:** arXiv:2107.05071v2 [cs.LG] 28 Jul 2021

---

## 1. Executive Summary (10문장 이내)

1. 반도체 대량 생산 공정에서 CVD(Chemical Vapor Deposition) 공정의 품질 관리를 위해 물리적 계측 대신 머신러닝 기반 **가상 계측(Virtual Metrology, VM)** 시스템을 구축하고 그 성능을 종합 비교 평가하였다.
2. 본 연구는 VM 성능에 영향을 미치는 세 가지 핵심 요소 — **결측치 대체(Data Imputing), 특징 선택(Feature Selection), 회귀 알고리즘(Regression)** — 에 대한 최초의 통합 크로스 벤치마크를 수행하였다.
3. 총 715개의 FDC(Fault Detection and Classification) 센서 피처를 포함하며, 데이터의 약 50~70%가 결측치인 현실적인 대량 생산 환경 데이터를 사용하였다.
4. 선형 알고리즘(LLS, PLS, BR, SVR)은 심각한 과소적합(underfitting)을 보였으며, 비선형 알고리즘(GB, NN)만이 의미 있는 예측 정확도를 달성하였다.
5. 결측치 대체 방법 중 **Nearest 임퓨팅**이 최고 성능을, **Random 임퓨팅**이 최저 성능을 나타냈다.
6. 최적 조합인 "Nearest 임퓨팅 + 비선형 피처 선택 + GB/NN 회귀"를 사용할 때 테스트 데이터셋에서 최대 $R^2 = 0.7$의 예측 정확도를 달성하였다.
7. 이는 CVD 공정 변동의 **70% 감소**가 가능함을 의미하며, 물리적 계측 빈도 절감과 웨이퍼 품질 향상으로 이어질 수 있다.
8. 피처 수 약 100~150개 수준에서 최적 테스트 정확도가 달성되었으며, 이 시점에서 결측 데이터 비율(MDAR)이 국소 최솟값을 형성함을 확인하였다.
9. 본 연구는 VM 커뮤니티에서 결측치 처리 방법이 예측 정확도에 미치는 영향을 체계적으로 분석한 **최초의 연구**이다.
10. 연구 결론은 향후 CVD VM 개발의 표준 파이프라인 기초를 제공하며, 비선형 알고리즘과 Nearest 임퓨팅의 조합을 표준 권장 방법으로 제시한다.

### 1-1. 연구의 목적과 필요성

| 구분 | 내용 |
|------|------|

## 2-1. 상세 기술 분석

### 🔴 해결하고자 하는 문제

- 대량 생산 CVD 공정에서 모든 웨이퍼 물리 계측의 **비용·시간 문제**
- 기존 VM 연구의 세 가지 한계:
  1. 결측치를 단순 제거하여 정보 손실 (약 70%만 가용)
  2. 선형 알고리즘 위주로 비선형 패턴 미포착
  3. 데이터 임퓨팅, 피처 선택, 회귀 알고리즘을 통합 비교한 연구 부재

---

### 🟡 제안하는 방법 및 수식

#### (1) 정확도 지표: $R^2$ (결정계수)

$$R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2}$$

| 기호 | 설명 |
|------|------|
| $y_i$ | $i$번째 실제 계측값 |
| $\hat{y}_i$ | $i$번째 모델 예측값 |
| $\bar{y}$ | 전체 실제 계측값의 평균 |
| $n$ | 샘플 수 |

> **💡 용어 설명**
> - **$R^2$ (결정계수):** 모델이 데이터의 분산을 얼마나 잘 설명하는지 나타내는 지표. 1에 가까울수록 예측 성능이 높음

#### (2) MDAR (Mean Data Available Ratio, 평균 데이터 가용률) — 논문 수식 (1)

$$MDAR = \frac{\displaystyle\sum_{i=1}^{M}\sum_{j=1}^{N} A_{ij}}{MN}$$

| 기호 | 설명 |
|------|------|
| $M$ | 선택된 입력 피처(feature)의 수 |
| $N$ | 전체 샘플(웨이퍼) 수 |
| $A_{ij}$ | $i$번째 피처의 $j$번째 샘플 데이터 가용 여부. 데이터가 있으면 1, 결측이면 0 |
| $MDAR$ | 전체 선택 피처-샘플 조합 중 실제 데이터가 존재하는 비율 |

> **💡 용어 설명**
> - **MDAR:** 피처 선택 과정에서 선택된 피처들의 평균적 데이터 완전성 지표. MDAR이 낮을수록 결측치가 많아 임퓨팅 의존도가 높음

#### (3) 5가지 결측치 대체(Imputation) 방법

| 방법 | 수식/원리 | 특징 |
|------|-----------|------|
| **ARIMA** | $X_t = c + \sum_{i=1}^p \phi_i X_{t-i} + \sum_{j=1}^q \theta_j \epsilon_{t-j} + \epsilon_t$ | 시계열 패턴 활용 |
| **KNN** | $\hat{x}\_{missing} = \frac{1}{k}\sum_{l=1}^k x_l$ (k개 최근접 이웃 평균) | 유사 샘플 활용 |
| **Nearest** | $\hat{x}\_{missing} = x_{t_{prev}}$ (직전 가용 데이터) | 가장 최근 값 사용 |
| **Random** | $\hat{x}\_{missing} \sim U(0, 1)$ | 무작위 균일분포 |
| **Random Forest** | 앙상블 트리 기반 예측 대체 | 피처 간 관계 활용 |

> **💡 용어 설명**
> - **ARIMA (AutoRegressive Integrated Moving Average):** 과거 값(AR), 차분(I), 이동평균(MA)을 결합한 시계열 예측 모델. $\phi_i$: AR 계수, $\theta_j$: MA 계수, $\epsilon_t$: 잔차

#### (4) 피처 선택 알고리즘 (반복적 축소)

피처 수 감소 비율 $r$:
$$NIF_{next} = \lfloor NIF_{current} \times (1 - r) \rfloor, \quad r \in [0.08, 0.11]$$

| 기호 | 설명 |
|------|------|
| $NIF_{current}$ | 현재 반복의 입력 피처 수 |
| $NIF_{next}$ | 다음 반복의 입력 피처 수 |
| $r$ | 피처 감소 비율 (8~11%) |

---

### 🟢 모델 구조

```
[원시 FDC 데이터 715 피처]
        ↓
[결측치 임퓨팅: ARIMA / KNN / Nearest / Random / RF]
        ↓
[정규화: 0~1 스케일링]
        ↓
[데이터 분할: Train(70%) / Dev(15%) / Test(15%)]
        ↓
[반복적 피처 선택 (8~11% 감소)]
        ↓
[회귀 알고리즘 학습]
  ├── 선형: LLS / PLS / Bayesian Ridge / SVR
  └── 비선형: Gradient Boosting / Neural Network
        ↓
[하이퍼파라미터 최적화 (Dev 셋 기준)]
        ↓
[최종 테스트 정확도 평가 (R²)]
```

> **💡 용어 설명**
> - **Gradient Boosting (GB):** 약한 학습기(주로 결정 트리)를 순차적으로 결합하여 이전 모델의 잔차를 학습하는 앙상블 방법
> - **Neural Network (NN):** 입력층-은닉층-출력층으로 구성된 비선형 함수 근사기. 본 논문에서는 완전연결(fully connected) 구조 사용
> - **하이퍼파라미터:** 모델 훈련 전 사람이 설정하는 파라미터 (예: 트리 깊이, 학습률 등)

### 🔵 성능 향상 및 한계

| 구분 | 내용 |
|------|------|
| **성능 향상** | Nearest + 비선형(GB/NN): 테스트 $R^2 \approx 0.7$ |
| **성능 향상** | 선형 대비 비선형 알고리즘: 약 40~50% 정확도 향상 |
| **성능 향상** | Random 임퓨팅 대비 Nearest: 약 10~15% 개선 |
| **한계 1** | 삼성 오스틴 반도체 단일 공정·단일 설비 데이터 → 일반화 불확실 |
| **한계 2** | 피처 및 공정 세부 정보 미공개 (영업 기밀) → 재현 불가 |
| **한계 3** | NN 구조(층 수, 뉴런 수 등) 상세 미기술 |
| **한계 4** | 샘플 수 및 절대적 데이터 규모 미공개 |
| **한계 5** | 결측치가 MCAR/MAR/MNAR 중 어떤 유형인지 분석 없음 |
| **한계 6** | $R^2 = 0.7$ 달성 시 나머지 30% 변동의 원인 미분석 |

> **💡 용어 설명**
> - **MCAR/MAR/MNAR:** 결측치 발생 메커니즘 분류. MCAR(완전 무작위), MAR(다른 변수에 의존적 무작위), MNAR(결측 자체가 값에 의존)

### 📌 저자가 직접 보고한 결과

| 항목 | 저자 보고 내용 |
|------|----------------|
| 최고 예측 정확도 | 테스트셋 기준 $R^2 \approx 0.7$ (GB 및 NN 모두) |

| 데이터 가용률 | 500개 피처가 약 50% 가용, 60개 피처만 >95% 가용 |

### 📌 분석자(필자)의 해석

| 항목 | 해석 |
|------|------|
| GB 과적합 vs NN 균형 | GB의 훈련 $R^2=0.95$ 대비 테스트 $R^2=0.7$은 과적합 명확. NN의 훈련-테스트 정확도 수렴은 더 신뢰할 수 있는 일반화를 의미 |
| Nearest 임퓨팅 우수성 원리 | 제조 공정의 연속성(temporal continuity) 특성상 직전 관측값이 결측 시점의 실제 공정 상태에 가장 근접하기 때문으로 해석 가능 |
| MDAR 최솟값과 정확도 관계 | 정확도 예측에 기여하는 핵심 피처들이 결측률이 높음을 의미. 즉, 결측 처리가 더 중요한 역할을 함 |
| $R^2 = 0.7$의 실용적 한계 | 30%의 설명되지 않는 변동은 측정되지 않은 환경 요인, 소재 특성 변화 또는 공정 간 상호작용에 기인할 가능성 있음 |
| 단일 공장 데이터의 위험성 | 삼성 오스틴 단일 팹(fab) 데이터만 사용하여 다른 제조 환경에의 적용 가능성은 검증되지 않음 |

> **💡 용어 설명**
> - **과적합(Overfitting):** 훈련 데이터에는 높은 정확도를 보이지만, 새로운 데이터에는 성능이 떨어지는 현상
> - **과소적합(Underfitting):** 모델이 너무 단순하여 훈련 데이터의 패턴조차 제대로 학습하지 못하는 현상

| 구분 | 내용 | 문제점 |
|------|------|--------|
| ⚠️ **샘플 수 미공개** | 훈련/테스트 분할 비율(70/15/15%)만 제시 | 절대 샘플 수 불명 → 통계적 검정력 평가 불가 |
| ⚠️ **단일 반복 실험** | 교차 검증(Cross-Validation) 미사용 | 결과의 안정성·재현성 불확실 |
| ⚠️ **신뢰구간 부재** | 모든 $R^2$ 수치가 단일 값으로만 보고 | 표준편차, 95% CI 없음 → 통계적 유의성 불명 |
| ⚠️ **NN 구조 미기술** | "Fully connected neural network"만 언급 | 층 수, 뉴런 수, 활성화 함수, 드롭아웃 등 미공개 → 재현 불가 |
| ⚠️ **70% 변동 감소 주장** | $R^2=0.7$ → 70% 공정 변동 감소로 연결 | 참고문헌 [47-49] 기반이나, 실제 R2R 적용 후 검증 없음 |
| ⚠️ **피처 정보 완전 비공개** | "영업 기밀" 이유로 피처명 비공개 | 도메인 전문가 검토 및 재현 불가 |
| ⚠️ **GB vs NN 동등성** | 두 알고리즘 모두 ~0.7로 보고 | 통계적 유의미한 차이 검정 없음 |
| ⚠️ **임퓨팅 방법 비교** | 시각적 누적 분포 비교에만 의존 | Wilcoxon 검정 등 통계적 비교 없음 |

## 6. 논문이 답하지 않는 질문

1. **NN 아키텍처는 무엇인가?** 층 수, 뉴런 수, 활성화 함수, 옵티마이저, 학습률 등 완전히 미기술
2. **전체 샘플 수는 얼마인가?** 통계적 검정력 평가의 기본 전제 정보 부재
3. **결측치 발생 메커니즘은?** MCAR/MAR/MNAR 분류 없이 임퓨팅 방법 선택
4. **다른 공정·팹(fab)에서도 동일한 결과가 나오는가?** 단일 공장 데이터 한계
5. **30%의 설명되지 않는 변동의 원인은?** 미측정 변수, 계측 노이즈, 모델 구조적 한계 중 어느 것인지 불명
6. **R2R 루프에 실제 통합 시 성능은?** 시뮬레이션이 아닌 실제 생산 라인 검증 없음
7. **GB의 과적합을 억제하면 NN보다 나은가?** 정규화, 조기 종료 등 과적합 방지 미적용 상태의 비교
8. **시간에 따른 모델 드리프트(drift)는?** 장비 노화, 소모품 교체 등에 따른 장기 안정성 미검토
9. **최적 피처 100~150개는 어떤 물리적 의미를 갖는가?** 영업 기밀로 피처명 비공개
10. **딥러닝(CNN, LSTM, Transformer) 적용 시 성능은?** Fully connected NN만 비교에 포함

> **💡 용어 설명**
> - **드리프트(Drift):** 시간이 지남에 따라 장비나 공정 특성이 서서히 변화하는 현상으로, 모델 예측 정확도 저하 원인이 됨

### 8-1. 모델 일반화 성능 향상 가능성

#### 현재 일반화 한계

본 논문에서 확인되는 일반화 위협 요인:

1. **데이터 단일 출처 편향:** 삼성 오스틴 반도체 단일 팹의 단일 CVD 공정 데이터만 사용
2. **GB의 과적합 구조:** 훈련($R^2=0.95$) → 테스트($R^2=0.7$) 간 25%p 괴리
3. **시간적 일반화 미검증:** 장비 노화, 소모품 교체, 계절 변화에 따른 드리프트 미검토
4. **교차 검증 부재:** 단일 Train/Dev/Test 분할로 분할 방법 의존성 존재

#### 일반화 향상을 위한 구체적 방법

**① 정규화를 통한 과적합 억제:**

$$L_{total} = L_{prediction} + \lambda \Omega(\theta)$$

$$L_1: \Omega(\theta) = \sum_j |\theta_j|, \quad L_2: \Omega(\theta) = \sum_j \theta_j^2$$

| 기호 | 설명 |
|------|------|
| $L_{prediction}$ | 예측 손실 (예: MSE) |
| $\lambda$ | 정규화 강도 하이퍼파라미터 |
| $\Omega(\theta)$ | 정규화 항 |
| $\theta_j$ | $j$번째 모델 파라미터 |

**② k-Fold 교차 검증:**

$$CV_{score} = \frac{1}{k}\sum_{i=1}^{k} R^2_i$$

현재 단일 분할 대신 k=5 또는 k=10 폴드 교차 검증으로 분산 추정

**③ 도메인 적응(Domain Adaptation):**

서로 다른 팹/장비 간의 분포 차이를 최소화:

$$\min_\theta \mathcal{L}_{source}(\theta) + \gamma \cdot d(\mathcal{D}_{source}, \mathcal{D}_{target})$$

여기서 $d(\cdot,\cdot)$는 두 도메인 간의 통계적 거리(예: MMD, KL-divergence)

**④ 앙상블을 통한 분산 감소:**

$$\hat{y}_{ensemble} = \frac{1}{T}\sum_{t=1}^{T} \hat{y}_t$$

$T$개의 서로 다른 모델 예측의 평균으로 단일 모델 분산 감소

> **💡 용어 설명**
> - **도메인 적응(Domain Adaptation):** 한 환경(소스 도메인)에서 학습된 모델이 다른 환경(타겟 도메인)에서도 잘 작동하도록 하는 전이 학습의 한 방법
> - **MMD (Maximum Mean Discrepancy):** 두 확률 분포 간의 거리를 측정하는 통계적 지표

### 8-2. 2020년 이후 최신 연구 비교 분석

> **⚠️ 중요 고지:** 아래 연구 동향은 본 논문의 참고문헌, 공개 학술 데이터베이스(arXiv, IEEE Xplore, Google Scholar)의 일반적 지식 기반으로 기술합니다. 개별 논문의 구체적 수치는 직접 검색·확인을 권장합니다.

#### 2020년 이후 VM/반도체 공정 ML 연구 동향

| 연구 방향 | 대표적 발전 | 본 논문과의 관계 |
|-----------|-------------|-----------------|
| **Transformer/Attention 기반 VM** | 시계열 FDC 데이터의 장기 의존성 포착에 유리 | 본 논문 NN은 FC 구조로 시간적 순서 미반영 |
| **Graph Neural Network (GNN)** | 다중 챔버, 다중 공정 간 상호의존성 모델링 | 본 논문은 단일 CVD 공정, 독립 피처 가정 |
| **Physics-Informed Neural Network (PINN)** | 반도체 물리 법칙을 손실 함수에 통합 | 본 논문은 데이터 기반으로 도메인 지식 미활용 |
| **Federated Learning (연합 학습)** | 다중 팹의 데이터를 공유 없이 모델 공동 학습 | 본 논문 단일 팹 한계 극복 가능성 |
| **AutoML/NAS** | 하이퍼파라미터·아키텍처 자동 탐색 | 본 논문 수동 하이퍼파라미터 최적화 한계 보완 |
| **불확실성 정량화 (Bayesian DL)** | 예측값과 함께 신뢰 구간 제공 | 본 논문 점 추정(point estimate)만 제공 |
| **대규모 사전학습 모델의 반도체 적용** | BERT류 모델의 공정 데이터 사전학습 | 본 논문 구조에 전이 학습 적용 가능성 |

#### 본 논문이 이후 연구에 미치는 영향

1. **결측치 처리의 중요성 각인:** 이후 VM 연구에서 결측치 처리를 필수 파이프라인으로 포함하는 표준을 제시
2. **비선형 알고리즘의 필요성 확립:** 선형 모델 위주였던 CVD VM 연구에 비선형 알고리즘 전환의 실증적 근거 제공
3. **크로스 벤치마크 방법론 확립:** 단일 알고리즘 제안이 아닌 비교 기반의 연구 방법론 도입
4. **Nearest 임퓨팅의 실용성 제안:** 계산 비용이 낮고 구현이 간단한 Nearest 임퓨팅이 복잡한 방법(ARIMA, RF)보다 우수함을 증명 → 실제 생산 환경에 즉시 적용 가능

#### 향후 연구 시 고려할 점

| 고려 사항 | 세부 내용 |
|-----------|-----------|
| **1. 시간적 구조 모델링** | LSTM, Temporal Convolutional Network, Transformer를 활용하여 FDC 데이터의 시계열 패턴 포착 |
| **2. 다중 공정 일반화** | CVD 외 CMP, Etch 등 다른 공정에서의 동일 파이프라인 검증 |
| **3. 온라인 학습(Online Learning)** | 공정 드리프트에 적응하는 점진적 모델 업데이트 메커니즘 도입 |
| **4. 불확실성 정량화** | 예측 신뢰구간 제공으로 R2R 제어 시스템의 안전 마진 설정 |
| **5. 결측치 메커니즘 분석** | MCAR/MAR/MNAR 분류 후 메커니즘에 적합한 임퓨팅 방법 선택 |
| **6. 소수 공정 데이터 적응** | 새로운 공정/장비 도입 시 소량 데이터로 모델 적응하는 Few-Shot Learning |
| **7. 설명 가능성(XAI) 강화** | SHAP, LIME 등으로 예측 근거 제공하여 엔지니어 신뢰성 확보 |
| **8. 다목표 최적화** | 두께 외에 균일도, 결함 밀도 등 다중 품질 지표 동시 예측 |

> **💡 용어 설명**
> - **PINN (Physics-Informed Neural Network):** CVD 반응 속도론, 열전달 방정식 등 물리 법칙을 신경망 학습 과정에 제약 조건으로 통합하는 방법
> - **Federated Learning (연합 학습):** 각 팹의 원시 데이터를 공유하지 않고 모델 파라미터만 교환하여 개인정보·영업 기밀을 보호하며 협업 학습하는 방법
> - **SHAP (SHapley Additive exPlanations):** 게임 이론 기반으로 각 피처가 예측 결과에 기여하는 정도를 정량화하는 설명 가능 AI 방법
> - **Few-Shot Learning:** 소량의 새로운 데이터만으로 모델을 빠르게 적응시키는 메타 학습 방법
