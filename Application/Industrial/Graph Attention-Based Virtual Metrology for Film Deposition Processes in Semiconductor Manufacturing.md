## 1. Executive Summary (10문장 이내)

1. 반도체 제조 공정에서 물리적 계측(Physical Metrology)은 측정 지연, 비용, 샘플링 제약으로 인해 고용량 생산 환경에서 확장성이 떨어집니다.
2. 본 연구는 이러한 한계를 극복하기 위해 박막 증착(Film Deposition) 공정에서 장비 센서 데이터만으로 웨이퍼 박막 두께를 예측하는 **그래프 어텐션 기반 가상 계측(Virtual Metrology, VM)** 프레임워크를 제안합니다.
3. 각 공정 단계(Step)–파라미터(Parameter) 쌍을 그래프 노드로 표현하고, Conv1D로 시계열 특징을 추출합니다.
4. 파라미터-레이어 그래프 어텐션 메커니즘을 통해 각 박막 레이어가 관련 공정 정보를 선택적으로 집계하도록 모델링합니다.
5. 인텔 파운드리(Intel Foundry)의 실제 생산 웨이퍼 데이터(804개)를 사용하여 모델을 검증했습니다.
6. 제안 모델은 MLP 베이스라인($R^2 = 0.7106$) 및 어블레이션 변형($R^2 = 0.7061$) 대비 $R^2 = 0.7227$을 달성하며 우수한 예측 성능을 보입니다.
7. 학습된 어텐션 가중치는 물리적 공정 거동과 일치하는 해석 가능한 파라미터-레이어 관계를 드러냅니다.
8. 온도 관련 파라미터와 초기 공정 단계가 대부분 박막 레이어에 지배적인 영향을 미침을 확인했습니다.
9. 이 프레임워크는 예측 정확도 향상뿐 아니라, 블랙박스 한계를 극복한 공정 모니터링 및 최적화를 위한 해석 가능성을 제공합니다.
10. 향후 연구로 물리 기반 제약 통합, 웨이퍼 내 비균일성 모델링, 도메인 전문가와의 검증 협업을 제시합니다.

### 1-1. 연구의 목적과 필요성

> **[p.1, Introduction]**

**필요성:**
- 현대 반도체 소자는 수십~수백 개의 박막 레이어로 구성되며, 각 레이어의 두께·조성·균일성이 소자 성능과 수율을 직접 결정합니다.
- 물리적 계측(CD-SEM, 분광 타원계, TEM 등)은 정확하나, **측정 지연(latency), 장비 비용, 샘플링 제약**으로 모든 웨이퍼를 실시간 측정하기 어렵습니다.
- 기존 ML 기반 VM 모델은 주로 **상관관계 기반(correlation-driven)**으로, 이종(heterogeneous) 공정 변수 간의 구조적 의존성을 포착하지 못하며 해석 가능성도 부족합니다.

> 📌 **용어 설명**
> - **Virtual Metrology (가상 계측)**: 실제 물리적 측정 없이 장비 센서 데이터를 이용해 웨이퍼 특성(두께 등)을 통계/ML 모델로 예측하는 방법론
> - **Film Deposition (박막 증착)**: 반도체 기판 위에 얇은 물질 층을 쌓는 공정. CVD(화학기상증착), PVD(물리기상증착) 등이 대표적
> - **Spectroscopic Ellipsometry (분광 타원계측)**: 편광된 빛의 반사를 이용해 박막 두께와 광학 특성을 비파괴적으로 측정하는 기법

**목적:**
- 고주파 센서 신호에서 시계열 특징을 학습하면서, 동시에 공정 파라미터와 박막 레이어 간의 **구조적(directed) 의존성을 명시적으로 모델링**하는 그래프 어텐션 기반 VM 프레임워크 개발
- 예측 성능 향상과 함께 공정 엔지니어에게 해석 가능한 인사이트 제공

### 2-1. 해결 문제, 제안 방법, 모델 구조, 성능 및 한계

#### 🔴 해결하고자 하는 문제

1. **측정 지연 및 비용 문제**: 물리적 계측의 latency와 고비용 → VM으로 대체
2. **구조적 의존성 미포착**: 기존 ML VM은 다단계 공정 파라미터 간 상호작용을 명시적으로 표현하지 못함
3. **블랙박스 해석 불가**: 딥러닝 VM 모델의 해석 불가능성으로 근본 원인 분석(Root Cause Analysis) 곤란

---

#### 🔵 제안하는 방법 (수식 포함)

**[단계 1] 공정 신호 표현** (p.3, Eq. 1-2)

$$x_{s,p} \in \mathbb{R}^{T_s} $$

- $x_{s,p}$: 공정 단계 $s$에서 파라미터 $p$의 시계열 신호
- $T_s$: 공정 단계 $s$의 시간 샘플 수
- $S$: 총 공정 단계 수, $P$: 총 파라미터 수

$$X = \{x_{s,p} \in \mathbb{R}^{T_s} \mid s = 1, \ldots, S,\; p = 1, \ldots, P\} $$

- $X$: 웨이퍼 한 장에 대한 전체 다변량 시계열 입력 집합

---

**[단계 2] 시계열 특징 추출 및 파라미터 노드 임베딩** (p.4-5, Eq. 5-7)

$$z_{s,p} = \text{Conv1D}(x_{s,p}) \in \mathbb{R}^{T_s \times d_h} $$

- $z_{s,p}$: Conv1D를 통해 추출된 시간적 특징 표현
- $d_h$: 임베딩 차원 (실험에서 64로 설정)
- Conv1D 커널 크기: 5 (§4.2)

$$h_{s,p} = \frac{1}{T_s} \sum_{t=1}^{T_s} z_{s,p}^{(t)} \in \mathbb{R}^{d_h} $$

- $h_{s,p}$: 공정 단계 $s$, 파라미터 $p$에 해당하는 파라미터 노드 임베딩 (고정 길이 벡터)
- 시간 평균 풀링으로 가변 길이 $T_s$를 정규화

$$N = \{h_{s,p} \mid s = 1, \ldots, S,\; p = 1, \ldots, P\} \in \mathbb{R}^{(S \cdot P) \times d_h} $$

- $N$: 전체 파라미터 노드 임베딩 집합 (총 $S \times P$개 노드)

> 📌 **용어 설명**
> - **Conv1D (1차원 합성곱)**: 시계열 데이터에서 지역적(local) 시간 패턴(예: 압력 상승 트렌드)을 추출하는 신경망 연산. 슬라이딩 윈도우로 필터를 적용
> - **Temporal Pooling (시간 풀링)**: 가변 길이 시계열을 고정 크기 벡터로 변환하는 집계 연산. 여기서는 평균(mean) 사용

---

**[단계 3] 파라미터-레이어 그래프 어텐션** (p.5, Eq. 8-10)

$$\alpha_{l,(s,p)} = \frac{\exp\!\left(q_l^\top h_{s,p} / \sqrt{d_h}\right)}{\sum_{s'=1}^{S}\sum_{p'=1}^{P} \exp\!\left(q_l^\top h_{s',p'} / \sqrt{d_h}\right)} $$

- $\alpha_{l,(s,p)}$: 박막 레이어 $l$에 대한 파라미터 노드 $(s,p)$의 어텐션 가중치 (상대적 중요도)
- $q_l \in \mathbb{R}^{d_h}$: 박막 레이어 $l$의 학습 가능한 쿼리(query) 임베딩
- $\sqrt{d_h}$: 스케일링 인자 (내적 값이 너무 커지는 것을 방지, Scaled Dot-Product Attention 방식)
- $\sum$이 모든 $(s',p')$에 걸쳐 있으므로 Softmax 정규화됨

$$e_l = \sum_{s=1}^{S}\sum_{p=1}^{P} \alpha_{l,(s,p)}\, h_{s,p} \in \mathbb{R}^{d_h} $$

- $e_l$: 레이어 $l$의 표현 벡터 (파라미터 노드 임베딩들의 어텐션 가중 합)

$$E = \{e_l \mid l = 1, \ldots, L\} \in \mathbb{R}^{L \times d_h} $$

- $L$: 총 박막 레이어 수, $E$: 전체 레이어 표현 집합

> 📌 **용어 설명**
> - **Bipartite Graph (이분 그래프)**: 두 종류의 노드 집합(여기서는 파라미터 노드와 레이어 노드) 사이에만 엣지가 존재하는 그래프
> - **Scaled Dot-Product Attention**: 쿼리(query)와 키(key)의 내적을 $\sqrt{d_h}$로 나눠 스케일링 후 Softmax를 적용하는 어텐션 메커니즘. Transformer에서 기원
> - **Granger Causality (그레인저 인과성)**: 한 변수의 과거 값이 다른 변수의 현재 값 예측에 유의미하게 기여하면 '인과적'이라고 보는 시계열 인과 분석 개념. 본 논문에서는 어텐션 가중치의 해석적 유추에 활용

---

**[단계 4] 박막 두께 예측 및 손실 함수** (p.6, Eq. 11-13)

$$\hat{y}_l = f_\theta(e_l), \quad l = 1, \ldots, L $$

- $f_\theta(\cdot)$: MLP (회귀 헤드)
- $\hat{y}_l$: 레이어 $l$의 예측 두께

$$\mathcal{L} = \frac{1}{L}\sum_{l=1}^{L}\left(\frac{\hat{y}_l - y_l}{\sigma_l}\right)^2 $$

- $y_l$: 레이어 $l$의 실측 두께
- $\sigma_l$: 학습 데이터의 레이어 $l$ 두께 표준편차 (스케일 정규화)
- 서로 다른 두께 스케일을 가진 레이어들을 균등하게 학습하기 위한 표준화된 MSE

$$R_l^2 = 1 - \frac{\sum_{i=1}^{N}(y_{i,l} - \hat{y}_{i,l})^2}{\sum_{i=1}^{N}(y_{i,l} - \bar{y}_l)^2} $$

- $N$: 테스트 샘플 수, $\bar{y}_l$: 레이어 $l$의 실측 평균

> 📌 **용어 설명**
> - **MLP (Multi-Layer Perceptron, 다층 퍼셉트론)**: 여러 개의 완전 연결층(fully connected layer)으로 구성된 기본 신경망
> - **$R^2$ (결정계수)**: 모델이 데이터 분산의 얼마나 많은 부분을 설명하는지 나타내는 지표. 1에 가까울수록 좋음. 음수도 가능 (평균보다 못한 예측)


### 🔍 내 해석 (저자 보고와 분리)

- **제한적 개선폭**: $R^2$ 기준 최대 0.0166 향상은 산업적 맥락에서 유의미할 수 있으나, **통계적 유의성 검정(t-test, 신뢰구간 등)이 제시되지 않아** 우연에 의한 차이 가능성을 배제할 수 없습니다.
- **어블레이션 설계의 불균형**: 어블레이션 변형(w/o attention)이 MLP 베이스라인보다 낮은 $R^2$를 보이는데, 이는 어텐션 제거 시 그래프 구조 자체가 오히려 정보 손실을 초래할 수 있음을 시사합니다. 하지만 저자는 이를 명시적으로 분석하지 않습니다.
- **Granger 인과성 유추의 한계**: 어텐션 가중치를 Granger 인과성으로 해석하는 것은 개념적 유추(analogy)이며, 실제 Granger 인과성 검정이 수행된 것은 아닙니다.
- **단일 공장 데이터**: Intel 파운드리 단일 환경 데이터로만 검증되어, 다른 장비나 공정 유형에 대한 일반화 가능성은 미확인 상태입니다.

## 7. 가장 중요한 그림 5개 해석

### Figure 1: Overall Framework (p.4)

> **저자 설명**: 전체 프레임워크의 5단계 파이프라인을 도식화

**해석:**
- 왼쪽: 실제 공정 장비 → 센서 데이터 수집 → VM 시스템 → 가상 계측 결과 vs. 실제 계측 결과의 UCL/LCL(관리 한계) 대조 구조를 보여줌
- 오른쪽: Stage 1(신호 표현) → Stage 2(Conv1D + 시간 풀링) → Stage 3(파라미터 노드 임베딩) → Stage 4(그래프 어텐션 모델링 + 레이어 집계) → 두께 예측(MLP)으로 이어지는 정보 흐름
- **핵심 인사이트**: 이분 그래프 구조에서 파라미터 노드(원형)와 레이어 노드(다이아몬드)의 연결이 명확하게 시각화되어, 어텐션 메커니즘이 어떻게 공정 정보를 선택적으로 집계하는지 직관적으로 이해 가능
- **내 해석**: UCL/LCL 제어 차트와 VM 결과의 병치는 이 프레임워크가 단순 예측을 넘어 실제 공정 제어 루프에 통합될 수 있음을 암시하나, 실시간 통합 방법은 논문에서 구체화되지 않음

> 📌 **용어 설명**
> - **UCL/LCL (상한/하한 관리 한계, Upper/Lower Control Limit)**: 통계적 공정 관리(SPC)에서 공정이 통제 범위 내에 있는지 판단하는 기준선

---

### Figure 2: Training and Validation Loss Curves (p.7)

> **저자 설명**: 100 에폭에 걸친 학습/검증 손실 곡선. "빠르게 수렴하고 이후 안정적으로 유지됨. 학습-검증 손실 간 갭은 로트 기반 분할의 분포 이동(distribution shift)을 반영하며, 과적합이 아님"

**해석:**
- 학습 손실과 검증 손실 모두 약 20~30 에폭 내에 급격히 감소 후 안정화 → 조기 수렴(early convergence) 양호
- **주목할 점**: 학습 손실(~0.45)과 검증 손실(~0.62) 사이의 지속적 갭이 존재함. 저자는 이를 로트 레벨 분할의 분포 이동으로 설명하나, **과적합(overfitting)과 분포 이동의 구분이 Loss Curve만으로는 불명확**
- **내 해석**: 갭의 원인을 규명하기 위해 같은 로트 내 무작위 분할과 로트 기반 분할의 비교 실험이 필요하나 제공되지 않음. 갭이 과적합인지 분포 이동인지에 따라 모델 개선 방향이 달라짐

> 📌 **용어 설명**
> - **Overfitting (과적합)**: 모델이 학습 데이터에만 지나치게 최적화되어 새로운 데이터에서 성능이 떨어지는 현상
> - **Distribution Shift (분포 이동)**: 학습 데이터와 테스트 데이터의 통계적 분포가 다른 현상. 로트 단위 분할 시 동일 로트의 웨이퍼들이 서로 다른 분포를 가질 수 있음

---

### Figure 3: Prediction Scatter Plot (p.7)

> **저자 설명**: 테스트 세트의 예측 두께 vs. 실측 두께 산점도. 점선은 완벽한 예측선. 두께 수치는 기밀로 생략

**해석:**
- 전체적으로 점들이 대각선 주변에 분포하여 모델이 일관된 예측 성능을 보임
- **주목할 점**: 두께 축의 수치가 기밀(confidentiality)로 생략되어 **오차의 절대적 크기(MAE, RMSE 등)를 알 수 없음**. 두께 값의 스케일에 따라 동일한 $R^2$도 실용적 허용 오차 범위를 만족하는지 판단 불가
- 산점도에서 최소 2-3개의 뚜렷한 점군(클러스터)이 보임 → Film A, Film B, Top Film 등 다른 두께 범위의 레이어들임을 시사
- **내 해석**: 레이어 유형별 산점도를 개별적으로 보여준다면 어느 레이어에서 예측 오류가 집중되는지 파악 가능하나, 현재 통합 표시로 인해 레이어별 성능 차이 분석 불가

### Figure 4: Full Attention Weight Heatmap (p.7)

> **저자 설명**: 테스트 세트 전체 평균 어텐션 가중치 히트맵. 행=박막 레이어, 열=공정 단계(각 35개 서브스텝 × 30 파라미터 = 1,000+ 변수)

**해석:**
- **초기·종료 공정 단계에서 높은 어텐션**: 램핑(ramping) 구간에서의 온도/압력 변화가 두께에 결정적 영향을 미침 → 물리적으로 타당 (핵 생성(nucleation) 및 성장 초기 조건이 중요)
- **중간 단계의 반복적 패턴**: 챔버 조건이 안정화된 구간에서는 레이어 간 유사한 어텐션 패턴 → 정상 증착(steady-state deposition) 구간
- 전체 히트맵의 복잡도(1,000+ 변수)로 인해 직접적 해석이 어려움 → Figure 5의 Top-k 필터링 필요성 정당화
- **내 해석**: 히트맵의 색상 스케일이 매우 좁은 범위(논문 Figure 4의 범례 확인)를 보여 대부분의 파라미터가 균일하게 낮은 어텐션을 받고, 소수 파라미터에 집중됨. 이는 Eq. 8의 Softmax 특성상 자연스러운 희소성(sparsity)을 유도

> 📌 **용어 설명**
> - **Nucleation (핵 생성)**: 박막 증착 초기에 기판 위에 원자들이 모여 최초의 작은 클러스터(핵)를 형성하는 단계. 이 단계의 조건이 최종 박막의 품질을 크게 결정

### Figure 5: Top-k Attention Weight Heatmap (p.8)

> **저자 설명**: 레이어별 상위 k개 어텐션 가중치만 표시, 나머지는 마스킹

**해석:**
- **희소성 확인**: 각 레이어가 소수의 핵심 파라미터에만 집중 → 실제 박막 증착에서 일부 변수가 지배적 역할을 한다는 물리적 사실과 일치
- **레이어별 이질성**: Film B 레이어들은 초기 램핑 구간에만 강하게 반응, Film A3와 Top Film은 종료 램핑에도 민감 → 재료별 증착 메커니즘 차이를 반영
- **주기적 패턴**: 모든 레이어에서 중간 단계의 반복 패턴 관찰 → Figure 4의 관찰과 일관성 유지
- **내 해석**: Top-k 필터링의 임계값 $k$가 어떻게 설정되었는지 논문에서 명시되지 않음. $k$ 값 선택이 해석에 영향을 미칠 수 있어, 민감도 분석이 필요함. 또한 마스킹된 영역의 어텐션 값이 실제로 0에 가까운지, 아니면 단순히 시각화를 위해 잘린 것인지 불명확

## 8. 결론: 시사점, 후속 연구, 추가 방향

### 8-1. 저자 제시 시사점 및 후속 연구 계획

**저자 제시 시사점 (p.8, §5):**
1. 그래프 어텐션 기반 VM이 예측 성능과 해석 가능성을 동시에 달성 가능함을 실증
2. 어텐션 가중치가 온도, 압력, 가스 유량의 증착 역학 지배 역할과 일치하는 물리적으로 의미 있는 파라미터-레이어 관계를 제공
3. 시계열 관점에서 어텐션 메커니즘이 공정 파라미터와 박막 레이어 간 방향적 의존성(directional dependency) 포착

**저자 제시 향후 연구 방향 (p.8, §5):**
1. 물리·화학 원리와의 정합성 검증 (도메인 전문가와의 협업)
2. 웨이퍼 내 두께 비균일성(intra-wafer spatial non-uniformity) 모델링으로 확장
3. 물리 정보 제약(physics-informed constraints) 통합으로 공정 드리프트 및 변동성 하에서 모델 견고성 향상

---

### 8-1. 모델의 일반화 성능 향상 가능성 (중점)

**현재 일반화의 한계:**
- 단일 공정 유형(CVD), 단일 파운드리(Intel OTF), 단일 장비 환경에서만 검증
- 804개 웨이퍼는 딥러닝 기준으로 소규모 → 과적합 위험과 통계적 불안정성
- 로트 기반 분할로 인한 분포 이동이 검증 성능에 영향

**일반화 성능 향상을 위한 제언:**

| 전략 | 방법 | 기대 효과 |
|------|------|-----------|
| **전이 학습(Transfer Learning)** | 유사 공정(PVD, ALD)의 사전 학습 모델을 CVD에 파인튜닝 | 소규모 데이터 환경에서 성능 향상 |
| **도메인 적응(Domain Adaptation)** | 장비/공정 조건 변화에 강건한 특징 학습 (예: DANN, MMD) | 공정 드리프트 상황의 성능 저하 완화 |
| **물리 정보 신경망(PINN)** | 증착 속도 방정식 등 제약 조건을 손실 함수에 통합 | 데이터 부족 시 물리적 타당성 보장 |
| **데이터 증강(Data Augmentation)** | 센서 신호에 물리적으로 타당한 노이즈 추가, 합성 데이터 생성 | 학습 데이터 다양성 증가 |
| **메타 러닝(Meta-Learning)** | 적은 수의 새 공정 샘플로 빠르게 적응하는 Few-shot 학습 | 신규 공정 전환 시 빠른 VM 구축 |
| **멀티태스크 학습(Multi-task Learning)** | Film A와 Film B 예측을 공유 표현으로 학습 | 레이어 간 공통 특징 활용 |
| **불확실성 정량화** | Bayesian 딥러닝 또는 MC Dropout으로 예측 신뢰구간 제공 | 예측 신뢰도 정보로 의사결정 지원 |

> 📌 **용어 설명**
> - **PINN (Physics-Informed Neural Network)**: 물리 방정식(예: 편미분방정식)을 신경망 손실 함수에 제약으로 추가하여 물리적으로 타당한 예측을 강제하는 방법
> - **Domain Adaptation (도메인 적응)**: 학습 도메인(예: 장비 A)과 테스트 도메인(예: 장비 B)의 분포 차이를 줄여 일반화 성능을 향상시키는 기법
> - **MMD (Maximum Mean Discrepancy)**: 두 분포 간의 거리를 재생 커널 힐베르트 공간(RKHS)에서 측정하는 통계량. 도메인 적응에 활용

### 8-2. 2020년 이후 관련 최신 연구 비교 분석

> ⚠️ **주의**: 아래 비교 분석은 본 논문의 참고문헌 및 AI 연구자로서의 일반 지식을 기반으로 작성합니다. 직접 열람하지 않은 논문에 대해서는 내용을 지어내지 않으며, 확인 가능한 사실만 기술합니다.

**본 논문(2026)과 관련 연구 비교:**

| 연구 | 방법 | 강점 | 본 논문과의 차이 |
|------|------|------|-----------------|
| **Zhou et al. (2024)** [23] - GCN for PVD | Graph Convolutional Network (GCN) for VM | 그래프 구조 활용 | GCN은 무방향 그래프, 본 논문은 방향성 이분 그래프 + 어텐션으로 해석 가능성 추가 |
| **Roh et al. (2018)** [11] - PECVD VM | 플라즈마 정보 변수 기반 VM | 물리 정보 변수 활용 | 시계열 그래프 구조 없음, 해석 가능성 제한 |
| **Zhang et al. (2026)** [21] - CNN-BiLSTM-Attention | 하이브리드 CNN-BiLSTM + Attention | 시계열 특징 추출 우수 | 그래프 구조 없음, 파라미터-레이어 의존성 미명시 |
| **Lee & Ko (2024)** [22] - AMTransformer | Koopman 이론 기반 Transformer | 물리적 해석 가능한 동역학 학습 | 제조 동역학 일반화에 초점, VM 특화 아님 |
| **Lee et al. (2026)** [24] - Graph Attention AM | 그래프 어텐션 + 인과 시공간 학습 | 이상 감지에 적용, 해석 가능성 | 적층 제조(AM) 대상, 반도체 증착 아님 |
| **Chien et al. (2022)** [14] - Decision-based VM | 의사결정 기반 VM + APC | 고급 공정 제어(APC) 통합 | ML 모델 구조보다 의사결정 프레임워크에 집중 |

**트렌드 분석 (2020년 이후):**

1. **그래프 신경망(GNN)의 VM 도입**: Zhou et al. (2024) [23]의 GCN 기반 VM이 등장하며 그래프 구조의 중요성이 부각. 본 논문은 이를 어텐션 메커니즘과 결합하여 해석 가능성을 추가한 차세대 접근
2. **해석 가능성(Explainability) 강조**: 규제 환경과 공정 엔지니어의 요구로 블랙박스 모델 탈피 요구 증가. 본 논문은 어텐션 가중치를 통한 해석 가능 VM의 선도적 사례
3. **멀티모달·멀티스케일 학습**: 단일 신호에서 다변량 시계열 + 그래프 구조로의 확장이 트렌드
4. **실제 생산 데이터 활용**: Intel 파운드리 실 생산 데이터 사용은 학술 연구의 현실 적용 가능성을 높이는 중요한 차별점

**본 논문이 앞으로의 연구에 미치는 영향:**

1. **해석 가능한 VM의 표준 설계 제시**: 파라미터 노드 → 레이어 노드의 이분 그래프 + 어텐션 구조는 반도체 VM 분야의 아키텍처 참조 모델이 될 가능성
2. **물리적 해석과 데이터 기반 학습의 연결 고리**: 어텐션 가중치를 Granger 인과성으로 유추하는 접근은 후속 연구에서 실제 인과 추론(causal inference) 방법론과의 결합을 자극할 것
3. **산업 데이터 공개의 필요성 부각**: 기밀로 생략된 두께 수치와 Intel 전용 데이터는 재현성(reproducibility) 문제를 야기. 벤치마크 공개 데이터셋 구축 필요성을 환기

**앞으로 연구 시 고려할 점:**

| 고려 사항 | 구체적 방향 |
|-----------|------------|
| **통계적 엄밀성** | 모델 간 성능 비교 시 반복 실험 + 유의성 검정 필수화 |
| **벤치마크 데이터셋** | 공개 가능한 반도체 VM 벤치마크 구축으로 연구 재현성 확보 |
| **공정 다양성** | CVD 외 ALD, PVD, 에칭 등 다양한 공정으로 일반화 검증 |
| **시공간 통합** | 웨이퍼 내 공간 분포(비균일성) + 시계열을 통합한 3D VM 모델 |
| **온라인 학습** | 공정 드리프트에 실시간 적응하는 온라인/연속 학습(continual learning) VM |
| **불확실성 정량화** | 예측 신뢰구간 제공으로 VM을 공정 제어(APC) 루프에 안전하게 통합 |
| **인과 추론 결합** | 어텐션 유추를 넘어 실제 구조적 인과 모델(SCM, DAG)과의 결합 |
| **경량화/엣지 배포** | 실시간 VM을 위한 모델 경량화(pruning, quantization) 및 엣지 컴퓨팅 적용 |

> 📌 **용어 설명**
> - **ALD (Atomic Layer Deposition, 원자층 증착)**: 기체 전구체를 한 번에 한 원자층씩 순차적으로 반응시켜 초박막을 형성하는 증착 방법. 두께 제어 정밀도가 매우 높음
> - **APC (Advanced Process Control, 고급 공정 제어)**: 계측 데이터와 모델을 실시간으로 활용하여 공정 파라미터를 자동 조정하는 시스템
> - **SCM/DAG (Structural Causal Model / Directed Acyclic Graph)**: 변수 간 인과 구조를 방향성 비순환 그래프로 명시적으로 표현하는 인과 추론 프레임워크
> - **Continual Learning (연속 학습)**: 새로운 데이터가 들어올 때 기존 학습 내용을 잊지 않으면서 지속적으로 모델을 업데이트하는 학습 패러다임
