# A Convolutional Autoencoder Approach for Feature Extraction in Virtual Metrology

---

## 1. Executive Summary (10문장 이내)

본 논문은 반도체 제조 공정의 **Virtual Metrology(VM)** 분야에서 Optical Emission Spectroscopy(OES) 데이터를 활용한 식각률(Etch Rate) 예측을 위해 **Convolutional Autoencoder(CAE)** 기반 특징 추출 방법을 제안한다.  
기존의 수동(hand-designed) 및 단순 자동 특징 추출 방법은 확장성 부족, 정보 손실, 도메인 지식 의존성이라는 한계를 가진다.  
OES 데이터는 시간(time)과 파장(wavelength) 두 축으로 구성된 2차원 구조를 가지므로, 컴퓨터 비전(Computer Vision) 기법에서 영감을 받은 CNN 기반 접근이 적합하다.  
저자들은 비지도 사전학습(unsupervised pre-training)과 지도 미세조정(supervised fine-tuning)을 결합한 반지도학습(semi-supervised) 파이프라인을 구성하였다.  
추출된 특징은 Support Vector Regression(SVR)에 공급되어 최종 식각률을 예측한다.  
실험 결과, 제안 모델(Autoencoder+SVR)은 MSE 0.146, $R^2$ 0.983을 달성하여 SVR 단독(MSE 0.238) 및 LASSO(MSE 0.18) 대비 우수한 성능을 보였다.  
성능 평가는 100회 Monte-Carlo 교차검증으로 수행되어 신뢰성을 확보하였다.  
본 방법은 도메인 지식 없이도 입력 복잡성을 자연스럽고 확장 가능한 방식으로 처리할 수 있다.  
다만, 데이터셋이 단일 공정·단일 설비에 한정되어 일반화 가능성 검증이 추가로 필요하다.  
저자들은 더 다양한 Autoencoder 구조 및 대규모 데이터셋과의 비교를 향후 과제로 제시하였다.

> 📌 **용어 설명**
> - **Virtual Metrology(VM)**: 실제 측정 대신 센서 데이터 등 간접 정보를 활용하여 품질 변수를 예측하는 기술
> - **Etch Rate(식각률)**: 플라즈마 식각 공정에서 단위 시간당 제거되는 표면 두께
> - **OES(Optical Emission Spectroscopy)**: 플라즈마 발광 스펙트럼을 측정하는 광학 분석 기술

### 1-1. 연구의 목적과 필요성

**[목적]**
반도체 식각 공정에서 식각률을 직접 측정하는 것은 비용과 시간이 매우 많이 소요되므로, OES 센서 데이터를 활용하여 식각률을 간접적으로 예측하는 VM 모델을 구축하는 것이 목적이다. (p.127)

**[필요성]**

| 기존 방법의 한계 | 구체적 문제 |
|---|---|
| 수동 특징 추출 | 시간 소모적, 확장성 부족, 도메인 전문가 의존 |
| 단순 자동 특징 추출 (PCA+통계량) | 정보 손실, 낮은 예측 성능 |

> 📌 **용어 설명**
> - **PCA(Principal Component Analysis)**: 데이터의 분산이 큰 방향으로 차원을 축소하는 통계적 기법
> - **Design Matrix**: ML 모델에 입력되는 행(관측치) × 열(특징) 형태의 2차원 행렬

### 2-1. 해결 문제 · 제안 방법 · 모델 구조 · 성능 및 한계

#### ① 해결하고자 하는 문제

반도체 식각 공정에서의 식각률 예측을 위해 OES의 복잡한 2차원(시간×파장) 구조 데이터로부터 효과적인 특징을 자동으로 추출하는 문제. (p.127)

---

#### ② 제안하는 방법 (수식 포함)

**[2단계 학습 파이프라인]**

**Step 1: 비지도 사전학습 (Unsupervised Pre-training)**

Autoencoder의 손실 함수로 입력 재구성 오차를 최소화:

$$\mathcal{L}_{recon} = \text{MSE}_{recon} = \frac{1}{N}\sum_{i=1}^{N}\|X_i - \hat{X}_i\|^2$$

- $X_i$: $i$번째 OES 입력 샘플 (2차원 행렬, 2014 파장 × 54 타임스탬프)
- $\hat{X}_i$: Autoencoder가 재구성한 출력
- $N$: 전체 학습 샘플 수

> 📌 **용어 설명**
> - **비지도 사전학습**: 레이블(정답) 없이 입력 데이터만으로 모델의 초기 가중치를 학습하는 과정

**Step 2: 지도 미세조정 (Supervised Fine-tuning)**

Encoder에 선형 출력 레이어를 추가하여 식각률 예측 오차 최소화:

$$\mathcal{L}_{pred} = \text{MSE}_{pred} = \frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2$$

- $y_i$: $i$번째 샘플의 실제 식각률
- $\hat{y}_i$: 모델이 예측한 식각률

**[성능 평가 지표]**

$$\text{MSE} = \frac{1}{N}\sum_{i=1}^{N_{test}}(y_i - \hat{y}_i)^2 \quad (Eq. 1)$$

$$R^2 = 1 - \frac{\sum_{i=1}^{N_{test}}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{N_{test}}(y_i - \bar{y})^2} \quad (Eq. 1)$$

- $y_i$: 테스트 샘플 $i$의 실제 식각률
- $\hat{y}_i$: 테스트 샘플 $i$의 예측 식각률
- $\bar{y}$: 테스트 출력값의 평균
- $N_{test}$: 테스트 샘플 수 ($= 0.3 \times N$)

> 📌 **용어 설명**
> - **$R^2$ (결정계수)**: 1에 가까울수록 모델이 데이터 분산을 잘 설명함을 의미 (최대 1.0)
> - **MSE(Mean Squared Error)**: 예측값과 실제값 차이의 제곱 평균, 낮을수록 좋음

**[CNN 합성곱 연산]**

레이어 $l$의 뉴런 $i$의 출력:

$$z_i^l = \sigma(W^l * a^{l-1} + b^l)$$

- $W^l$: 레이어 $l$의 합성곱 커널(필터) 가중치
- $b^l$: 레이어 $l$의 편향(bias)
- $*$: 합성곱(convolution) 연산
- $a^{l-1}$: 이전 레이어($l-1$)의 출력(활성화 값)
- $\sigma(\cdot)$: 활성화 함수

> 📌 **용어 설명**
> - **합성곱(Convolution)**: 커널(작은 행렬)을 입력 데이터 위에 슬라이딩하며 내적을 계산하는 연산. 지역적 패턴을 효과적으로 추출함

---

#### ③ 모델 구조 (Fig. 3, p.131)

```
입력 OES 데이터
[1@2048×54]
      ↓
[Convolution Layer 1] → [Avg Pooling 1] → Feature Map [8@256×18]
      ↓
[Convolution Layer 2] → [Avg Pooling 2] → Feature Map [4@64×6]
      ↓
[Convolution Layer 3] → [Avg Pooling 3] → Feature Map [2@16×2]
      ↓
[Flatten 1, 2, 3] → Concat → 최종 특징 벡터 $\bar{X}$ (p=38,464)
      ↓
[SVR] → 식각률 예측값 $\hat{y}$
```

- **표기법**: `C@H×W` = C 채널, 높이 H, 너비 W
- 3개의 합성곱 레이어 + 평균 풀링 레이어가 교대로 구성
- **모든 풀링 레이어의 출력을 평탄화(flatten)하여 연결(concat)** → 다층 특징 활용 (p.131)

> 📌 **용어 설명**
> - **Average Pooling**: 특정 영역의 평균값을 취하여 차원을 축소하는 연산. 회귀 문제에서 부드러운 특징 추출에 적합
> - **SVR(Support Vector Regression)**: 마진 최대화 원리를 회귀 문제에 적용한 지도학습 알고리즘

### 4-2. 내 해석 (저자 기술과 분리)

> ⚠️ **이하는 논문 내용을 바탕으로 한 분석자의 해석입니다.**

- **$R^2=0.983$의 해석**: 저자 스스로도 언급(p.132)하듯, 전체적으로 높은 $R^2$ 값은 데이터셋 자체의 높은 선형성을 시사하며, 제안 모델의 절대적 우위를 과장할 수 있음. 비선형성이 강한 데이터셋에서의 검증이 필요함.

- **특징 벡터 차원 $p=38,464$의 문제**: 원본 크기(2014×54=108,756)를 약 1/3로 압축했다고 하나, 38,464 차원은 여전히 매우 고차원이며 SVR의 계산 비용 문제를 야기할 수 있음. 저자는 이 점을 명시적으로 논의하지 않음.

- **단일 데이터셋 한계**: N=1,747은 딥러닝 모델로는 소규모이며, 저자도 데이터 증가 시 성능 향상을 기대한다고 밝혔지만(p.132), 이는 곧 현재 성능이 데이터 부족으로 최적화되지 않았음을 인정하는 것임.

## 7. 가장 중요한 그림 5개 해석

### Fig. 1(a) - FNN 완전연결 레이어 구조 (p.129)
전통적인 Feedforward Neural Network에서 각 뉴런이 이전 레이어의 **모든** 뉴런과 연결되는 구조를 보여준다. 이 구조는 2차원 공간 정보를 보존하지 못하며, OES와 같은 구조화된 2D 데이터에 직접 적용 시 공간적 상관관계 정보가 손실된다. 이는 CNN 도입의 필요성을 설명하는 대조 기준점 역할을 한다.

### Fig. 1(b) - CNN 파라미터 공유 구조 (p.129)
CNN에서 레이어 $l$의 뉴런 $i$가 이전 레이어의 **수용 영역(receptive field)**에만 연결되고, 동일한 커널을 공유하는 파라미터 공유(parameter sharing) 구조를 나타낸다. 이는 공간적 패턴을 위치 불변적으로 학습할 수 있게 하며, OES 데이터의 파장-시간 영역에서 반복되는 패턴을 효과적으로 포착할 수 있는 근거가 된다.

> 📌 **용어 설명**
> - **수용 영역(Receptive Field)**: 특정 뉴런이 반응하는 이전 레이어의 입력 영역 크기

### Fig. 2(a)(b) - Autoencoder 구조 및 Fine-tuning (p.130)
- **(a)**: $X$(입력) → Encoder → $\bar{X}$(압축 표현) → Decoder → $\hat{X}$(재구성 출력)의 대칭 구조를 보여줌. 비지도 학습으로 입력을 재구성하는 과정에서 유용한 특징이 $\bar{X}$에 압축됨.
- **(b)**: Encoder 뒤에 회귀 출력 레이어 $y=f^*(X;\theta)$를 추가하여 식각률을 예측하는 지도 미세조정 단계를 보여줌. 사전학습된 가중치를 초기값으로 활용하여 수렴 속도와 성능을 높인다.

### Fig. 3 - 제안 특징 추출 파이프라인 전체 구조 (p.131)
입력 OES 데이터(1@2048×54)가 3개의 합성곱-풀링 블록을 거쳐 점진적으로 압축되는 과정과, **3개 풀링 레이어의 출력을 모두 평탄화하여 연결(Concat)**하여 최종 특징 벡터 $\bar{X}$를 생성하는 구조가 시각화되어 있다. 이는 단일 레이어 특징만 사용하는 기존 방법과의 핵심 차별점으로, 다중 스케일 특징(multi-scale features)을 동시에 활용한다는 아이디어를 직관적으로 보여준다.

> 📌 **용어 설명**
> - **Multi-scale Features**: 서로 다른 해상도/크기에서 추출된 특징들로, 다양한 수준의 패턴 정보를 포함함

### Fig. 4(a)(b) - 100회 CV 성능 분포 박스플롯 (p.132)
- **(a) $R^2$ 분포**: Autoencoder+SVR이 가장 높은 중앙값과 좁은 분포를 보임 → 안정적이고 우수한 예측 성능
- **(b) MSE 분포**: Autoencoder+SVR이 가장 낮은 MSE와 좁은 분포를 보임 → 오차가 작고 일관적
- **주목할 점**: SVR과 LASSO의 박스플롯 범위가 상대적으로 넓어 결과의 분산이 크고, Autoencoder+SVR은 이상치(outlier, +로 표시)가 존재하나 전반적 분포는 우수함
- **해석 주의**: 전체적으로 $R^2 > 0.95$ 수준으로 모든 방법이 높은 예측력을 보이므로, 실질적 차이의 크기(effect size)는 제한적일 수 있음

### 8-1. 모델 일반화 성능 향상 가능성 (중점 분석)

**[현재 일반화 한계 요인]**

1. **단일 공정/설비 데이터**: N=1,747 샘플, 단일 플라즈마 식각 챔버 (p.130)
2. **데이터 크기**: 딥러닝 모델 일반화를 위한 데이터 부족
3. **도메인 편향**: 특정 가스 조성, 챔버 조건에 과적합 가능

**[일반화 향상을 위한 제안 방향]**

| 방향 | 구체적 방법 |
|---|---|
| 데이터 증강 | OES 데이터에 적합한 시간-파장 축 노이즈 주입, 슬라이딩 윈도우 |
| 전이학습 적용 | 대규모 공정 데이터로 사전학습 후 소규모 타겟 공정에 미세조정 |
| 도메인 적응 | 챔버 간 편차(chamber mismatch) 보정을 위한 도메인 적응 기법 결합 |
| Denoising AE 활용 | 노이즈 입력에서 복원하도록 훈련 → 노이즈 강건성 및 일반화 향상 |
| 정규화 강화 | Dropout, Batch Normalization 추가로 과적합 방지 |
| 다중 설비 학습 | 여러 챔버 데이터 통합 학습으로 일반화 범위 확대 |

> 📌 **용어 설명**
> - **전이학습(Transfer Learning)**: 한 도메인에서 학습된 모델을 다른 관련 도메인에 적용하는 방법
> - **도메인 적응(Domain Adaptation)**: 학습 데이터와 테스트 데이터의 분포 차이를 극복하는 기법
> - **Dropout**: 학습 중 랜덤으로 일부 뉴런을 비활성화하여 과적합을 방지하는 정규화 기법

**[2020년 이후 주요 연구 트렌드 비교]**

| 연구 방향 | 본 논문(2018) 접근 | 2020년 이후 발전 방향 |
|---|---|---|
| 특징 추출 방법 | CAE + SVR | Transformer 기반 자기지도학습, 대조 학습(Contrastive Learning) |

| 다중 공정 데이터 처리 | 단일 공정 | 멀티태스크 학습, 메타러닝 적용 |
| 도메인 적응 | 미적용 | 챔버 간 전이학습, Few-shot Learning |
| 모델 경량화 | 미고려 | Neural Architecture Search(NAS), 지식 증류(Knowledge Distillation) |

**[본 논문이 이후 연구에 미치는 영향]**

1. **반도체 VM 분야 DL 적용의 초기 선도 연구**: OES 데이터에 CNN 기반 특징 추출을 최초로 체계적으로 적용한 논문 중 하나로, 이후 유사 연구의 참조 기준점(baseline)이 됨

2. **다층 특징 연결 아이디어**: 모든 풀링 레이어 출력을 연결하는 방식은 이후 Feature Pyramid Network(FPN), U-Net 등 다중 스케일 특징 활용 방법론과 맥을 같이하며 영향을 미침

3. **반지도학습 파이프라인의 유효성 검증**: 레이블 데이터가 부족한 산업 환경에서 비지도 사전학습 + 지도 미세조정 조합의 실용성을 입증

**[향후 연구 시 고려해야 할 점]**

| 고려 사항 | 세부 내용 |
|---|---|
| ① 데이터 규모 확장 | N=1,747은 DL에 부족. 수만 건 이상의 다양한 공정 데이터 확보 필요 |
| ② 설명 가능성 확보 | 산업 현장 적용을 위해 특징의 물리적 의미 해석 방법 개발 필요 |
| ③ 실시간 적용 가능성 | 추론 지연(latency) 및 계산 비용 최적화 연구 필요 |
| ④ 강건성 평가 | 센서 노이즈, 결측값, 챔버 드리프트 상황에서의 성능 검증 필요 |
| ⑤ 다중 출력 예측 | 식각률 외에도 균일성(uniformity), 선택비(selectivity) 등 다중 품질 변수 동시 예측 연구 |
| ⑥ 이상 탐지 결합 | VM과 공정 이상 탐지를 통합한 멀티태스크 학습 프레임워크 개발 |
| ⑦ 최신 아키텍처 비교 | Vision Transformer(ViT), Mamba 등 최신 시계열/이미지 모델과의 체계적 비교 필요 |

> 📌 **용어 설명**
> - **대조 학습(Contrastive Learning)**: 유사한 샘플은 가깝게, 다른 샘플은 멀게 표현 공간을 학습하는 자기지도학습 방법
> - **지식 증류(Knowledge Distillation)**: 큰 모델(teacher)의 지식을 작은 모델(student)에 전달하여 경량화하는 방법
> - **Vision Transformer(ViT)**: 이미지를 패치로 분할하여 Transformer 구조로 처리하는 모델, 최근 CNN을 능가하는 성능 보임
