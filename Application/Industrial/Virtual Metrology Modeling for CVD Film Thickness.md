## 1. Executive Summary (10문장 이내)

1. 반도체 제조 공정에서 모든 웨이퍼를 물리적으로 계측하는 것은 비용과 시간 측면에서 비현실적이며, 이를 대체하기 위한 **가상 계측(Virtual Metrology, VM)** 기술이 필요하다.
2. 본 논문은 PECVD(Plasma Enhanced Chemical Vapor Deposition) IMD(Inter Metal Dielectric) 공정에서 산화막 두께를 예측하는 VM 모델 개발을 목표로 한다.
3. FDC(Fault Detection and Classification) 센서 데이터와 계측 데이터를 입력으로 사용하며, 출력은 웨이퍼별 평균 산화막 두께이다.
4. 두 가지 모델 — **PLS(Partial Least Squares Regression)** 와 **Tree Ensemble** — 을 비교 평가하였다.
5. 핵심 혁신은 여러 제품, 레이어, 두 개의 척(chuck)을 단일 모델로 통합한 것으로, 기존 12개 개별 모델 대비 유지보수 부담을 획기적으로 줄였다.
6. PLS 모델은 4개의 주성분으로 X 변동성의 46.5%, Y 변동성의 89.7%를 설명하였으며, TRMSE는 0.58%이다.
7. Tree Ensemble 모델은 5개 변수만으로 $R^2=0.84$, TRMSE 0.59%를 달성하여 PLS와 동등한 예측 성능을 보였다.
8. 두 모델 모두 실측값과 우수한 일치도를 보였으나, **시간에 따른 모델 강건성 유지**와 **신뢰도 지표(Indicator of Confidence)** 부재가 핵심 한계로 지적된다.
9. 정적(static) 모델은 챔버 노화, 예방 정비 등으로 인한 공정 드리프트에 취약하며, 동적 모델 업데이트 전략이 필수적임을 강조한다.
10. 최종 목표는 VM 예측 결과를 CMP(Chemical Mechanical Polishing) 공정의 피드포워드 제어 입력으로 활용하여 처리량 향상 및 비용 절감을 실현하는 것이다.

### 1-1. 연구의 목적과 필요성

| 구분 | 내용 |
|------|------|
| **산업적 배경** | 반도체 제조는 다단계 대량생산 시스템으로, 공정 안정성과 수율 확보를 위해 정확한 계측이 필수 |
| **현재 계측의 한계** | 전수 웨이퍼 계측은 비용·시간 과다 소요 → 일부 샘플만 계측 → 불량 웨이퍼 조기 발견 불가 |
| **VM의 필요성** | 모든 웨이퍼에 대해 계측값을 **예측**함으로써 정확도(accuracy), 속도(speed), 처리량(throughput), 유연성(flexibility) 4가지 과제를 동시 해결 |
| **구체적 목표** | PECVD IMD 공정의 산화막 평균 두께를 FDC 데이터 기반으로 예측하여, 후속 CMP 공정의 피드포워드 제어에 활용 |

> 💡 **용어 설명**
> - **APC(Advanced Process Control)**: 공정 데이터를 실시간으로 분석하여 제조 장비를 자동으로 제어하는 시스템
> - **FDC(Fault Detection and Classification)**: 장비 센서 데이터를 실시간으로 수집하여 공정 이상을 감지·분류하는 시스템
> - **CMP(Chemical Mechanical Polishing)**: 웨이퍼 표면을 화학적·기계적으로 연마하여 평탄화하는 공정
> - **IMD(Inter Metal Dielectric)**: 금속 배선 층 사이를 절연하는 유전체 층
> - **PECVD(Plasma Enhanced CVD)**: 플라즈마를 이용하여 저온에서 박막을 증착하는 화학기상증착 방법

### 2-1. 해결하고자 하는 문제 / 제안 방법 / 모델 구조 / 성능 및 한계

#### ① 해결하고자 하는 문제

- **전수 웨이퍼 물리 계측의 비용·시간 문제**: 샘플링 계측만으로는 조기 불량 감지 불가
- **공정 드리프트 대응**: 챔버 노화, 예방 정비 후 공정 변화에 모델이 강건해야 함
- **다품종·다레이어·다척 공정의 단일 모델화**: 12개 개별 모델 유지보수 부담 해소
- **예측 신뢰도 부재**: 예측값의 신뢰 여부를 판단할 지표 없음

---

#### ② 제안하는 방법 및 수식

**[공통 기본 모델]**

$$Y = XB + E $$

| 기호 | 설명 |
|------|------|
| $Y$ | 출력 데이터 행렬 (계측값, 산화막 두께) — $(I \times m)$ |
| $X$ | 입력 데이터 행렬 (FDC 데이터) — $(I \times p)$ |
| $B$ | 회귀 계수 행렬 |
| $E$ | 오차 행렬 (평균 0, 분산 $\sigma^2$의 독립 분포) |

---

**[성능 지표: VRMSE & TRMSE]**

$$VRMSE = 100 \times \left(\frac{1}{N}\sum_{i=1}^{N}\left(\frac{y_i - \hat{y}_i}{y_i}\right)^2\right)^{1/2} $$

$$TRMSE = 100 \times \left(\frac{1}{n}\sum_{i=1}^{n}\left(\frac{y_i - \hat{y}_i}{y_i}\right)^2\right)^{1/2} $$

| 기호 | 설명 |
|------|------|
| $y_i$ | 실제 측정값 |
| $\hat{y}_i$ | 모델 예측값 |
| $N$ | 훈련 데이터 셋 크기 |
| $n$ | 테스트 데이터 셋 크기 |
| $VRMSE$ | 훈련-검증 데이터 기반 평균제곱근오차 (%) |
| $TRMSE$ | 테스트 데이터 기반 예측 평균제곱근오차 (%) |

> 💡 **용어 설명**
> - **RMSE(Root Mean Square Error)**: 예측값과 실측값의 차이를 제곱 평균한 후 제곱근을 취한 오차 지표. 값이 낮을수록 예측 정확도가 높음

---

**[PLS 모델]**

$$\hat{Y}^{PLS} = X\hat{B}^{PLS} + E $$

$$X = TP^T + E $$

$$Y = TQ^T + F $$

$$\mathbf{p}_1 = \frac{X^T \mathbf{t}_1}{\mathbf{t}_1^T \mathbf{t}_1} $$

$$X_2 = X - \mathbf{t}_1 \mathbf{p}_1^T $$

$$Y_2 = Y - \mathbf{t}_1 \mathbf{q}_1^T $$

$$\mathbf{q}_1 = \frac{\mathbf{t}_1^T Y}{\mathbf{t}_1^T \mathbf{t}_1} $$

| 기호 | 설명 |
|------|------|
| $\hat{Y}^{PLS}$ | PLS 모델의 출력 예측값 |
| $T$ | 잠재변수 스코어 행렬 — $(I \times A)$ |
| $P$ | X 공간의 로딩 행렬 — $(p \times A)$ |
| $Q$ | Y 공간의 로딩 행렬 — $(m \times A)$ |
| $E, F$ | 각각 X, Y의 잔차 오차 행렬 |
| $\mathbf{t}_1$ | 첫 번째 잠재변수 스코어 벡터 |
| $\mathbf{p}_1$ | 첫 번째 X 로딩 벡터 |
| $\mathbf{q}_1$ | 첫 번째 Y 로딩 벡터 |
| $A$ | 잠재변수 공간의 차원 수 |

> 💡 **용어 설명**
> - **PLS(Partial Least Squares)**: X와 Y의 공분산을 최대화하는 잠재변수(Latent Variable)를 추출하여 고차원 데이터를 저차원으로 투영하는 회귀 방법. 다중공선성 문제에 강함
> - **잠재변수(Latent Variable)**: 직접 관측되지 않지만, 여러 관측 변수들의 공통 변동을 설명하는 숨겨진 변수
> - **NIPALS 알고리즘**: PLS에서 잠재변수를 반복적으로 추출하는 수치 계산 방법

---

**[Tree Ensemble 모델]**

$$\hat{y} = \frac{1}{nTrees}\sum_{i=1}^{nTrees}\tau_i(\mathbf{X}) $$

**선형 효과 결합 최종 모델:**

$$\hat{y} = \mathbf{A}\mathbf{X}^{lin} + \frac{1}{nTrees}\sum_{i=1}^{nTrees}\tau_i(\mathbf{X}^{nlin}) $$

**결정계수($R^2$):**

$$R^2 = 1 - \frac{\frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2}{S_y^2} $$

| 기호 | 설명 |
|------|------|
| $\tau_i(\mathbf{X})$ | $i$번째 회귀 트리의 예측 함수 |
| $nTrees$ | 앙상블에서 생성·집계되는 트리의 수 |
| $\mathbf{A}$ | 선형 부분의 회귀 계수 벡터 |
| $\mathbf{X}^{lin}$ | 선형 효과를 처리하는 입력 변수 부분집합 |
| $\mathbf{X}^{nlin}$ | 비선형 Tree Ensemble로 처리하는 입력 변수 부분집합 |
| $S_y^2$ | 출력 $y$의 분산 |
| $N$ | 훈련 데이터 셋 크기 |

> 💡 **용어 설명**
> - **Tree Ensemble(앙상블 트리)**: 여러 개의 결정 트리를 독립적으로 학습하고 예측을 평균하여 단일 트리보다 정확하고 안정적인 예측을 수행하는 방법
> - **Bagging(부트스트랩 집계)**: 원본 데이터에서 복원 추출로 여러 학습 세트를 만들어 각각 모델을 학습하고, 결과를 평균내는 앙상블 기법
> - **Out-of-Bootstrap 예측**: Bagging 과정에서 특정 샘플이 포함되지 않은 트리들만으로 해당 샘플을 예측하는 교차검증 방식
> - **CART(Classification and Regression Trees)**: 이진 분할 기반의 결정 트리 알고리즘
> - **VIP(Variable Importance in Projection)**: PLS 모델에서 각 변수가 Y 예측에 기여하는 정도를 정량화한 지표. 일반적으로 VIP > 1이면 중요한 변수로 간주

**내용**: USG 레이어(FDC 데이터 수집 대상) / HDP 산화물 층 / 금속 층의 3층 구조 및 전체 스택 두께 표시

### Figure 2 — Process flow (p.27)

**내용**: 상단은 기존 공정 흐름(PECVD HDP → 계측 → PECVD USG → 계측 → CMP), 하단은 VM 적용 후 공정 흐름(중간 계측 단계 일부를 VM으로 대체)

### 8-1. 모델의 일반화 성능 향상 가능성

본 논문에서 일반화 성능(generalization)과 관련된 도전 과제와 향후 개선 가능성을 중점적으로 분석한다.

#### 현재 일반화 성능의 한계

| 한계 요인 | 상세 내용 |
|----------|-----------|
| **데이터 도메인 제한** | 단일 Fab, 단일 PECVD 장비, 0.35µm 기술 노드에 국한 |
| **시간적 범위 제한** | "a few weeks" 데이터로 학습 → 장기 계절성, 대형 PM 사이클 미포함 |
| **제품·레이어 다양성** | 3개 레이어, 한정된 제품 종류 → 신규 제품 투입 시 재학습 필요 |
| **정적 모델의 드리프트 취약성** | Figure 5에서 확인: 시간 경과에 따른 성능 저하 명확 |

#### 일반화 성능 향상을 위한 제안 방향

**① 전이 학습(Transfer Learning) 적용**

동일 유형의 다른 Fab 또는 다른 장비에서 수집된 데이터를 활용하여 사전 학습된 모델을 미세조정(fine-tuning)하면, 신규 환경에서의 일반화 성능을 크게 향상시킬 수 있다.

$$\hat{y}_{target} = f_{source}(\mathbf{X}) + \Delta f(\mathbf{X}_{target}) $$

> 💡 **전이 학습(Transfer Learning)**: 한 도메인에서 학습한 모델 지식을 유사한 다른 도메인에 적용하는 머신러닝 기법. 데이터가 부족한 새 환경에서 특히 유용함.

**② 도메인 적응(Domain Adaptation)**

장비 간, 챔버 간 분포 차이(distribution shift)를 보정하는 도메인 적응 기법 적용으로 모델을 새로운 환경에 빠르게 적응시킬 수 있다.

**③ 베이지안 업데이트(Bayesian Update)**

새로운 데이터가 수집될 때마다 사전 분포(prior)를 업데이트하는 베이지안 접근법으로 불확실성을 정량화하면서 일반화 성능을 유지할 수 있다.

$$P(\theta | \mathcal{D}_{new}) \propto P(\mathcal{D}_{new} | \theta) \cdot P(\theta | \mathcal{D}_{old})$$

> 💡 **베이지안 업데이트**: 기존 지식(사전 분포)에 새로운 데이터(우도)를 결합하여 모델 파라미터의 사후 분포를 업데이트하는 통계적 방법론

**④ 앙상블 다양성 강화**

현재 Tree Ensemble은 Bagging + Random Splits 조합을 사용하나, Gradient Boosting 또는 XGBoost 계열을 추가하면 편향-분산 트레이드오프를 개선하여 일반화 성능을 높일 수 있다.

**⑤ 피처 엔지니어링 개선**

FDC 시계열 데이터를 단순 통계량(평균, 최대값 등)이 아닌 주파수 도메인 특징(FFT), 시계열 패턴(DTW 거리) 등으로 변환하면 공정 물리적 정보를 더 풍부하게 포착할 수 있다.

> 💡 **FFT(Fast Fourier Transform, 고속 푸리에 변환)**: 시계열 신호를 주파수 성분으로 분해하여 주기적 패턴을 추출하는 수학적 기법

2. **모델 업데이트의 중요성 강조**: Figure 5를 통해 정적 모델의 한계를 명확히 보여줌으로써, 이후 적응형 VM(Adaptive VM) 연구의 동기를 부여

3. **신뢰도 지표 개념 선제 제안**: 이후 Reliance Index, Quality Index 등의 연구(예: Cheng et al. 2011[26], Kao et al. 2011[26])로 발전하는 기초를 제공

4. **반도체 이외 분야 확장**: VM 개념이 디스플레이(TFT-LCD), 태양전지 등 유사 박막 공정으로 확장되는 데 이론적 근거 제공

#### 앞으로 연구 시 고려할 점

| 고려 사항 | 상세 내용 |
|----------|-----------|
| **모델 해석가능성(Explainability)** | 변수명 익명화 문제 해결 및 SHAP 값 등을 통한 물리적 해석 제공 필요 |
| **실시간 처리 성능** | 온라인 VM을 위한 inference latency 최적화 연구 필요 |
| **다중 출력 예측** | 평균 두께 외 균일성(uniformity), 사이트별 두께 분포 예측으로 확장 |
| **연방 학습(Federated Learning)** | 여러 Fab의 데이터를 공유하지 않고도 협력 학습 가능한 프레임워크 — 지적재산 보호 동시 |
| **이상 탐지 통합** | VM과 FDC를 통합하여 이상 발생 시 자동으로 VM 신뢰도를 낮추는 시스템 구축 |
| **Few-shot Learning** | 신규 제품·레이어 투입 시 소량 데이터로 빠르게 적응하는 few-shot VM 개발 |
| **물리 정보 포함 머신러닝(PINN)** | 순수 데이터 기반 한계를 극복하기 위해 CVD 공정 물리 방정식을 ML 학습에 제약 조건으로 통합 |
| **표준화된 벤치마크 데이터셋 부재** | 연구 간 비교 가능성을 위한 공개 반도체 VM 벤치마크 데이터셋 구축 필요 (현재 대부분 기업 내부 데이터) |

> 💡 **SHAP(SHapley Additive exPlanations)**: 게임 이론의 Shapley 값을 기반으로 각 입력 변수가 모델 예측에 기여하는 정도를 정량화하는 모델 해석 기법
> 
> 💡 **연방 학습(Federated Learning)**: 각 데이터 보유자(Fab)가 원본 데이터를 공유하지 않고, 로컬에서 학습한 모델 파라미터만 집계하여 전체 모델을 개선하는 분산 학습 방식
>
> 💡 **PINN(Physics-Informed Neural Networks)**: 신경망 학습 과정에 물리 법칙(편미분 방정식 등)을 손실 함수 제약 조건으로 포함하여, 데이터가 부족해도 물리적으로 타당한 예측을 생성하는 모델
