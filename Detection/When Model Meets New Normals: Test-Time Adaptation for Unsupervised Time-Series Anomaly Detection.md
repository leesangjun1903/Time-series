# When Model Meets New Normals: Test-Time Adaptation for Unsupervised Time-Series Anomaly Detection

---

## 1. Executive Summary (10문장 이내)

본 논문은 비지도 시계열 이상 탐지(unsupervised time-series anomaly detection)에서 학습 시점과 테스트 시점 간의 **분포 변화(distribution shift)** 문제, 즉 **"새로운 정상(new normal) 문제"** 를 다룬다.  
기존 모델들은 훈련 데이터의 정규성(normality) 개념이 고정되어 있다고 가정하지만, 실제 환경에서는 정상 데이터의 분포가 시간에 따라 변화한다.  
저자들은 이 문제를 해결하기 위해 **지수 이동 평균(EMA) 기반 추세 추정(trend estimation)** 과 **자기지도(self-supervised) 방식의 테스트 시간 모델 업데이트(TTA)** 를 결합한 간단하면서도 효과적인 전략을 제안한다.  
추세 추정 모듈은 비정상적 트렌드 변화에 대응하고, 모델 업데이트는 추세만으로는 포착되지 않는 복잡한 분포 변화를 학습한다.  
제안 방법은 기존 이상 탐지기(autoencoder)에 플러그인(plug-in) 형태로 적용 가능하며 추가 레이블이 불필요하다.  
SWaT, WADI, SMD, MSL, SMAP, Yahoo 등 다수의 실제 벤치마크에서 일관된 성능 향상을 달성하였다.  
AnoShift 벤치마크에서는 AUROC 기준 최대 0.216 향상을 보였다. WADI에서는 AUROC 13%, MSL(P-15)에서는 AUPRC 51% 향상이라는 두드러진 결과를 얻었다.  
다만 분포 변화가 적은 CreditCard 데이터셋에서는 제한적인 향상만이 관찰되었다.  
이 연구는 실시간 모니터링 시스템에서 과거 데이터 접근 없이 모델을 지속적으로 갱신할 수 있는 실용적 프레임워크를 제시한다.

### 1-1. 연구의 목적과 필요성

**목적:** 시계열 이상 탐지 모델이 배포(deployment) 이후 발생하는 정상 분포의 변화에 적응하여 허위 양성(false positive)을 줄이고 탐지 성능을 유지하도록 하는 것.

**필요성:**
- 실제 산업 시스템(수처리, 서버, 우주선 등)에서 센서 데이터의 정상 패턴은 시간에 따라 변화함 (Fig. 1-(a), p.1)
- 기존 비지도 모델들은 훈련 데이터 기반 정상성 개념을 고정하여 사용하므로, 테스트 시 분포가 변화하면 허위 경보(false alarm)를 대거 생성함
- 레이블 없이, 과거 데이터 접근 없이 실시간으로 모델을 갱신해야 하는 실용적 제약 존재

> 💡 **분포 변화(Distribution Shift):** 모델이 훈련된 데이터의 통계적 분포($P_{train}$)와 실제 사용 환경의 데이터 분포($P_{test}$)가 달라지는 현상. 이로 인해 모델 성능이 저하됨.

> 💡 **허위 양성(False Positive):** 실제로는 정상인데 모델이 이상(anomaly)으로 잘못 판단하는 경우. 모니터링 시스템의 신뢰성을 저하시킴.

### 2-1. 상세 설명

#### 해결하고자 하는 문제

**새로운 정상 문제(New Normal Problem):** 시계열 이상 탐지에서 정상성의 분포 $\mathbb{P}$가 고정되지 않고 시간에 따라 변하는 현상, 즉 $\mathbb{P}\_{train} \neq \mathbb{P}_{test}$ 인 상황.

수식적으로, 이상은 다음과 같이 정의됨 (p.3):

$$p(x) < \epsilon$$

여기서 $p(x)$는 정상 분포 $\mathbb{P}$ 하의 확률 밀도이며, $\epsilon$은 이상 판단 임계값.

> 💡 **비정상성(Non-stationarity):** 시계열 데이터의 통계적 특성(평균, 분산 등)이 시간에 따라 변하는 성질. 이상 탐지 모델의 일반화를 방해하는 주요 원인.

---

#### 제안하는 방법

**구성 1: 추세 추정 기반 입력 정규화 (Input Normalization Using Trend Estimate)**

추세-이상치(trend-outlier)의 정의 (Eq. 1, p.3):

$$\Delta(\mathcal{T}(\cdot), \tilde{\mathcal{T}}(\cdot)) > \delta$$

- $\Delta$: 두 함수 간의 불일치를 측정하는 함수
- $\tilde{\mathcal{T}}$: 정상 시퀀스의 추세를 반환하는 함수
- $\mathcal{T}$: 비교 대상 임의 시퀀스의 추세
- $\delta$: 이상 판단 임계값

EMA 기반 추세 추정 (Eq. 2, p.3):

$$\tilde{\mathcal{T}}(\cdot) : \mu_t \leftarrow \gamma\mu_{t-w} + (1-\gamma)\hat{\mu}$$

- $\mu_t$: 시점 $t$에서의 추정 추세(평균)
- $\gamma$: EMA 업데이트 속도를 조절하는 하이퍼파라미터 (0과 1 사이)
- $\hat{\mu} = \frac{1}{w}\sum_{i=t-w+1}^{t} X_i$: 스트림 데이터의 경험적 평균
- $w$: 슬라이딩 윈도우 크기

모델은 원래 입력 $\mathcal{X}\_{w,t}$ 대신 **디트렌드된 입력** $\mathcal{X}_{w,t} - \mu_t$를 재구성하고, 최종 출력 시 $\mu_t$를 다시 더함.

> 💡 **지수 이동 평균(EMA, Exponential Moving Average):** 최근 데이터에 더 높은 가중치를 부여하는 가중 이동 평균. 시계열 추세 추적에 효율적으로 사용됨.

> 💡 **디트렌딩(Detrending):** 시계열에서 추세 성분을 제거하는 과정. 비정상 추세를 제거함으로써 모델이 순수한 동역학 패턴만 학습하도록 함.

---

**구성 2: 새로운 정상 학습을 위한 모델 업데이트 (Model Update with New Normals)**

온라인 경사 하강법 기반 파라미터 업데이트 (Eq. 3, p.4):

$$\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}(\mathcal{X}_{w,t}, \hat{\mathcal{Y}}_{w,t}, \mu_t, \tau)$$

- $\theta$: 모델 파라미터
- $\eta$: 테스트 시간 학습률(test-time learning rate)
- $\hat{\mathcal{Y}}_{w,t}$: 모델의 예측 레이블 (자기지도 신호로 활용)
- $\mu_t$: 현재 추세 추정값
- $\tau$: 이상 분류를 위한 결정 임계값

오토인코더 기반 손실 함수 (Eq. 4, p.4):

$$\mathcal{L}(\mathcal{X}_{w,t}, \hat{\mathcal{Y}}_{w,t}, \mu_t, \tau) = (1 - \hat{\mathcal{Y}}_{w,t}^\top)(\hat{\mathcal{X}}_{w,t} - \mathcal{X}_{w,t})^2$$

- $\hat{\mathcal{X}}_{w,t}$: 모델의 재구성(reconstruction) 출력
- $\hat{\mathcal{Y}}_{w,t}$: 예측 레이블 (0=정상, 1=이상)
- $(1 - \hat{\mathcal{Y}}_{w,t}^\top)$: **정상으로 예측된 샘플만 선택**하는 마스크 역할

이 설계의 핵심: **모델이 정상으로 예측한 샘플만 파라미터 업데이트에 사용**하여, 이상 샘플이 모델을 손상시키는 것을 방지.

> 💡 **자기지도 학습(Self-supervised Learning):** 레이블 없이 모델 자신의 예측을 지도 신호로 활용하는 학습 방식. 본 논문에서는 테스트 시간에 모델의 예측을 정상/이상 필터링에 활용.

> 💡 **온라인 경사 하강법(Online Gradient Descent):** 데이터를 순차적으로 처리하며 매 스텝마다 모델 파라미터를 갱신하는 최적화 방법. 실시간 스트림 처리에 적합.

---

#### 모델 구조

```
입력 시퀀스 X_{w,t}
    ↓
[추세 추정 모듈]
  μ_t ← γμ_{t-w} + (1-γ)μ̂  (EMA 업데이트)
    ↓
디트렌드 입력: X_{w,t} - μ_t
    ↓
[오토인코더 f_θ]  (MLP/LSTM 등 임의 기저 모델)
    ↓
재구성 출력 + μ_t → X̂_{w,t}
    ↓
[이상 점수 계산] A(X_{w,t})
    ↓
[정상/이상 판단] Ŷ_{w,t} = A(X_{w,t}) > τ
    ↓
[파라미터 업데이트] 정상 예측 샘플로만 θ 업데이트
    ↓
출력: 이상 점수 A(X_{w,t})
```

(Fig. 3 기반, p.4)

> 💡 **오토인코더(Autoencoder):** 입력을 압축(인코딩)했다가 원래대로 복원(디코딩)하는 신경망. 정상 데이터로만 훈련 시, 이상 데이터는 복원 오차가 크게 나타남을 이용해 이상 탐지에 활용.

## 4. 저자 직접 보고 vs. 해석 분리

### 4-1. 저자가 직접 보고한 결과

**연구 주제:**
- 비지도 시계열 이상 탐지에서의 분포 변화 문제(new normal problem) 정의 및 해결

**방법:**
- 추세 추정: $\mu_t \leftarrow \gamma\mu_{t-w} + (1-\gamma)\hat{\mu}$ (Eq. 2)
- 파라미터 업데이트: $\theta \leftarrow \theta - \eta\nabla_\theta\mathcal{L}(\mathcal{X}\_{w,t}, \hat{\mathcal{Y}}_{w,t}, \mu_t, \tau)$ (Eq. 3)
- 손실 함수: $\mathcal{L} = (1-\hat{\mathcal{Y}}\_{w,t}^\top)(\hat{\mathcal{X}}\_{w,t} - \mathcal{X}_{w,t})^2$ (Eq. 4)

**직접 보고 결과 (Table 1, p.5):**
- WADI AUROC: MLP 0.485 → Ours 0.624 (+13%)
- MSL(P-15) AUPRC: MLP 0.061 → Ours 0.575 (+51%)
- Yahoo(A1-R20) F1: MLP 0.067 → Ours 0.678
- AnoShift FAR AUROC: MLP 0.208 → MLP+Ours 0.424 (+0.216)
- 5회 독립 실험 평균값 보고, 신뢰구간은 Table 13(p.16)에 제시

### 4-2. 검토자(내) 해석

- **긍정적 측면:** EMA + 선택적 파라미터 업데이트의 조합은 구현이 단순하면서도 실용적이며, 기존 모델에 비침습적으로 적용 가능하다는 점에서 실용 가치가 높음.
- **한계 해석:** 결과의 상당 부분이 MLP 단일 기저 모델에 의존하며, 더 복잡한 기저 모델(e.g., Transformer 계열)과의 결합 효과는 충분히 검증되지 않음.
- **임계값 공정성 문제:** 기존 베이스라인들은 테스트 데이터 기반 최적 임계값( $Q^\*$ )을 사용하는 반면, 제안 방법은 훈련 데이터 기반 임계값을 사용하여 비교가 다소 제안 방법에 유리할 수 있음.
- **데이터셋 편향:** 분포 변화가 심한 데이터셋을 의도적으로 선택한 점은 방법론의 강점을 부각하지만, 일반화 가능성에 대한 추가 검증이 필요.

| ⚠️ **Yahoo(A1-R20) 높은 표준편차** | F1: $0.678 \pm 0.170$, AUPRC: $0.637 \pm 0.153$ — 결과 분산이 매우 큼 | Table 13, p.16 |
| ⚠️ **SMD(M-2-1) F1 표준편차** | $0.249 \pm 0.137$ — 결과 불안정 | Table 13, p.16 |
| ⚠️ **AnoShift 비교 불공정** | 일부 베이스라인(†)은 원 논문에서 보고된 값, MLP는 재구현 값으로 실험 조건 다를 수 있음 | Table 2, p.6 |
| ⚠️ **F1-PA 지표 과대평가** | F1-PA는 이상 구간 내 임의 시점만 탐지해도 전체 구간 탐지로 간주 → 분류기 성능 과대 추정 | p.5 (Kim et al. 2022a 인용) |
| ⚠️ **MSL(P-15) AUPRC 높은 분산** | $0.575 \pm 0.094$ — 안정성 검토 필요 | Table 13, p.16 |
| ⚠️ **WADI F1 성능 저하** | 제안 방법이 USAD(0.260), LSTM(0.245) 대비 낮은 F1(0.148) — 임계값 설정 특수성으로 설명하나 불완전한 해명 | Table 1, p.5 |
| ⚠️ **데이터셋 선택 편향** | 분포 변화가 심한 서브셋만 선택 (SMD 28개 중 2개, SMAP 28개 중 1개 등) | p.4 (Experiment Setup) |

> 💡 **F1-PA (Point Adjust F1):** 이상 구간(anomaly segment) 내 하나의 시점이라도 탐지되면 전체 구간을 탐지한 것으로 간주하는 완화된 평가 지표. 실제 성능보다 높게 보고될 수 있음.

## 7. 가장 중요한 그림 5개 해석

### Figure 1 (p.2) — 연구 동기
**(a) SWaT T-SNE 시각화:**
- 빨간 점(훈련 정상), 파란 점(테스트 정상), X(테스트 이상)가 서로 다른 공간에 위치함
- → 훈련과 테스트 정상 분포가 명확히 분리됨을 시각적으로 증명
- 이것이 "새로운 정상 문제"의 핵심 근거

**(b) 성능 개요:**
- MLP+Ours가 F1 기준으로 THOC, USAD, MLP 등 모든 기존 모델을 능가
- 단순한 기저 모델(MLP)에 제안 방법 적용만으로도 최첨단 모델 초과 달성

**(c) 재구성 결과(SWaT AIT201):**
- 시간이 지남에 따라 MLP 단독(파란선)의 재구성 오차가 급증하는 반면, MLP+Ours(붉은선)는 새로운 추세에 적응
- "세상은 변하는데 모델은 과거에 머물러 있다"는 문제를 직관적으로 보여줌

> 💡 **T-SNE (t-distributed Stochastic Neighbor Embedding):** 고차원 데이터를 2차원으로 시각화하는 기법. 유사한 데이터는 가깝게, 다른 데이터는 멀게 배치.

---

### Figure 2 (p.3) — 두 구성 요소의 필요성
**(a) NeurIPS-TS-UNI (추세 추정 필요성):**
- 추세 변화 전후로 동일한 진폭의 동역학을 유지하나 평균값이 급변
- 추세 적응 없이는 변화 이후 정상 데이터가 이상으로 분류됨
- → 추세 추정 모듈의 필요성 입증

**(b) Yahoo-A1-R20 (모델 업데이트 필요성):**
- 훈련(보라색 음영)과 테스트(노란색 음영)의 표준편차 자체가 달라짐
- 추세 추정으로는 분산 변화(dynamics shift) 포착 불가
- → 파라미터 업데이트 필요성 입증

---

### Figure 4 (p.4) — KL 발산을 통한 분포 변화 정량화

$$D_{KL}(\mathcal{D}_{test} \| \mathcal{D}_{train})$$

- SWaT, WADI, SMD 등이 매우 높은 KLD 값($10^3$ 이상)을 보임
- CreditCard는 매우 낮은 KLD → 제안 방법의 제한적 효과와 일치
- 실험 데이터셋 선택의 합리적 근거를 정량적으로 제시

> 💡 **KL 발산(Kullback-Leibler Divergence):** 두 확률 분포 간의 차이를 측정하는 지표. $D_{KL}(P\|Q)$가 클수록 $P$와 $Q$가 더 다름을 의미.

---

### Figure 8 (p.7) — Ablation Study (MSL P-15)
**(a) 재구성 결과 비교:**
- 파란선(MLP 단독): 추세 변화 후에도 높은 재구성 오차 지속 → 허위 양성 다수 발생
- 초록선(DT 단독): 추세 적응은 되나 이상 민감도 부족
- 노란선(TTA 단독): 추세 추정 없이 업데이트 시 오히려 추세 변화 전 데이터에 과적합
- 빨간선(DT+TTA=Ours): 가장 안정적이고 낮은 재구성 오차 유지

**(b) ROC 곡선:**
- Ours(빨간선)가 가장 넓은 곡선하 면적 달성
- 두 구성요소의 상호보완적 효과를 명확히 시각화

---

### Figure 10 (p.17) — 이상 점수 시각화 (SWaT)
- **MLP, LSTM, USAD, THOC:** 테스트 후반부로 갈수록 이상 점수(anomaly score)가 점진적으로 증가 → 새로운 정상에 적응하지 못함을 직접 증명
- **Anomaly Transformer:** 이상 점수가 전체 구간에 걸쳐 과도하게 높아 실제 이상 구간 식별 어려움
- **MLP+Ours:** 이상 점수가 안정적으로 유지되며, 실제 이상 구간(빨간 음영)에서만 임계값을 초과
- → 제안 방법이 분포 변화에 실제로 적응함을 시각적으로 가장 직접적으로 보여주는 그림

## 8. 결론, 시사점 및 후속 연구

### 8-1. 저자 제시 시사점 및 후속 연구 계획 (p.7)

**저자 제시 시사점:**
1. 비지도 시계열 이상 탐지에서 분포 변화 문제가 심각하며 광범위함
2. 추세 추정 + 자기지도 모델 업데이트라는 간단한 조합이 효과적
3. 실시간 모니터링에서 과거 데이터 없이도 적응 가능한 프레임워크 제시

**저자 제안 후속 연구:**
- 능동 학습(active learning)을 통한 일부 테스트 데이터 레이블 획득으로 적응 성능 강화
- 허위 양성 감소와 진양성 유지 간의 트레이드오프 균형 전략 연구

---

### 8-1. 모델의 일반화 성능 향상 가능성

**현재 일반화 한계:**
- 주로 MLP 오토인코더에서 검증되어, 다른 아키텍처로의 범용성 미검증
- 분포 변화가 뚜렷한 데이터셋에서만 효과적 (CreditCard 등 저변화 데이터셋에서는 한계)
- 하이퍼파라미터($\gamma$, $\eta$)가 데이터셋마다 크게 다름 → 자동 설정 메커니즘 필요

**일반화 향상 방향:**

1. **메타 학습(Meta-learning) 통합:** 적응 속도 파라미터를 데이터 특성에서 자동 학습하는 방향으로 발전 가능. 예를 들어 MAML(Model-Agnostic Meta-Learning) 기반 초기화를 통해 빠른 적응 지원.

2. **다양한 기저 모델과의 결합:** Transformer 계열(Anomaly Transformer), GNN, Flow 기반 모델 등과의 통합 검증 필요.

3. **적응적 임계값 조정:** 분포 변화에 따라 임계값 $\tau$도 동적으로 조정하는 메커니즘 추가:

$$\tau_t \leftarrow \alpha \tau_{t-1} + (1-\alpha) \cdot \text{percentile}(A(\mathcal{X}_{w,t}), p)$$

4. **다중 스케일 추세 추정:** 단일 EMA 대신 단기/장기 추세를 동시에 추정하는 다중 스케일 접근법.

5. **도메인 지식 통합:** 특정 산업 도메인(수처리, 항공우주 등)의 사전 지식을 추세 추정에 반영하여 일반화 성능 강화.

---

### 8-2. 2020년 이후 관련 최신 연구 비교 분석

아래 분석은 논문 내 인용 문헌 및 본 논문의 맥락을 기반으로 하며, 논문 외부 정보에 대해서는 불확실한 부분을 명시합니다.

| 연구 | 방법 | 분포 변화 대응 | 비교 분석 |
|------|------|--------------|-----------|
| **본 논문 (2024)** | EMA + 자기지도 TTA | ✅ 명시적 대응 | 기준점 |
| **Anomaly Transformer (Xu et al., 2022, ICLR)** | Association Discrepancy 기반 Transformer | ❌ 미대응 | F1-PA는 높으나 정밀 탐지(F1, AUROC) 낮음; 분포 변화에 취약 |
| **USAD (Audibert et al., 2020, KDD)** | Dual autoencoder + adversarial training | ❌ 미대응 | 정적 분포 가정; 본 논문의 기저 모델로도 활용 가능 |
| **AnoShift (Dragoi et al., 2022, NeurIPS)** | 분포 변화 벤치마크 제시 | N/A (평가 프레임워크) | 본 논문의 FAR split에서 AUROC +0.216 달성 |
| **FITNESS (Sankararaman et al., 2022, ICML)** | 동적 윈도우 기반 적응 | ✅ 부분 대응 | 과거 시퀀스 접근 필요 vs. 본 논문은 과거 데이터 불필요 |
| **Online RNN-AD (Saurav et al., 2018)** | RNN + 모든 스트림으로 역전파 | ✅ 부분 대응 | 이상 샘플 필터링 없음 vs. 본 논문은 정상 예측 샘플만 업데이트 |
| **TENT (Wang et al., 2021, ICLR)** | 엔트로피 최소화 기반 TTA | ✅ 비지도 TTA | 컴퓨터 비전 대상; 이상 샘플 포함 시 성능 저하 우려 |
| **Continual TTA (Wang et al., 2022, CVPR)** | 지속적 도메인 적응 | ✅ 연속 적응 | 컴퓨터 비전 대상; 시계열 이상 탐지 특성 미반영 |

**본 논문이 앞으로의 연구에 미치는 영향:**

1. **새로운 평가 패러다임 제시:** 정적 학습-추론 분리(train-test split) 패러다임에서, **동적 적응형 평가(online adaptive evaluation)** 로의 전환을 촉구함.

2. **플러그인 모듈 설계 원칙 확립:** 기존 모델 구조를 변경하지 않고 적용 가능한 TTA 모듈 설계 방식은 후속 연구의 참조 설계로 활용될 것.

3. **비지도 TTA의 안전성 문제 부각:** 이상 샘플이 포함된 테스트 스트림에서 안전하게 업데이트하는 문제는 향후 중요 연구 주제.

**앞으로 연구 시 고려할 점:**

1. **공정한 임계값 비교 프로토콜 수립:** 모든 방법에 동일한 임계값 설정 방식 적용 필요.

2. **이론적 수렴 보장 분석:** EMA + 선택적 업데이트의 수렴성 및 안정성에 대한 이론적 분석 부재.

3. **다중 레이블 이상 유형 고려:** 점(point), 문맥(contextual), 집단(collective) 이상 각각에 대한 차별화된 적응 전략 연구.

4. **연합 학습(Federated Learning)과의 결합:** 분산 센서 네트워크 환경에서 개인정보 보호를 고려한 분산 TTA.

5. **에너지 효율적 업데이트:** 임베디드 시스템 등 자원 제약 환경에서의 경량 TTA 구현.

6. **이상 탐지 신뢰도(calibration) 연구:** 테스트 시간 업데이트가 이상 점수의 신뢰도에 미치는 영향 분석.
